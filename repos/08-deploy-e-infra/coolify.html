O que é

O Coolify é uma plataforma para gerenciar servidores, aplicações e bancos de dados no seu próprio hardware, precisando apenas de uma conexão SSH. Pode ser uma VPS, um servidor dedicado, um Raspberry Pi ou qualquer máquina acessível por SSH.

Você ganha a comodidade de uma plataforma em nuvem (deploy por push no Git, HTTPS automático, previews de pull request) mantendo o controle da infraestrutura. As configurações ficam nos seus servidores e, se você parar de usar o Coolify, os recursos em execução continuam funcionando.

Existe também o Coolify Cloud, uma instância mantida pela equipe, paga, para quem não quer manter o painel.

Principais recursos

  • Deploy de qualquer aplicação a partir de GitHub, GitLab, Bitbucket ou Gitea, com Nixpacks, Railpack, Dockerfile, Docker Compose ou imagem Docker pronta.
  • Bancos de dados e mais de 300 serviços de um clique, com volumes persistentes e credenciais geradas.
  • Deploy a cada push, previews de pull request, webhooks de deploy e rollback.
  • Domínios próprios, certificados HTTPS automáticos, proxy reverso e health checks.
  • Gerenciamento de vários servidores, logs, terminal de container e monitoramento.
  • Backups de bancos e storage, tarefas agendadas, variáveis de ambiente, segredos e notificações.
  • Controle por dashboard, API, CLI, MCP e acesso por equipes.

Pré-requisitos

  • Um servidor Linux com acesso SSH (consulte o guia de instalação para os requisitos de versão, CPU e memória).
  • Acesso root ou equivalente para rodar o script de instalação.
  • O README recomenda um servidor para o Coolify e um ou mais servidores para os recursos implantados.

Instalação

Instalação com um comando em um servidor suportado:

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash

Você pode revisar o script antes em scripts/install.sh. Os requisitos e instruções detalhadas estão no guia de instalação.

Comandos e uso

Depois de instalado, o uso é pelo painel web:

  1. Crie a conta administradora no primeiro acesso.
  2. Adicione um servidor (o próprio localhost ou outro via SSH).
  3. Conecte um provedor Git e crie um recurso (aplicação, banco ou serviço de um clique).
  4. Configure o domínio e faça o deploy; ative o deploy automático por push, se quiser.

A automação é possível pela API, CLI e MCP, descritas na documentação.

Quando usar

  • Hospedar apps e bancos em VPS próprias sem pagar por plataformas como Vercel ou Heroku.
  • Subir serviços self-hosted populares (n8n, Chatwoot, bancos etc.) pelo catálogo de um clique.
  • Gerenciar vários servidores e projetos de uma equipe em um só painel.

Observações

  • Gratuito e open source quando auto-hospedado; o Coolify Cloud é pago.
  • O script de instalação roda como root; revise-o antes de executar em um servidor de produção.
  • Use um servidor separado para o painel e outro(s) para as cargas de trabalho, como o README recomenda.
