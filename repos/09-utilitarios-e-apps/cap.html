O que é

O Cap grava a tela com câmera e microfone e deixa você compartilhar por link ou exportar um vídeo editado. Serve para demos de produto, reportes de bug, onboarding, tutoriais, revisões de design e atualizações assíncronas, sempre que mostrar é mais rápido que marcar uma reunião.

Tem app nativo para macOS, Windows e Linux, e um painel web para ver, compartilhar e gerenciar as gravações. Você escolhe onde ficam os vídeos: Cap Cloud, seu próprio bucket S3, só local, ou a plataforma inteira self-hosted.

Principais recursos

  • Instant Mode: envia enquanto grava e dá o link assim que você para.
  • Studio Mode: grava localmente e abre o editor com fundos, zooms, cortes, legendas e exportação.
  • Comentários, reações, transcrições, analytics de visualização e workspaces de time.
  • Cap AI: títulos, resumos, capítulos clicáveis, legendas e transcrições automáticos.
  • Compartilhamento público ou privado, com senha e domínio próprio.
  • Armazenamento em AWS S3, Cloudflare R2, Backblaze B2, MinIO, Wasabi ou outro compatível com S3.
  • Importação de vídeos do Loom.

Pré-requisitos

  • macOS, Windows ou Linux para o app.
  • Self-hosting: Docker (ou Railway, Coolify).
  • Desenvolvimento: Node.js 24+, Bun 1.4.4, Rust (rustup) e Docker.

Instalação

App

  1. Baixe em cap.so/download.
  2. Entre ou crie uma conta.
  3. Escolha Instant Mode ou Studio Mode e grave.

Self-hosting (Docker Compose)

git clone https://github.com/CapSoftware/Cap.git
cd Cap
docker compose up -d

Disponível em http://localhost:3000. Sem e-mail configurado, os links de login aparecem nos logs:

docker compose logs cap-web

Em produção, defina as URLs públicas e troque os segredos padrão antes de expor na internet:

CAP_URL=https://cap.yourdomain.com
S3_PUBLIC_URL=https://s3.yourdomain.com

No app desktop, aponte para sua instância em Settings > Cap Server URL. Também há deploy com Railway e Coolify (docker-compose.coolify.yml).

Comandos e uso

Desenvolvimento local:

bun install
bun run env-setup
bun run cap-setup
bun run dev            # stack completa
bun run dev:web        # só a web
bun run dev:desktop    # app desktop

Quando usar

  • Gravar demos e tutoriais com edição rápida, sem pagar Loom.
  • Reportar bugs com vídeo e link instantâneo.
  • Manter gravações sensíveis no próprio servidor ou bucket.

Observações

  • Licença AGPL-3.0 para a maior parte do código; oferecer versão modificada como serviço exige publicar as modificações.
  • Gravações com áudio ou rosto de terceiros envolvem dados pessoais; atenção à LGPD ao compartilhar.
  • Guia completo de self-hosting (e-mail, IA, SSL, armazenamento, hardening): cap.so/docs/self-hosting.
