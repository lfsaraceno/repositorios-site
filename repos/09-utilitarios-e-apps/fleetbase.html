O que é

O Fleetbase é um sistema operacional de logística (LSOS) modular. Reúne despacho, gestão de frota, rastreamento ao vivo, comércio, armazenagem e finanças em uma plataforma, com API REST, webhooks e um sistema de extensões. Você pode rodá-lo na própria infraestrutura ou usar o Fleetbase Cloud.

Atende operações de transporte rodoviário, courier, entrega de comida, e-commerce, saúde, coleta de resíduos e outras. Como cada fluxo, campo e status é configurável, a mesma base se adapta a operações bem diferentes.

Principais recursos

  • Fleet-Ops: pedidos, motoristas, veículos, rastreamento ao vivo, otimização de rotas, fluxos configuráveis e manutenção.
  • Storefront: comércio headless para negócios on-demand e marketplaces multi-lojista.
  • Pallet: gestão de armazém (inventário, picking, contagem cíclica). O README o lista como em desenvolvimento.
  • Ledger: faturas, pagamentos, carteiras e contabilidade para operadores logísticos.
  • Customer Portal: área de autoatendimento para clientes pedirem, acompanharem e pagarem.
  • API REST, webhooks, chaves de API e marketplace de extensões.
  • CLI própria (@fleetbase/cli) para instalar e gerenciar extensões.

Pré-requisitos

(Conforme o Quickstart do README.)

  • Docker com Docker Compose v2.
  • Git.
  • Node.js 18 ou superior.
  • Pelo menos 4 GB de RAM alocados ao Docker.

Instalação

Instalação local self-hosted com a CLI interativa:

npm install -g @fleetbase/cli
flb install-fleetbase

Ao terminar, abra o console em http://localhost:4200 e crie a primeira conta de administrador e a organização. A API fica em http://localhost:8000.

O guia Running locally também cobre a instalação com Docker Compose ou script, a configuração de e-mail, mapas e SMS, e a resolução de problemas. Para produção em nuvem (AWS, GCP, Azure etc.), veja Deploy in your cloud. Para desenvolver o próprio Fleetbase, use o guia de desenvolvimento.

Comandos e uso

flb install-fleetbase   # instala o Fleetbase de forma interativa

A CLI também instala e publica extensões; veja a documentação da CLI. No console, o fluxo típico é cadastrar motoristas e veículos, criar pedidos, despachar e acompanhar o rastreamento. A integração por código usa a API.

Quando usar

  • Operar entregas, frota e rotas com um sistema próprio no lugar de um TMS legado.
  • Construir um produto de logística personalizado sobre a API e as extensões.
  • Ter soberania de dados com auto-hospedagem (por exemplo, em órgãos públicos).

Observações

  • A licença é AGPL-3.0: se você modificar e oferecer o sistema como serviço em rede, precisa disponibilizar o código das modificações.
  • Há também a opção paga Fleetbase Cloud, sem instalação.
  • Alguns módulos citados no README (como o Pallet) aparecem no roadmap como em desenvolvimento.
  • Para recursos como mapas, e-mail e SMS é preciso configurar serviços externos.
