O que é

O Fleetbase é um sistema operacional de logística (LSOS) modular. Reúne despacho, gestão de frota, rastreamento ao vivo, comércio, armazenagem e finanças em uma plataforma, com API REST, webhooks e um sistema de extensões. Você pode rodá-lo na própria infraestrutura ou usar o Fleetbase Cloud.

Atende operações de courier, e-commerce, saúde e farmácia, coleta de resíduos, contêineres, governo e outras. Como cada fluxo, campo e status é configurável, a mesma base se adapta a operações bem diferentes.

Principais recursos

  • Fleet-Ops: pedidos, motoristas, veículos, rastreamento ao vivo, otimização de rotas, fluxos configuráveis e manutenção.
  • Storefront: comércio headless para negócios on-demand e marketplaces multi-lojista.
  • Pallet: gestão de armazém (inventário, picking, contagem cíclica e fulfilment). Ainda em desenvolvimento no roadmap.
  • Ledger: faturas, pagamentos, carteiras e contabilidade para operadores logísticos.
  • Customer Portal: área de autoatendimento para clientes pedirem, acompanharem, receberem orçamentos, pagarem, verem faturas e abrirem chamados.
  • AI: criação de pedidos em linguagem natural, consultas sobre a operação e análise de pedidos, com OpenAI ou Claude.
  • Developer console: chaves de API, webhooks, eventos de socket e do sistema e logs de requisições, com ambientes de teste e produção separados.
  • Apps abertos para iOS e Android: Navigator (motorista, com navegação e comprovante de entrega), Storefront (loja ou marketplace) e Passenger (transporte de passageiros, tipo app de corrida).
  • API REST, WebSockets, webhooks e marketplace de extensões (gratuitas e pagas).
  • CLI própria (@fleetbase/cli) para instalar e gerenciar extensões.

Pré-requisitos

(Conforme o Quickstart do README.)

  • Docker com Docker Compose v2.
  • Git.
  • Node.js 18 ou superior.
  • Pelo menos 4 GB de RAM alocados ao Docker.

Instalação

Instalação local self-hosted com a CLI interativa:

npm install -g @fleetbase/cli
flb install-fleetbase

Ao terminar, abra o console em http://localhost:4200 e crie a primeira conta de administrador e a organização. A API fica em http://localhost:8000.

O guia Running locally também cobre a instalação com Docker Compose ou script, a configuração de e-mail, mapas e SMS, e a resolução de problemas. Para produção em nuvem (AWS, GCP, Azure etc.), veja Deploy in your cloud.

Cada release publica imagens Docker e também binários standalone da API (build estático com FrankenPHP, sem precisar de PHP nem Composer). Os binários ainda exigem MySQL e Redis, e o console roda à parte. Para produção, o recomendado continua sendo Docker. Para desenvolver o próprio Fleetbase, use o guia de desenvolvimento.

Comandos e uso

flb install-fleetbase   # instala o Fleetbase de forma interativa

A CLI também instala e publica extensões; veja a documentação da CLI. No console, o fluxo típico é cadastrar motoristas e veículos, criar pedidos, despachar e acompanhar o rastreamento. A integração por código usa a API.

Quando usar

  • Operar entregas, frota e rotas com um sistema próprio no lugar de um TMS legado.
  • Construir um produto de logística personalizado sobre a API e as extensões.
  • Ter soberania de dados com auto-hospedagem (por exemplo, em órgãos públicos).
  • Lançar app próprio de delivery, loja ou corrida com os apps abertos do Fleetbase.

Observações

  • A licença é AGPL-3.0: se você modificar e oferecer o sistema como serviço em rede, precisa disponibilizar o código das modificações.
  • Há também a opção paga Fleetbase Cloud, sem instalação.
  • Em desenvolvimento no roadmap (previsão nov/2026): Pallet, Navigator v3 (visão do dia, inspeção de veículo, fila offline) e Registry v2 de extensões. Dynamic Rules está planejado para 2027.
  • O Fleetbase AppHelm (serviço da Fleetbase) publica os apps Storefront e Passenger com a sua marca na App Store e no Google Play, sem programar.
  • O módulo de IA usa OpenAI ou Claude, então exige chave e custo de API do provedor.
  • Para recursos como mapas, e-mail e SMS é preciso configurar serviços externos.
