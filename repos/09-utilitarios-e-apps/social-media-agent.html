Social Media Agent

Agente da LangChain (LangGraph + Claude) que recebe um link, lê o conteúdo e escreve posts para X/Twitter e LinkedIn, com aprovação humana antes de publicar e agendamento. Pode puxar links de um canal do Slack todo dia.

O que é

Um agente feito com LangGraph que a própria LangChain usa para divulgar conteúdo. Você manda uma URL (post de blog, repositório do GitHub, tweet, vídeo do YouTube). O agente lê o conteúdo, confere se é relevante para o seu negócio, escreve um relatório de marketing e gera o post.

O fluxo é human-in-the-loop: antes de publicar, o post para numa caixa de entrada (o Agent Inbox), onde você aceita, edita, rejeita ou responde. Depois de aprovado, o post é agendado e publicado no X e no LinkedIn (pessoal ou página de empresa).

Na configuração completa, um cron lê os links enviados num canal do Slack e gera os posts uma vez por dia. Na LangChain, a equipe joga links num canal e o agente cuida do resto.

Principais recursos

  • Gera posts para X/Twitter e LinkedIn a partir de uma URL.
  • Lê vários tipos de fonte: páginas web (FireCrawl), GitHub, tweets e vídeos do YouTube (Vertex AI) na configuração completa.
  • Aprovação humana pelo Agent Inbox (versão hospedada ou local).
  • Agendamento e publicação, inclusive como página de empresa no LinkedIn.
  • Imagens: escolhe e envia imagens para os posts (guardadas no Supabase).
  • Slack: ingestão diária de links por cron e mensagens de atualização num canal.
  • Estilo configurável por prompts: contexto do negócio, exemplos de posts, estrutura e regras de conteúdo.

Pré-requisitos

  • Node com yarn, e Python com pip (para o langgraph-cli).
  • Configuração básica: chaves da Anthropic, LangSmith (gratuita), FireCrawl (500 créditos grátis para novos usuários) e Arcade (autenticação nas redes).
  • Configuração completa: além dessas, Google Vertex AI, contas de desenvolvedor do X e do LinkedIn, token do GitHub, Supabase e, opcionalmente, Slack.

Instalação

git clone https://github.com/langchain-ai/social-media-agent.git
cd social-media-agent
yarn install
cp .env.quickstart.example .env        # configuração completa: .env.full.example
pip install langgraph-cli

No .env básico:

LANGSMITH_API_KEY=
ANTHROPIC_API_KEY=
FIRECRAWL_API_KEY=
ARCADE_API_KEY=
# para postar como empresa no LinkedIn:
POST_TO_LINKEDIN_ORGANIZATION=true
LINKEDIN_ORGANIZATION_ID=

A autenticação nas redes é feita pelo Arcade (mais rápido) ou por apps próprios no X e no LinkedIn, nunca os dois. Os apps próprios usam yarn start:auth (servidor OAuth em http://localhost:3000) para obter os tokens. Para enviar mídia ao X, precisa do app próprio mesmo usando o Arcade.

Comandos e uso

yarn langgraph:in_mem:up     # sobe o servidor LangGraph local (porta 54367)
yarn generate_post           # gera um post a partir da URL definida no script
yarn start:auth              # servidor OAuth para obter tokens do X e do LinkedIn
yarn cron:create             # cria o cron que lê links do Slack uma vez por dia

Para revisar os posts, adicione o grafo no Agent Inbox com:

Graph ID: generate_post
Graph API URL: http://localhost:54367

Para usar com o seu negócio, edite os prompts em src/agents/generate-post/prompts/: BUSINESS_CONTEXT, TWEET_EXAMPLES, POST_STRUCTURE_INSTRUCTIONS e POST_CONTENT_RULES.

Quando usar

  • Divulgar posts de blog, lançamentos e vídeos da empresa no X e no LinkedIn com um fluxo de aprovação.
  • Equipes que juntam links interessantes num canal do Slack e querem transformar isso em posts diários.
  • Base para montar um agente próprio de social media com LangGraph.

Observações

  • Vem configurado para a LangChain: os prompts e os exemplos de posts falam de produtos da LangChain e de conteúdo de IA. Troque BUSINESS_CONTEXT e TWEET_EXAMPLES antes de usar; senão os posts saem fora do seu contexto.
  • Muitas contas e chaves: a configuração completa envolve cerca de dez serviços. Comece pela básica (sem GitHub, YouTube, Slack e imagens).
  • Só X e LinkedIn. Instagram, TikTok e outras redes não estão no README.
  • Postar como empresa no LinkedIn exige o produto Advertising API, verificação do app pela página e um papel de administrador ou de postagem.
  • O bucket images do Supabase precisa ser público.
  • Gera tudo em inglês por padrão; para posts em português, ajuste os prompts e os exemplos.
  • Relacionados no catálogo: as Social Media Research Skills pesquisam o que funciona nas redes. As Marketing Skills têm a skill social para escrever posts dentro do Claude Code.
