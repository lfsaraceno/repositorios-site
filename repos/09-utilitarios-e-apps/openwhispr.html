OpenWhispr

App de ditado por voz open-source e gratuito, alternativa ao Wispr Flow e ao Granola: aperte um atalho, fale e o texto aparece no cursor; também transcreve reuniões, faz notas e conversa com agentes de IA, com modelos locais ou na nuvem.

O que é

O OpenWhispr transforma sua voz em texto, notas e ações no desktop. Você aperta uma tecla de atalho, fala, e as palavras são coladas onde está o cursor, em qualquer app. Pode usar transcrição totalmente offline com modelos locais (Whisper, NVIDIA Parakeet, Cohere Transcribe e outros), sem o áudio sair do computador, ou provedores na nuvem para mais velocidade. Sem coleta de dados nem telemetria.

Além do ditado, detecta chamadas do Zoom, Teams e FaceTime e transcreve reuniões com identificação de quem fala, organiza notas com busca semântica e tem um assistente de voz que manda comandos para GPT-5, Claude, Gemini ou modelos locais.

Principais recursos

  • Ditado com atalho global e colagem automática em qualquer app.
  • Ditado com tradução: fala num idioma e cola em outro.
  • Assistente de voz com atalho próprio: o que você fala vira comando para a IA; texto selecionado é editado no lugar; opcionalmente envia captura de tela como contexto.
  • Transcrição de reuniões com diarização local, impressão digital de voz e integração com Google, Microsoft ou Apple Calendar.
  • Notas com pastas, busca semântica, sincronização e ações de IA; espaços de time e compartilhamento.
  • Importação de áudio e vídeo, inclusive link do YouTube.
  • Whisper local com aceleração por GPU (Metal, CUDA e Vulkan).
  • API pública e servidor MCP para conectar o Claude e outros assistentes.
  • Controles corporativos: SSO, SCIM, Amazon Bedrock ou Azure OpenAI gerenciados.

Pré-requisitos

  • macOS (Apple Silicon ou Intel), Windows ou Linux.
  • Para rodar do código: Node.js 24+.

Instalação

Baixe em Releases:

  • Windows: .exe
  • macOS: .dmg (Apple Silicon e Intel)
  • Linux: .AppImage, .deb, .rpm ou .tar.gz

No macOS ou Linux x86_64, também via Homebrew (cask mantido pela comunidade):

brew install --cask openwhispr

Do código-fonte:

git clone https://github.com/OpenWhispr/openwhispr.git
cd openwhispr
npm install
npm run dev

Comandos e uso

  1. Instale, escolha modelo local ou provedor na nuvem (com sua chave).
  2. Configure os atalhos de ditado, tradução e assistente.
  3. Em qualquer app, aperte o atalho e fale; o texto é colado no cursor.
  4. Para conectar ao Claude, configure o servidor MCP.

Quando usar

  • Escrever e-mails, mensagens e prompts falando, inclusive para o Claude Code.
  • Transcrever reuniões sem mandar áudio para servidores de terceiros.
  • Substituir Wispr Flow ou Granola sem assinatura.

Observações

  • Em Macs Intel, a identificação de falantes ao vivo e a impressão digital de voz não funcionam (o ONNX Runtime deixou de distribuir binários x86_64 para macOS); a transcrição funciona normalmente.
  • Ao usar provedores na nuvem, o áudio sai do computador; para dados sensíveis, use modelos locais.
  • Gravar reuniões exige consentimento dos participantes.
  • Relacionados no catálogo: Whisper (modelo de transcrição) e VoiceStudio.
