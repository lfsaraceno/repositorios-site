Local Deep Research

Assistente de pesquisa profunda com IA que roda local: pesquisa na web, em bases acadêmicas (arXiv, PubMed) e nos seus documentos e entrega relatórios com citações. Funciona com modelos locais (Ollama, LM Studio, llama.cpp) ou na nuvem, guarda tudo criptografado e tem servidor MCP para o Claude.

O que é

O Local Deep Research (LDR) é uma alternativa aberta ao "Deep Research" do ChatGPT e do Gemini. Você faz uma pergunta complexa, e ele pesquisa sozinho em vários buscadores, lê as fontes e escreve um relatório com citações.

A estratégia principal (langgraph-agent) deixa o modelo decidir o que buscar, em quais motores especializados e quando sintetizar. Com ela, o projeto relata cerca de 95% no benchmark SimpleQA usando o Qwen3.6-27B numa única RTX 3090, tudo local.

As fontes encontradas podem ser baixadas para uma biblioteca própria e criptografada. O LDR extrai o texto, indexa, e nas próximas pesquisas busca nos seus documentos e na web ao mesmo tempo.

Principais recursos

  • Modos de pesquisa: resumo rápido (30 s a 3 min), pesquisa detalhada, relatório com seções e sumário, e análise de documentos.
  • Modo chat: conversa com pesquisa em várias rodadas, acumulando contexto.
  • Buscadores gratuitos: arXiv, PubMed, Semantic Scholar, Wikipedia, SearXNG, GitHub, Elasticsearch, Wayback Machine, The Guardian e Wikinews.
  • Buscadores pagos: Tavily, Google (SerpAPI ou Programmable Search) e Brave Search.
  • Seus documentos: arquivos locais, Paperless-ngx, Elasticsearch e qualquer retriever do LangChain (FAISS, Chroma, Pinecone, Weaviate).
  • Qualidade de periódicos: pontua a reputação de mais de 212 mil fontes acadêmicas e detecta periódicos predatórios.
  • Assinaturas: resumos automáticos diários ou semanais sobre temas que você acompanha.
  • Privacidade: banco SQLCipher (AES-256) separado por usuário, com chave derivada da senha. Sem telemetria.
  • Controle de saída (egress): modos Public only, Private only (só fontes locais e modelo local), Strict e Adaptive.
  • Integrações: API Python, API HTTP, servidor MCP, painel de custos e métricas, exportação em PDF e Markdown.

Pré-requisitos

  • Docker (recomendado) ou Python com pip.
  • Um modelo: Ollama, LM Studio, llama.cpp ou qualquer endpoint compatível com OpenAI; ou modelos na nuvem (OpenAI, Claude, Gemini, OpenRouter).
  • SearXNG para busca na web (opcional, mas recomendado).
  • CPU com AVX (Intel Sandy Bridge / AMD Bulldozer ou mais novo).
  • GPU NVIDIA opcional, para rodar o modelo local mais rápido.

Instalação

Docker Compose (todas as plataformas, incluindo Windows)

curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.yml && docker compose up -d

Com GPU NVIDIA (Linux):

curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.yml && \
curl -O https://raw.githubusercontent.com/LearningCircuit/local-deep-research/main/docker-compose.gpu.override.yml && \
docker compose -f docker-compose.yml -f docker-compose.gpu.override.yml up -d

Abra http://localhost:5000 depois de uns 30 segundos.

Docker run (Linux)

O README mostra três contêineres (Ollama, SearXNG e LDR) com --network host. No Windows/Mac com Docker Desktop, isso só funciona com Enable host networking ligado (versão 4.34+); senão, use o Compose acima.

pip

pip install local-deep-research
python -m local_deep_research.web.app     # interface em http://localhost:5000

Precisa do Ollama (ou outro endpoint) e do SearXNG rodando à parte. No Windows, exportar PDF exige o Pango instalado.

Comandos e uso

API Python:

from local_deep_research.api import quick_query
summary = quick_query("username", "password", "What is quantum computing?")

Servidor MCP para o Claude Code (em .mcp.json do projeto):

pip install "local-deep-research[mcp]"

{
  "mcpServers": {
    "local-deep-research": {
      "command": "ldr-mcp",
      "env": {
        "LDR_LLM_PROVIDER": "ollama",
        "LDR_LLM_OLLAMA_URL": "http://localhost:11434"
      }
    }
  }
}

Ferramentas do MCP:

search                 # resultados brutos de um buscador (arxiv, pubmed, wikipedia...), sem custo de LLM
quick_research         # resumo rápido (1-5 min)
detailed_research      # análise completa (5-15 min)
generate_report        # relatório em Markdown (10-30 min)
analyze_documents      # busca nas suas coleções locais

Quando usar

  • Pesquisas com fontes citadas sem mandar suas perguntas para um serviço de terceiros.
  • Pesquisa acadêmica e técnica (artigos, PubMed, arXiv).
  • Montar uma base de conhecimento própria que cresce a cada pesquisa.
  • Dar ao Claude Code uma ferramenta de pesquisa profunda via MCP.

Observações

  • "Local" tem limites: buscas na web saem para a internet (o SearXNG repassa as consultas aos buscadores). Um endpoint local que repassa para um modelo na nuvem não é detectado como remoto. Para ficar só no seu computador, use o modo Private only com fontes e modelo locais. Mesmo assim, o controle de saída é uma proteção de melhor esforço; para um bloqueio real, filtre no firewall.
  • MCP só local: o servidor MCP não tem autenticação. Não exponha na rede.
  • Atualização para a versão 2.0: faça backup antes. Depois de migrar, não dá para voltar direto à v1.10.7. O guia de upgrade explica.
  • Desde a 1.6.3, não há modelo padrão: escolha um em Settings → LLM.
  • Os benchmarks são da comunidade, com amostras pequenas.
  • Relacionados no catálogo: o Hermes Agent é um agente geral; o LDR é especializado em pesquisa com citações.
