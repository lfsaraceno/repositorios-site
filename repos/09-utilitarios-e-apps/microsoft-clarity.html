Microsoft Clarity

Biblioteca open source de analytics comportamental da Microsoft (a mesma que roda no Clarity hospedado): grava sessões e reproduz exatamente o que o visitante viu e fez no site, com foco em privacidade e desempenho; tem servidor MCP oficial para consultar os dados em linguagem natural.

O que é

O Clarity mostra como as pessoas usam o seu site em qualquer dispositivo e navegador: onde clicam, até onde rolam, onde travam. Ajuda a ver onde uma página ou funcionalidade falha e onde funciona, para melhorar conversão e retenção.

Este repositório é o código aberto por trás do serviço hospedado da Microsoft em clarity.microsoft.com. Para a maioria dos sites, o caminho é usar o serviço hospedado; o código serve para quem quer entender, contribuir ou montar a própria solução.

O projeto tem quatro pacotes:

  • clarity-js: o script que vai no site e registra interações e mudanças de layout.
  • clarity-decode: roda no servidor e decodifica os dados recebidos.
  • clarity-visualize: transforma os dados em replay da sessão, fiel ao pixel.
  • clarity-devtools: extensão para navegadores Chromium que faz capturas ao vivo de qualquer site.

Principais recursos

  • Gravação e replay de sessões.
  • Conteúdo sensível mascarado por padrão antes do envio, com opções extras de mascaramento.
  • Script leve, pensado para não pesar no site.
  • Servidor MCP oficial (microsoft/clarity-mcp-server) para consultar no agente:
    • métricas do painel (tráfego, navegadores, países);
    • listas de gravações filtradas (mobile, erros de JavaScript, mais cliques);
    • dados de AI Visibility: citações do seu domínio em respostas de IA, atividade de robôs de IA (exige CDN conectada) e relatórios por tema;
    • a documentação do Clarity.

Pré-requisitos

  • Para o serviço: uma conta no Clarity e acesso ao código do site para colocar o script.
  • Para o MCP: Node.js 16 ou mais novo e acesso de admin ou membro a pelo menos um projeto do Clarity.

Instalação

No site: crie o projeto em clarity.microsoft.com e cole o script que o painel gera.

Servidor MCP (Claude Code, Claude Desktop, VS Code e outros clientes MCP):

{
  "mcpServers": {
    "microsoft-clarity": {
      "command": "npx",
      "args": ["-y", "--prefer-online", "@microsoft/clarity-mcp-server@latest"]
    }
  }
}

No Claude Desktop também dá para instalar pela galeria: File → Settings → Customize → Connectors, procure Microsoft Clarity.

Comandos e uso

Com o MCP ativo, peça ao agente para entrar no Microsoft Clarity. O servidor abre a página de login no navegador e, depois, você escolhe o projeto padrão. Exemplos de perguntas (do README):

How many Clarity sessions did we get in the past 7 days?
List the most recent Clarity sessions from mobile devices.
Get Clarity recordings where users encountered JavaScript errors.
Which AI queries cite my domain most often this month?

Quando usar

  • Entender por que uma landing page não converte: onde as pessoas param de rolar e o que ignoram.
  • Achar bugs de interface vendo gravações de sessões com erro.
  • Medir se o seu site está sendo citado por buscas e assistentes de IA.
  • Deixar o agente analisar os dados do site junto com o código.

Observações

  • LGPD: gravar sessões coleta dados de comportamento. Informe na política de privacidade e no aviso de cookies, e revise o mascaramento de campos sensíveis.
  • O MCP antes usava token da Data Export API; esse modo está sendo descontinuado em favor do login OAuth.
  • Relacionados no catálogo: o Search Console MCP traz os dados do Google; o Claude SEO audita SEO.
