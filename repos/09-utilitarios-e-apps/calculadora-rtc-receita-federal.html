Calculadora de Tributos RTC (Receita Federal)

Código aberto da calculadora oficial da Reforma Tributária do Consumo (LC 214/2025), publicado pela Receita Federal com o SERPRO: APIs que calculam CBS, IBS e Imposto Seletivo no regime geral e no Simples Nacional, consultam as tabelas oficiais, geram e validam o XML da nota e um serviço que gera o DANFSe em PDF.

O que é

A Receita Federal publicou no GitHub o código da sua calculadora de tributos da reforma tributária do consumo. O mesmo motor de cálculo que roda no simulador online pode rodar na sua máquina ou no servidor da sua empresa e ser chamado pelo ERP por API.

Os documentos de governança dizem que o projeto é mantido pela Receita Federal do Brasil (RFB) e desenvolvido em parceria com o SERPRO. As mudanças são publicadas em versões, com CHANGELOG e ROADMAP.

São três repositórios:

Repositório O que faz Porta padrão
calculadora-rtc-regime-regular CBS, IBS e Imposto Seletivo no regime geral, tabelas oficiais, geração e validação do XML 8080
calculadora-rtc-simples-nacional CBS e IBS no Simples Nacional e consulta das atividades do Simples 8082
calculadora-rtc-gerador-danfse Gera o DANFSe (PDF) a partir do XML de uma NFS-e 8080

Principais recursos

  • Cálculo: POST /regime-geral falha na operação inteira no primeiro erro. A versão com observabilidade (/observabilidade/regime-geral) mostra os erros item a item, sem parar os outros.
  • Base de cálculo unificada da NF-e/NFC-e e da NFS-e.
  • XML: gera o grupo de tributação a partir do resultado do cálculo e valida grupo ou nota contra o XSD.
  • Dados abertos: CST, classificações tributárias (cClassTrib), fundamentações legais, NCM, NBS e alíquotas de referência da União, dos estados e dos municípios.
  • Simples Nacional: cálculo com observabilidade e consulta das atividades vigentes numa data.
  • DANFSe: PDF da NFS-e por POST /api/danfse, com opções de situação da nota (válida, substituída ou cancelada) e de esconder o canhoto. Não grava o XML nem o PDF nos logs.
  • Swagger com todos os endpoints e exemplos.
  • Banco SQLite embutido, aberto só para leitura.

Pré-requisitos

  • Calculadoras: Java 25 ou mais novo e Git. O Maven vem pelo wrapper (mvnw), que baixa o necessário na primeira execução.
  • DANFSe: Go 1.27 ou mais novo, ou Docker. O Task é opcional.

Instalação

Calculadora do regime geral. O banco precisa ser gerado antes; sem ele, a aplicação não inicia:

git clone https://github.com/ReceitaFederal/calculadora-rtc-regime-regular.git
cd calculadora-rtc-regime-regular
mkdir -p ./calculadora/db
./mvnw flyway:migrate -Dflyway.configFiles=./flyway/flyway-pro.conf --batch-mode --errors
./mvnw spring-boot:run -Dspring-boot.run.profiles=offline

No Windows, use mvnw.cmd e coloque o -D... entre aspas: mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=offline".

Para gerar o JAR:

./mvnw clean package
java -Dspring.profiles.active=offline -jar target/api-regime-geral.jar

O Simples Nacional segue os mesmos passos, mas usa a pasta flyway/ copiada do repositório do regime regular para gerar o banco. O JAR é target/api-simples-nacional.jar.

DANFSe:

git clone https://github.com/ReceitaFederal/calculadora-rtc-gerador-danfse.git
cd calculadora-rtc-gerador-danfse
go run ./cmd/danfse                         # ou: task run
docker build -t danfse-go . && docker run -p 8080:8080 danfse-go:latest

Comandos e uso

  • Regime geral: http://localhost:8080/api/calculadora, Swagger em http://localhost:8080/api/swagger-ui.html.
  • Simples Nacional: http://localhost:8082/api, Swagger em http://localhost:8082/api/swagger-ui.html.

Gerar o PDF de uma NFS-e:

curl -X POST "http://localhost:8080/api/danfse?canhoto=false" \
  -H "Content-Type: application/xml" \
  --data-binary @/caminho/para/documento.xml \
  -o danfse.pdf

Os exemplos de chamada da calculadora estão em docs/exemplos.md.

Quando usar

  • Calcular CBS, IBS e IS no seu ERP ou sistema de notas com o motor oficial, sem reimplementar as regras.
  • Testar a emissão de notas no novo modelo antes da transição.
  • Consultar NCM, NBS, cClassTrib e alíquotas de referência por API.
  • Gerar o DANFSe de uma NFS-e no seu próprio servidor.

Observações

  • A organização no GitHub não tem o selo de verificada. Os sinais de que é oficial são os documentos de governança (RFB e SERPRO) e os commits feitos com e-mails do domínio serpro.gov.br. Confira pelo portal oficial antes de depender dela em produção.
  • O DANFSe e o regime geral usam a mesma porta padrão (8080). Para rodar os dois juntos, mude a do DANFSe com SERVER_PORT=8081.
  • As regras da reforma ainda mudam. Acompanhe o CHANGELOG e atualize o banco de dados a cada versão nova.
  • Relacionado no catálogo: a RTC Calculadora Offline espelha, todo dia, o pacote fechado que o portal oficial distribui.
