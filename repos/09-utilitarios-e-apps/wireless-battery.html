Wireless Battery

App leve para Windows 10/11 que mostra na barra de tarefas a bateria de mouses, headsets, teclados e controles sem fio (Logitech, Razer, SteelSeries, Corsair, HyperX, PlayStation, Xbox, AirPods, Bluetooth e dezenas de marcas), sem precisar do software do fabricante.

O que é

O Wireless Battery mostra o nível de bateria dos seus periféricos sem fio direto na barra de tarefas do Windows, ao lado da área de notificação (algo como 🎧 30% 🖱 93%). Ele substitui a necessidade de abrir o G HUB, Synapse, iCUE, SteelSeries GG ou NGenuity só para ver a bateria, e não entra em conflito com eles se estiverem abertos.

É um app pequeno: cerca de 350 KB, uns 2 MB de RAM, C++/Win32 puro, sem runtime e sem serviço em segundo plano. Instala sem permissão de administrador.

Cada fabricante tem um "driver" próprio no código, que reconhece o aparelho pelo ID USB e envia só consultas de leitura de bateria. Dispositivos desconhecidos nunca recebem comandos. Para o resto, ele usa caminhos genéricos: a bateria que o Windows já conhece de aparelhos Bluetooth, o padrão HID de bateria, a API de controles do Xbox e o HeadsetControl, que vem junto.

Principais recursos

  • Muitas marcas: Logitech (Unifying, Bolt, Lightspeed), Razer, SteelSeries, Corsair, HyperX, Glorious, ASUS ROG, ZOWIE, Keychron, Jabra, JBL, Sony (DualShock 4, DualSense, INZONE), Xbox, 8BitDo, GameSir, Samsung Galaxy Buds, AirPods/Beats e várias marcas chinesas (Attack Shark, Ajazz, Redragon, MCHOSE, VXE, Pulsar e outras).
  • Celular: mostra a bateria de um Android conectado pelo Phone Link da Microsoft.
  • Na barra de tarefas: número vermelho com 15% ou menos, raio azul quando carregando, texto apagado quando o aparelho está dormindo (mostra o último valor).
  • Vários monitores: aparece na barra de cada monitor, útil com jogo em tela cheia.
  • Visual: segue tema claro/escuro e DPI, cores das marcas opcionais, modo empilhado, suporte a barras verticais e a temas transparentes (Windhawk).
  • Modo ícones de bandeja: um ícone por aparelho, com aviso de bateria fraca em 15%.
  • Idiomas: inclui português do Brasil; dá para criar traduções próprias em arquivo de texto.
  • Linux (experimental): versão com GTK4 para parte das marcas.

Pré-requisitos

  • Windows 10 ou 11.
  • Para compilar: MinGW-w64 (por exemplo via MSYS2) e, para gerar o instalador, Inno Setup.
  • Linux: g++, make, GTK4 e Cairo, mais uma regra udev para acesso HID.

Instalação

Windows (instalador)

  1. Baixe WirelessBattery-Setup-<versão>.exe da última release.
  2. Execute e avance. Não precisa de administrador, drivers nem apps do fabricante.

O instalador cria atalho no menu Iniciar, desinstalador em Configurações → Aplicativos e opção de iniciar com o Windows.

Windows (portátil)

Baixe WirelessBattery-<versão>-portable.zip, descompacte em qualquer pasta e rode WirelessBattery.exe.

Compilar do código

pacman -S mingw-w64-x86_64-gcc make   # no MSYS2
make                                  # ou build.bat num cmd com g++ e windres no PATH

Linux (experimental)

./build-linux.sh
sudo cp linux/99-wireless-battery.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger

Comandos e uso

No dia a dia: passe o mouse para ver detalhes e clique para o menu (esconder aparelho, modo de exibição, Refresh now, Start with Windows, idioma, Exit). Os níveis atualizam a cada 60 segundos e na hora quando um aparelho é conectado ou o PC acorda.

WirelessBattery.exe --list     # lista os aparelhos e a bateria de cada um, e sai
WirelessBattery.exe --dump     # inventário completo de HID/USB/Bluetooth (salvo em %TEMP%\WirelessBattery-dump.txt)
WirelessBattery.exe --report   # abre a janela de pedido de suporte para um aparelho
WirelessBattery.exe --demo     # mostra aparelhos de exemplo de todas as marcas
WirelessBattery.exe --quit     # fecha a instância em execução

Para o app nunca abrir um aparelho específico, crie o valor de texto IgnoreDevices em HKCU\Software\WirelessBattery com pares VID:PID separados por vírgula (os IDs aparecem no --dump).

Quando usar

  • Você tem mouse, headset ou controle sem fio e quer ver a bateria sem abrir o software do fabricante.
  • Usa periféricos de marcas diferentes e quer tudo num lugar só.
  • Joga em tela cheia e quer a bateria visível na barra de outro monitor.

Observações

  • Projeto muito novo e em ritmo acelerado: criado em 16/nov/2026, já com várias versões por dia. O README tem linhas duplicadas de merges; espere mudanças frequentes.
  • Aparelhos não testados: só uma lista de aparelhos foi testada em hardware real; o resto foi implementado a partir de documentação de protocolo e outros projetos.
  • Executável sem assinatura: o Windows SmartScreen pode avisar "O Windows protegeu o computador". As releases são compiladas e publicadas pelo GitHub Actions a partir do código do repositório (verificado nas releases), mas se preferir, compile você mesmo.
  • Internet: segundo o README, a única conexão do app é a janela Request support for a device, e só quando você clica em Send. O pedido vai para uma lista pública em krisgfx.com e abre uma issue no GitHub.
  • Phone Link: a bateria do celular vem de um arquivo não documentado do Phone Link e pode parar de funcionar com atualizações dele.
  • Licença GPL-3.0: quem redistribuir versões modificadas precisa liberar o código sob a mesma licença.
  • Sem suporte ainda: a maioria dos mouses e teclados MSI, headsets Razer Kraken, parte dos HyperX Pulsefire e o Xbox Wireless Headset no adaptador (funciona via Bluetooth).
