Stirling PDF

Plataforma de PDF open source com mais de 50 ferramentas: editar texto, juntar, dividir, assinar, tarjar, converter, OCR e comprimir. Roda como app de desktop, no navegador ou no seu servidor com API REST e servidor MCP, sem mandar os documentos para fora.

O que é

Um "canivete suíço" de PDF que você hospeda. No servidor, abre no navegador e atende a equipe toda, com login. No desktop, as ferramentas básicas rodam no próprio computador; OCR e conversões de Office pedem o seu servidor ou a nuvem paga da Stirling.

Principais recursos

  • Edição: editor de texto e imagens do PDF, editor de páginas (girar, reordenar, apagar, inserir), juntar, dividir, cortar, numerar páginas, marca d'água e carimbo com QR code.
  • Conversão: PDF para Word, PowerPoint, HTML, Markdown, PDF/A, EPUB e imagem, e de Office, HTML, e-mail e e-books para PDF.
  • OCR para tornar escaneados pesquisáveis, com idiomas extras.
  • Segurança: tarja definitiva, senha e permissões, limpeza de JavaScript e anexos, assinatura desenhada ou com certificado digital, carimbo de tempo RFC 3161 e validação de assinaturas.
  • Verificação: comparar dois PDFs, ver todos os metadados e checar acessibilidade (PDF/UA).
  • Automação: pipelines sem código na interface, pastas monitoradas e API REST para quase todas as ferramentas.
  • Servidor MCP (desligado por padrão) para agentes de IA usarem as ferramentas.
  • Login com SSO OAuth2/OIDC, interface em mais de 40 idiomas, imagens para amd64 e arm64.

Pré-requisitos

  • Para o servidor: Docker, com uns 4 GB de RAM para a imagem padrão.
  • Para o desktop: Windows 10 ou 11, macOS 10.15+ ou Linux x86_64.

Instalação

Servidor com Docker Compose (docker-compose.yml):

services:
  stirling-pdf:
    image: docker.stirlingpdf.com/stirlingtools/stirling-pdf:latest
    container_name: stirling-pdf
    ports:
      - '8080:8080'
    volumes:
      - ./stirling-data/configs:/configs
      - ./stirling-data/logs:/logs
      - ./stirling-data/customFiles:/customFiles
      - ./stirling-data/pipeline:/pipeline
      - ./stirling-data/storage:/storage
      - ./stirling-data/tessdata:/usr/share/tessdata
    mem_limit: 4g
    restart: unless-stopped

docker compose up -d

Abra http://localhost:8080 e siga o assistente de configuração. Imagens: latest (padrão, com LibreOffice, OCR e conversões), latest-fat (inclui o motor de IA, 6 GB) e latest-ultra-lite (só o básico, sem login, 2 GB). Também saem no Docker Hub (stirlingtools/stirling-pdf) e no GHCR.

Desktop:

winget install StirlingTools.StirlingPDF

brew tap stirling-tools/stirling-pdf
brew install --cask stirling-pdf

No Linux, há .deb, .rpm, AppImage e o pacote stirling-pdf-desktop no AUR. No primeiro uso, escolha Continue without signing in para trabalhar só no computador.

Comandos e uso

API REST, com a chave criada em Settings → Preferences → API Keys:

curl -X POST "$STIRLING_URL/api/v1/misc/compress-pdf" \
  -H "X-API-KEY: $STIRLING_API_KEY" \
  -F "fileInput=@document.pdf" \
  -F "optimizeLevel=5" \
  -o compressed.pdf

curl -X POST "$STIRLING_URL/api/v1/convert/pdf/word" \
  -H "X-API-KEY: $STIRLING_API_KEY" \
  -F "fileInput=@document.pdf" \
  -F "outputFormat=docx" \
  -o document.docx

Para n8n, Make ou Zapier, use a ação genérica de HTTP: POST, corpo multipart/form-data, arquivo em fileInput e a chave no cabeçalho X-API-KEY.

Ligar o MCP no servidor (MCP_ENABLED=true e MCP_AUTH_MODE=apikey) e conectar o Claude Code pelo .mcp.json:

{
  "mcpServers": {
    "stirling-pdf": {
      "type": "http",
      "url": "https://seu-servidor/mcp",
      "headers": { "X-API-KEY": "sua-chave-stirling" }
    }
  }
}

Quando usar

  • Dar à equipe um editor de PDF completo sem pagar Adobe e sem subir documentos sigilosos para sites de terceiros.
  • Tarjar, assinar com certificado ou converter contratos e documentos internos.
  • Automatizar OCR, compressão e conversão de PDFs por API, pipelines ou pastas monitoradas.

Observações

  • Troque a senha inicial. Num servidor novo, o primeiro acesso entra como admin / stirling. O assistente obriga a trocar, mas não exponha o servidor na internet antes disso. Para já subir com outra senha, use SECURITY_INITIALLOGIN_USERNAME e SECURITY_INITIALLOGIN_PASSWORD.
  • Limites do plano gratuito no servidor: 5 usuários e 1.000 unidades por mês de automação, IA e chamadas de API. Passou disso, a API responde 402. Usar as ferramentas na interface não conta. Banco externo, cluster, SAML e auditoria são dos planos pagos (Team e Enterprise).
  • Pode enviar dados anônimos de uso (PostHog e Scarf), nunca o conteúdo dos documentos. O assistente pergunta; para desligar, defina SYSTEM_ENABLEANALYTICS=false.
  • No desktop em modo Stirling Cloud, as ferramentas que o computador não roda vão para a nuvem da Stirling. Para documentos sigilosos, use o modo Local Only ou o seu servidor.
  • Monte sempre os volumes /configs e /storage: ali ficam as configurações, o banco e os arquivos salvos.
