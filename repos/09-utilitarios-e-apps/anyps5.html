O que é

O AnyPS5 faz o port automático de executáveis do PS5 para Linux e Windows. Ele não é um emulador. O relinker converte o executável ELF do console para o formato nativo do sistema de destino: ELF no Linux, .exe no Windows, Mach-O no macOS. Junto vêm implementações próprias das bibliotecas de sistema do PS5 (.prx), carregadas como bibliotecas dinâmicas comuns. O resultado roda como um programa normal, sem processo de emulação por trás.

Isso funciona porque o PS5 usa CPU x86-64 (Zen 2): o código do jogo roda direto no processador do PC. Os shaders da GPU são recompilados para SPIR-V e rodam em Vulkan.

É um projeto em andamento. O site mostra o percentual das funções conhecidas do sistema que já foram implementadas, e cada jogo tem um tópico de teste em Game bring-up.

Principais recursos

  • Relinker de linha de comando para Linux, Windows e macOS. No macOS, só o relinker roda, inclusive em Apple Silicon.
  • Conversor web: o arquivo é processado no navegador e não sai do seu computador. Converte vários apps de uma vez num ZIP.
  • Bibliotecas de sistema do PS5 reimplementadas para Linux e Windows.
  • Recompilador de shaders para SPIR-V e Vulkan, com cache de shaders.
  • Controles: joysticks via SDL (até 4, com analógicos e gatilhos; o controle de Xbox é mapeado para os botões do PlayStation), teclado e mouse configuráveis em anyps5-input.ini, e vibração ajustável.
  • Tela cheia (F11), captura de tela (F12), overlay de desempenho, volume do host (F5/F6/F8), troféus lidos dos dados do próprio jogo, HDR e escolha de GPU.
  • Patches por jogo: arquivos TOML que conferem os bytes antes de alterar o executável, e uma ferramenta que sugere patches de um catálogo (tools/suggest_patches.py).
  • No Linux, pede o modo de jogo do Feral GameMode.

Pré-requisitos

  • CPU com as extensões do Zen 2: AVX2, FMA, F16C, BMI1, BMI2, LZCNT e MOVBE. O título verifica isso ao iniciar e para se faltar alguma. Instruções específicas de AMD exigem processador AMD, ou a opção --to-intel no caso de PCs com Intel; ela não cobre código gerado pelo jogo durante a execução.
  • GPU com Vulkan.
  • Linux: se o driver de vídeo importa memória dma-buf (não vale para o driver proprietário da NVIDIA), o usuário precisa de acesso a /dev/udmabuf, normalmente entrando no grupo kvm.
  • Windows: memória virtual suficiente. Um jogo pode mapear até cerca de 13,5 GB de "memória direta", que precisa caber no limite de RAM mais arquivo de paginação.
  • Um executável de PS5 já descriptografado (ELF limpo), com os módulos do jogo. O AnyPS5 não inclui nem obtém chaves, firmware ou jogos.

Instalação

Baixe do último release:

  • relinker-<versão> (Linux) ou relinker-<versão>.exe (Windows): o conversor;
  • prx-linux-<versão> ou prx-windows-<versão> (.zip / .tar.gz): as bibliotecas de sistema do AnyPS5;
  • USAGE.md e INPUT_MAPPING.md: o manual de uso e o mapeamento de controles.

Para quem não quer usar o terminal, há o conversor web. Para compilar do código-fonte, siga o guia de build.

Comandos e uso

1. Organize a entrada (os módulos do jogo ficam ao lado do executável):

source/
    input.elf
    sce_module/
        <módulos ELF do jogo>

2. Converta:

relinker source/input.elf app.elf                 # Linux
relinker --windows source/input.elf app.exe       # Windows
relinker --macos source/input.elf eboot           # macOS (x86-64, via Rosetta no Apple Silicon)
relinker --help                                   # todas as opções

Opções úteis:

  • --to-intel: para PCs com processador Intel;
  • --to-rosetta: para o Apple Silicon;
  • --module-dir <pasta>: módulos em outro lugar;
  • --sce-module-path <pasta>: pasta-mãe dos módulos.

Contêineres SELF já descriptografados podem ser desempacotados com tools/unwrap_self.py <input.self> <output.elf>.

3. Monte a pasta de execução (caminhos relativos ao executável gerado):

app.elf (Linux) ou app.exe (Windows)
libs/
    *.prx               ← bibliotecas do AnyPS5 (do pacote prx-*), não as do console
app0/
    <recursos do jogo>
    eboot.bin           ← o original, que muitos jogos procuram
    sce_sys/param.json
    sce_module/
        <módulos convertidos .guest.prx>

4. Rode:

./app.elf          # Linux (se perdeu a permissão: chmod +x app.elf)

.\app.exe          # Windows

Teclado padrão (sem anyps5-input.ini):

Ação Tecla
X / Círculo / Triângulo / Quadrado Enter ou Espaço / C / I / botão esquerdo do mouse
Analógico esquerdo / direito W A S D / T F G H
L1 / R1 / L2 / R2 Q / E / R / botão direito do mouse
Options Esc
Tela cheia / captura de tela F11 / F12

Quando usar

  • Pesquisa, preservação e compatibilidade: rodar no PC homebrew e jogos de PS5 que você mesmo extraiu do seu console.
  • Estudar como funcionam ports nativos, recompilação de shaders e reimplementação de bibliotecas de sistema.
  • Contribuir com testes de compatibilidade de jogos.

Observações

  • Questão legal: o projeto declara que é para interoperabilidade, pesquisa e preservação, e que não inclui nem exige software protegido, firmware, chaves ou bibliotecas proprietárias. Você é responsável por obter os executáveis de forma legal, por exemplo extraindo de jogos seus no seu próprio console. Baixar jogos de terceiros é pirataria. O projeto não é afiliado à Sony.
  • Segurança: o próprio manual avisa que o jogo convertido roda como um programa comum, com as permissões da sua conta e sem o sandbox do console, e sem ASLR no executável. Converta só títulos e módulos em que você confia, e de preferência rode com outro usuário, num container ou numa máquina virtual.
  • Compatibilidade parcial: situações não suportadas encerram o processo com erro (std::runtime_error). Não há suporte a VR, a resolução de renderização é a que o jogo escolhe, e fontes do sistema e alguns ícones de troféus podem faltar. Confira o tópico do jogo antes de tentar.
  • Patches de catálogos de terceiros: a ferramenta só confere se o patch bate com os arquivos. Ela não garante que o patch é seguro. Revise antes de aplicar.
  • Projeto muito ativo e novo (criado em ago/2026), com releases frequentes. O último é o v0.1.3, de out/2026.
