O que é

O scrcpy (pronuncia-se "screen copy") espelha a tela de aparelhos Android conectados por USB ou TCP/IP e permite controlá-los com o teclado e o mouse do computador. Não exige root nem app instalado no aparelho, e funciona em Linux, Windows e macOS.

Foca em leveza, desempenho (30 a 120 fps), qualidade (1920x1080 ou mais), baixa latência (35 a 70 ms) e inicialização rápida (cerca de 1 s). Sem conta, sem anúncios e sem internet. O README alerta que o repositório do GitHub é a única fonte oficial: não baixe de sites aleatórios.

Principais recursos

  • Espelhamento de vídeo e encaminhamento de áudio (Android 11+).
  • Gravação de tela.
  • Display virtual e espelhamento com a tela do aparelho apagada.
  • Copiar e colar nos dois sentidos.
  • Qualidade configurável (codec, resolução, bitrate, fps).
  • Espelhamento da câmera (Android 12+).
  • Simulação de teclado e mouse físicos (HID), gamepad e modo OTG.
  • Conexão por USB ou sem fio (TCP/IP).

Pré-requisitos

  • Aparelho Android com API 21 (Android 5.0) ou superior.
  • Depuração USB ativada nas opções de desenvolvedor (não é necessária no modo OTG).
  • Em alguns aparelhos (principalmente Xiaomi), ative também a opção "Depuração USB (configurações de segurança)" para controlar com teclado e mouse; é preciso reiniciar o aparelho uma vez.
  • Para áudio: Android 11 ou superior (API 30+).

Instalação

Windows (foco principal)

Opção 1, pacote oficial: baixe o .zip na página de releases e extraia. O guia doc/windows.md lista a versão v5.0.1 em três variantes:

  • scrcpy-win64-v5.0.1.zip (64 bits);
  • scrcpy-win32-v5.0.1.zip (32 bits);
  • scrcpy-winarm64-v5.0.1.zip (ARM 64 bits).

O guia traz também o hash SHA-256 de cada arquivo para conferência (veja doc/windows.md). O pacote inclui o ADB.

Opção 2, gerenciadores de pacote (o WinGet instala o ADB e as outras dependências junto):

winget install --exact Genymobile.scrcpy

choco install scrcpy
choco install adb    # se ainda não tiver

scoop install scrcpy
scoop install adb    # se ainda não tiver

Para compilar manualmente, veja doc/build.md.

Como executar no Windows

O scrcpy é um aplicativo de linha de comando. No pacote extraído:

  • dê duplo clique em open_a_terminal_here.bat para abrir um terminal na pasta e digite os comandos;
  • ou crie um arquivo .bat (por exemplo myscrcpy.bat) com o comando e as opções que você sempre usa, e execute-o com duplo clique;
  • para abrir sem terminal, use scrcpy-noconsole.vbs (erros não serão exibidos); para passar argumentos, edite uma cópia do arquivo.

Exemplo de .bat do guia (acrescente --pause-on-exit=if-error para o console não fechar em caso de erro):

scrcpy --prefer-text --turn-screen-off --stay-awake --pause-on-exit=if-error

Comandos e uso

scrcpy                                   # espelha o aparelho conectado por USB
scrcpy --no-audio --record=file.mkv      # sem áudio, gravando em arquivo
scrcpy -m1024                            # limita a resolução (melhora o desempenho)
scrcpy --video-codec=h265 --max-size=1920 --max-fps=60 --no-audio --keyboard=uhid   # H.265, 1920 px, 60 fps, teclado físico simulado
scrcpy --new-display=1920x1080 --start-app=org.videolan.vlc   # app em um display virtual
scrcpy --video-source=camera --video-codec=h265 --camera-size=1920x1080 --record=file.mp4   # grava a câmera
scrcpy --serial=0123456789abcdef         # escolhe o aparelho pelo número de série
scrcpy -d                                # usa o aparelho USB
scrcpy --tcpip                           # configura e conecta por Wi-Fi (TCP/IP)
scrcpy --tcpip=192.168.1.1               # conecta a um IP (porta padrão 5555)
scrcpy --help                            # lista todas as opções

Atalhos úteis: clique direito = Voltar, clique do meio = Home, <kbd>Alt</kbd>+<kbd>f</kbd> = tela cheia. Veja todos em doc/shortcuts.md.

Quando usar

  • Controlar o celular pelo PC (testes, demonstrações, jogos, apps sem versão desktop, como o WhatsApp no aparelho).
  • Gravar a tela do Android com áudio.
  • Usar o celular com a tela apagada ou como webcam (a opção V4L2 é só para Linux).

Observações

  • Baixe somente do repositório oficial, como o README alerta.
  • Conferir o SHA-256 dos arquivos é recomendado; o guia de verificação está em doc/verify-release.md.
  • Para conexão sem fio, o aparelho e o PC precisam estar na mesma rede.
