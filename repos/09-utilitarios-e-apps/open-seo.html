O que é

O OpenSEO é uma ferramenta de SEO para quem acha Semrush e Ahrefs caros ou inchados. Em vez de assinatura, você traz sua chave de API da DataForSEO e paga só pelo que consultar. A interface é simples, com fluxos focados.

Ele expõe um servidor MCP para que agentes como Claude Code, ChatGPT, Codex, Cursor, OpenClaw e Hermes usem seus dados de SEO diretamente, e traz Agent Skills prontas com fluxos de trabalho de SEO.

Pode ser usado na versão hospedada (gratuita para testar; assinatura de US$ 10/mês para apoiar) ou self-hosted com Docker ou Cloudflare.

Principais recursos

  • Pesquisa de palavras-chave.
  • Rank tracking (acompanhamento de posições).
  • Análise de concorrentes.
  • Backlinks.
  • Auditoria de sites.
  • Visibilidade em IA (presença em respostas de IA).
  • Servidor MCP e Agent Skills para agentes.
  • Contas por e-mail e senha com convites para o time; clientes MCP entram com as mesmas contas.

Pré-requisitos

  • Chave de API da DataForSEO (ou conta treg, que também dá acesso).
  • Self-hosting: Docker (inclui Coolify, Portainer, Dokploy) ou conta Cloudflare (funciona no plano gratuito).

Instalação

Hospedado

Crie a conta em openseo.so.

Self-hosted

  • Docker: imagem pronta; siga docs/SELF_HOSTING_DOCKER.md.
  • Cloudflare: um comando de deploy na sua conta; siga docs/SELF_HOSTING_CLOUDFLARE.md.

O primeiro visitante cria a conta de administrador. Configure a chave em docs/DATAFORSEO_API_KEY.md.

Conectar agentes

  • MCP
  • Agent Skills
  • ChatGPT (planos gratuito e pagos)
  • Codex

Comandos e uso

Depois de conectar o MCP e as skills, peça ao agente em linguagem natural, por exemplo:

Find low-competition keywords for my project management SaaS and check where my site ranks for them.

Skill para abrir issues bem descritas no projeto:

npx skills add every-app/open-seo --skill simple-issue-description

Quando usar

  • SEO de sites próprios e de clientes sem pagar assinatura cara de Semrush/Ahrefs.
  • Deixar o Claude Code fazer pesquisa de palavras-chave e auditoria com dados reais.
  • Agências que querem uma ferramenta self-hosted e personalizável.

Observações

  • Custo variável: a DataForSEO cobra por requisição; a versão hospedada cobra 28% a mais sobre esse custo.
  • Opções avançadas de segurança: Cloudflare Access na frente do deploy, ou Docker sem login atrás de Tailscale ou proxy autenticado.
  • Para auditoria de SEO via skill sem servidor, veja Claude SEO.
