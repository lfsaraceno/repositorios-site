O que é

O RustDesk é uma solução de desktop remoto que funciona "out of the box", sem configuração. Você tem controle total dos seus dados: pode usar o servidor público de rendezvous/relay da equipe, montar o seu próprio ou até escrever um servidor próprio.

O ecossistema tem duas partes: o cliente (aplicativo para Windows, Linux, macOS e Android, que permite controlar e ser controlado) e o servidor (hbbs e hbbr), que você hospeda para que as conexões passem pela sua infraestrutura.

Principais recursos

  • Acesso remoto multiplataforma com interface Flutter (a interface Sciter está obsoleta).
  • Servidor próprio gratuito: hbbs (ID/rendezvous) e hbbr (relay).
  • Chave pública do servidor para restringir conexões à sua infraestrutura.
  • Binários prontos, versão noturna, F-Droid e Flathub.
  • Existe um RustDesk Server Pro (pago) com recursos avançados.

Pré-requisitos

  • Windows (cliente): instalador .exe ou .msi das releases (a release mais recente consultada é a 1.5.0, com rustdesk-1.5.0-x86_64.exe e .msi).
  • Servidor: uma máquina com IP/domínio acessível e portas liberadas (21115 a 21119, conforme o docker-compose.yml do servidor) ou Docker.

Instalação

Cliente no Windows

  1. Abra a página de releases e baixe rustdesk-<versão>-x86_64.exe ou rustdesk-<versão>-x86_64.msi.
  2. Execute o instalador (ou abra o .exe direto, se for a versão portátil) e anote o ID exibido.
  3. Para usar o seu servidor, abra Configurações > Rede (ou ID/Relay server) e informe o endereço do servidor e a chave pública (id_ed25519.pub). O passo a passo está na documentação.

Servidor self-hosted com Docker Compose

O repositório rustdesk-server traz este docker-compose.yml (ajuste rustdesk.example.com para o seu domínio ou IP):

services:
  hbbs:
    container_name: hbbs
    ports:
      - 21115:21115
      - 21116:21116
      - 21116:21116/udp
      - 21118:21118
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r rustdesk.example.com:21117
    volumes:
      - ./data:/root
    depends_on:
      - hbbr
    restart: unless-stopped

  hbbr:
    container_name: hbbr
    ports:
      - 21117:21117
      - 21119:21119
    image: rustdesk/rustdesk-server:latest
    command: hbbr
    volumes:
      - ./data:/root
    restart: unless-stopped

docker compose up -d

A chave pública é gerada na pasta ./data (arquivo id_ed25519.pub); use-a nos clientes.

Outras opções do servidor: compilar com cargo build --release (gera hbbs, hbbr e rustdesk-utils) ou baixar binários nas releases do servidor. Veja o manual e as variáveis de ambiente.

Comandos e uso

O servidor aceita flags e variáveis de ambiente:

hbbs --help                 # lista as opções do servidor de ID
hbbr --help                 # lista as opções do servidor de relay
hbbs -r rustdesk.example.com:21117   # informa o relay a usar

Variáveis úteis: KEY (chave), ALWAYS_USE_RELAY=Y (força relay, sem conexão direta) e RUST_LOG=debug (logs detalhados).

No cliente: informe o ID do outro computador, digite a senha e conecte.

Quando usar

  • Suporte remoto a clientes e acesso a máquinas próprias sem pagar licença de TeamViewer.
  • Manter o tráfego de acesso remoto na sua infraestrutura (self-hosted).
  • Instalação do servidor via SetupOrion, que lista o RustDesk no catálogo.

Observações

  • Licença AGPL-3.0. O README tem um aviso contra uso indevido (acesso não autorizado).
  • Os servidores hbbs e hbbr precisam de portas TCP e UDP liberadas no firewall.
  • O RustDesk Server Pro é um produto pago, à parte.
  • Este documento foi montado a partir do README e do docker-compose.yml do servidor; confira a documentação oficial antes de produção.
