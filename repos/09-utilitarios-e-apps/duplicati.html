Duplicati

Backup gratuito e open source para Windows, macOS e Linux: guarda cópias criptografadas (AES-256), incrementais e comprimidas em S3, Backblaze B2, Google Drive, OneDrive, Dropbox, SFTP, WebDAV e dezenas de outros destinos, com agendador, interface web, linha de comando e servidor MCP para agentes de IA.

O que é

Um cliente de backup que criptografa os arquivos no seu computador antes de enviar. Só o primeiro backup leva tudo; os seguintes mandam apenas o que mudou. Com uma senha forte, os arquivos ficam protegidos mesmo num servidor público.

Vem em três pacotes:

  • GUI: ícone na bandeja, servidor com interface web e linha de comando. Para um computador de casa.
  • CLI: servidor e linha de comando, sem desktop. Para servidores.
  • Agent: controle remoto pelo Duplicati Console, só no plano Enterprise.

Principais recursos

  • Criptografia AES-256 ou GPG antes do envio.
  • Backups incrementais e comprimidos, com agendamento embutido e regras de retenção.
  • Mais de 30 destinos: Amazon S3 e compatíveis, Backblaze B2, IDrive e2, Azure, Google Cloud e Drive, OneDrive, Dropbox, Box, MEGA, Storj, SFTP, FTP, WebDAV, SMB, rclone e outros.
  • Copia arquivos abertos ou travados com VSS no Windows e LVM no Linux.
  • Filtros por pasta e tipo de arquivo, limite de banda e limite de envio por execução.
  • Relatórios por e-mail, HTTP, Telegram e XMPP.
  • Ferramentas de recuperação para destinos danificados e para copiar um backup de um destino para outro.
  • Servidor MCP (experimental): um agente como o Claude Code lista os backups, roda um backup antes de mexer em arquivos e restaura se algo der errado.

Pré-requisitos

  • Windows, macOS ou Linux (x64, ARM64 e ARMv7), ou Docker.
  • Uma conta ou servidor de destino para guardar os backups.

Instalação

Baixe o pacote em duplicati.com/download ou na página de releases: .msi no Windows, .dmg/.pkg no macOS e .deb, .rpm ou AppImage no Linux. As releases são assinadas com GPG (chave 3DAC703D).

Docker (imagem oficial duplicati/duplicati, dados em /data, porta 8200):

services:
  duplicati:
    image: duplicati/duplicati:latest
    ports:
      - "8200:8200"
    volumes:
      - ./data:/data
    environment:
      SETTINGS_ENCRYPTION_KEY: "<chave de criptografia das configurações>"
      DUPLICATI__WEBSERVICE_PASSWORD: "<senha da interface>"

Para não deixar as senhas no arquivo, a documentação mostra como usar Docker secrets com um arquivo de pré-carga ou um provedor de segredos.

Comandos e uso

A interface web abre em http://localhost:8200. Pela linha de comando (duplicati-cli no Linux e macOS, Duplicati.CommandLine.exe no Windows):

duplicati-cli backup <url do destino> <pasta de origem> --passphrase=<senha> --exclude=*.iso
duplicati-cli restore <url do destino> <arquivo>
duplicati-cli find <url do destino> <arquivo>
duplicati-cli repair <url do destino>
duplicati-cli help

Ligar o MCP e conectar o Claude Code (o token é criado em Settings > MCP access tokens ou pelo duplicati-server-util issue-mcp-token):

duplicati-server --webservice-enable-mcp-server=true
claude mcp add --transport http duplicati http://localhost:8200/mcp --header "Authorization: Bearer <token>"

Quando usar

  • Backup automático e criptografado de computadores e servidores para uma nuvem barata (B2, S3, Drive).
  • Backup de servidores e VPS sem interface gráfica.
  • Dar a um agente de IA um ponto de restauração antes de ele alterar arquivos.

Observações

  • Guarde a senha do backup fora do computador. Sem ela, não há como recuperar os arquivos.
  • O servidor web atende só no próprio computador e só por IP. Para acessar de outra máquina, ligue o acesso remoto e use HTTPS. Rodando como administrador, esse servidor tem os mesmos privilégios.
  • Desde a versão 2.3.1.0, a pasta de dados precisa de permissões restritas, senão o Duplicati não inicia. No Docker, a variável DUPLICATI__ALLOW_INSECURE_DATAFOLDER=true desliga essa checagem.
  • Envia telemetria anônima por padrão. Para desligar tudo, defina USAGEREPORTER_Duplicati_LEVEL=none antes de iniciar.
  • O restore pelo MCP reescreve os arquivos do backup, mas não apaga os arquivos criados depois. Não é um rollback completo da pasta.
  • Recursos como backup de Microsoft 365 e Google Workspace ficam na pasta proprietary/ e exigem assinatura para uso em produção.
  • Relacionado no catálogo: o SetupOrion instala o Duplicati numa VPS.
