O que é

A Receita Federal distribui a calculadora offline como um pacote para baixar no portal. Este repositório automatiza o acompanhamento: um workflow do GitHub Actions roda todo dia à meia-noite (UTC), pede à API oficial o link do pacote mais recente, baixa e compara o hash com a versão anterior. Se mudou, descompacta o código-fonte, faz o commit e cria uma release.

Assim você tem o histórico de versões da calculadora no Git e um jeito fácil de baixar sempre a última.

Principais recursos

  • Verificação diária automática, ou manual pela aba Actions.
  • Código-fonte do backend descompactado na pasta codigo-fonte-backend, com histórico de commits por data.
  • Cada versão vira uma release pacote-AAAAMMDD-HHMMSS com a imagem Docker (calculadora.tar.gz), os codigo-fonte-*.zip, scripts-instalacao.zip, versoes.txt e SHA256SUMS.txt.

Pré-requisitos

  • Docker.
  • GitHub CLI (gh) para baixar a release pelo terminal.

Instalação

Baixar a última imagem e subir a calculadora:

gh release download --repo nfe/rtc-calculadora-offline --pattern calculadora.tar.gz --clobber
docker import calculadora.tar.gz calculadora-image
docker run -t -i --rm -p 8080:8080 -p 8081:8081 -p 8082:8082 -p 80:80 -w /calculadora calculadora-image bash start.sh

Comandos e uso

Para acompanhar versões novas, assine as releases do repositório (Watch → Custom → Releases) ou rode o gh release download acima de tempos em tempos.

Para forçar uma checagem num fork: Actions → "Download and Update Código Fonte da Calculadora da Reforma Tributária" → Run workflow.

Quando usar

  • Subir a calculadora oficial completa num servidor com um comando Docker.
  • Ver o que mudou entre versões da calculadora (diff do código no Git).
  • Automatizar a atualização da calculadora no seu ambiente.

Observações

  • Não é da Receita Federal: é um espelho mantido pela organização nfe no GitHub. Confira o SHA256SUMS.txt e, em caso de dúvida, baixe o pacote no portal oficial.
  • O repositório não declara licença.
  • Relacionado no catálogo: a Calculadora de Tributos RTC é o código-fonte publicado pela própria Receita no GitHub.
