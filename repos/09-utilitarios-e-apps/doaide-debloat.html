O que é

O DoAide Debloat limpa celulares e tablets Android de bloatware: anúncios na tela de bloqueio (Glance), anúncios dentro das Configurações (MSA da Xiaomi), serviços de perfilamento (Samsung Customization Service), lojas e navegadores duplicados, atalhos que pedem para instalar apps. Muitos desses apps são de "sistema" e não podem ser removidos pelo celular, mas podem ser desativados pelo ADB.

Nada é apagado da imagem do sistema: os pacotes são desativados com pm disable-user --user 0, um por comando, e tudo é registrado num arquivo que permite desfazer com um comando. Não precisa de root.

O projeto foi feito para ser conduzido por um agente de programação: você abre o agente na pasta do repositório e diz "clean up my phone". O agente identifica o modelo, faz backup, explica cada pacote, pergunta o que o dono usa, desativa o resto, verifica e deixa um arquivo de restauração. Também funciona à mão, pela linha de comando.

Inclui um modo pais (parent mode), que audita o celular de um familiar em busca de riscos de golpe (apps de acesso remoto, apps que instalam APK, acesso a SMS e acessibilidade) e desfaz o que o dono aprovar.

Principais recursos

  • Probe: lê modelo, versão do Android, fabricante e quais apps são a tela inicial, teclado, telefone, SMS e navegador; esses ficam protegidos durante toda a execução.
  • Backup da lista de pacotes, desativados, removidos, props e configurações em backups/.
  • Plan: cruza os pacotes instalados com um perfil por fabricante (anúncios, telemetria, lixo e uma lista "perguntar ao dono"), enriquecido com a lista comunitária do UAD; não altera nada.
  • Apply com verificação: depois de aplicar, refaz o probe e, se tela inicial, teclado, telefone ou SMS mudaram, restaura sozinho.
  • Restore exato a partir do registro ou do backup; check reaplica o que voltou depois de uma atualização de firmware.
  • Lista de pacotes que nunca são desativados (data/never-disable.txt): pacotes do Android, Play Services, Knox, segurança da Xiaomi etc.
  • Perfis para Samsung, Xiaomi/Redmi/POCO, OnePlus/OPPO/realme, vivo/iQOO, Motorola, Pixel e tablets Amazon Fire.
  • Conexão por cabo USB ou por Wi-Fi (depuração sem fio com código de pareamento).

Pré-requisitos

  • Python 3.9+ (sem outras dependências).
  • adb (Android Platform Tools).
  • Celular com Opções do desenvolvedor e Depuração USB ativadas, e cabo de dados.
  • Opcional: um agente de IA (Claude Code, Codex, Hermes, Gemini CLI).

Instalação

1. Preparar o celular

Configurações > Sobre o telefone > toque 7 vezes em Número da versão. Depois Configurações > Opções do desenvolvedor > ative Depuração USB. Os caminhos por marca estão em recipes/android-phone.md.

2. Instalar o adb e clonar

winget install Google.PlatformTools        # Windows
brew install android-platform-tools        # macOS
sudo apt install adb                       # Debian/Ubuntu

git clone https://github.com/DoAideAi/DoAide-Debloat && cd DoAide-Debloat

Como skill de agente (sem clonar antes)

npx skills add DoAideAi/DoAide-Debloat     # instala skills/android-debloat/SKILL.md no Claude Code, Codex, Cursor etc.

A skill instrui o agente a clonar o repositório e seguir o AGENTS.md.

Comandos e uso

Com um agente de IA

Abra o agente na pasta do repositório e cole o conteúdo de PROMPT.md, ou diga:

Clean up my Samsung phone, follow AGENTS.md

Aceite Permitir depuração USB? no celular e responda ao checklist de apps opcionais (Samsung Pay, Bixby, Mi Video, Alexa...). Só o que você não marcar é desativado. Leva uns 15 minutos.

À mão

python3 tools/debloat.py probe                          # identifica o aparelho e o que fica protegido
python3 tools/debloat.py backup                         # snapshot em backups/
python3 tools/debloat.py plan                           # mostra o que seria desativado e grava um plano
python3 tools/debloat.py plan --remove com.samsung.android.spay,com.samsung.android.bixby.agent   # tira pacotes do plano
python3 tools/debloat.py apply --plan backups/plan-<model>-<time>.json --yes   # aplica o plano
python3 tools/debloat.py restore --record backups/record-<model>-<time>.json   # desfaz tudo
python3 tools/debloat.py check --record backups/record-<model>-<time>.json --fix  # após atualização de firmware
python3 tools/debloat.py lookup glance bixby --device   # explica o que é um pacote

No Windows, troque python3 por python se for o caso.

Por Wi-Fi

Ative Depuração sem fio no celular, abra "Parear dispositivo com código de pareamento" e rode:

python3 tools/debloat.py connect --discover --code 123456   # encontra as portas sozinho na mesma rede

Use o --serial ip:port que ele imprimir em todos os outros comandos.

Modo pais (anti-golpe)

python3 tools/debloat.py parent audit                        # só leitura; grava backups/parent-audit-*.json
python3 tools/debloat.py parent apply --audit <file> --yes   # aplica as mudanças [auto]; --fix <id> para as [ask]
python3 tools/debloat.py parent card --record <file> --who Mum   # gera um cartão compartilhável (só contagens)
python3 tools/debloat.py parent finish --record <file> --yes # desliga depuração USB e sem fio; último passo
python3 tools/debloat.py parent restore --record <file>      # desfaz

Com agente: "make this phone safe, follow recipes/parent-mode.md".

Quando usar

  • Limpar anúncios e apps de fábrica de um celular Samsung, Xiaomi, OnePlus, vivo ou Motorola sem root.
  • Configurar o celular de pais ou parentes com um agente de IA fazendo o trabalho e explicando cada passo.
  • Reduzir o risco de golpe em celular de idosos (apps de acesso remoto, permissões de SMS, acessibilidade).
  • Deixar o celular "chato" de propósito (tons de cinza, launcher mínimo) com recipes/dumbphone.md.

Observações

  • Projeto muito novo (nov/2026, poucas estrelas). Testado de ponta a ponta em um único aparelho real (OnePlus CPH2487, Android 16). Os demais fabricantes têm listas verificadas pela comunidade, mas não em aparelho. O modo pais só foi testado em dispositivo simulado.
  • --allow-uninstall usa pm uninstall -k --user 0 para pacotes que alguns fabricantes não deixam desativar. É reversível (cmd package install-existing), mas mais agressivo que o padrão.
  • Ao terminar, desligue a depuração USB: um celular com ADB ligado é um risco (parent finish faz isso).
  • A lista do UAD (GPL-3.0) é baixada em tempo de execução para ~/.cache/doaide-debloat/, não é redistribuída.
  • Não funciona para Android TV/Google TV (use cleanyourtv), Fire TV (use dumbtv), Tizen, webOS, Roku nem iPhone.
  • Para espelhar e controlar o celular pelo PC via ADB, veja scrcpy; o DoAide Debloat foca em desativar pacotes.
