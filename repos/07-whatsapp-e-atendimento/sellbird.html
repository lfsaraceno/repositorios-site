Sellbird (antigo Harvey)

Plataforma open source de prospecção por e-mail que roda no seu plano do Claude ou do ChatGPT. Ela encontra empresas e quem decide, verifica os e-mails, escreve e envia cold e-mails personalizados e cuida das respostas.

Atenção: cold e-mail para pessoas no Brasil envolve tratamento de dados pessoais (nome e e-mail). Exige base legal na LGPD, em geral o legítimo interesse documentado, além de informar a origem dos dados e oferecer descadastro fácil. A documentação do Sellbird cobre as regras dos EUA (CAN-SPAM) e da Europa (GDPR), não a LGPD. Consulte um advogado antes de enviar em escala.

O que é

O Sellbird é um pipeline de vendas outbound que roda na sua máquina. Você pode rodar tudo de ponta a ponta ou parar em qualquer etapa. Ele não usa chave de API de modelo: pensa pela CLI do Claude Code (plano Pro ou Max) ou pelo Codex (plano do ChatGPT).

Por padrão, nenhum e-mail sai sem a sua aprovação.

Principais recursos

  • Encontra empresas parecidas com o seu cliente ideal. A fonte padrão é o OpenStreetMap, gratuita. Fontes pagas mostram o custo antes de rodar.
  • Lê o site de cada empresa em busca de sinais de compra, por exemplo "não tem agendamento online", "está anunciando" ou "está contratando". São 29 sinais, sem chamar o modelo.
  • Encontra quem decide: dono ou gestor citado nas páginas da empresa, no máximo duas pessoas por empresa.
  • Verifica o e-mail: descobre o padrão de endereços da empresa e marca cada um como verificado, arriscado, palpite ou inválido. Só envia para os entregáveis.
  • Escreve e envia uma sequência curta para cada pessoa, pelo Gmail, Microsoft 365 ou SMTP. Respeita o limite diário e o horário comercial de quem recebe.
  • Cuida das respostas:
    • rascunha a resposta;
    • separa as respostas automáticas;
    • respeita pedidos de descadastro na hora;
    • passa para você o que não deve responder sozinho.
  • Painel web local, com caixa de saída para aprovação.
  • Exporta a lista em CSV (sellbird export) se você só quiser os contatos.

Pré-requisitos

  • Python 3.11+.
  • Claude Pro ou Max, com a CLI logada (claude login), ou um plano do ChatGPT com a CLI do Codex.
  • Uma caixa de e-mail para envio, de preferência num domínio separado do principal (Google Workspace, Microsoft 365 ou SMTP).
  • Aquecimento (warmup) dessa caixa antes de começar, para não cair no spam.

Instalação

Com o Claude Code guiando:

git clone https://github.com/ethanplusai/sellbird.git
cd sellbird
claude

Depois peça "set up Sellbird for me". O CLAUDE.md do repositório transforma o Claude Code no guia de instalação.

Manual:

python3.13 -m venv .venv && source .venv/bin/activate && pip install -e .
cp .env.example .env          # preencha as credenciais (documentadas no arquivo)
sellbird train https://sua-empresa.com.br   # aprende o seu produto pelo site
sellbird signals --confirm free             # confirma os sinais de bom cliente
sellbird discover                           # busca empresas (fonte gratuita)
sellbird dashboard                          # painel em http://127.0.0.1:5555
sellbird run                                # inicia o ciclo

No Linux também roda com Docker.

Comandos e uso

sellbird run              # ciclo contínuo: escreve, envia e responde (a cada 15 min)
sellbird status           # situação atual
sellbird export           # CSV com os contatos verificados
sellbird sending pause    # para todos os envios na hora

A caixa de saída do painel mostra cada e-mail para aprovar. O autopilot só liga se você ativar. Mesmo ligado, ele segura e-mails com link para domínios de fora ou que citam as instruções internas do Sellbird.

Antes da primeira campanha, defina compliance.postal_address no sellbird.yaml. Ela vai no rodapé de todo cold e-mail, junto com a linha de descadastro.

Quando usar

  • Prospecção B2B de pequenas empresas locais (clínicas, construtoras, serviços) sem pagar Apollo, ZoomInfo ou Clay.
  • Gerar listas de empresas com o contato de quem decide, mesmo que você envie por outra ferramenta.
  • Comparação no catálogo:
    • o DeskComm CRM e o Chatwoot cuidam do atendimento e do relacionamento com quem já chegou;
    • o Sellbird faz a prospecção ativa, por e-mail.

Observações

  • LGPD: veja o aviso no topo. Raspar nomes e deduzir e-mails de sites é tratamento de dados pessoais. Documente a origem e o legítimo interesse, e honre o descadastro. A documentação legal do projeto também diz que não é aconselhamento jurídico.
  • Termos do plano de IA: o Sellbird usa a sua assinatura do Claude ou do ChatGPT para automação contínua. Isso pode esbarrar nos termos de uso desses planos. Confira antes.
  • Reputação do domínio: cold e-mail mal feito queima o domínio. Use um domínio separado, faça o aquecimento e respeite os limites diários.
  • AGPL-3.0: se oferecer uma versão modificada como serviço na rede, precisa abrir o código das modificações.
  • Links de afiliado: os links do TrulyInbox no projeto rendem comissão ao mantenedor.
  • Versão hospedada: existe em sellbird.ai, em acesso antecipado.
  • Quem vinha do Harvey: configuração e dados são migrados automaticamente na primeira execução. Projeto muito ativo (última: v0.4.0, nov/2026).
