O que é

A APIBrasil se descreve como "Serviços de API for Brazil". Ela oferece uma plataforma com APIs de WhatsApp, SMS, consultas (CPF, CNPJ, veículos, CEP, correios) e pagamentos (PIX e boleto), cobradas por créditos ou assinatura. A organização no GitHub reúne os SDKs oficiais, exemplos de integração e alguns projetos abertos.

O foco do WhatsApp é o MyZap, uma API de WhatsApp da própria APIBrasil, com painel de gestão de dispositivos. Os SDKs permitem chamar a plataforma em várias linguagens com poucas linhas de código.

Principais recursos

  • SDKs oficiais com a mesma ideia de uso (WhatsApp, consultas, auth) em várias linguagens.
  • Painel open source para gerenciar dispositivos conectados ao MyZap.
  • Disparador gratuito de mensagens para servidores da APIBrasil.
  • API de multas dos Detrans (web scraping retornando JSON).
  • Cliente de exemplo do servidor MCP da APIBrasil para agentes de IA.
  • Exemplos de bot com Dialogflow e de chat com Node.js, socket e webhook.

Pré-requisitos

  • Conta e credenciais da APIBrasil (Bearer Token, Device Token), obtidas em apibrasil.com.br.
  • Node.js 18+ para o SDK Node; PHP 8.0+ para o SDK PHP.

Existem ainda SDKs para Java, Go, Flutter, Ruby, C++, Rust, Elixir, Scala, Lua e .NET (NuGet), a maioria recente e com poucas estrelas, além de forks de whatsmeow e wppconnect.

SDK Node.js

npm install apigratis-sdk-nodejs --save

Requer Node.js 18 ou superior. Sem dependências de runtime, com builds ESM e CJS.

SDK PHP

composer require jhowbhz/apigratis-sdk-php

Requer PHP 8.0 ou superior.

Painel apibrasil-whatsapp

O README descreve uma instalação em servidor Ubuntu 20.04+ (1 GB de RAM, 1 vCPU) com Nginx, MariaDB, PHP 7.4 e Certbot, clonando o projeto em /opt/painel-whatsapp. Há um vídeo de instalação no README. Consulte o passo a passo completo no repositório, pois ele inclui regras de firewall e configuração do PHP.

Comandos e uso

Exemplo do SDK Node.js (do README):

import { ApiBrasil } from 'apigratis-sdk-nodejs';

const api = new ApiBrasil({
  bearerToken: process.env.APIBRASIL_BEARER_TOKEN,
  deviceToken: process.env.APIBRASIL_DEVICE_TOKEN,
});

await api.whatsapp.sendText({ number: '5511999999999', text: 'Olá!' });
const empresa = await api.consulta.cnpj({ cnpj: '00000000000000' });

Os SDKs também leem as variáveis APIBRASIL_BEARER_TOKEN, APIBRASIL_DEVICE_TOKEN, APIBRASIL_SECRET_KEY e APIBRASIL_BASE_URL, e suportam login por e-mail e senha, inclusive com 2FA.

Quando usar

  • Integrar WhatsApp (MyZap) e consultas brasileiras (CPF, CNPJ, veículos, CEP) em sistemas próprios.
  • Gerenciar dispositivos de WhatsApp com um painel pronto.
  • Dar a agentes de IA acesso às APIs por meio do servidor MCP da APIBrasil.

Observações

  • A plataforma APIBrasil é um serviço comercial (créditos e assinaturas); os repositórios são clientes e utilitários, não substituem o serviço.
  • O painel apibrasil-whatsapp usa PHP 7.4, que já está fora de suporte; avalie isso antes de expor em produção.
  • Projetos de web scraping (como api-multas) dependem dos sites dos Detrans e podem quebrar sem aviso.
  • A lista de repositórios muda com frequência; confira a organização para ver novidades.
