O que é

O ZuckZapGo Private é um gateway de API de WhatsApp premium e comercial, desenvolvido pela Setup Automatizado. Ele implementa a biblioteca whatsmeow como um serviço RESTful com suporte a múltiplos dispositivos e várias sessões simultâneas.

O repositório use-zuckzapgo não contém o código-fonte do produto: é um material de apoio (README com planos, vídeos de instalação e um exemplo de stack Docker Swarm). O serviço é distribuído como imagem Docker privada e exige uma chave de licença.

Principais recursos

  • Multi-dispositivo e múltiplas sessões simultâneas, em Go, com foco em desempenho.
  • Mensagens ricas: texto, imagem, vídeo e documento.
  • Mensagens interativas: botões, listas, carrosséis, enquetes e WhatsApp Flows (botões e carrosséis nos planos Premium).
  • Entrega de eventos por webhooks (com retry), WebSockets, RabbitMQ, Amazon SQS e Redis Streams.
  • Armazenamento de mídia em S3 compatível (AWS, MinIO, DigitalOcean Spaces, Google Cloud Storage).
  • Suporte a proxy, grupos, comunidades, newsletters/canais e verificação de usuários.
  • Integração com Chatwoot e nodes de comunidade para n8n.

Pré-requisitos

  • Assinatura ativa e LICENSE_KEY emitida pelo ZuckZapGo.
  • Docker (o exemplo do README usa Docker Swarm com Portainer e uma rede externa network_public).
  • Serviços de apoio conforme o uso (por exemplo PostgreSQL, Redis, RabbitMQ, S3/MinIO).

Instalação

O repositório traz apenas um exemplo de stack "Docker Compose (Swarm) v1.4.3" para Portainer, usando a imagem setupautomatizado/zuckzapgo-private:latest. As variáveis de ambiente incluem:

  • LICENSE_KEY (chave de licença; habilita ou restringe recursos como botões e flows);
  • INSTANCE_ID e SERVER_IP (opcionais);
  • ZUCKZAPGO_ADDRESS (URL pública da instância, enviada nos eventos);
  • APP_ENV e APP_REGION.

A seção "Quick Start" do README está vazia. Para a instalação completa, use o vídeo de instalação passo a passo citado no README (YouTube) e o material recebido ao assinar. Não copie chaves de exemplo do README; use a sua própria licença.

Comandos e uso

O uso é por chamadas HTTP à API. A coleção do Postman da Setup Automatizado e a documentação da API (acessadas após a assinatura) listam os endpoints de sessão, envio de mensagens, grupos e webhooks.

Quando usar

  • Quando você quer uma API de WhatsApp com suporte comercial e recursos interativos (botões, carrosséis) sem manter um fork próprio.
  • Para operações que precisam de eventos em filas (RabbitMQ, SQS, Redis Streams) e mídia em S3.

Observações

  • Produto comercial pago: o acesso é por assinatura (planos Standard e Premium, mensais ou anuais, vendidos via Hotmart). Standard: 1 licença por IP público e instâncias ilimitadas. Premium: até 2 instalações simultâneas, com botões interativos, carrosséis e recursos Enterprise.
  • O código-fonte não está no repositório; ele guarda apenas documentação e exemplos.
  • Como toda API baseada no WhatsApp Web (whatsmeow), não é uma solução oficial da Meta, e há risco de bloqueio de números.
  • Alternativas gratuitas na mesma categoria: Evolution API e WA-AKG.
