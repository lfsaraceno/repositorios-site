O que é

A Evolution API é uma API REST pronta para produção que controla conexões de WhatsApp e permite enviar e receber mensagens a partir de qualquer sistema. Nasceu como um controlador de WhatsApp baseado no CodeChat, que usa a biblioteca Baileys, e hoje faz parte do ecossistema da Evolution Foundation.

Ela suporta dois tipos de conexão: a WhatsApp API baseada em Baileys (gratuita, usa o WhatsApp Web) e a WhatsApp Cloud API oficial da Meta (para volumes maiores, com custo por mensagem e regras da Meta).

É voltada para quem precisa integrar WhatsApp a CRMs, bots, automações (n8n, Typebot) e plataformas de atendimento como o Chatwoot.

Principais recursos

  • Conexão via Baileys (WhatsApp Web) ou WhatsApp Cloud API oficial.
  • Integrações de chatbot: Typebot, Chatwoot, OpenAI, Dify, Flowise e N8N.
  • Eventos em tempo real via WebSocket (Socket.io), RabbitMQ, Apache Kafka, Amazon SQS, NATS e Pusher.
  • Armazenamento de mídia em disco local ou S3/MinIO.
  • Transcrição opcional de áudio via OpenAI.
  • Banco PostgreSQL ou MySQL (com Prisma) e cache Redis.
  • Imagem Docker oficial evoapicloud/evolution-api.

Pré-requisitos

  • Node.js 20+ (para instalação manual).
  • PostgreSQL ou MySQL.
  • Redis (recomendado, para cache).
  • Docker, se usar a imagem pronta.

Instalação

Manual (código-fonte)

git clone git@github.com:evolution-foundation/evolution-api.git
cd evolution-api
npm install
cp .env.example .env
# edite o .env com banco, Redis e a chave de API

Configuração do banco (Prisma):

export DATABASE_PROVIDER=postgresql   # ou mysql
npm run db:generate
npm run db:deploy

Execução:

npm run dev:server                    # desenvolvimento com hot reload
npm run build && npm run start:prod   # produção

Docker

docker pull evoapicloud/evolution-api:latest
docker run -p 8080:8080 --env-file .env evoapicloud/evolution-api:latest

O README não traz um docker-compose completo com banco e Redis; consulte a documentação oficial para montar a stack.

Comandos e uso

npm run dev:server      # servidor de desenvolvimento
npm run build           # compila o projeto
npm run start:prod      # inicia a versão compilada
npm run db:generate     # gera o cliente Prisma
npm run db:deploy       # aplica as migrations

O uso no dia a dia é por chamadas HTTP à API (criar instância, ler o QR code, enviar mensagens, configurar webhooks e integrações). Os endpoints estão na documentação oficial.

Quando usar

  • Enviar e receber WhatsApp a partir de sistemas próprios, CRMs e automações.
  • Plugar WhatsApp no Chatwoot para atendimento em equipe.
  • Criar bots com Typebot, Dify ou OpenAI conectados ao WhatsApp.

Observações

  • A conexão Baileys usa o WhatsApp Web e não é oficial; há risco de bloqueio de números e limitações em comparação com a Cloud API.
  • A licença é Apache 2.0 com condições extras (preservar logo/copyright e aviso de uso). Leia o arquivo LICENSE antes de uso comercial ou revenda.
  • O projeto coleta telemetria anônima (rotas usadas e versão da API).
  • O repositório mudou de dono: antes era EvolutionAPI/evolution-api.
