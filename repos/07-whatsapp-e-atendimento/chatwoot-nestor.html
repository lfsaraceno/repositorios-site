O que é

O chatwoot-nestor é um fork do Chatwoot mantido por jmelati, criado em outubro de 2024. Ele é, por sua vez, um fork de AntonionniGomes/chatwoot-mod, uma versão modificada do Chatwoot. O repositório não tem descrição própria e o README é o mesmo do Chatwoot original.

O que difere do Chatwoot original

O README não documenta as diferenças. Pelo histórico de commits (branch develop, último push em setembro de 2024) e pelos arquivos alterados, as mudanças se concentram em uma integração com a Unoapi (uma API de WhatsApp):

  • UnoapiConfiguration.vue: tela de configuração da Unoapi no painel (a maioria dos commits).
  • unoapi_webhook_setup_service.rb: serviço Ruby que prepara o webhook da Unoapi.
  • inboxMgmt.json: textos de tradução da gestão de caixas de entrada.
  • Um ajuste no Makefile.

Todos os commits têm a mensagem genérica "Update ...", então não há changelog explicando cada alteração. Trate o fork como uma variação comunitária e pequena do Chatwoot, sem releases nem documentação própria.

Principais recursos

  • Todos os recursos do Chatwoot (caixa omnichannel, equipes, etiquetas, automações, relatórios, API e webhooks).
  • Configuração de Unoapi dentro das caixas de entrada de WhatsApp.
  • Criação do webhook da Unoapi por um serviço dedicado.
  • Textos traduzidos para a nova configuração.

Pré-requisitos

  • Os mesmos do Chatwoot: Docker/Docker Compose (ou ambiente Ruby/Node), Postgres e Redis.
  • Uma instância da Unoapi, caso queira usar a integração.

Instalação

O repositório não traz instruções próprias. O README é o do Chatwoot e aponta para a documentação oficial (chatwoot.com/help-center) e para os métodos de deploy do projeto original (Heroku, DigitalOcean Kubernetes e a página de deploy).

O repositório não cita nenhuma imagem Docker publicada para este fork, então o caminho seria construir a partir do código-fonte, seguindo os guias do Chatwoot. Veja chatwoot.md para a instalação padrão via Docker.

Comandos e uso

Não há comandos específicos do fork documentados. Depois de subir a instância, a configuração da Unoapi deve aparecer nas configurações da caixa de entrada de WhatsApp (componente UnoapiConfiguration.vue).

Quando usar

  • Quando você já usa a Unoapi e quer a configuração dela embutida no Chatwoot.
  • Para estudar como a integração foi feita em um fork pequeno.

Observações

  • Projeto pequeno, sem releases e sem descrição; último push em 23/09/2024. Provavelmente está defasado em relação ao Chatwoot atual.
  • Para produção, prefira o Chatwoot oficial, que recebe correções de segurança.
  • A análise das diferenças foi feita pelos nomes de arquivos e commits, não por um diff completo.
