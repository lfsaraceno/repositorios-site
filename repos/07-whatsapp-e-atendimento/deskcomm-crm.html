O que é

O DeskcommCRM ("comercial de mesa") é um sistema operacional de vendas feito no Brasil, com README e documentação em português. Ele reúne num só lugar o atendimento pelo WhatsApp, o funil de vendas (kanban) e agentes de IA que operam o CRM de verdade: atendem o cliente, qualificam, movem o lead no funil, disparam automações e sabem a hora de passar para um humano.

Começou como CRM de e-commerce, com integração Nuvemshop, e hoje atende clínicas, imobiliárias, infoprodutos, agências e prestadores de serviço. O vocabulário muda por funil: o lead vira Paciente, Comprador ou Cliente, e "ganho" vira Pago, Agendado ou Fechado.

Roda no seu servidor (VPS com Docker), com banco no Supabase e a chave de IA que você escolher. Não tem mensalidade nem versão paga com recursos travados. É multiempresa (multi-tenant), com isolamento por RLS testado no CI, e foi pensado para a LGPD.

Principais recursos

  • Agentes de IA com base de conhecimento própria por empresa (RAG), skills executadas durante o atendimento, memória, análise de sentimento, passagem auditada da IA para um humano e teto de gasto por organização.
  • Follow-up automático de conversas que esfriaram, com tempo adaptativo, e um Radar que mostra quem está para ficar sem resposta.
  • Agentes que se aprimoram: conversas resolvidas viram conhecimento, e a IA sugere melhorias para si mesma ("Propostas"), sempre com aprovação humana.
  • WhatsApp de duas formas: por QR code (WAHA, vários números, com proteção contra banimento) ou pelo canal oficial da Meta (Cloud API, com templates).
  • IA à sua escolha: OpenRouter, Anthropic ou OpenAI, trocável pela tela e separada por parte do sistema.
  • Webhooks e automações: recebe leads de landing pages, formulários, Zapier ou n8n, e monta regras QUANDO/SE/ENTÃO que movem o lead, atribuem atendente ou enviam WhatsApp.
  • Gestão do atendimento: papéis e permissões (RBAC), fila com rodízio, transferências auditadas e roteamento por intenção.
  • Servidor MCP interno, para agentes externos operarem o CRM (o MCP público está no roadmap).
  • Atualização pela tela, com um clique, com backup automático e volta para a versão anterior se der problema.

Pré-requisitos

Item Observação
VPS com Docker 4 GB de RAM recomendados. Funciona em x86 e em ARM64 (ex.: Oracle Ampere). O projeto tem parceria com a HostGator, mas qualquer VPS serve
Domínio Um registro A apontando para o IP da VPS (ex.: crm.suaempresa.com.br)
Supabase Conta grátis em supabase.com: 3 chaves + connection string do Session pooler. O instalador também pode criar o projeto sozinho com um SUPABASE_ACCESS_TOKEN
Chave de IA OpenRouter, Anthropic ou OpenAI
WhatsApp O seu número, conectado por QR code no onboarding, ou o canal oficial da Meta

Não precisa instalar Node nem compilar nada na VPS: a imagem do app vem pronta, e o instalador oferece instalar o Docker se faltar.

Instalação

Na VPS (caminho principal)

Conecte na VPS. No Windows, pelo PowerShell:

ssh -p PORTA root@SEU_IP

Já dentro da VPS:

git clone https://github.com/melgarafael/DeskcommCRM.git
cd DeskcommCRM
bash hostgator-setup-kit/install.sh

O instalador pergunta só o que é seu (domínio, chaves, senha do admin) e valida cada resposta antes de seguir. Depois, ele gera os segredos, aplica o schema do banco, cria o admin, sobe tudo com HTTPS automático e instala o cron das automações e o agente de atualização. Pode rodar de novo sem quebrar nada.

Modo não interativo: copie o .env.hostgator.example para .env, preencha e rode bash hostgator-setup-kit/install.sh --yes.

VPS que já tem proxy reverso (Coolify, Dokploy, CapRover, Hostinger): o instalador detecta o proxy nas portas 80/443 e publica o CRM através dele. Veja o README do kit.

Instalar com ajuda de um agente de IA

O repositório traz guias que funcionam no Claude Code, Codex, Cursor, OpenCode e Antigravity. Para instalá-los no seu computador:

curl -fsSL https://raw.githubusercontent.com/melgarafael/DeskcommCRM/main/scripts/instalar-guias.sh | bash

Depois, numa sessão nova, diga "quero instalar o CRM na minha VPS" ou chame /deskcomm-instalar no Claude Code. Para remover os guias, rode o mesmo comando com bash -s -- --remover.

Primeiro acesso

Abra https://<seu-domínio> (o cadeado do HTTPS leva cerca de 1 minuto para aparecer), entre com o admin e, no onboarding, escaneie o QR code com o WhatsApp. A verificação em duas etapas é opcional e fica em Configurações › Segurança.

Comandos e uso

Atualizar: quando sai versão nova, o menu lateral mostra "Nova versão". Clique e acompanhe em Configurações → Atualização; o backup é automático. Pelo terminal:

bash hostgator-setup-kit/update.sh       # atualiza para a última versão publicada, com backup antes

Scripts do kit (na pasta do projeto, dentro da VPS):

bash hostgator-setup-kit/backup.sh          # backup do banco + sessões do WhatsApp
bash hostgator-setup-kit/restore.sh         # restaura um backup (só em banco vazio)
bash hostgator-setup-kit/healthcheck.sh     # diagnóstico de todos os serviços
bash hostgator-setup-kit/reset-password.sh  # redefine a senha de um usuário
bash hostgator-setup-kit/reset-mfa.sh       # remove o MFA de quem perdeu o celular
bash desinstalar_docker.sh                  # remove só os containers, volumes e redes deste projeto

Receber leads de fora: em Webhooks → Receber dados, crie uma fonte e use o endereço /api/v1/webhooks/in/<token> para enviar leads por POST (JSON ou formulário) a partir de landing pages, n8n ou Zapier.

Telas principais: Inbox (você e a IA lado a lado), Radar, Kanban, Contatos, Funis, Agentes, Conhecimento (RAG), Follow-ups, Webhooks, Desempenho, Evolução da IA, Audit Log e LGPD.

Quando usar

  • Atender e vender pelo WhatsApp com IA sem pagar mensalidade de Kommo, Octadesk ou similares.
  • Clínicas, imobiliárias, infoprodutores, lojas Nuvemshop e prestadores de serviço que vendem pelo chat.
  • Agências que querem oferecer CRM com IA para clientes: há guia de white-label para trocar a marca e revender.
  • Como alternativa mais completa de vendas a montar à mão Chatwoot + Evolution API + automações.

Observações

  • WhatsApp por QR code não é oficial. O projeto tem proteções contra banimento (ritmo de envio, intervalos aleatórios, janela de horário), mas o risco de bloqueio do número existe. Para volume alto, use o canal oficial da Meta.
  • LGPD: quem hospeda a instância é o controlador dos dados (clientes, conversas, pedidos), com as obrigações legais que isso traz.
  • Backup é com você: o plano grátis do Supabase não faz backup sozinho. Agende o backup.sh no cron todo dia.
  • Telemetria (Sentry): o instalador pergunta. Se aceitar, envia relatórios de erro com dados pessoais mascarados. Para desligar, coloque SENTRY_DSN=off no .env.
  • Suporte é da comunidade, sem SLA, via Issues e Discussions.
  • A tabela de tecnologias do README cita o WAHA Plus. Confira na documentação do WAHA se a sua configuração exige licença paga.
  • O README tem um link de afiliado da HostGator. A instalação funciona em qualquer VPS com Docker.
  • Projeto jovem (criado em abr/2026) e muito ativo: versão v1.86.0 em out/2026. Leia o CHANGELOG.md antes de atualizar.
