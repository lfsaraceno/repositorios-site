O que é

O WA-AKG transforma contas de WhatsApp em uma API REST programável, com um painel web para gerenciar tudo. Usa a biblioteca @whiskeysockets/baileys para a conexão (QR code) e o Prisma para o banco de dados (MySQL ou PostgreSQL).

É pensado para quem quer um gateway pronto, com interface, para criar bots, automações e integrações de atendimento sem montar tudo do zero. A versão citada no README é a 1.6.2, e há uma branch beta com recursos experimentais.

Principais recursos

  • Gerenciamento de múltiplas sessões de WhatsApp, conectadas por QR code.
  • Agendador de mensagens com suporte a mídia (imagem, vídeo, documento).
  • Broadcast com mecanismos anti-banimento (atrasos aleatórios de 10 a 30 s e envio em lotes).
  • Auto-resposta por palavras-chave, com contexto (grupo, privado ou todos) e anexos.
  • Controle de acesso com whitelist e blacklist para comandos do bot e auto-respostas.
  • Webhooks em tempo real (mensagens, conexão, status e grupos).
  • Gerador de figurinhas com remoção de fundo (integração remove.bg).
  • Nodes oficiais de comunidade para n8n (n8n-nodes-wa-akg) e documentação OpenAPI/Swagger com mais de 109 endpoints.

Pré-requisitos

  • Node.js 20+ (22 recomendado).
  • MySQL ou PostgreSQL.
  • Git.
  • PM2 instalado globalmente (npm install -g pm2) para produção.

Instalação

Instalação manual

git clone https://github.com/mrifqidaffaaditya/WA-AKG.git
cd WA-AKG
npm install
cp .env.example .env
# edite o .env: DATABASE_URL, AUTH_SECRET, PORT etc.
npm run db:push
npm run make-admin admin@example.com password123

Desenvolvimento:

npm run dev

Produção com PM2 (recomendado)

Opção A, script automático que checa a configuração, instala dependências, sincroniza o banco, compila e inicia/recarrega o PM2:

./start.sh

Opção B, manual:

npm run build
pm2 start ecosystem.config.js
pm2 startup   # copie e execute o comando que ele imprimir
pm2 save

Docker (alternativa)

O README também descreve um deploy com Docker Compose: copie .env.example para .env e ajuste DATABASE_URL para o container do banco. Veja os detalhes no README do repositório.

Comandos e uso

pm2 status            # estado do processo
pm2 logs wa-akg       # logs
pm2 restart wa-akg    # reinicia
pm2 stop wa-akg       # para

Depois de instalar, entre no painel com o SuperAdmin criado, adicione uma sessão e leia o QR code. A documentação Swagger fica em /docs na própria aplicação.

Quando usar

  • Ter um gateway de WhatsApp com painel próprio, de código aberto e fácil de hospedar.
  • Automatizar respostas, agendamentos e disparos controlados.
  • Integrar WhatsApp a n8n ou a qualquer sistema por webhooks.

Observações

  • Usa Baileys (WhatsApp Web, não oficial): risco de bloqueio de números, principalmente em disparos em massa.
  • Troque a senha de exemplo do make-admin (password123) por uma senha forte.
  • O próprio README recomenda PM2 em vez de Docker para produção.
  • Há uma branch beta e pré-releases com recursos experimentais.
