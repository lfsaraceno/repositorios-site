Anatomy

Skill que explica um conceito técnico construindo um objeto físico que funciona como ele: ilustrações isométricas interativas, com dezenas de peças, em SVG, WebGL e 3D, que se autoverificam no navegador.

O que é

Você pede uma figura que explique uma ideia técnica, e o Anatomy faz o agente inventar uma máquina cujo funcionamento é o próprio conceito. Dois exemplos do README:

  • uma chave de cache que pula o trabalho quando nada mudou vira uma fechadura de pinos que só gira quando todos os pinos batem;
  • um contexto de GPU servindo vários canvases vira um plotter com um único cabeçote que visita 16 poços.

Depois, o agente monta o objeto com dezenas de peças sólidas e sombreadas. Coloca tudo num card com título, dica e um mostrador ao vivo, faz as peças se moverem com o mouse e o teclado e confere o próprio trabalho dando zoom em cada junta. Todo número que aparece na figura sai do mesmo modelo que move as peças.

Funciona no Claude Code, Antigravity, OpenCode, Codex e MiniMax Code.

Principais recursos

Tipo de figura O que é Exemplos
SVG O núcleo: peças isométricas com sombreamento em quatro tons, num card com mostrador e movimento suave. Sai como página HTML, arquivo .svg avulso ou componentes React/Next.js dial-indicator, desk-computer, arcade-cabinet, test-rig
SVG + WebGL Para o que linhas não desenham: fogo, exaustão, água, cáusticas, luz, brilho, vapor. O shader roda entre um SVG de fundo e um da frente, na mesma câmera isométrica raptor-engine, ripple-tank
3D (beta) Peças que giram em 3D de verdade: um dial que roda, dedos que dobram, uma peça que se solta e cai turning-dial
  • Kit de desenho próprio (kit/): câmera isométrica, sólidos, peças redondas em qualquer eixo, tubos e cabos, camada WebGL, runtime 3D e componentes React. Só usa módulos nativos do Node.
  • Verificação automática:
    • kit/audit.mjs prova a geometria: nada atravessa nada, toda ponta está presa e a ordem de profundidade está certa;
    • scripts com Chrome headless tiram screenshots, closes e folhas de contato em câmera lenta, e reprovam linhas que terminam no ar.
  • Impressão: gera PDFs A4 (pôster, desenho técnico e explicação detalhada) a partir de um sheet.mjs.
  • Tema claro (o principal) e escuro. Com movimento reduzido, a figura fica parada.
  • Galeria da comunidade: o agente pode enviar a sua figura para a galeria.

Pré-requisitos

  • Um agente suportado: Claude Code, Antigravity, OpenCode, Codex ou MiniMax Code.
  • Node.js 20.10+, sem nada para instalar com npm.
  • Chrome ou Chromium, para as verificações. Use CHROME_PATH se o executável estiver num lugar incomum.
  • React 18+, só para a saída em React.
  • A CLI npx skills pede Node 22.20+.

Instalação

Com a CLI npx skills (ver Vercel Skills CLI):

npx skills add wheresryan22/anatomy -g -a claude-code    # Claude Code, para o seu usuário
npx skills add wheresryan22/anatomy -g -a antigravity    # ou: opencode, codex, minimax-code
npx skills add wheresryan22/anatomy                      # só neste projeto

Com git (exemplo para o Claude Code):

git clone https://github.com/wheresryan22/anatomy.git ~/.claude/skills/anatomy

Para atualizar, rode git pull dentro da pasta. As pastas dos outros agentes são ~/.gemini/antigravity/skills/, ~/.config/opencode/skills/, ~/.agents/skills/ (Codex) e ~/.minimax/skills/. Também dá para baixar o ZIP e renomear a pasta para anatomy.

O Claude Code reconhece a skill na sessão aberta. Se a pasta skills não existia quando a sessão começou, rode /reload-skills.

Comandos e uso

/anatomy explain how a token bucket rate limiter works, interactive

No Codex, use $anatomy. A skill também ativa sozinha quando você pede uma ilustração isométrica, uma figura explicativa para docs, blog ou landing page, ou um explicador interativo.

Outros pedidos de exemplo:

/anatomy a figure for our Next.js docs on database connection pooling: a pool of 10 connections, requests borrow one and give it back, and when all 10 are busy new requests wait in a queue. A React component plus a static HTML preview, dark theme.
/anatomy an isometric SVG explaining how a CDN edge cache works, cache hit vs miss, TTL of 60 s, for a dark landing page. Just the SVG file and a PNG preview.
/anatomy a Bunsen burner on a lab bench: opening the air collar turns the lazy yellow flame into a roaring blue cone. WebGL for the flame, one HTML file, dark theme.

Dicas do autor para melhores figuras:

  1. Diga a ideia, não o desenho, com os números reais: tamanhos, quantidades, taxas e limites. Inventar o objeto é a maior parte do trabalho, e a skill faz isso melhor do que uma descrição de caixas e setas.
  2. Ou diga o objeto, se já sabe qual máquina quer, e o que deve se mexer.
  3. Diga onde a figura vai morar: HTML avulso, arquivo SVG ou componente React/Next.js, e se o tema é claro ou escuro.

O resultado é código-fonte seu: um script de build em Node e a página que ele gera, ou, em React, módulos de geometria, um server component para a arte estática e um client component para o movimento.

Exemplos do repositório (os .html já gerados vêm no repositório):

node examples/dial-indicator/build.mjs            # o menor, ~300 linhas
node examples/raptor-engine/build.mjs --light     # motor Raptor 2; o build leva alguns minutos
node examples/raptor-engine/build.mjs --audit     # roda a auditoria de geometria
node scripts/print.mjs examples/raptor-engine/sheet.mjs --format all   # três PDFs A4
node scripts/capture.mjs page.html --out shots/page.png                # screenshot pelo Chrome headless

Quando usar

  • Figuras explicativas para documentação, posts técnicos e landing pages: cache, filas, pools de conexão, rate limiting, CDN.
  • Explicadores interativos de máquinas e instrumentos, como motor, máquina de espresso ou bico de Bunsen.
  • Comparação: o motionmaxxing faz vídeos de marca em motion graphics. O Anatomy faz ilustrações técnicas interativas, que vivem dentro da página. Para animações de interface, veja as Emil Kowalski Skills.

Observações

  • Lento de propósito. Uma figura leva uma sessão longa: lista de peças, geometria, auditoria e closes de cada junta nos dois temas. Uma auditoria 3D completa leva de 15 a 20 minutos para 30 peças. Isso consome bastante tempo e tokens.
  • Limites: não é uma biblioteca de gráficos (não tem eixos nem séries). Desenha máquinas, instrumentos, ferramentas e móveis, e não pessoas nem mapas exatos. Ideias sem um mecanismo para construir saem mais fracas.
  • O modo 3D é beta. Só foi provado no exemplo e numa figura de teste. A mão de estresse com 380 peças rodou a cerca de 20 fps.
  • Codex: as verificações abrem o Chrome headless, e o sandbox pode bloquear. Prefira aprovar caso a caso (approval_policy = "on-request"). O --sandbox danger-full-access tira todos os limites da sessão; o próprio README recomenda usá-lo só em projetos confiáveis.
  • Galeria da comunidade: ao pedir "publish this figure to the Anatomy community gallery", o agente abre um pull request público no repositório anatomy-community com a sua conta do GitHub. Ele mostra o que vai enviar e pede confirmação antes; revise antes de aceitar.
  • A CLI npx skills copia o repositório inteiro, com os exemplos (cerca de 10 MB).
  • Projeto novo (out/2026). O último release é o v1.1.0.
