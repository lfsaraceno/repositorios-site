O que é

O Motion é uma biblioteca de animação para interfaces web, com pacotes próprios para React, JavaScript puro e Vue. É o novo nome do Framer Motion: em React, importa-se de motion/react em vez de framer-motion.

Usa um motor híbrido, que combina JavaScript com as APIs nativas do navegador para animações a 120 fps aceleradas pela GPU. Vem com gestos, springs, transições de layout, efeitos ligados à rolagem e timelines. É o motor de animação dos sites feitos no Framer.

Para agentes de IA, tem uma skill /motion gratuita, um servidor MCP com a documentação e um llms.txt.

Principais recursos

  • API simples em React (<motion.div animate={{ x: 100 }} />), JavaScript (animate()) e Vue (motion-v).
  • Springs, gestos (hover, tap, drag), transições de layout e animações de entrada e saída.
  • Animações ligadas à rolagem e timelines.
  • TypeScript, tree-shaking e pacote pequeno.
  • Mais de 450 exemplos oficiais, 110 com tutorial passo a passo.
  • Skill /motion (MIT) e MCP https://mcp.motion.dev, gratuitos e sem conta.
  • Motion Studio: editor visual de keyframes, easing e springs numa timeline, que aplica o resultado no código.

Pré-requisitos

  • Um projeto React, JavaScript ou Vue com npm.

Instalação

npm install motion      # React / JavaScript
npm install motion-v    # Vue

Para agentes (instala a skill /motion e configura os servidores MCP no Claude Code, Cursor, Amp, OpenCode, Gemini CLI e Copilot):

npx motion-ai

Comandos e uso

React:

import { motion } from "motion/react"

function Component() {
    return <motion.div animate={{ x: 100 }} />
}

JavaScript:

import { animate } from "motion"
animate("#box", { x: 100 })

No agente, depois do npx motion-ai, peça a animação normalmente ou chame /motion.

Quando usar

  • Animações de interface em React (modais, listas, layout que muda, gestos).
  • Microinterações com springs naturais.
  • Projetos que já usavam Framer Motion (troque o import para motion/react).

Observações

  • A biblioteca é MIT. O Motion+ é pago (licença pessoal vitalícia ou plano anual por assento) e dá exemplos premium, APIs extras, editor de transições e recursos de IA a mais. As páginas pagas aparecem marcadas no llms.txt.
  • Relacionados no catálogo: o GSAP é mais forte em sequências longas e fora do React; o Motion Design Skill ensina os princípios de tempo e easing; as Emil Kowalski Skills cobrem animação de interface com bom gosto.
