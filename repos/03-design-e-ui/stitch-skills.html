O que é

O Stitch é a ferramenta do Google que gera telas de interface a partir de texto ou imagem. Estas skills ligam o agente de código ao Stitch pelo servidor MCP dele, nos dois sentidos: do código para o design e do design para o código.

Seguem o padrão aberto Agent Skills e funcionam no Codex, Antigravity, Gemini CLI, Claude Code, Cursor e OpenCode (este com instalação manual). São organizadas em três plugins.

Principais recursos

stitch-design

  • Gerar telas novas, editar telas e criar variantes (generate-design).
  • Converter código frontend existente em design no Stitch (code-to-design).
  • Extrair um DESIGN.md do código (extract-design-md) e aplicar design systems às telas (manage-design-system).
  • Extrair HTML estático de um app rodando e enviar arquivos ao Stitch.

stitch-build

  • Converter telas em componentes React (react-components) ou React Native.
  • Dashboards React + Vite (react-vite-dashboard).
  • Orientação para shadcn/ui.
  • Vídeos de apresentação do projeto com Remotion.

stitch-utilities

  • Melhorar prompts vagos de UI (enhance-prompt).
  • Gerar DESIGN.md (design-md) e um DESIGN.md premium sem cara genérica (taste-design).
  • Montar o SITE.md do projeto (site-md) e gerar sites de várias páginas com validação (stitch-loop).

Pré-requisitos

  • Servidor Stitch MCP configurado e rodando no agente, com as credenciais do guia de configuração.
  • Node (npx) para a instalação.

Instalação

Claude Code (instala no projeto atual):

npx plugins add google-labs-code/stitch-skills --scope project --target claude-code

Cursor:

npx plugins add google-labs-code/stitch-skills --scope workspace --target cursor

Codex:

codex plugin marketplace add google-labs-code/stitch-skills --ref main

Depois, instale os plugins stitch-design, stitch-build e stitch-utilities que quiser.

Skills avulsas:

npx skills add google-labs-code/stitch-skills

As skills dependem umas das outras: na instalação avulsa, inclua as dependências.

Comandos e uso

Exemplos de pedidos (do README):

"Make a browse tab for a mobile app for romance and date night ideas."
"Scan /src and extract the design system into .stitch/DESIGN.md."
"Convert all screens in Stitch project projects/123 to React components."
"Build a 5-page portfolio website with Stitch."

Quando usar

  • Gerar e iterar telas no Stitch e trazer o resultado como código React.
  • Levar um app existente para o Stitch e redesenhar em cima dele.
  • Padronizar o design system de um projeto num DESIGN.md.

Observações

  • Sem o Stitch MCP configurado, as skills não funcionam.
  • O README avisa que não é um produto oficialmente suportado pelo Google.
  • No OpenCode, as skills com nome stitch::… precisam ser renomeadas para kebab-case.
  • Relacionados no catálogo: o Awesome DESIGN.md reúne arquivos DESIGN.md de sites conhecidos; o Taste Skill também dá direção de arte ao agente para evitar o visual genérico.
