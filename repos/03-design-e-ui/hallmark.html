Hallmark

Skill de design para Claude Code, Codex, Cursor e OpenCode que evita páginas com "cara de IA". Sorteia três temas de um catálogo de 50, monta a página em torno do que o visitante veio fazer e confere o resultado num navegador real.

O que é

O Hallmark é uma skill da Together AI que guia o agente na criação de páginas web. Ela funciona em três camadas de regras:

  • Piso: nunca é violado. Inclui contraste, foco visível, movimento reduzido, layout de celular e nada de fatos inventados.
  • Reflexos: barram os vícios típicos de IA, como um rótulo em caixa-alta acima de cada título, uma palavra colorida na manchete, cadastro de e-mail no fim de toda página e formulário que agradece sem enviar nada. Dá para quebrar uma regra com justificativa registrada.
  • Acabamento: detalhes de capricho, que não bloqueiam a entrega.

No fim, um revisor com contexto limpo dá a palavra final.

Principais recursos

  • 50 temas. Cada tema é um "material" (papel, tipografia, cor, superfícies, componentes) com a foto de uma página pronta. O tema não define o conteúdo nem a ordem, então dois pedidos no mesmo tema geram páginas diferentes.
  • Página construída a partir da tarefa. Página de agendamento agenda, loja vende, newsletter inscreve. A ação fica onde a categoria espera, e a página termina nela.
  • Modo custom: sem temas, só com as regras e uma direção curta.
  • Seu produto real: aponte para uma URL, um servidor de desenvolvimento ou um app, e ele captura as telas sozinho.
  • Fotos reais: 755 fotos de licença aberta da Wikimedia Commons, com crédito na página.
  • Redesign e auditoria:
    • /hallmark redesign <caminho> reconstrói a página e mantém conteúdo, links, campos e handlers;
    • /hallmark audit <caminho> só gera um relatório.
  • sloplint: lint que confere a página em oito larguras de tela.

Pré-requisitos

  • Node.js 18+.
  • Para as verificações no navegador (screenshots, sloplint --render): puppeteer-core e o Chrome. Sem eles, só as verificações estáticas rodam.

Instalação

npx skills add nutlope/hallmark -g        # todos os projetos
npx skills add nutlope/hallmark           # só o projeto atual
npx skills add nutlope/hallmark -g --agent claude-code   # só um agente
npm i -g puppeteer-core                   # opcional, para as verificações no navegador

Como plugin do Claude Code:

/plugin marketplace add nutlope/hallmark
/plugin install hallmark@hallmark

Assim instalado, o comando vira /hallmark:hallmark. A partir de um clone, node skills/hallmark/scripts/install.mjs valida e instala, e install-hook.mjs adiciona uma checagem do Piso a cada edição no Claude Code.

Comandos e uso

/hallmark landing page para uma clínica odontológica com agendamento online
/hallmark custom portfólio de um estúdio de arquitetura
/hallmark redesign ./src/app
/hallmark audit ./index.html

No redesign, diga keep the layout para só trocar o estilo, ou polish para corrigir apenas os vícios.

Lint de qualquer página:

node skills/hallmark/scripts/sloplint.mjs <arquivo-ou-pasta> --render

Se a skill não disparar sozinha, peça explicitamente: use hallmark to build ....

Quando usar

  • Criar landing pages e sites que não pareçam gerados por IA.
  • Auditar ou redesenhar uma página existente sem perder links e formulários.
  • Comparação no catálogo:
    • o Impeccable, o Taste Skill e o UI UX Pro Max também combatem o visual genérico. O Hallmark cita todos como inspiração;
    • o diferencial do Hallmark é o catálogo de temas e o lint num navegador real;
    • as skills do Emil Kowalski focam em animação e detalhes de interface.

Observações

  • Fotos: a biblioteca só aponta para imagens da Wikimedia Commons (CC0, domínio público, CC BY e CC BY-SA), e a skill credita cada uma. Imagens CC BY-SA exigem que adaptações usem a mesma licença.
  • Nada inventado: a skill pede fotos, screenshots e números reais antes de começar. Ela não preenche a página com dados falsos.
  • Não mexe em design pronto a menos que você peça (redesign ou audit).
  • O hook de edição mexe na configuração do Claude Code. Instale só se quiser a checagem a cada edição.
  • Sem releases no GitHub; atualize reinstalando com npx skills add.
