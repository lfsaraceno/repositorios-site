O que é

Uma skill do designer Damir Sokolovsky, criador da série "Unslopping" no X. Ela pega telas feitas no "vibe coding", que todo mundo reconhece como geradas por IA, e as redesenha com caráter próprio.

Antes de editar qualquer coisa, a skill audita a tela e propõe uma direção, para você ajustar cedo. Se a tela já estiver boa, ela diz isso e sugere só refinamentos. Funciona com Next.js, React, Vue, Svelte, Tailwind ou HTML/CSS puro, em dashboards, apps e landing pages, e até num site no ar, só com o link.

Principais recursos

  • Auditoria: lista cada sinal de "slop" e onde ele está.
  • Direção: caráter, "mundo" visual, os um ou dois momentos que levam a cor e um detalhe assinatura, tudo tirado do seu produto.
  • Passadas em ordem: espaçamento, cor, ícones, copy, tipografia, layout, detalhes, visuais e movimento.
  • Visuais: mostra o produto em vez de uma bolha brilhante genérica. Quando o hero precisa de uma cena ou objeto, gera a imagem por um serviço (fal, Replicate, OpenAI, Higgsfield), mostrando o prompt e pedindo confirmação antes de cada geração paga.
  • Vídeo "story": um vídeo quadrado de menos de 10 s da tela se transformando, pronto para postar.
  • Site ao vivo: tira um snapshot de uma URL e trabalha sobre ele.

Pré-requisitos

  • Claude Code, Codex ou Google Antigravity.
  • Para snapshot de site ao vivo e vídeo: Playwright com Chromium no projeto.
  • Para o vídeo: ffmpeg no PATH.
  • Opcional: conta num serviço de geração de imagem, conectado como MCP.

Instalação

Claude Code (plugin)

claude plugin install unslop --marketplace heydamir/unslop

Em versões antigas do Claude Code, sem --marketplace:

claude plugin marketplace add heydamir/unslop
claude plugin install unslop@heydamir

Adicione --scope local para um projeto só, ou --scope project para todo o time (e faça commit do .claude/settings.json). Depois abra uma sessão nova ou rode /reload-plugins. Para atualizar: claude plugin update unslop@heydamir.

Se você copiou a skill antes para ~/.claude/skills/ ou .claude/skills/, apague a cópia; senão o /unslop continua rodando a versão antiga.

Codex

$skill-installer install https://github.com/heydamir/unslop/tree/main/skills/unslop

Ou copie skills/unslop para ~/.agents/skills/ (ou .agents/skills/ do projeto).

Antigravity

Copie skills/unslop para ~/.gemini/config/skills/ (ou .agents/skills/ do projeto).

Snapshot e vídeo (opcional)

npm install -D playwright
npx playwright install chromium

Comandos e uso

/unslop this dashboard
/unslop the hero of https://example.com
/unslop my landing page and make the story video so I can post it

Use /unslop:unslop se outra skill já tiver o nome /unslop. No Codex, $unslop. Também dá para pedir com suas palavras. O repositório traz duas telas de exemplo em examples/ para testar.

Quando usar

  • O app ou a landing page ficou com a cara genérica de site feito por IA.
  • Antes de lançar, para dar identidade visual a um MVP.
  • Para corrigir uma tela específica sem redesenhar o produto inteiro.

Observações

  • Licença CC-BY-4.0: pode usar, alterar e compartilhar, inclusive comercialmente, desde que dê crédito a Damir Sokolovsky e linke o repositório.
  • Imagens podem custar: a geração de visuais usa serviços pagos, sempre com confirmação antes.
  • O autor também vende o serviço manual ("Hire the unslopper").
  • Relacionados no catálogo: o Impeccable tem um vocabulário de comandos de design e detector de antipadrões. O Taste Skill e o UI UX Pro Max orientam o design desde o início. O Unslop é focado em consertar uma tela que já existe.
