O que é

O UI UX Pro Max é uma skill de IA que dá ao seu agente conhecimento de design para construir interfaces profissionais. O destaque da v2.0 é o Gerador de Design System: um motor de raciocínio que analisa o pedido (por exemplo, "landing page para um spa de beleza") e devolve, em segundos, uma recomendação completa e adequada ao setor.

Por trás há bases pesquisáveis de estilos, paletas, pares de fontes, padrões de landing page, gráficos e diretrizes de UX, consultadas por um script Python (search.py) que usa só a biblioteca padrão. A saída inclui anti-padrões a evitar e um checklist de pré-entrega (contraste, foco, prefers-reduced-motion, responsividade).

Funciona com dezenas de agentes (Claude Code, Cursor, Windsurf, Codex CLI, Gemini CLI, Copilot e outros).

Principais recursos

  • Gerador de design system: padrão de página, estilo, paleta, tipografia, efeitos e anti-padrões.
  • Bases pesquisáveis: 192 categorias de produto e paletas, 79 estilos de UI, 74 combinações de fontes e 34 padrões de landing page (números do README).
  • Regras de raciocínio por setor (192) e ranking BM25.
  • Busca por domínio (style, typography, chart, ux, icons) e por stack (React, HTML + Tailwind, JavaFX e outras).
  • Checklist de entrega com acessibilidade e responsividade (375, 768, 1024 e 1440 px).
  • Instalação por plugin, CLI uipro ou global, para mais de 20 assistentes.
  • Ativação automática ao pedir trabalho de UI/UX.

Pré-requisitos

  • Python 3.x para o script de busca (apenas biblioteca padrão; os scripts não instalam nada nem fazem chamadas de rede). Verifique com python3 --version.
  • Node.js/npm se for usar a CLI uipro.
  • Os agentes não devem instalar software por conta própria; o README instrui a pedir ao usuário.

Instalação

Plugin do Claude Code

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

CLI (recomendada)

npm install -g ui-ux-pro-max-cli
cd /caminho/do/seu/projeto
uipro init --ai claude

Troque claude por cursor, windsurf, antigravity, copilot, codex, gemini, opencode, universal ou all, entre outros listados no README.

Instalação global (todos os projetos)

uipro init --ai claude --global

O pacote npm é ui-ux-pro-max-cli e instala o comando uipro. Versões antigas do uipro-cli estão defasadas e não devem ser usadas.

Comandos e uso

Nos agentes suportados, a skill ativa sozinha. Basta pedir, por exemplo:

Build a landing page for my SaaS product

Gerar um design system direto pelo script:

python3 .claude/skills/ui-ux-pro-max/scripts/search.py "beauty spa wellness" --design-system -p "Serenity Spa"

Buscar por domínio ou por stack:

python3 .claude/skills/ui-ux-pro-max/scripts/search.py "glassmorphism" --domain style
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "form validation" --stack react

Gerenciar a instalação:

uipro update            # atualiza os arquivos da skill
uipro init --dry-run    # pré-visualiza sem escrever
uipro uninstall --ai claude

No Windows, o README mostra python3; se o seu Python se chama python, ajuste o comando.

Quando usar

  • Começar uma landing page, dashboard ou app com direção visual coerente.
  • Escolher paleta, tipografia e estilo adequados ao tipo de negócio.
  • Revisar a UI com um checklist de acessibilidade e responsividade.

Observações

  • O caminho dos scripts muda por ferramenta (por exemplo .continue/skills/, .factory/skills/, .amazonq/skills/).
  • Algumas contagens do README (estilos, paletas) diferem entre trechos e versões.
  • O projeto aceita doações e divulga outros projetos dos autores no README.
