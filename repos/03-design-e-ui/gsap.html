O que é

O GSAP (GreenSock Animation Platform) é uma das bibliotecas de animação mais usadas da web, presente em mais de 12 milhões de sites. Funciona com qualquer framework (ou nenhum) e anima propriedades CSS, atributos, SVG, canvas, cores, textos, caminhos de movimento e objetos JavaScript em geral.

O ponto forte é o sequenciamento: timelines precisas, controle fino e correção de inconsistências entre navegadores. Com a compra pela Webflow, todo o pacote ficou gratuito, inclusive os plugins que antes eram pagos (Club GSAP).

É o motor de animação usado por várias ferramentas de vídeo em código, como o HyperFrames e o Motionmaxxing.

Principais recursos

  • Núcleo sem dependências, com utilitários (interpolate(), mapRange()), easings, snapping e modificadores.
  • ScrollTrigger e ScrollSmoother: animações ligadas à rolagem.
  • SplitText, MorphSVG, MotionPath, Flip, Draggable e Observer, todos gratuitos.
  • gsap.matchMedia() para animações responsivas e com acessibilidade.
  • Pacote @gsap/react com o hook useGSAP(), que cuida da limpeza.
  • Arquivos ES modules e UMD; aceito pelas grandes redes de anúncios.

Pré-requisitos

  • Um projeto web (com ou sem bundler).

Instalação

npm install gsap

Ou por CDN:

<script src="https://cdn.jsdelivr.net/npm/gsap@3.15/dist/gsap.min.js"></script>

Comandos e uso

import gsap from "gsap";
import ScrollTrigger from "gsap/ScrollTrigger";
import Flip from "gsap/Flip";
import Draggable from "gsap/Draggable";
// ou tudo de uma vez:
import { gsap, ScrollTrigger, Draggable, MotionPathPlugin } from "gsap/all";

gsap.registerPlugin(ScrollTrigger, Draggable, Flip, MotionPathPlugin);   // registre os plugins antes de usar

Para o agente escrever GSAP bem, instale as GSAP Skills oficiais.

Quando usar

  • Animações de site com sequência complexa, rolagem e texto animado.
  • Motion graphics em HTML que depois vira vídeo (HyperFrames, Motionmaxxing).
  • Animações de SVG e morphing.

Observações

  • Licença: a licença padrão da GreenSock é gratuita e permite uso comercial, mas não é MIT. Leia em gsap.com/standard-license.
  • Bugs e dúvidas vão preferencialmente para os fóruns do GSAP.
  • Relacionados no catálogo: as GSAP Skills ensinam o GSAP ao agente; o Motion é a alternativa mais usada em React; o Lottie toca animações exportadas do After Effects.
