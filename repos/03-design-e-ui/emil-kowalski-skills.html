O que é

Uma coleção de skills para designers e engenheiros, escrita a partir da experiência do autor na Vercel e na Linear. A ideia é que agentes não têm bom gosto. Eles erram detalhes pequenos, como usar ease-in numa animação de entrada (o certo é ease-out) ou uma borda sólida onde caberia uma sombra semitransparente. Esses detalhes se somam e decidem se a interface fica ótima ou só razoável. As skills listam esses erros e explicam como corrigir cada um.

A maior parte trata de animação, mas há skills de design geral, de mobile, de Swift e da biblioteca de toasts Sonner. São só arquivos Markdown, sem scripts.

Principais recursos

Animação:

Skill O que faz
emil-design-eng A skill principal: filosofia de polimento de UI, componentes e decisões de animação
animate Cria uma animação do zero, escolhendo curva, duração e propriedades
animate-expo O mesmo padrão para React Native e Expo: gestos, sheets, haptics, transições de tela, animação fora da thread de JS
review-animations Revisão rígida das animações, pelas regras do autor (só manual)
improve-animations Audita todas as animações do projeto e gera planos priorizados que outro agente, até um modelo mais barato, executa. Não altera o código
find-animation-opportunities Acha onde movimento ajudaria de verdade, e onde não animar
remove-animations O contrário: tira animações desnecessárias, como em atalhos de teclado, fade-in em toda seção e atraso em todo tooltip
animation-performance Corrige animações que perdem quadros
animation-vocabulary Ensina as palavras certas para pedir animações a uma IA

Design e UI:

Skill O que faz
apple-design Princípios de interface e movimento da Apple, tirados das palestras da WWDC e adaptados para a web
mobile-native Faz o web app parecer nativo no celular: hover que gruda, flash de toque, bug do 100vh, zoom em inputs, toque lento, safe areas
break-ui Testa a UI com os piores dados realistas (nomes enormes, e-mails sem quebra, contagens gigantes, listas vazias, emoji, texto não latino), com um botão para alternar e a correção de cada problema
prototype Cria várias versões bem diferentes de um componente com um seletor para comparar ao vivo (só manual)
pick-ui-library Escolhe a biblioteca certa numa lista curada pelo autor (números, OTP, gráficos, command menu, virtualização, drag and drop, toasts, estado, estilo) em vez de deixar a IA improvisar (só manual)
ask-sonner Guia do Sonner, a biblioteca de toasts do autor: setup, estilo, receitas e problemas comuns
write-swift Swift moderno: value types, concorrência do Swift 6, generics, desempenho e Swift Testing

"Só manual" significa que a skill tem disable-model-invocation: true: o agente não a ativa sozinho, você precisa chamar.

O repositório também traz dois resumos rápidos, ui-cheatsheet.md e performance-cheatsheet.md, com dicas como font-variant-numeric: tabular-nums para números que tremem, scale(0.97) no :active de botões, animar só transform e opacity, e não usar transition: all.

Pré-requisitos

  • Um agente que suporte Agent Skills, como Claude Code, Codex ou Cursor.
  • Node.js, para a CLI npx skills.

Instalação

Com a CLI npx skills (ver Vercel Skills CLI):

npx skills@latest add emilkowalski/skills

Comandos e uso

A maioria das skills entra sozinha quando o pedido combina com ela, por exemplo "review the animations" ou "make this app feel better". As três manuais (prototype, pick-ui-library e review-animations) são chamadas pelo nome, como /prototype no Claude Code.

Chamadas sem uma pergunta, as skills só respondem que estão prontas e esperam o pedido.

Exemplos de pedido:

/prototype a hold-to-delete button
/pick-ui-library I need toasts
Try the worst case on this user card.
Audit the motion in this app and give me a plan.

Quando usar

  • Ao criar ou revisar animações e microinterações num app React, React Native ou web.
  • Para deixar um web app com sensação de app nativo no celular.
  • Para testar componentes com dados reais e feios antes de publicar.
  • Comparação: o Impeccable e a Taste Skill cuidam da direção visual e da página inteira. Estas skills cuidam do acabamento, sobretudo de movimento. A skill web-design-guidelines do Vercel Agent Skills é uma lista de regras de revisão de UI, mais ampla e menos opinativa.

Observações

  • Opinativo: as regras e a lista de bibliotecas são escolhas pessoais do autor. A pick-ui-library evita sair da lista, mas confere primeiro o package.json e não troca uma dependência existente sem você pedir.
  • Contexto: algumas skills são longas. A write-swift tem cerca de 42 KB e a emil-design-eng cerca de 27 KB, e isso pesa no contexto quando são carregadas.
  • O autor divulga uma newsletter para acompanhar novas skills (aiforui.dev).
