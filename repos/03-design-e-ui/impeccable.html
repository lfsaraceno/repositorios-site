Impeccable

Vocabulário de design para agentes de código: 24 comandos para direcionar, revisar e finalizar interfaces, modo ao vivo no navegador e um detector com 62 regras que pega clichês de UI gerada por IA antes de publicar.

O que é

Peça uma página a um agente sem nenhuma orientação e os mesmos vícios aparecem sempre, em qualquer modelo: Inter em tudo, gradiente roxo para azul, cards dentro de cards, texto cinza sobre fundo colorido, um ícone em quadrado arredondado acima de cada título. O Impeccable resolve isso de três formas:

  • Vocabulário: em vez de "deixa mais bonito", /impeccable bolder the pricing cards carrega um roteiro escrito para aquele movimento e aplica num alvo só.
  • Revisor: critique dá nota ao design com heurísticas de usabilidade e ordena o que corrigir. audit confere acessibilidade, desempenho, temas e responsividade, com achados de P0 (bloqueia) a P3 (acabamento).
  • Detector de "slop": 62 regras determinísticas, sem LLM e sem chave de API, que também pegam espaçamento apertado e títulos fora de ordem.

O Impeccable é mais forte em interfaces que já existem: aponte para uma página ou componente e itere. Ele também cria páginas novas, um modo mais difícil com um guia próprio. Começou a partir da skill frontend-design da Anthropic.

Principais recursos

Os 24 comandos:

Grupo Comandos
Direcionar bolder (ousar mais), quieter (acalmar), distill (tirar o que sobra), colorize (dar cor), typeset (tipografia), layout (espaçamento e ritmo), animate (transições e feedback), delight (personalidade), overdrive (shaders, física de mola, efeitos de rolagem)
Revisar critique (revisão de UX com nota), audit (relatório técnico)
Finalizar polish (passada final), harden (erros, i18n, overflow, casos de borda), clarify (reescreve textos confusos), adapt (telas e dispositivos), optimize (carregamento e renderização), onboard (primeiro uso e estados vazios)
Iterar ao vivo live (escolhe um elemento no navegador e alterna variantes), generate (variantes de um elemento pelo nome)
Planejar e configurar shape (planeja a UX antes do código), init (cria PRODUCT.md), document (cria DESIGN.md), extract (leva padrões repetidos para o design system)

O 24º, craft, ficou obsoleto e hoje é só um pedido de construção comum.

Outros recursos:

  • Arquivos de contexto: PRODUCT.md (público, propósito, restrições) e DESIGN.md (sistema visual atual), lidos por todos os comandos.
  • Modo live: abre o servidor de desenvolvimento com uma camada por cima. Você escolhe um elemento, as variantes trocam na hora, e a escolhida é gravada no código. Funciona com Vite, Next, SvelteKit, Astro, Nuxt e HTML puro.
  • Detector em três lugares:
    • um hook que confere cada arquivo de UI editado pelo agente antes de ele dar a tarefa por concluída;
    • a CLI npx impeccable detect, para terminal e CI;
    • uma extensão do Chrome que mostra os achados sobre qualquer página.
  • Caminho de construção: para landing pages novas, pode gerar um mockup completo primeiro e construir igual a ele (mais ousado e mais lento), ou ir direto no código. Só aparece se o agente gera imagens.
  • Atalhos próprios: /impeccable pin audit cria /audit.
  • /impeccable doctor acha arquivos de contexto velhos, configurações sem uso e hooks quebrados.
  • Suporta Claude Code, Cursor, Codex CLI, GitHub Copilot, Devin, Replit Agent, Gemini CLI, Grok Build, OpenCode, Google Antigravity, Kiro, Trae, Rovo Dev, Qoder, Mistral Vibe, Pi, Hermes Agent, DeepSeek Harness e Veto.

Pré-requisitos

  • Um agente de código suportado.
  • Node.js só para o npx. A skill usa um binário próprio, que vem junto ou é baixado uma vez para ~/.impeccable/bin/.
  • Para escanear URLs com a CLI: Chrome ou Edge instalado.
  • Para a extensão do VS Code: VS Code 1.109.3+, Copilot Chat e workspace confiável.

Instalação

Instalador (recomendado)

Na raiz do projeto:

npx impeccable install

O instalador detecta suas ferramentas, pergunta se é para o projeto ou global e oferece o hook de design onde houver suporte. O autor recomenda aceitar o hook. Recarregue a ferramenta depois.

npx impeccable update                                       # atualizar
npx impeccable install --providers=claude,codex,cursor --scope=project   # sem perguntas

Três ferramentas pedem um passo a mais para o hook funcionar:

  • Codex: aprove o hook em /hooks, também depois de atualizações que mudem o hook;
  • Grok Build: rode /hooks-trust ou inicie com --trust;
  • Hermes Agent: rode hermes plugins enable impeccable-design-hook uma vez.

Plugins

  • Claude Code: /plugin marketplace add pbakaus/impeccable, depois abra /plugin e instale o Impeccable.
  • Copilot no VS Code: code --install-extension renaissance-geek.impeccable. Instala a skill, mas sem o hook.
  • Grok Build: grok plugin install pbakaus/impeccable#plugin --trust.

Submódulo Git (versão fixa para o time)

git submodule add https://github.com/pbakaus/impeccable vendor/impeccable
npx impeccable link --source=vendor/impeccable --providers=claude,cursor

Faça commit do .gitmodules, do submódulo e dos links. O link instala as skills, mas não os hooks.

Cópia manual (sem Node)

Baixe o ZIP da sua ferramenta em impeccable.style, ou copie skills/impeccable da pasta da ferramenta no repositório, por exemplo .claude/ para o Claude Code. A cópia manual não traz o hook nem os subagentes.

Comandos e uso

/impeccable init                          # uma vez por projeto: cria o PRODUCT.md
/impeccable document                      # registra o sistema visual atual no DESIGN.md
/impeccable critique the pricing cards    # bom primeiro passo: um componente só
/impeccable quieter the landing page
/impeccable polish settings
/impeccable harden checkout
/impeccable redo this hero section        # também aceita descrição livre
/impeccable live                          # iteração no navegador

No Codex, use $impeccable ou abra /skills. Digite /impeccable sozinho para ver a lista. Alvos estreitos dão resultados melhores: uma seção revisada de perto rende mais que uma página inteira de relance.

Detector pela CLI (sem agente):

npx impeccable detect src/                   # escaneia uma pasta
npx impeccable detect http://localhost:5173  # escaneia a página renderizada
npx impeccable detect --json .               # saída para máquinas
npx impeccable detect --github src/          # anotações no GitHub Actions
npx impeccable detect --list-rules           # lista todas as regras

Arquivos JSX e TSX recebem só as regras de padrão. Regras que dependem da página renderizada, como contraste baixo e texto pequeno, só rodam escaneando uma URL. O código de saída 2 significa que houve achados, e 1 que um alvo não pôde ser escaneado.

Para liberar a fonte da sua marca, use npx impeccable ignores add-value overused-font Inter --reason "Brand font". Para desligar uma regra num arquivo, use o comentário <!-- impeccable-disable overused-font: motivo -->.

Git: o Impeccable grava seus arquivos em .impeccable/. Vão para o repositório o config.json, o live/config.json, o design.json, surfaces/*.md, critique/*.md, o PRODUCT.md e o DESIGN.md. O resto (screenshots, caches, estado) deve ir para o .gitignore; o bloco pronto está no README.

Quando usar

  • Dar identidade a interfaces geradas por IA que saem todas iguais.
  • Revisar e finalizar telas existentes: auditoria, polimento, acessibilidade, casos de borda.
  • Barrar "slop" no CI com o detect.
  • Comparação: a Taste Skill conduz a construção de uma página nova, da direção de arte à checagem no navegador. O Impeccable brilha iterando sobre o que já existe. As Emil Kowalski Skills focam no acabamento de animações. Para começar de um sistema visual pronto de outra marca, veja o Awesome DESIGN.md.

Observações

  • Hooks rodam fora da aprovação do modelo. No Claude Code, os hooks instalados rodam mesmo quando você nega os comandos do modelo, então a primeira edição pode baixar o binário do motor. Revise os hooks antes de deixar o agente rodando sozinho, ou desligue numa execução com --settings '{"disableAllHooks": true}'.
  • Telemetria: ao começar um design novo, a skill busca direções visuais no catálogo do impeccable.style. Desligar a telemetria não impede essa busca; só deixa de registrar, de forma anônima, quais direções foram mostradas e escolhidas. Nome do projeto, arquivos, código e PRODUCT.md nunca são enviados, segundo o README. Para desligar, use npx impeccable telemetry off, DO_NOT_TRACK=1 ou "telemetry": false em .impeccable/config.json.
  • Modo live: só use em um checkout local. Não injete num site publicado nem afrouxe a CSP de produção. Ao aplicar edições de texto, ele roda o script opcional impeccable:manual-edit-validate do seu package.json com as suas permissões. Revise esse script antes de usar o live num repositório que você não conhece.
  • No Cursor e no Gemini CLI, talvez seja preciso habilitar Agent Skills nas configurações. No Hermes, skills de projeto pedem hermes skills trust. Reinicie o Trae depois de copiar.
  • Evite duas cópias da skill no mesmo workspace, por exemplo a extensão do VS Code junto com a instalação pela CLI.
  • Projeto muito ativo. O último release da CLI é o cli-v4.8.0, de out/2026.
