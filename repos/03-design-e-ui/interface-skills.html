O que é

Coleção de skills de design engineering que cobrem os temas que o autor escreve no site pessoal e na revista Interfaces. Em vez de conselhos genéricos, elas trazem valores concretos: raio de borda, alinhamento ótico, sombras, duração e easing de animação, escala tipográfica, contraste.

Algumas revisam (uma tela, um fluxo ou um PR) e outras constroem (a partir de Figma, de imagem ou de variantes).

Principais recursos

  • better-interface: revisa a interface em acessibilidade, layout, texto, tipografia, cor, polimento e animação, e devolve um relatório priorizado.
  • better-ui: polimento de superfícies e ícones (raio, alinhamento ótico, sombras, estados).
  • better-motion: decide o que animar e como (duração, easing, entradas, saídas, layout compartilhado, drag).
  • better-typography, better-colors e better-layout: escala de texto, paletas e tokens semânticos com contraste, agrupamento e estrutura responsiva.
  • better-accessibility: teclado, foco, ARIA, formulários e zoom conforme WCAG 2.2.
  • better-writing: textos de interface (rótulos, erros, estados vazios, confirmações).
  • interface-review: revisa um branch, PR ou mudança não commitada atrás de regressões de interface.
  • explain-interface: explica como um site, efeito ou animação foi feito, a partir de URL ou print.
  • build-design: constrói a UI a partir de um arquivo Figma ou imagem, usando os tokens e componentes do projeto.
  • break, state-machine e variant: testam um componente em todos os cenários, mostram todos os estados e geram variantes para comparar.
  • afk e upskill: trabalham no projeto enquanto você está fora e sugerem skills e automações a partir das suas sessões.

Pré-requisitos

  • Um agente compatível com skills (Claude Code, Codex, Cursor etc.).
  • Node (npx) para a instalação.

Instalação

npx skills add jakubkrehel/skills

No Claude Code, se a CLI instalar só em .agents/skills/, passe o agente com -a claude-code (opção da Vercel Skills CLI).

Comandos e uso

As skills de revisão e construção carregam sozinhas conforme o pedido. As marcadas como "user-invoked" no README (interface-review, explain-interface, break, state-machine, variant, afk, upskill) são chamadas por você, pelo nome.

"Revise esta tela com o better-interface"
/interface-review
/explain-interface https://site-que-voce-admira.com

Quando usar

  • Revisão final de uma página ou app antes de publicar.
  • Polimento de detalhes (sombras, raios, tipografia, microanimações).
  • Revisar PRs de frontend atrás de regressões visuais e de acessibilidade.

Observações

  • O README é curto; os detalhes de cada skill ficam no SKILL.md correspondente.
  • Relacionados no catálogo: as Emil Kowalski Skills seguem a mesma linha de design engineering; o Impeccable também revisa e dá polimento a interfaces.
