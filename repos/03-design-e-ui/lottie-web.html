O que é

O Lottie resolve um problema antigo: o designer cria a animação no Adobe After Effects e ela vai para o site ou app sem que um programador precise refazê-la à mão. A animação é exportada como JSON pelo plugin Bodymovin e o player a renderiza em tempo real, vetorial e leve.

Este repositório tem o plugin do After Effects e o player web (lottie-web). Os players para Android, iOS, React Native e Windows ficam em repositórios próprios.

Também dá para usar arquivos Lottie prontos (por exemplo, de bibliotecas como a LottieFiles), sem passar pelo After Effects.

Principais recursos

  • Renderização em svg, canvas ou html.
  • Controle completo: play, pause, stop, velocidade, direção, ir para um quadro, tocar trechos (playSegments).
  • Eventos (complete, loopComplete, enterFrame, data_ready etc.).
  • Carregamento por JS (lottie.loadAnimation) ou só com atributos HTML (class="lottie").
  • Título e descrição acessíveis no SVG.
  • Suporte do After Effects: precomps, formas, sólidos, imagens, nulls, textos, máscaras, time remapping e parte das expressões.

Pré-requisitos

  • Para criar animações: Adobe After Effects (CC 2014 ou mais novo) com o plugin Bodymovin.
  • Para tocar: só o player JavaScript.

Instalação

Player web

npm install lottie-web

Ou o script do cdnjs.

Plugin do After Effects

Baixe pelo aescripts (recomendado) ou pela Adobe Exchange. Depois, em Edit > Preferences > Scripting & Expressions, marque "Allow Scripts to Write Files and Access Network".

Comandos e uso

No After Effects: Window > Extensions > bodymovin, escolha a composição e a pasta de destino e clique em Render.

Na página:

lottie.loadAnimation({
  container: element, // o elemento DOM que vai conter a animação
  renderer: 'svg',
  loop: true,
  autoplay: true,
  path: 'data.json' // caminho para o JSON da animação
});

Sem JavaScript:

<div class="lottie" data-animation-path="animation/" data-anim-loop="true" data-name="ninja"></div>

Quando usar

  • Ícones animados, ilustrações e estados de carregamento em sites e apps.
  • Levar animações do After Effects para web e mobile com arquivo pequeno.
  • Usar animações prontas de bibliotecas Lottie.

Observações

  • Pouca atividade: o último commit é de set/2025. Para recursos novos, a LottieFiles mantém o ecossistema dotLottie.
  • Não suporta sequências de imagens, vídeo nem áudio, nem esticar camadas negativamente.
  • Comprima com gzip o JSON e o player em produção.
  • No Safari, máscaras podem sumir: chame lottie.setLocationHref() antes de criar a animação.
  • Relacionados no catálogo: o Motion Design Skill é da LottieFiles e exporta Lottie pelo Creator MCP; o GSAP e o Motion animam em código, sem After Effects.
