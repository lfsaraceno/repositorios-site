Taste Skill

Skill que dá "bom gosto" de design ao agente de código: escolhe uma direção de arte, usa fotos reais de acervos abertos e confere a página num navegador de verdade, em vez de montar a landing page genérica de IA.

O que é

A Taste Skill é uma Agent Skill (instalada como design-taste-frontend) para o agente desenhar sites e telas de app com cara de projeto de designer. A versão 2 foi construída a partir do estudo de 247 sites selecionados. Cada construção segue seis passos:

  1. Lê o briefing e lista o que só aquele cliente tem.
  2. Um script sorteia três de 20 direções de arte pesquisadas, e o agente escolhe uma.
  3. Acha a ideia: uma frase que liga o material do cliente à direção escolhida.
  4. Constrói com fotos e vídeos reais de acervos abertos, com os créditos na página.
  5. Confere a página num navegador real em três larguras e reprova o que tiver cara de "slop".
  6. Olha os próprios screenshots e corrige os três maiores problemas, em até três rodadas.

A partir da v2.1, dashboards e telas de app têm um caminho próprio: estilos tirados de telas de produtos reais, painéis discretos, números alinhados, cor reservada para os dados e navegação que se recolhe no celular. A v2.1 também confere o enquadramento de cada página e usa movimentos medidos nos 100 últimos "Sites of the Day" do Awwwards.

O mesmo autor lançou o TasteCode (tastecode.dev), um app desktop gratuito e open source com a Taste Skill e um agente de design embutido.

Principais recursos

  • Direções de arte sorteadas de uma biblioteca em JSON (paletas, tipografia, heroes, seções, movimentos e fotos).
  • Imagens reais de acervos como Wikimedia Commons, Openverse e o Met. Só oferece arquivos em domínio público, CC0, CC BY e CC BY-SA, e coloca os créditos na página.
  • Checagem no navegador (Chrome, Edge ou Chromium) em três larguras, com regras contra clichês de IA. Telas de app usam inspect.mjs --app.
  • Auditoria de página existente: antes de mexer num site pronto, analisa a página no navegador. Isso substitui a antiga skill redesign-existing-projects.
  • Funciona com React, Vue, Svelte ou HTML puro, porque as regras são de design e não de framework.
  • Não instala nada no sistema e não precisa de chave de API.

Pré-requisitos

  • Node.js 22+.
  • Chrome, Edge ou Chromium instalado.
  • Acesso à internet, só para buscar imagens.
  • Um agente que suporte Agent Skills, como Claude Code, Codex ou Cursor.

Instalação

Com a CLI npx skills (ver Vercel Skills CLI):

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

Como plugin do Claude Code (a skill fica com o prefixo taste-skill:, sem conflito com outras skills):

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill

Para atualizar depois, use /plugin update.

Como plugin do Codex:

codex plugin marketplace add Leonxlnx/taste-skill
codex plugin add taste-skill@taste-skill

Depois, abra uma nova sessão do Codex.

A partir de um clone: o ./install.sh cria um link da skill no Claude Code. Use --codex para o Codex ou --all-agents para os dois. Assim, um git pull já atualiza a skill.

Comandos e uso

Peça ao agente uma página ou tela em linguagem natural, por exemplo um site para uma cafeteria ou um dashboard administrativo. A skill entra sozinha nas tarefas de frontend visual.

Uma construção completa leva de 30 a 45 minutos e algumas centenas de milhares de tokens.

Quando usar

  • Landing pages, sites institucionais e páginas de produto em que a qualidade visual importa.
  • Dashboards e telas de app com cara de produto real.
  • Revisar e melhorar um site que já existe.
  • Comparação: o Impeccable dá ao agente vocabulário de design e comandos de crítica e polimento. A Taste Skill conduz a construção inteira, da direção de arte à checagem no navegador. O UI UX Pro Max é uma base de estilos e paletas para consulta. A mesma ideia aplicada a vídeo é o motionmaxxing.

Observações

  • Custo: cada construção consome algumas centenas de milhares de tokens. Num plano pago por uso, isso pesa.
  • Imagens de terceiros: as fotos têm licença aberta, mas CC BY e CC BY-SA exigem crédito, e CC BY-SA exige que obras derivadas usem a mesma licença. Mantenha os créditos que a skill coloca, ou troque pelas suas imagens.
  • Golpe de cripto: o autor avisa que a Taste Skill não tem token, moeda nem projeto de cripto. Qualquer token com o nome dele é falso.
  • Projeto muito ativo. O último release é o v2.1.5, de out/2026.
