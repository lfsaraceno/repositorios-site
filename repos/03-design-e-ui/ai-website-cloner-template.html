O que é

É um repositório-modelo pronto para o agente trabalhar. Ele traz a stack montada (Next.js 16, React 19, shadcn/ui, Tailwind CSS v4) e a skill /clone-website. O autor recomenda o Claude Code com Opus 5.5, mas também funciona com Codex, Cursor e OpenCode.

A skill segue quatro etapas:

  1. Mapear: liga as URLs de origem às rotas locais, preservando o que já existe.
  2. Observar: inspeciona o site em desktop e mobile, extrai imagens, fontes e SVGs reais e testa os estados alternativos.
  3. Construir: cria componentes editáveis com interações funcionando.
  4. Comparar: compara origem e cópia no mesmo tamanho e estado, corrige as diferenças e roda a checagem de produção.

Tem orientação específica para páginas feitas no Framer e sites animados (cenas fixas, movimento por scroll). A entrega inclui o mapa de rotas, prints de comparação e as lacunas que sobraram.

Principais recursos

  • Recriação de um site inteiro a partir da URL, com um comando.
  • Código editável em Next.js + shadcn/ui + Tailwind, não um HTML copiado.
  • Comparação visual automática entre original e cópia.
  • Uma skill portátil em .agents/skills/clone-website/ lida por Codex, Cursor e OpenCode, com uma ponte em .claude/commands/ para o Claude Code.
  • Docker Compose para rodar o app.

Pré-requisitos

  • Node.js 24 ou mais novo.
  • Um agente de código com acesso ao navegador ativado.

Instalação

Clique em Use this template no GitHub para criar o seu repositório, clone-o e rode:

npm install
npm run check   # lint + typecheck + build

Ou peça ao agente para fazer isso (texto sugerido no README):

Set up https://github.com/JCodesMore/ai-website-cloner-template
as a standalone project in a new folder on my computer.
Ask me where to put it. Clone the repository, remove its origin remote,
install dependencies, and run npm run check. Leave it ready for me
to clone a website.

Comandos e uso

No Claude Code ou Cursor, com o projeto aberto:

/clone-website https://example.com

Depois, peça os ajustes ao agente. Comandos do projeto:

npm run dev        # servidor de desenvolvimento
npm run build      # build de produção
npm run check      # lint + typecheck + build
docker compose up dev --build   # modo dev na porta 3001

Quando usar

  • Migrar um site seu de WordPress, Webflow ou Squarespace para Next.js.
  • Recuperar o código de um site seu que está no ar mas perdeu o repositório.
  • Estudar como sites de produção fazem layouts, animações e responsividade.

Observações

  • Uso responsável: o README proíbe phishing e falsificação. Logos, marca e textos pertencem aos donos, e alguns sites proíbem cópia nos termos de uso. Use em sites seus ou como estudo, e confira os termos antes.
  • Consome bastante do agente: ele navega, extrai e compara página por página.
  • Relacionados no catálogo: o Replica Skill clona a funcionalidade de um app; o RES estuda um SaaS e gera uma base de conhecimento.
