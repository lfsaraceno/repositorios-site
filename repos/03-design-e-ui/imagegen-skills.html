O que é

São as skills de geração de imagem do autor da Taste Skill. Elas viviam no repositório da Taste Skill e foram separadas em out/2026: a Taste Skill constrói e confere frontends, e este repositório gera as imagens. Por isso o repositório tem poucas estrelas, embora as skills sejam usadas há mais tempo.

A mais conhecida é a image-to-code. Ela impõe uma ordem fixa:

  1. Gerar as imagens de design primeiro, uma imagem grande e legível por seção, em vez de um painel único comprimido.
  2. Analisar as imagens a fundo: layout, tipografia, espaçamento e hierarquia.
  3. Só então programar o site, o mais fiel possível às imagens.

A skill combate vícios comuns da IA: cards dentro de cards, hero escuro e centralizado, texto pequeno demais, rótulos e "pills" sem função e pouca imagem para muitas seções.

Principais recursos

Skill O que faz
imagegen-frontend-web Mockups de site: uma imagem por seção da landing page, com composição variada e texto legível
imagegen-frontend-mobile Telas e fluxos de app para iOS, Android e multiplataforma, coerentes entre si
brandkit Painéis de identidade visual: direções de logo, símbolos, paletas, tipografia e aplicações
image-to-code O fluxo completo: gera as imagens, estuda e implementa o site

As três primeiras só produzem imagens. Use com o ChatGPT Images, o modo de imagem do Codex ou outro agente que gere imagens, e depois entregue as imagens ao agente de código.

Pré-requisitos

  • Para image-to-code: um agente que gere imagens e escreva código. A descrição da skill foi escrita pensando no Codex.
  • Para as outras três: qualquer agente ou ferramenta que gere imagens.

Instalação

Com a CLI npx skills (ver Vercel Skills CLI):

npx skills add https://github.com/Leonxlnx/imagegen-skills --skill "image-to-code"

Troque image-to-code por qualquer nome da tabela, ou tire o --skill para instalar as quatro.

Como plugin do Claude Code:

/plugin marketplace add Leonxlnx/imagegen-skills
/plugin install imagegen-skills@imagegen-skills

Como plugin do Codex:

codex plugin marketplace add Leonxlnx/imagegen-skills
codex plugin add imagegen-skills@imagegen-skills

Depois, abra uma nova sessão do Codex. Quem instalou essas skills pela Taste Skill deve reinstalar a partir daqui; os nomes não mudaram.

Comandos e uso

Peça em linguagem natural, por exemplo uma landing page para um produto. Com image-to-code, o agente deve gerar as imagens das seções, analisá-las e só depois escrever o código.

A skill tem uma configuração base, em escala de 1 a 10, que você pode citar no pedido para ajustar o resultado:

Parâmetro Padrão Significado
DESIGN_VARIANCE 8 De convencional a assimétrico e autoral
VISUAL_DENSITY 3 De arejado a denso
ART_DIRECTION 8 De comercial seguro a declaração criativa ousada
SPACING_GENEROSITY 9 De compacto a espaçoso
IMAGE_GENERATION_EAGERNESS 10 De poucas imagens a quantas forem necessárias

Quando usar

  • Quando o agente gera imagens bem, mas o código sai genérico: a imagem vira a referência visual que guia a implementação.
  • Para mockups de site, telas de app ou brand kit antes de programar.
  • Comparação: a Taste Skill parte de fotos reais de acervos e confere o resultado no navegador. A image-to-code parte de imagens geradas pela própria IA. Para copiar a linguagem visual de uma marca existente, use o Awesome DESIGN.md.

Observações

  • Repositório novo (criado em out/2026 e sem atualizações desde a semana de criação). O único teste confere o cabeçalho dos SKILL.md. São skills de texto: não há scripts que rodem na sua máquina.
  • Custo: a image-to-code gera muitas imagens de propósito (IMAGE_GENERATION_EAGERNESS: 10). Num plano pago por imagem, o custo sobe rápido.
  • As imagens geradas por IA podem trazer textos, logos ou elementos parecidos com marcas reais. Revise antes de usar comercialmente.
