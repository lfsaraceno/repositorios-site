O que é

O Magic MCP era um servidor MCP que funcionava como um "v0 dentro do seu editor": buscar entre mais de 10 mil componentes React/Tailwind, gerar UI com IA e publicar os seus. Ele foi substituído pelo 21st MCP, instalado pelo CLI da 21st. O pacote @21st-dev/magic continua publicado como um proxy stdio de compatibilidade, para que configurações antigas sigam funcionando.

O servidor atual expõe muito mais que as quatro ferramentas originais: busca em catálogo de componentes, temas e templates, recuperação de código, favoritos, bibliotecas de equipe, geração de UI com variantes e gestão de perfil.

Principais recursos

  • Busca de componentes, temas e templates (search, get_component).
  • Geração de UI com variantes (generate, iterate_generation), quando o acesso a IA está habilitado.
  • Inspiração de design (get_inspiration) e busca de logos (search_logo).
  • Servidor HTTP simples, com chave de API no cabeçalho x-api-key.
  • Proxy de compatibilidade: nomes antigos de ferramentas continuam sendo traduzidos.
  • Empacotado também como plugin para Claude Code, Grok Build e Codex CLI.

Pré-requisitos

  • Node.js, para usar npx.
  • Uma chave de API da 21st, gerada em 21st.dev/mcp (há chave gratuita). As chaves antigas do Magic foram resetadas e não funcionam mais.
  • Um cliente MCP: Cursor, Claude Code, VS Code, Windsurf ou Codex.

Instalação

21st MCP via CLI (recomendado)

npx @21st-dev/cli@latest init --client cursor

Troque cursor por claude, vscode, windsurf ou codex.

Configuração manual (HTTP)

{
  "mcpServers": {
    "21st": {
      "url": "https://21st.dev/api/mcp",
      "headers": { "x-api-key": "YOUR_21ST_API_KEY" }
    }
  }
}

Plugin

claude plugin marketplace add 21st-dev/magic-mcp   # depois: /plugin install 21st
grok plugin marketplace add 21st-dev/magic-mcp && grok plugin install 21st --trust
codex plugin marketplace add 21st-dev/magic-mcp

Defina a chave na variável API_KEY_21ST.

Proxy legado (configs antigas)

npx -y @21st-dev/magic@latest API_KEY="..."

Comandos e uso

Use linguagem natural no agente, por exemplo: "busque no 21st um componente de pricing table" ou, com IA habilitada, peça para gerar uma interface com variantes. Os gatilhos antigos /ui e /21 eram convenção das descrições das ferramentas, não do protocolo.

Mapa de nomes antigos para novos:

Ferramenta antiga Ferramenta atual
21st_magic_component_builder generate
21st_magic_component_inspiration get_inspiration
21st_magic_component_refiner generate
logo_search search_logo

Quando usar

  • Acelerar telas e componentes React/Tailwind sem sair do editor.
  • Buscar inspiração e referências de UI antes de implementar.
  • Manter funcionando configs antigas do Magic MCP.

Observações

  • O acesso de construtor a componentes não habilita a IA hospedada da 21st: generate e iterate_generation só aparecem se o acesso a IA estiver ativo (veja get_usage.aiGenerationEnabled). Sem IA, use search e get_component e adapte o código com seu agente.
  • Um erro ai_subscription_required indica que a IA não está habilitada; não repita a chamada até habilitar.
  • Serviço hospedado de terceiros: seu uso depende da conta e dos planos da 21st.
