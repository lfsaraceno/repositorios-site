O que é

O Free Claude Code (FCC) é um projeto independente de código aberto, sem afiliação com a Anthropic. Ele sobe um servidor local com uma interface de administração (Admin UI) e conecta agentes de código, como Claude Code, a um catálogo único de modelos vindos de vários provedores, incluindo camadas gratuitas, planos pagos e modelos locais.

Os agentes são iniciados por launchers (fcc-claude, fcc-codex etc.) que sobem o servidor automaticamente. Na Admin UI você cadastra chaves de API, escolhe o modelo padrão, define modelos por tier (Fable, Opus, Sonnet, Haiku) e configura uma lista de modelos de fallback.

Serve a quem quer testar agentes de código sem depender de uma única assinatura ou quem precisa alternar entre provedores.

Principais recursos

  • Catálogo com 61 provedores citados como compatíveis com seus termos de uso (NVIDIA NIM, OpenRouter, Groq, DeepSeek, Gemini, Ollama, LM Studio, llama.cpp e outros)
  • 11 agentes de código suportados, entre eles Claude Code, Codex, Pi, OpenCode, Cline, Hermes, Grok Build, Aider e VS Code Chat
  • Fallback automático para o próximo modelo configurado quando o provedor falha
  • Roteamento independente por tier (MODEL_FABLE, MODEL_OPUS, MODEL_SONNET, MODEL_HAIKU) e controle de esforço de raciocínio
  • Redução de tokens opcional com RTK e Headroom
  • Integrações com VS Code, JetBrains, Claude Desktop, Codex App, Discord e Telegram
  • Notas de voz com Whisper local ou NVIDIA NIM
  • Sessões nativas de Codex no navegador

Pré-requisitos

  • Instalador para macOS/Linux (shell) ou Windows (PowerShell)
  • Badge do README indica Python 3.14 e gerenciador uv (o instalador cuida disso; ao desinstalar, uv e Python são mantidos)
  • Ao menos uma chave de API de provedor (ex.: NVIDIA NIM) ou um servidor local (Ollama, LM Studio, llama.cpp)
  • Ao menos um agente de código instalado ou escolhido no instalador

Instalação

1. Instalar

macOS/Linux:

curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh

Windows PowerShell:

& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))

O instalador pergunta quais agentes instalar e se deseja ativar RTK + Headroom.

2. Iniciar o FCC

  • Windows e macOS: abra o atalho Free Claude Code (área de trabalho, menu Iniciar ou Applications).
  • Linux: execute fcc-server e mantenha o terminal aberto.

3. Configurar um provedor (exemplo: NVIDIA NIM)

  1. Crie uma chave em build.nvidia.com/settings/api-keys.
  2. Abra a URL da Admin UI mostrada no log do servidor.
  3. Em Providers, abra NVIDIA NIM, clique em Add key, cole a chave e salve.
  4. Mantenha o MODEL padrão (nvidia_nim/nvidia/nemotron-3-super-120b-a12b) ou escolha outro.
  5. Clique em Apply.

Comandos e uso

fcc-claude      # Claude Code com modelos do FCC
fcc-codex       # Codex
fcc-pi          # Pi
fcc-opencode    # OpenCode 2
fcc-cline       # Cline
fcc-hermes      # Hermes
fcc-dsh         # DeepSeek Harness Web
fcc-grok        # Grok Build
fcc-muse        # Muse Code
fcc-aider       # Aider
fcc-server      # sobe só o servidor (Linux)
fcc-update      # atualiza o FCC
fcc-doctor      # diagnóstico para relatos de bug
  • No Claude Code, os modelos do FCC aparecem no seletor /model.
  • Para editores e apps (VS Code, JetBrains, Claude Desktop, Codex App), abra Admin UI → Integrations e clique em Connect.
  • Provedor sem listagem de modelos: informe <provider-id>/<exact-provider-model-id> manualmente.
  • Para proteger o proxy local, ative Proxy Authentication na Admin UI.

Desinstalar (macOS/Linux):

curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/uninstall.sh" | sh

No Windows, use o script uninstall.ps1 equivalente do mesmo diretório scripts/.

Quando usar

  • Experimentar agentes de código com camadas gratuitas de vários provedores
  • Manter o trabalho andando quando um provedor cai ou atinge a cota (fallback)
  • Rodar agentes com modelos locais via Ollama, LM Studio ou llama.cpp
  • Alternar entre agentes e modelos mantendo um catálogo único

Observações

  • Projeto independente, sem afiliação com a Anthropic. Claude e Claude Code são marcas da Anthropic.
  • Risco de termos de uso: o FCC redireciona o tráfego do Claude Code para provedores de terceiros. Cada provedor controla limites, disponibilidade e termos, e as camadas gratuitas podem mudar a qualquer momento. O README afirma que o projeto segue os termos dos provedores e remove integrações que deixem de ser permitidas, mas confira os termos do provedor e do agente que você usa. Alguns planos têm restrições explícitas (por exemplo, o Coding Plan da QwenCloud é para uso local, pessoal e interativo).
  • Risco de segurança: o proxy recebe seu código, prompts e chaves de API e os repassa a serviços de terceiros. Não envie código sensível ou segredos por modelos gratuitos sem entender a política de retenção e treinamento de cada provedor. Ative a autenticação do proxy, mantenha-o acessível só localmente e guarde as chaves com cuidado.
  • O instalador é executado com curl ... | sh (ou irm no PowerShell); leia o script antes de rodar se quiser auditar o que será instalado.
  • Um pedido que falha pode passar por mais de um provedor e consumir cota de todos eles (efeito do fallback).
  • Licença AGPL-3.0: exige disponibilizar o código-fonte de versões modificadas oferecidas como serviço em rede.
