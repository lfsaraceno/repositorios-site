Firecrawl

O que é

O Firecrawl entrega dados da web prontos para LLM. Você manda uma URL e recebe Markdown limpo, HTML, screenshot ou JSON estruturado; ele cuida de proxies rotativos, páginas pesadas em JavaScript, limites de taxa e conteúdo bloqueado. Também busca na web e devolve o conteúdo completo dos resultados, e interage com páginas (clicar, rolar, digitar) antes de extrair.

Funciona como serviço hospedado (com chave de API e créditos) ou self-hosted, e se conecta a agentes via skill, CLI ou servidor MCP. O Alexandria, só na nuvem, dá ao agente acesso a mais de 550 provedores de dados.

Principais recursos

  • Search: busca na web com o conteúdo das páginas.
  • Scrape: URL para Markdown, HTML, screenshot ou JSON estruturado.
  • Interact: age na página com prompts ou código depois de raspar.
  • Agent: descreva o que precisa e o agente pesquisa, navega e extrai (com esquema opcional e níveis de esforço low, medium, high).
  • Crawl (site inteiro), Map (descobre todas as URLs), Batch Scrape (milhares de URLs).
  • Parse: PDF, DOCX e outros documentos para Markdown ou JSON.
  • Monitor: avisa quando o conteúdo de um site muda.
  • SDKs para Python, Node.js, Go, Java, Elixir, Rust, Ruby, .NET e PHP; integrações com n8n, Zapier e Lovable.

Pré-requisitos

  • Chave de API em firecrawl.dev (para o serviço hospedado), ou servidor próprio para self-hosting.
  • Node.js para a skill/CLI e o MCP.

Instalação

Skill para agentes (Claude Code, Antigravity, OpenCode)

npx -y firecrawl-cli@latest init --all --browser

Reinicie o agente depois.

MCP

{
  "mcpServers": {
    "firecrawl-mcp": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR_API_KEY"
      }
    }
  }
}

SDKs

pip install firecrawl        # Python
npm install firecrawl        # Node.js

Self-hosting

Siga o guia de self-hosting. A versão self-hosted não inclui o Alexandria e alguns recursos da nuvem.

Comandos e uso

CLI:

firecrawl search "firecrawl" --limit 5                 # busca na web
firecrawl scrape https://firecrawl.dev                 # raspa uma página
firecrawl https://firecrawl.dev --only-main-content    # só o conteúdo principal
firecrawl interact exec --prompt "Click the first result"

Python:

from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR_API_KEY")
doc = app.scrape("https://firecrawl.dev", formats=["markdown"])
docs = app.crawl("https://docs.firecrawl.dev", limit=50)
result = app.agent(prompt="Find the pricing plans for Notion")

Com o MCP ou a skill instalados, peça ao Claude Code: "use o Firecrawl para ler a documentação de X e resumir".

Quando usar

  • Dar ao agente acesso confiável a páginas web, inclusive com muito JavaScript.
  • Montar bases de conhecimento (RAG) a partir de sites e documentação.
  • Extrair dados estruturados de páginas para planilhas ou sistemas.

Observações

  • Respeite os termos de uso e políticas dos sites ao raspar; o Firecrawl respeita robots.txt por padrão. Dados pessoais raspados estão sujeitos à LGPD.
  • Licença AGPL-3.0 no servidor: oferecer versão modificada como serviço exige publicar o código.
  • O serviço hospedado cobra por créditos.
  • Alternativas no catálogo para navegação por agente: Playwright MCP, Chrome DevTools MCP; para converter arquivos em Markdown: MarkItDown.
