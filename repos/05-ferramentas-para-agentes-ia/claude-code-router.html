Claude Code Router (CCR)

Gateway local de modelos para agentes de programação: dá ao Claude Code, Codex, OpenCode e outros um endpoint único e deixa você escolher provedores e modelos (OpenRouter, DeepSeek, Gemini, Kimi etc.), com regras de roteamento, fallback, rotação de chaves e logs de custo.

O que é

O CCR fica entre os agentes e os provedores de modelo. Cada agente (Claude Code, Claude Design, Codex, Grok CLI, Kimi CLI, Kilo Code, OpenCode, Pi, ZCode, WorkBuddy) aponta para um endpoint local estável (http://127.0.0.1:3456), e você gerencia por trás, num só lugar, provedores, modelos, contas, regras de roteamento e ferramentas.

Na prática, permite usar o Claude Code com modelos de outros provedores, trocar de modelo sem mexer na configuração de cada agente, manter as requisições rodando com retentativas e modelos reserva, e ver o que aconteceu em cada chamada (modelo resolvido, latência, tokens, custo estimado).

Principais recursos

  • Perfis prontos para os principais agentes, aplicados pela interface.
  • Protocolos OpenAI (Chat/Responses), Anthropic Messages e Gemini; provedores OpenRouter, DeepSeek, SiliconFlow, Moonshot, Kimi Code, Mistral, Z.AI, Bailian e endpoints compatíveis.
  • Roteamento por condições (cabeçalhos, corpo), prefixos, reescritas, retentativas e fallback ordenado.
  • Pool de credenciais e rotação de chaves.
  • Fusion: adiciona visão, busca na web e ferramentas MCP a modelos que não têm; ToolHub e automação de navegador embutida.
  • Chaves de cliente próprias com expiração e cotas de requisições, tokens e imagens.
  • Observabilidade: logs de requisição e resposta, rota resolvida, latência, tokens, custo, tool calls.
  • AgentClaw: acessar agentes por Slack, Discord, Telegram e outros mensageiros.

Pré-requisitos

  • App desktop: macOS, Windows ou Linux.
  • CLI: Node.js 22+.
  • Chaves de API dos provedores que quiser usar.

Instalação

App desktop (recomendado)

Baixe em Releases (Windows .exe, Linux .AppImage, macOS .dmg para Apple Silicon e Intel) e abra.

CLI (sem Electron)

npm install -g @musistudio/claude-code-router
ccr ui    # abre a interface em http://127.0.0.1:3458

Docker

npm run docker:compose:up

Leia o guia de Docker antes de expor o CCR remotamente.

Comandos e uso

  1. Providers → Add Provider: escolha um preset ou endpoint, coloque a chave, o protocolo e os modelos.
  2. Server → Start: o gateway sobe em http://127.0.0.1:3456.
  3. Agent Config: escolha o agente (ex.: Claude Code), o modelo e aplique o perfil.
  4. Use o agente normalmente; confira em Logs o provedor, modelo, tokens, latência e erros.
  5. Em Routing, adicione condições, retentativas, reescritas e modelos reserva.

Referência da CLI: ccrdesk.top/en/guides/cli.

Quando usar

  • Rodar o Claude Code com modelos mais baratos (DeepSeek, Kimi, GLM) ou via OpenRouter.
  • Ter fallback automático quando um provedor cai ou estoura limite.
  • Controlar custo e uso de vários agentes e chaves num só painel.

Observações

  • Usar o Claude Code com outros modelos pode ter comportamento diferente do esperado e deve respeitar os termos de uso de cada provedor.
  • Expor o gateway na rede exige autenticação; ele concentra suas chaves de API.
  • Alternativas no catálogo: OmniRoute e Free Claude Code; para trocar configurações entre agentes num app desktop, CC Switch.
