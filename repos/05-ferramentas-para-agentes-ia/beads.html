Beads (bd)

Rastreador de tarefas em grafo, distribuído e versionado (sobre o banco Dolt), que serve de memória estruturada para agentes de programação: substitui planos soltos em Markdown por tarefas com dependências, para o agente tocar trabalhos longos sem perder o contexto.

O que é

O Beads (comando bd), criado por Steve Yegge, dá ao agente um lugar persistente para criar, priorizar e encadear tarefas ("beads"). Cada tarefa pode bloquear outras; o comando bd ready mostra só o que está livre para ser feito, o agente reivindica a tarefa, conclui e libera as próximas.

Os dados ficam no Dolt, um banco SQL versionado com branches e merge por célula, sincronizado entre máquinas e agentes via o remoto git. IDs por hash (bd-a1b2) evitam conflitos quando vários agentes ou branches trabalham ao mesmo tempo. Tarefas antigas fechadas são resumidas ("decaimento de memória") para economizar contexto.

É uma ferramenta de linha de comando instalada uma vez no sistema; você não clona o repositório no seu projeto.

Principais recursos

  • Grafo de dependências com detecção automática de tarefas prontas.
  • Saída em JSON pensada para agentes.
  • Hierarquia de épicos, tarefas e subtarefas (bd-a3f8, bd-a3f8.1, bd-a3f8.1.1).
  • Memórias de projeto (bd remember) injetadas no contexto por bd prime.
  • Ligações relates-to, duplicates, supersedes, replies-to; mensagens com threads.
  • Modo stealth (uso local sem commitar arquivos) e modo contribuidor (planejamento em repositório separado).
  • Sincronização com GitHub Issues, backend HTTP experimental e uso sem git.
  • bd rules audit e bd rules compact para regras do Claude em .claude/rules/.
  • Integrações: Claude Code, Codex, Cursor, Factory Droid, Copilot.

Pré-requisitos

  • macOS, Linux, Windows ou FreeBSD.

Instalação

brew install beads           # macOS / Linux (recomendado)
npm install -g @beads/bd     # via Node.js
curl -fsSL https://raw.githubusercontent.com/gastownhall/beads/main/scripts/install.sh | bash   # script

No seu projeto:

cd your-project
bd init            # cria/atualiza AGENTS.md e instala integrações do Claude Code, Codex e Cursor
bd setup claude    # hooks e configurações do Claude Code
bd setup codex     # skill, AGENTS.md e hooks do Codex

Windows e outras formas: guia de instalação.

Comandos e uso

bd ready                        # tarefas sem bloqueios abertos
bd create "Title" -p 0          # cria tarefa prioridade P0
bd update <id> --claim          # reivindica a tarefa (responsável + em andamento)
bd dep add <child> <parent>     # liga tarefas
bd show <id>                    # detalhes e histórico
bd close <id> "Fixed"           # conclui
bd prime                        # contexto de fluxo e memórias para o agente
bd remember "insight"           # guarda um fato do projeto
bd dolt push / bd dolt pull     # sincroniza entre máquinas
bd init --stealth               # uso local, sem commitar arquivos no repo

Para agentes sem bd setup, acrescente ao AGENTS.md: "This project uses bd (beads) for issue tracking. Run bd prime for workflow context. Do not use markdown TODO lists for task tracking."

Quando usar

  • Tarefas longas que atravessam várias sessões e compactações de contexto.
  • Vários agentes trabalhando em paralelo no mesmo projeto.
  • Substituir TODOs em Markdown por algo com dependências e histórico.

Observações

  • Atualizações que cruzam migração de esquema exigem cuidado em bancos sincronizados: siga o guia de upgrade.
  • Verifique o checksum dos binários baixados; o arquivo .beads/.env ignora variáveis de comando e credenciais por segurança.
  • O repositório migrou de steveyegge/beads para gastownhall/beads.
  • Alternativa mais simples, em arquivos Markdown: Planning with Files.
