CC Switch

App desktop que gerencia num só lugar os provedores de API, servidores MCP, skills, prompts e sessões do Claude Code, Claude Desktop, Codex, Gemini CLI, OpenCode e outros, trocando de provedor com um clique, sem editar JSON, TOML ou YAML à mão.

O que é

Cada ferramenta de IA para programação tem seu próprio formato de configuração, e trocar de provedor de modelo significa editar arquivos à mão; MCP, skills e prompts também precisam ser mantidos separadamente em cada uma. O CC Switch junta tudo num app desktop: escolha um preset, coloque a chave e troque com um clique.

A troca altera só os dados de conexão (endpoint, chave e modelo); plugins, hooks, MCP e comentários que você adicionou ficam intactos, e cada arquivo é copiado antes da primeira reescrita. Na primeira execução, ele importa sua configuração atual como provedor default, para nada se perder.

Atende 12 ferramentas: Claude Code, Claude Desktop, Codex, Gemini CLI, Grok Build, OpenCode, OpenClaw, Hermes, Pi, MiniMax Code, Kimi Code e Oh My Pi.

Principais recursos

  • Mais de 90 presets de provedores (incluindo AWS Bedrock, NVIDIA NIM e relays) e configurações customizadas.
  • Três modos: Direto (ferramenta fala com o provedor), Roteamento (passa pela sua máquina, converte formatos de API e faz failover; ex.: usar GPT no Claude Code) e Agregação (modelos de vários provedores numa só lista no Claude Code ou Codex).
  • MCP, skills e prompts centralizados, sincronizados com as ferramentas que você escolher; busca no skills.sh e instalação de skills do GitHub.
  • Projetos: salva provedor, MCP, skills e prompts de uma configuração e troca tudo de uma vez.
  • Sessões legíveis: histórico de conversas com resumo por turno, arquivos alterados e passos que falharam; copia o comando para retomar.
  • Uso e cotas: tokens, custo, taxa de cache e saldo/cota restante das assinaturas, no app e na bandeja do sistema.
  • Gerencia versões das CLIs (instalar, atualizar, diagnosticar duplicatas), inclusive dentro do WSL no Windows.
  • Sincronização entre máquinas via WebDAV ou S3; deep links ccswitch://.

Pré-requisitos

  • Windows 10+, macOS 12+ ou Linux x86_64/ARM64 com glibc 2.35+ e WebKitGTK 4.1 (Ubuntu 22.04+, Debian 12+, Fedora recente).

Instalação

  • Windows: baixe CC-Switch-v{version}-Windows.msi (ou a versão Portable .zip; há builds arm64) em Releases.

  • macOS:

    brew install --cask cc-switch
brew upgrade --cask cc-switch     # atualizar

    Ou o .dmg universal (assinado e notarizado) em Releases.

  • Arch Linux: paru -S cc-switch-bin

  • Linux: .deb, .rpm ou .AppImage em Releases.

Comandos e uso

  1. Na barra lateral, escolha a ferramenta e clique em + para adicionar um provedor (preset ou customizado).
  2. Selecione o provedor e clique em Enable (ou troque pela bandeja do sistema).
  3. O Claude Code não precisa reiniciar; Codex, Gemini CLI e Grok Build precisam reiniciar o terminal; o Claude Desktop precisa reiniciar o app.
  4. Para voltar ao login oficial, ative o provedor oficial (ex.: "Claude Official") e refaça o login.
  5. Opcional: nas abas Routing ou Aggregation, clique em "Start routing" ou "Switch to Aggregation"; "Back to direct" desfaz.
  6. Em MCP, Prompts e Skills, adicione uma vez e ligue a sincronização por ferramenta.

Quando usar

  • Alternar entre a assinatura oficial do Claude e provedores alternativos (Kimi, GLM, DeepSeek, OpenRouter) sem editar arquivos.
  • Manter os mesmos MCPs e skills em vários agentes.
  • Acompanhar consumo e cotas de várias ferramentas num painel.

Observações

  • Termos de uso: o recurso Accounts (beta) permite usar assinaturas do Copilot, ChatGPT e Grok fora do cliente oficial; o próprio projeto alerta que isso pode violar os termos dos fornecedores.
  • O README é dominado por patrocinadores, em grande parte relays de API chineses com descontos; avalie com cuidado antes de mandar código e chaves para intermediários.
  • O site oficial é só ccswitch.io; desconfie de cópias.
  • A ficha cobre o README até a seção de recursos; o FAQ não foi lido por inteiro.
  • Alternativa em forma de gateway: Claude Code Router; também OmniRoute.
