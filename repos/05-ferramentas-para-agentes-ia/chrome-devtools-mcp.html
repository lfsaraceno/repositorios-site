O que é

O chrome-devtools-mcp é um servidor Model Context Protocol (MCP) que dá ao seu assistente de código (Antigravity, Claude, Cursor, Copilot etc.) acesso a uma instância real do Chrome. Com isso, o agente pode automatizar ações, depurar problemas e analisar performance usando o próprio Chrome DevTools.

A automação usa o Puppeteer e espera automaticamente o resultado das ações. O pacote também oferece uma CLI para uso sem MCP. O navegador só é iniciado quando o cliente MCP usa uma ferramenta que precisa dele; apenas conectar ao servidor não abre o Chrome.

Principais recursos

  • Insights de performance: grava traces e extrai recomendações acionáveis com o Chrome DevTools.
  • Depuração avançada: análise de requisições de rede, capturas de tela e mensagens do console (com stack traces mapeados por source map).
  • Automação confiável com Puppeteer, com espera automática pelos resultados.
  • Modo --slim com conjunto reduzido de ferramentas para tarefas básicas de navegador.
  • Opções de configuração como --headless e --isolated, e conexão a um Chrome já em execução (veja o guia de uso avançado).
  • Suporte oficial ao Google Chrome e ao Chrome for Testing.
  • CLI incluída para uso sem MCP.

Pré-requisitos

  • Node.js, versão LTS.
  • Chrome estável atual ou mais recente.
  • npm.

Instalação

Adicione esta configuração ao seu cliente MCP:

{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}

Usar @latest garante que o cliente sempre rode a versão mais recente. Para tarefas básicas, use o modo enxuto:

{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest", "--slim", "--headless"]
    }
  }
}

Instruções específicas para Claude Code, Cursor, VS Code e Antigravity estão no guia de configuração de clientes.

Comandos e uso

Primeiro prompt para testar (o cliente deve abrir o navegador e gravar um trace de performance):

Check the performance of https://developers.chrome.com

Flags mencionadas no README:

--headless                 # executa o Chrome sem janela
--isolated                 # perfil isolado
--slim                     # conjunto reduzido de ferramentas
--no-performance-crux      # não envia URLs de trace à API CrUX
--no-usage-statistics      # desativa estatísticas de uso do Google

Variáveis de ambiente: CHROME_DEVTOOLS_MCP_NO_USAGE_STATISTICS, CHROME_DEVTOOLS_MCP_NO_UPDATE_CHECKS (e a variável CI também desativa as estatísticas).

Quando usar

  • Depurar uma página no navegador real (console, rede, DOM) a partir do agente.
  • Medir e melhorar performance (Core Web Vitals, traces) com orientação do agente.
  • Automatizar fluxos de teste e capturas de tela.

Observações

  • O servidor expõe o conteúdo do navegador ao cliente MCP, que pode inspecionar, depurar e modificar qualquer dado do navegador e do DevTools. Evite compartilhar informações sensíveis.
  • O Google coleta estatísticas de uso por padrão (taxa de sucesso, latência, ambiente); desative com --no-usage-statistics.
  • Ferramentas de performance podem enviar URLs de trace à API CrUX (Chrome User Experience Report); desative com --no-performance-crux.
  • Outros navegadores baseados em Chromium podem funcionar, sem garantia.
  • O servidor verifica periodicamente o registro do npm por atualizações; desative com a variável CHROME_DEVTOOLS_MCP_NO_UPDATE_CHECKS.
