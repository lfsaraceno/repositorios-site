Headroom

Comprime tudo o que o agente de IA lê (saídas de ferramentas, logs, JSON, arquivos, trechos de RAG e histórico) antes de chegar ao modelo, localmente e de forma reversível; funciona como biblioteca, proxy, wrapper de agentes e servidor MCP.

O que é

O Headroom (headroom-ai no PyPI e npm) fica entre o agente e o provedor de modelo e encolhe o contexto: detecta o tipo de conteúdo e aplica o compressor certo (JSON, código por AST, texto com um modelo próprio, imagens). Os originais ficam guardados localmente, e o modelo pode pedir o texto completo quando precisar. Nada do conteúdo é enviado a terceiros para ser comprimido.

Nos cenários medidos pelo projeto, a economia de tokens de entrada foi de 21% a 57%, passando de 90% em arrays JSON e linhas de log repetitivos, e quase nada em texto corrido. A compressão leva menos de 1 ms e preserva o cache de prompt do provedor.

Para agentes como o Claude Code, basta headroom wrap claude: ele sobe um proxy local e abre o agente configurado para passar por ele.

Principais recursos

  • Biblioteca: compress(messages) em Python ou TypeScript.
  • Proxy: headroom proxy --port 8787, sem mudar código.
  • Wrap de agentes: Claude Code, Codex, Grok CLI, Copilot, Cursor (manual), Aider, OpenCode, Cline, Continue, Goose, OpenHands e outros; desfaz com headroom unwrap.
  • MCP: ferramentas headroom_compress, headroom_retrieve, headroom_stats.
  • Memória entre agentes (Claude, Codex, Gemini, Grok) com deduplicação.
  • headroom learn: analisa sessões que falharam e escreve correções em CLAUDE.local.md, CLAUDE.md ou AGENTS.md.
  • Redução de tokens de saída (opcional): pede respostas mais enxutas sem quebrar o cache.
  • Integrações com LangChain, LiteLLM, Vercel AI SDK, Agno, Strands e SDKs da Anthropic e OpenAI.

Pré-requisitos

  • Python 3.11+ (para a CLI e o proxy). Recomenda-se uv com Python 3.13.
  • Rodas nativas para macOS Apple Silicon, Linux e Windows; em Mac Intel, use Docker.

Instalação

uv tool install --python 3.13 "headroom-ai[all]"   # CLI isolada (recomendado)
pip install "headroom-ai[all]"                     # CLI e proxy via pip
npm install headroom-ai                            # só o SDK TypeScript (sem CLI)
docker pull ghcr.io/headroomlabs-ai/headroom:latest

Comandos e uso

headroom wrap claude                    # abre o Claude Code passando pelo Headroom
headroom wrap claude --code-memory serena   # também instala o Serena para navegação de código
headroom deploy                         # instalação persistente local + configuração de agentes
headroom proxy --port 8787              # proxy para qualquer cliente compatível com OpenAI
headroom doctor                         # verifica se o roteamento funciona
headroom dashboard                      # economia ao vivo
headroom savings                        # economia no seu tráfego real
headroom learn --verbosity --apply      # aprende o nível de concisão das suas sessões
headroom mcp install                    # instala o servidor MCP
headroom unwrap claude                  # desfaz o wrap
headroom update                         # atualiza

Em código Python:

from headroom import compress

result = compress(messages, model="gpt-4o")
print(f"Saved {result.tokens_saved} tokens ({result.compression_ratio:.0%})")

Quando usar

  • Agentes que leem muita saída de ferramentas, logs ou JSON (incidentes, triagem de issues, exploração de código).
  • Apps próprios que mandam resultados de busca, linhas de banco ou históricos longos para o modelo.
  • Compartilhar memória entre Claude Code, Codex e outros agentes.

Observações

  • Telemetria anônima ligada por padrão (taxas de compressão, contadores, IDs de modelo, SO; nunca prompts ou código). Desligue com HEADROOM_TELEMETRY=off, DO_NOT_TRACK=1 ou HEADROOM_OFFLINE=1.
  • Pouco ganho em prompts curtos e texto corrido.
  • Ao usar provedores compatíveis com OpenAI de terceiros (DeepSeek, OpenRouter), passe --openai-api-url, senão a chave vai para a OpenAI.
  • Em redes corporativas com inspeção SSL, veja o guia de redes corporativas.
  • Complementares no catálogo: RTK (saída de comandos), Caveman (respostas curtas) e Serena (navegação semântica, recomendada pelo projeto).
