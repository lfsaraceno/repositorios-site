Search Console MCP

Servidor MCP que dá ao Claude (e a outros agentes) acesso aos dados reais do seu site no Google Search Console, Bing Webmaster Tools, Google Analytics 4 e AdSense, com análises prontas: quedas de tráfego, palavras quase no topo, canibalização, saúde do site e indexação.

O que é

Os dados de um site ficam espalhados em vários painéis: Search Console, Bing, GA4 e AdSense. Responder "minha receita caiu por queda de tráfego ou de RPM?" costuma exigir exportar CSVs e cruzar planilhas à mão.

O Search Console MCP põe essas fontes atrás de um só conjunto de ferramentas que o agente chama direto. As análises (canibalização, anomalias, atribuição de queda) são feitas no servidor, antes de os dados chegarem ao contexto do Claude. Você pergunta em linguagem natural e o agente responde com os números do seu site.

Principais recursos

  • Fontes: Google Search Console, Bing Webmaster Tools, Google Analytics 4 e Google AdSense.
  • Análises: comparação de períodos, causa de queda de tráfego, detecção de anomalias, Google x Bing.
  • Auditorias de SEO (seo_audit): quick wins, palavras na "zona de ataque" (posições 8 a 15), canibalização, consultas perdidas, marca x não marca.
  • Saúde do site (site_health_check) e PageSpeed/Core Web Vitals (pagespeed_analyze).
  • Inspeção de URL e indexação: status, cota e envio por API do Google/Bing ou IndexNow.
  • Sitemaps: listar, enviar e remover.
  • Consultas de IA (genai_query_insights): marca consultas com cara de pergunta para IA. É heurística própria, não dado oficial do Google ou do Bing.
  • Várias contas: mais de 20 contas, e o servidor descobre sozinho qual conta é dona de cada site.
  • CLI: todas as ferramentas também rodam no terminal, com saída em JSON, CSV ou tabela.

Pré-requisitos

  • Node.js (roda com npx).
  • Um site verificado no Google Search Console, com a conta Google que tem acesso.
  • Opcional: chave da API do Bing Webmaster Tools; conta de serviço do Google Cloud para o GA4.

Instalação

npx search-console-mcp setup

O comando abre o navegador, autoriza sua conta Google e guarda as credenciais. Depois adicione ao cliente MCP (Claude Desktop, Cursor, Antigravity etc.):

{
  "mcpServers": {
    "search-console": {
      "command": "npx",
      "args": ["search-console-mcp"]
    }
  }
}

No Claude Code, o equivalente é claude mcp add search-console -- npx search-console-mcp (forma padrão do Claude Code; o README só mostra o JSON).

Reinicie o cliente.

Outras fontes:

npx search-console-mcp setup --engine=ga4        # Google Analytics 4 (conta de serviço)
npx search-console-mcp setup --engine=adsense    # AdSense (OAuth só leitura)

Para o Bing, defina a variável BING_API_KEY com a chave gerada nas configurações do Bing Webmaster Tools.

Conta de serviço (servidores e automação): crie a conta no Google Cloud, gere a chave JSON, adicione o e-mail da conta como usuário no Search Console e aponte GOOGLE_APPLICATION_CREDENTIALS para o arquivo.

Comandos e uso

Perguntas do README para colar no agente:

My traffic dropped this week vs. last. Find exactly when it started and which pages are responsible.
Find keywords for example.com ranking positions 8–15 with 1,000+ impressions — my best quick wins.
Check for keyword cannibalization — are two of my pages competing for the same query?
Compare Google vs Bing performance for the last 30 days (compare_engines) — where is Bing winning?

Gerenciar contas e rodar ferramentas pelo terminal:

npx search-console-mcp accounts list
npx search-console-mcp accounts add-site --account=voce@empresa.com --site=example.com
npx search-console-mcp run --help
npx search-console-mcp run seo_audit --siteUrl=https://example.com --type=quick_wins
npx search-console-mcp run sites_list --engine=all --format=table

Quando usar

  • Descobrir por que o tráfego orgânico caiu e em quais páginas.
  • Achar palavras-chave que estão quase na primeira página para priorizar conteúdo.
  • Relatórios de SEO de vários sites ou clientes sem abrir cada painel.
  • Dar ao Claude dados reais antes de pedir uma estratégia de SEO.

Observações

  • Só leitura por padrão: enviar ou apagar sitemaps e gerenciar sites pede uma autorização de escrita separada, oferecida na primeira vez que a ferramenta for usada.
  • Credenciais: ficam no cofre do sistema (no Windows, o Gerenciador de Credenciais). Sem cofre, vão para um arquivo criptografado com uma chave da máquina.
  • Use o modo stdio (o padrão). O modo SSE está obsoleto e vai sair na próxima versão.
  • Projeto de um desenvolvedor só, com poucas estrelas. Ainda assim, recebe correções frequentes (v2.1.4).
  • Relacionados no catálogo: o Claude SEO também lê o Search Console e faz auditoria completa. O Open SEO pesquisa palavras-chave e backlinks. O GEO Optimizer prepara o site para ser citado por IAs.
