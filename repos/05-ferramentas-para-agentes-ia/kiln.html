O que é

O Kiln é uma bancada de trabalho para o ciclo completo de desenvolvimento de um produto de IA, como um chatbot, um agente, um classificador ou um extrator de dados. A ideia central é definir uma tarefa uma vez e, sobre o mesmo conjunto de dados, avaliar, otimizar o prompt, escolher o modelo, adicionar RAG, montar agentes, gerar dados sintéticos e fazer fine-tuning. Os resultados de cada etapa se somam.

Ele resolve um problema comum: mudar o prompt ou trocar de modelo melhora uma coisa e piora outra sem ninguém perceber. O Kiln mede a qualidade em todas as dimensões que você definir e, com o Auto-Optimize, testa centenas de variações para achar a melhor combinação.

Tem duas faces: um app desktop (Windows, Mac e Linux) em que gestores, especialistas e QA dão nota às respostas e adicionam exemplos sem programar, e uma biblioteca Python que leva as mesmas tarefas para produção. Roda localmente, com as suas chaves de API ou totalmente offline via Ollama. A sincronização entre pessoas da equipe usa o Git.

Principais recursos

  • Eval Builder: gera automaticamente os testes (um modelo-juiz e um dataset sintético) e os ajusta à sua preferência em cerca de 10 minutos.
  • Auto-Optimize: busca a melhor forma de rodar a tarefa, otimizando prompt, modelo, ferramentas, skills, subagentes e parâmetros.
  • RAG: você arrasta documentos (PDF, imagem, vídeo, áudio) e ele gera a base e os testes dela.
  • Subagentes: hierarquias de agentes, cada um com o seu próprio contexto. Também suporta ferramentas e MCP.
  • Dados sintéticos para testes ou fine-tuning.
  • Fine-tuning sem código em mais de 60 modelos (Qwen, Llama, GPT, Gemini) via Fireworks, Together e Vertex, com deploy serverless.
  • Mais de 190 modelos testados: OpenAI, Anthropic, Gemini, Bedrock, Ollama, OpenRouter, Fireworks, Groq e qualquer endpoint compatível com OpenAI.
  • Projetos em arquivos JSON abertos (.kiln), fáceis de versionar no Git e de abrir com pandas.

Pré-requisitos

  • Windows, macOS ou Linux para o app.
  • Python, para usar a biblioteca.
  • Chaves de API dos provedores que for usar, ou Ollama para rodar offline.

Instalação

App desktop

Baixe em kiln.tech/download, instale com um clique e siga o quickstart de 5 minutos. Conecte os provedores de IA pela interface: as credenciais ficam em ~/.kiln_ai/settings.yaml e são lidas também pela biblioteca.

Biblioteca Python

pip install kiln-ai

Comandos e uso

Fluxo no app: crie um projeto, defina uma tarefa (instrução e, se quiser, os esquemas JSON de entrada e saída), rode alguns exemplos, dê notas às respostas, gere os testes com o Eval Builder e compare prompts e modelos.

Abrir um projeto pela biblioteca:

from kiln_ai.datamodel import Project

project = Project.load_from_file("path/to/your/project.kiln")   # fica em ~/Kiln Projects/<nome>/
for task in project.tasks():
    print(task.name, len(task.runs()))   # tarefas e tamanho do dataset de cada uma

Empacotar só o necessário para rodar uma tarefa em produção:

uvx kiln_ai package_project "/path/to/your/project.kiln" -t TASK_ID_TO_EXPORT

Rodar a tarefa dentro da sua aplicação, com a configuração padrão definida no app:

from kiln_ai.adapters.adapter_registry import adapter_for_task
from kiln_ai.datamodel.task import Task

async def run_kiln_task(input: str):
    task = Task.load_from_file(TASK_PATH)
    run_config = next(c for c in task.run_configs() if c.id == task.default_run_config_id)
    adapter = adapter_for_task(task, run_config_properties=run_config.run_config_properties)
    task_run, run_output = await adapter.invoke_returning_run_output(input)
    return run_output.output    # task_run.usage traz custo e tokens

Importar um dataset existente: crie objetos TaskRun com entrada, saída e nota (opcional), e salve com item.save_to_file(). O Kiln valida cada item contra o esquema da tarefa. Também dá para carregar os .kiln direto em pandas ou polars.

A biblioteca exporta o RAG para vector stores do LlamaIndex (ex.: LanceDB) e se conecta a OpenTelemetry e Braintrust. Há também uma API REST.

Quando usar

  • Medir e melhorar o prompt de um agente antes de colocá-lo em produção. Por exemplo, o agente de vendas de um CRM como o DeskcommCRM.
  • Comparar modelos e provedores para achar o mais barato que mantém a qualidade.
  • Montar e testar uma base RAG com documentos da empresa.
  • Treinar um modelo menor e mais barato com os seus próprios dados (fine-tuning).
  • Envolver pessoas não técnicas (gestor, especialista) na avaliação das respostas da IA.

Observações

  • Licença mista: só a biblioteca Python e o servidor REST são MIT. O app desktop é source-available (fair-code): o uso é gratuito, mas não é software livre no sentido estrito.
  • Kiln Pro (pago e opcional): o assistente de IA, o Auto-Optimize e o Eval Builder fazem parte desse serviço. O app básico funciona sem ele.
  • O Auto-Optimize e os testes chamam os modelos muitas vezes, o que gera custo de API nos seus provedores.
  • O fine-tuning roda em provedores externos (Fireworks, Together, Vertex), que cobram à parte.
