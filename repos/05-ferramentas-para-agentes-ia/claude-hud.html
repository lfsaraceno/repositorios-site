Claude HUD

Plugin do Claude Code que mostra na status line o uso de contexto, limites de uso, ferramentas ativas, subagentes rodando e progresso das tarefas, sempre visível abaixo da caixa de entrada.

O que é

O Claude HUD transforma a status line do Claude Code num painel. Por padrão são duas linhas: modelo, provedor (Bedrock, Vertex, MiniMax), pasta e branch git; e barras de contexto usado (verde, amarelo, vermelho) e de limite de uso da assinatura, com o tempo até reiniciar.

[Opus] │ my-project git:(main*)
Context █████░░░░░ 45% │ Usage ██░░░░░░░░ 25% (resets in 1h 30m)

Linhas opcionais mostram ferramentas em uso, subagentes e tarefas, entre cerca de cem opções.

Principais recursos

  • Barra de contexto e de limite de uso com tempo para reset.
  • Linhas opcionais de ferramentas (Edit, Read ×3), agentes (explore [haiku]) e todos (2/5).
  • Configuração por conversa: peça ao Claude ou use /hud ("use the compact layout", "the HUD is blank"); mostra prévia antes de salvar e desfaz a última mudança.
  • Relatório de bug com dados mascarados, que você lê antes de enviar.
  • Processo Node isolado pelo modelo de permissões: não inicia programas, não lê credenciais e não acessa a rede.

Pré-requisitos

  • Claude Code v2.1.260 ou mais novo.
  • Node.js 22.18 ou mais novo (o /hud ajuda a encontrar ou instalar).

Instalação

Dentro do Claude Code:

/plugin marketplace add jarrodwatts/claude-hud
/plugin install claude-hud
/reload-plugins
/hud

Pelo terminal:

claude plugin marketplace add jarrodwatts/claude-hud
claude plugin install claude-hud@claude-hud

Depois rode /reload-plugins e /hud numa sessão.

Comandos e uso

/hud     # confere a instalação, aponta a status line para o HUD, altera opções e desfaz mudanças

claude plugin marketplace update claude-hud          # atualiza o marketplace
claude plugin update claude-hud@claude-hud           # atualiza o plugin (depois /reload-plugins)
  • Configuração em ~/.claude/plugins/claude-hud/config.json.
  • Desligar numa sessão: inicie o Claude Code com CLAUDE_HUD_DISABLE=1.
  • Atualização automática: /plugin → Marketplaces → claude-hud → Enable auto-update.

Quando usar

  • Acompanhar o quanto do contexto já foi usado antes de compactar ou abrir nova sessão.
  • Ver quanto falta do limite de uso da assinatura.
  • Acompanhar subagentes e ferramentas em tarefas longas.

Observações

  • --extra-cmd roda um comando de shell a cada atualização: só funciona com CLAUDE_HUD_ALLOW_EXTRA_CMD=1 e equivale a execução de código arbitrário; nunca use comando de fonte não confiável.
  • O HUD substitui a status line atual (pede confirmação antes).
