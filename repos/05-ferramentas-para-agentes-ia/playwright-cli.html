Playwright CLI

CLI oficial da Microsoft para agentes de código controlarem o navegador com comandos curtos (abrir, clicar, preencher, tirar screenshot, gravar vídeo), gastando menos tokens que o Playwright MCP.

O que é

O playwright-cli dá acesso ao Playwright pela linha de comando, junto com skills que ensinam o agente a usá-lo. Funciona com o Claude Code, o GitHub Copilot e outros agentes.

O README explica a diferença para o Playwright MCP:

  • CLI: os agentes de código preferem cada vez mais CLI com skills, porque o modelo não precisa carregar esquemas de ferramentas nem árvores de acessibilidade enormes no contexto. Gasta menos tokens e sobra contexto para o código.
  • MCP: continua útil para fluxos longos e autônomos que precisam de estado persistente e de análise detalhada da página, como automação exploratória e testes que se corrigem sozinhos. Ver Playwright MCP.

Principais recursos

  • Comandos curtos para tudo: navegação, cliques, digitação, teclado, mouse, abas, upload, arrastar e soltar e diálogos.
  • Snapshots da página salvos em arquivo, com referências (e15, e21) para mirar nos elementos. find busca texto no snapshot sem trazê-lo inteiro.
  • Sessões separadas por projeto (-s=nome), com perfil em memória ou persistente (--persistent).
  • Painel visual (playwright-cli show) para ver e controlar todas as sessões dos agentes ao vivo.
  • Saídas: screenshot, PDF, trace, vídeo com cursor animado e capítulos, e gravação de ações que vira código Playwright.
  • Emulação de dispositivo, tema claro ou escuro, redução de movimento, contraste e cores forçadas.
  • Rede e armazenamento: mock de requisições, cookies, localStorage, sessionStorage e salvar ou carregar o estado.
  • WebMCP: lista e chama ferramentas que a própria página registra para agentes (API experimental).
  • As skills instaladas trazem guias para rodar e depurar testes, gerar testes, fazer mock, trace, vídeo e anexar evidências em PRs.

Pré-requisitos

  • Node.js 18+.
  • Claude Code, GitHub Copilot ou outro agente de código.

Instalação

npm install -g @playwright/cli@latest
playwright-cli --help
playwright-cli install --skills    # instala as skills para os agentes

Se o projeto já tem Playwright instalado, dá para usar a versão local com npx playwright cli em vez do comando global.

Sem instalar as skills, o agente também se vira: peça para ele consultar playwright-cli --help.

Comandos e uso

Pedido ao agente:

Use playwright skills to test https://demo.playwright.dev/todomvc/.
Take screenshots for all successful and failing scenarios.

Manual:

playwright-cli open https://demo.playwright.dev/todomvc/ --headed   # headless é o padrão
playwright-cli type "Buy groceries"
playwright-cli press Enter
playwright-cli snapshot          # gera as referências dos elementos
playwright-cli check e21
playwright-cli screenshot

Comandos principais:

Comando Para quê
open [url] / goto <url> Abrir o navegador / navegar
click <ref> / fill <ref> <texto> / type <texto> Interagir com a página
snapshot / find <texto> Ler o estado da página
screenshot / pdf Salvar a página
console / requests Ver o console e as requisições
route <padrão> Fazer mock de requisições
tracing-start / video-start / recording-start Gravar trace, vídeo ou ações
generate-locator <ref> Gerar um locator do Playwright
show / show --annotate Abrir o painel / revisar a UI com anotações
list / close-all / kill-all Gerenciar sessões

Sessões:

playwright-cli -s=example open https://example.com --persistent
PLAYWRIGHT_CLI_SESSION=todo-app claude .     # o agente usa essa sessão

Uma sessão headless fecha sozinha depois de 1 hora sem comandos. Mude com open --idle-timeout=<ms> (0 desativa).

Outras opções de open: --browser=chrome, --mobile, --device="iPhone 15", --profile=<pasta>, --config=arquivo.json. A configuração padrão é lida de .playwright/cli.config.json.

Quando usar

  • Deixar o agente testar o próprio frontend: abrir, clicar, conferir e tirar screenshots.
  • Gerar e depurar testes Playwright.
  • Gravar vídeos ou traces de um fluxo para anexar num PR.
  • Comparação: o Chrome DevTools MCP é um MCP voltado a depuração e desempenho no Chrome. O Playwright CLI é uma CLI com skills, mais econômica em tokens, e funciona com Chromium, Firefox e WebKit. Combina com a Taste Skill e o Impeccable para conferir a interface gerada.

Observações

  • Navegador logado: attach --cdp=chrome e attach --extension=chrome conectam o agente ao seu navegador real, com todas as contas logadas. --persistent grava cookies e sessões em disco. Use perfis separados e não deixe o agente navegar logado em contas sensíveis.
  • Conteúdo da página não é confiável: o README avisa que nomes, descrições e resultados de ferramentas WebMCP vêm da página e são entrada não confiável, não instruções. Uma página maliciosa pode tentar manipular o agente com prompt injection.
  • Acesso a arquivos: por padrão, o acesso fica limitado à pasta do projeto. allowUnrestrictedFileAccess (ou PLAYWRIGHT_MCP_ALLOW_UNRESTRICTED_FILE_ACCESS) libera arquivos de qualquer lugar, inclusive URLs file://. Só ative se precisar. As listas de origens permitidas e bloqueadas não são uma barreira de segurança.
  • O repositório é antigo (2020), mas foi reaproveitado para a CLI atual. O último release é o v0.1.22, de set/2026.
