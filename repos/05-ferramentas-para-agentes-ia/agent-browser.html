Agent Browser

CLI nativa em Rust da Vercel Labs que dá um navegador ao agente de IA, um comando por vez: o agente lê a página como texto compacto, com uma referência (@e1) para cada elemento, e age sobre essas referências.

O que é

O comando snapshot devolve a página como texto, com uma referência para cada elemento clicável. O agente age sobre uma referência, lê a página de novo para conferir e repete. O navegador fica aberto entre os comandos, então cada passo é uma chamada curta no terminal, o que gasta poucos tokens.

Um daemon em segundo plano controla o navegador pelo Chrome DevTools Protocol. Por padrão usa o Chrome for Testing, mas também conecta a um Chrome já aberto, usa outros motores (Lightpanda, Obscura, Firefox), o Safari do simulador de iOS ou navegadores na nuvem (Browserbase, Browserless, Browser Use e outros).

Principais recursos

  • Navegar e ler: open, snapshot, read, get.
  • Interagir: click, fill, type, press, select, scroll, drag, upload, find.
  • Capturar: screenshot, pdf, record, diff.
  • Depurar: console, erros, rede, Web Vitals, React, acessibilidade, profiler.
  • Sessões e login salvos, cofre de credenciais, lista de domínios permitidos e políticas de ação.
  • Um clique falha de verdade (em vez de fingir sucesso) quando o elemento está escondido, desativado ou coberto, por exemplo por um banner de cookies.
  • Skills que acompanham a versão da CLI e servidor MCP (agent-browser mcp).
  • Binários para macOS, Linux e Windows.

Pré-requisitos

  • Node.js (para instalar via npm) ou Homebrew.

Instalação

npm install -g agent-browser
agent-browser install           # baixa o Chrome for Testing (só na primeira vez)

Sem instalar: npx agent-browser open example.com. No Linux, agent-browser install --with-deps instala também as bibliotecas do sistema.

Para ensinar o agente a usar:

npx skills add vercel-labs/agent-browser

Ou adicione ao AGENTS.md: "Use agent-browser for browser automation. Before the first use, run agent-browser skills get core and follow it."

Comandos e uso

agent-browser open example.com
agent-browser snapshot -i       # elementos interativos, cada um com uma referência
agent-browser click @e1         # age sobre uma referência do snapshot
agent-browser get url           # confere o resultado
agent-browser close

Depois de navegar ou de a página mudar, tire um snapshot novo antes de usar as referências de novo. Também funciona com seletores CSS, texto e localizadores semânticos:

agent-browser find role button click --name "Submit"

Quando usar

  • Dar ao agente de código um navegador barato em tokens para testar o próprio app.
  • Automatizar tarefas na web (preencher formulários, extrair dados, conferir fluxos).
  • Testes de ponta a ponta guiados por agente.

Observações

  • O agente navega com acesso real: use as listas de domínios permitidos e as políticas de ação ao lidar com contas e dados sensíveis.
  • Por padrão, o navegador headless fecha após uma hora sem comandos.
  • Relacionados no catálogo: o Playwright CLI e o Playwright MCP são as alternativas da Microsoft.
