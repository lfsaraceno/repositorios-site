API Anything

Transforma sites sem API em operações JSON que o agente chama por MCP, CLI, TypeScript, Python ou HTTP: aprende a requisição pelo tráfego do próprio site, usa HTTP simples quando dá e se conserta quando o site muda. Já vem com 114 sites e 323 operações de leitura.

O que é

O API Anything dá ao agente uma "API" para sites que não têm uma: buscar a nota de um livro no Goodreads, voos no Google Flights ou menções a um projeto no Hacker News, sem pilotar um navegador a cada consulta.

Funciona em três etapas. Aprender: um navegador sem interface carrega a página com dois valores de exemplo; o que muda vira parâmetro, o resto é guardado igual, e os cookies viram referências. Não usa LLM nessa etapa. Chamar: a operação é enviada por fetch do Node (tier 1); se o site bloquear, a requisição sai de dentro de uma página do navegador (tier 2); em último caso, roda a página e lê a resposta (tier 3). Consertar: quando a resposta deixa de bater, tenta uma versão atualizada do catálogo ou reaprende, e só salva se o replay der certo.

Existe um catálogo compartilhado em que as instalações publicam operações aprendidas em páginas públicas (sem cookies nem tokens). Outras instalações verificam cada operação antes de ela entrar no ar. As chamadas sempre rodam na sua máquina; o catálogo não faz proxy.

Principais recursos

  • 114 sites e 323 operações de leitura prontas, que funcionam sem o catálogo.
  • Servidor MCP com find_sites, list_operations, call_operation, learn_site, login e outras ferramentas.
  • Uso por MCP, CLI (inclusive lotes em JSONL), TypeScript, Python e servidor HTTP local com REST e OpenAPI.
  • Respostas enxutas: --fields escolhe os campos, e get_result recupera o resto localmente sem chamar o site de novo.
  • Monitoramento: --changes mostra o que é novo, sumiu ou mudou; --max-age reaproveita uma resposta recente.
  • Sessões locais: login importa cookies do navegador que você escolher, criptografados (DPAPI no Windows).
  • Escritas desligadas por padrão, enviadas uma vez só e confirmadas por uma leitura. Nenhuma operação de escrita vem pronta.
  • Classificação de erro com motivo e próximo passo (rate, blocked, retryAfterMs etc.).

Pré-requisitos

  • Node 22.13 ou mais novo.
  • Um navegador Chromium (Chrome, Edge, Brave, Chromium, Vivaldi, Arc) para aprender sites novos e para os tiers 2 e 3. As operações compartilhadas em HTTP simples funcionam sem navegador.
  • Não precisa de conta nem de chave de API.

Instalação

Testar sem instalar

npx -y api-anything call hacker-news search query=sqlite --fields title,url --max-tier 1

Conectar ao agente (recomendado)

npx -y api-anything setup                                   # pergunta o cliente e a opção de compartilhar
npx -y api-anything setup --agents claude-code --no-share   # Claude Code, sem compartilhar o que aprender
npx -y api-anything setup --agents claude-code --no-share --local-only   # nada vai para o catálogo, nem buscas
npx -y api-anything setup --dry-run                         # mostra o que mudaria antes de mudar

Clientes suportados: claude-code, codex, cursor, claude-desktop, gemini e vscode (Hermes com --agents hermes). O setup conecta o servidor MCP, instala a skill quando o agente aceita, procura um Chromium e faz backup de cada arquivo de configuração antes de editar. Reinicie o agente depois.

Instalação global e configuração manual

npm install -g api-anything
claude mcp add --scope user api-anything -- api-anything mcp   # Claude Code
codex mcp add api-anything -- api-anything mcp                 # Codex
api-anything mcp --print-config                                # entrada pronta para outros clientes

Plugin do Claude Code

Instala só o servidor MCP e a skill, sem os outros passos do setup:

/plugin marketplace add goodnight000/api-anything
/plugin install api-anything@api-anything

Comandos e uso

Depois de conectado, pergunte ao agente em linguagem natural:

What does Goodreads rate Piranesi?

Pela CLI:

api-anything call hacker-news search query=sqlite                # chama uma operação pronta
api-anything learn 'https://lobste.rs/domains/{domain}' \
  --args domain=github.com --args2 domain=arxiv.org --args3 domain=youtube.com   # ensina um site novo (2 exemplos + 1 de checagem)
api-anything login linkedin                                       # importa a sessão do navegador para um site com login
api-anything mcp --sites goodreads,hacker-news                    # expõe cada operação como ferramenta própria
api-anything serve                                                # servidor HTTP local (REST, OpenAPI, MCP)

Exemplo do repositório que junta menções a um projeto em cinco sites:

npm ci
node examples/mentions.mjs duckdb --json

Quando usar

  • Dar ao agente acesso rápido e barato a sites sem API, em vez de navegar página por página.
  • Monitorar preços, menções ou listas que mudam com o tempo.
  • Montar scripts e apps que consultam sites como se fossem APIs JSON.

Observações

  • Termos de uso: muitos sites proíbem acesso automatizado. O README avisa que a responsabilidade é sua. Não resolve CAPTCHA: o que não passa volta como blocked (o Reddit bloqueia HTTP simples em muitas redes).
  • Privacidade e LGPD: as buscas no catálogo enviam as palavras, o domínio ou a URL. Com o compartilhamento ligado, operações aprendidas em páginas públicas, consertos e relatórios (versão, resultado, tier, tempo; nunca seus argumentos ou dados) vão para o catálogo. Operações aprendidas com login só são compartilhadas com sua autorização. Para não enviar nada, use --no-share --local-only (ou API_ANYTHING_LOCAL_ONLY=1).
  • Escritas: ficam desligadas até você liberar (--allow-writes). Cuidado ao liberar em sites com sua conta logada.
  • Sem cofre do sistema (container, CI), defina API_ANYTHING_KEY com uma senha e guarde-a: sem ela, as sessões criptografadas ficam ilegíveis.
  • Projeto novo (criado em set/2026) e catálogo ainda pequeno. Uma operação que funciona para outros pode falhar na sua região ou rede.
  • Relacionados no catálogo: o Firecrawl extrai conteúdo de páginas para LLMs, enquanto o API Anything reaproveita as requisições internas do site como operações; o Playwright MCP e o Playwright CLI pilotam o navegador a cada ação, e o API Anything só usa navegador quando precisa.
