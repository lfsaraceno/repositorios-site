O que é

Modelos de linguagem aprendem com dados de meses ou anos atrás: geram exemplos antigos, inventam APIs que não existem e respondem sobre versões velhas de pacotes. O Context7, da Upstash, busca a documentação e os exemplos de código atuais direto da fonte e os coloca no contexto do agente.

Funciona de dois jeitos: CLI + Skills (uma skill orienta o agente a buscar docs com o comando ctx7, sem MCP) ou MCP (registra o servidor Context7 para o agente chamar as ferramentas de documentação). Basta acrescentar "use context7" ao pedido, ou deixar uma regra para isso.

Este repositório tem o código do servidor MCP; a API, o parser e o crawler são privados.

Principais recursos

  • Documentação atualizada e por versão de milhares de bibliotecas (indexadas pela comunidade).
  • Configuração com um comando para Claude Code, Cursor e OpenCode, via OAuth.
  • Ferramentas MCP resolve-library-id e query-docs; comandos CLI ctx7 library e ctx7 docs.
  • IDs de biblioteca (/supabase/supabase, /vercel/next.js) para pular a etapa de busca.
  • Servidor remoto em https://mcp.context7.com/mcp para mais de 30 clientes MCP.
  • SDK TypeScript, ferramentas para o Vercel AI SDK e extensão para pi.dev.

Pré-requisitos

  • Node.js 22.13 ou mais novo para a CLI ctx7.
  • Chave de API gratuita (recomendada, para limites maiores) em context7.com/dashboard.

Instalação

npx ctx7 setup              # autentica via OAuth, gera chave e instala a skill (escolha CLI + Skills ou MCP)
npx ctx7 setup --claude     # direciona para o Claude Code (também --cursor, --opencode)
npx ctx7 remove             # desfaz a configuração

Manual (qualquer cliente MCP): URL https://mcp.context7.com/mcp com o cabeçalho Authorization: Bearer YOUR_API_KEY. Instruções por cliente: context7.com/docs/resources/all-clients.

Comandos e uso

Prompts:

Configure a Cloudflare Worker script to cache JSON API responses for five minutes. use context7
Implement basic authentication with Supabase. use library /supabase/supabase for API and docs.
How do I set up a Next.js 16 proxy? use context7

CLI:

ctx7 library <name> <query>     # busca a biblioteca e retorna os IDs
ctx7 docs <libraryId> <query>   # traz a documentação (ex.: /vercel/next.js)

Regra para o CLAUDE.md (se não usou o ctx7 setup):

Always use Context7 when I need library/API documentation, code generation, setup or configuration steps without me having to explicitly ask.

Quando usar

  • Trabalhar com bibliotecas que mudam rápido (Next.js, Supabase, frameworks de IA) sem receber código de versões antigas.
  • Configurar ferramentas e APIs com a documentação oficial atual no contexto.
  • Reduzir APIs inventadas em projetos com dependências novas.

Observações

  • A documentação indexada é contribuída pela comunidade; a Upstash não garante precisão nem segurança de todo conteúdo.
  • O backend é um serviço da Upstash; o uso envia suas consultas para lá.
