Serena

Servidor MCP que dá ao agente de IA ferramentas de IDE: busca, edição, refatoração e depuração de código no nível de símbolos (classes, funções, referências), com suporte a mais de 40 linguagens via language servers ou via plugin JetBrains.

O que é

Agentes de programação costumam navegar no código por números de linha e busca de texto, o que é lento e frágil em projetos grandes. O Serena entrega ferramentas no estilo de uma IDE, que trabalham com símbolos e suas relações: achar uma função, listar quem a referencia, renomear em todos os arquivos, substituir o corpo de um método.

Ele se conecta a qualquer cliente via MCP (Claude Code, Codex, OpenCode, Gemini CLI, Cursor, IDEs JetBrains, Claude Desktop e outros). O entendimento do código vem de duas fontes, à sua escolha: language servers (LSP, gratuito, padrão) ou o plugin Serena para JetBrains (pago, com teste grátis), que usa a análise da sua IDE.

A versão 2 trouxe uma interface de agente baseada em REPL (execução de código).

Principais recursos

  • Busca: achar símbolo, visão geral do arquivo, referências, declaração, implementações, diagnósticos; com JetBrains, também hierarquia de tipos e busca em dependências.
  • Refatoração: renomear símbolos (LSP) ou símbolos, arquivos e pastas, mover, inline e remoção de código não usado (JetBrains).
  • Edição simbólica: substituir corpo de símbolo, inserir antes/depois, exclusão segura.
  • Depuração interativa com breakpoints e inspeção de variáveis (só JetBrains).
  • Memória de projeto para fluxos longos, que pode ser desligada.
  • Mais de 40 linguagens via LSP: Python, TypeScript, Java, C#, Go, Rust, PHP, Ruby, Kotlin, Dart, Elixir e outras.
  • Configuração em camadas via YAML (global, por projeto, por cliente, modos).

Pré-requisitos

  • uv (único pré-requisito).
  • Algumas linguagens exigem dependências extras do language server.
  • Opcional: IDE JetBrains com o plugin Serena (pago).

Instalação

uv tool install -p 3.13 serena-agent    # instala o comando serena
serena init                             # inicializa com o backend de language servers
serena init -b JetBrains                # alternativa: backend JetBrains

Depois configure o comando de inicialização no seu cliente MCP seguindo o guia de clientes (Claude Code, Codex, Claude Desktop, IDEs).

Comandos e uso

Com o MCP conectado, o agente passa a ter as ferramentas do Serena. Peça normalmente:

Rename the class UserService to AccountService across the whole project and update all references.

Find every caller of calculate_tax and show me the call sites.

No Claude Code e no Codex, as ferramentas básicas do Serena (leitura de arquivo, shell, regex) ficam desligadas por padrão, porque o agente já as tem.

Quando usar

  • Projetos grandes ou monorepos onde o agente se perde com busca de texto.
  • Refatorações entre vários arquivos (renomear, mover) com segurança.
  • Economizar tokens lendo só os símbolos necessários em vez de arquivos inteiros.

Observações

  • Não instale via marketplace de MCP ou de plugins: segundo o projeto, os comandos lá estão desatualizados. Use o uv como acima.
  • Licença GPL-3.0-or-later para a aplicação; distribuições que combinam com o SolidLSP (MIT) ficam sob GPL.
  • O plugin JetBrains é pago; Rider e CLion não são suportados.
  • Para mapear a arquitetura do código em grafo, veja Graphify.
