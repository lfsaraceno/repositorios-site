O que é

MarkItDown é uma biblioteca e CLI em Python que transforma arquivos de vários formatos em Markdown. O foco é preservar a estrutura relevante do documento (títulos, listas, tabelas, links) para que o texto seja consumido por LLMs e pipelines de análise de texto, e não produzir uma conversão de alta fidelidade para leitura humana.

O Markdown é usado porque fica próximo do texto puro, é bem compreendido pelos LLMs e gasta poucos tokens. A ferramenta é comparável ao textract, mas com ênfase em manter a estrutura.

É útil para quem monta pipelines de RAG, alimenta agentes com documentos ou precisa indexar arquivos heterogêneos em um formato único.

Principais recursos

  • Converte PDF, PowerPoint, Word, Excel, imagens (metadados EXIF e OCR), áudio (metadados e transcrição de fala), HTML, CSV/JSON/XML, ZIP, URLs do YouTube e EPub
  • CLI simples (markitdown arquivo.pdf > documento.md) e API Python
  • Dependências opcionais por formato (pdf, docx, pptx, xlsx, xls, outlook, audio-transcription, youtube-transcription etc.)
  • Descrição de imagens por LLM (llm_client e llm_model) para arquivos pptx e imagens
  • Integração opcional com Azure Document Intelligence e Azure Content Understanding
  • Suporte a plugins de terceiros e plugin markitdown-ocr (OCR via LLM com visão)
  • Imagem Docker para uso isolado

Pré-requisitos

  • Python 3.10 a 3.14
  • Recomendado usar um ambiente virtual (venv, uv ou Conda)
  • Para recursos de nuvem: endpoint do Azure Document Intelligence ou Content Understanding (cobrados pela Azure)
  • Para descrição de imagens e OCR por LLM: um cliente compatível com OpenAI

Instalação

Ambiente virtual (recomendado)

python -m venv .venv
source .venv/bin/activate

No Windows, ative com .venv\Scripts\activate.

Com uv:

uv venv --python=3.12 .venv
source .venv/bin/activate
# use 'uv pip install' em vez de 'pip install'

Via pip

pip install 'markitdown[all]'

Para instalar só alguns formatos:

pip install 'markitdown[pdf, docx, pptx]'

A partir do código-fonte

git clone git@github.com:microsoft/markitdown.git
cd markitdown
pip install -e 'packages/markitdown[all]'

Docker

docker build -t markitdown:latest .
docker run --rm -i markitdown:latest < ~/your-file.pdf > output.md

Comandos e uso

markitdown path-to-file.pdf > document.md        # converte e redireciona a saída
markitdown path-to-file.pdf -o document.md       # grava direto em arquivo
cat path-to-file.pdf | markitdown                # lê da entrada padrão
markitdown --list-plugins                        # lista plugins instalados
markitdown --use-plugins path-to-file.pdf        # ativa plugins na conversão
markitdown path-to-file.pdf -o document.md -d -e "<endpoint>"   # usa Azure Document Intelligence

API Python:

from markitdown import MarkItDown

md = MarkItDown(enable_plugins=False)  # True para habilitar plugins
result = md.convert("test.xlsx")
print(result.markdown)

Descrição de imagens com LLM:

from markitdown import MarkItDown
from openai import OpenAI

md = MarkItDown(llm_client=OpenAI(), llm_model="gpt-4o")
result = md.convert("example.jpg")
print(result.markdown)

Quando usar

  • Preparar documentos de escritório e PDFs para indexação em RAG
  • Dar a um agente de IA acesso ao conteúdo de planilhas, apresentações e relatórios
  • Extrair texto de imagens e áudios em pipelines de análise
  • Padronizar uma pasta de arquivos variados em Markdown

Observações

  • O README alerta que o MarkItDown faz I/O com os privilégios do processo atual. Em ambientes com entrada não confiável, sanitize as entradas e use a função convert_* mais restrita possível (convert_stream(), convert_local()).
  • A saída é voltada a máquinas; não é indicada para conversões de alta fidelidade para leitura humana.
  • Azure Document Intelligence e Content Understanding geram chamadas de API cobradas.
