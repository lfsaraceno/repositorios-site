O que é

O Claude-Mem preserva o contexto entre sessões do Claude Code (e de outros agentes, como Codex, Gemini, Copilot, OpenCode e OpenClaw). Ele registra automaticamente as observações de uso de ferramentas, gera resumos semânticos e os disponibiliza para as sessões seguintes. Assim, o agente mantém a continuidade do conhecimento sobre o projeto mesmo depois que a sessão termina ou reconecta.

Por baixo, ganchos (hooks) de ciclo de vida (SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, SessionEnd) alimentam um serviço worker local, gerenciado pelo Bun, com API HTTP e interface web. Os dados ficam em SQLite, com busca textual (FTS5) e busca híbrida semântica com o banco vetorial Chroma.

A busca segue um padrão de "divulgação progressiva" em 3 camadas para economizar tokens: primeiro um índice compacto, depois a linha do tempo ao redor dos resultados e, por fim, os detalhes completos só dos IDs filtrados (economia de cerca de 10x, segundo o README). Existe tradução automática do README em português do Brasil em docs/i18n/README.pt-br.md.

Principais recursos

  • Memória persistente: o contexto sobrevive entre sessões, sem intervenção manual.
  • Ferramentas MCP de busca: search, timeline e get_observations, no fluxo de 3 camadas.
  • Skill mem-search para consultar o histórico do projeto em linguagem natural.
  • Controle de privacidade com tags <private> para excluir conteúdo sensível do armazenamento.
  • Interface web (viewer) e "My Work", com requisições, progresso e fila de revisão; TeamBrain opcional para equipes.
  • Configuração fina do contexto injetado e modos de fluxo/idioma via CLAUDE_MEM_MODE.
  • Cloud Sync opcional para backup das memórias em cmem.ai.
  • Integrações com várias ferramentas: Claude Code, OpenCode, Antigravity CLI, T3 Code, Pi, OpenClaw e outras.

Pré-requisitos

  • Node.js 20.0.0 ou superior.
  • Claude Code recente, com suporte a plugins.
  • Bun (instalado automaticamente se faltar).
  • uv, gerenciador de pacotes Python para a busca vetorial (instalado automaticamente se faltar).
  • SQLite 3 (embutido).

Instalação

Instalador (recomendado)

npx claude-mem install

O instalador configura tudo e depois pede login no navegador (link mágico por e-mail, sem cartão) para liberar o "claude-mem observer", com 30 dias de teste grátis. Depois você escolhe o provedor de memória: o observer do claude-mem, sua própria chave do OpenRouter ou Gemini, ou o seu plano da Anthropic. Para pular o login, passe um --provider explícito, defina CLAUDE_MEM_ONLINE_OPTIN=false ou rode em CI/shell não interativo.

Pelo marketplace de plugins do Claude Code

/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem

Reinicie o Claude Code. O contexto das sessões anteriores aparece automaticamente nas novas.

Outros agentes

npx claude-mem install --ide opencode
npx claude-mem install --ide antigravity
npx claude-mem install --ide t3code
npx claude-mem install --ide pi

Para gateways OpenClaw, o README documenta um script de instalação via curl (install.cmem.ai/openclaw.sh); revise o script antes de executar.

Windows

Os hooks do Claude Code não precisam do Git Bash: cada hook chama o claude-mem diretamente. O instalador coloca o launcher em %LOCALAPPDATA%\claude-mem\bin\claude-mem.exe e adiciona a pasta ao Path do usuário; reinicie o terminal ou a IDE depois. Se aparecer o erro npm : The term 'npm' is not recognized, instale o Node.js (nodejs.org) e reinicie o terminal.

Comandos e uso

npx claude-mem install    # instala e configura o claude-mem
npx claude-mem repair     # reaplica a instalação (citado pelo README em "Smart Install")

Uso das ferramentas MCP de busca (exemplo do README):

// 1) índice compacto
search(query="authentication bug", type="bugfix", limit=10)
// 2) contexto cronológico em volta de um resultado
timeline(...)
// 3) detalhes completos apenas dos IDs relevantes
get_observations(ids=[123, 456])

As configurações ficam em ~/.claude-mem/settings.json, criado com valores padrão na primeira execução.

Quando usar

  • Projetos longos em que o agente precisa lembrar decisões, bugs e padrões de sessões anteriores.
  • Retomar o trabalho depois de dias sem reexplicar o contexto.
  • Equipes que querem um espaço compartilhado de memória (TeamBrain).

Observações

  • npm install -g claude-mem instala apenas o SDK/biblioteca; não registra hooks nem sobe o worker. Use sempre npx claude-mem install ou os comandos /plugin.
  • O observer hospedado tem teste grátis de 30 dias; depois a memória volta para o seu plano da Anthropic, a menos que você assine.
  • A tradução em docs/i18n/README.pt-br.md é automática e reflete uma versão anterior (13.4.0, contra 14.0.1 do README principal).
