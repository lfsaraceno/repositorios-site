T3 Code

App open source que roda os agentes de código na sua máquina (Claude Code, Codex, Cursor, OpenCode, Antigravity e outros) numa interface única, rápida, no desktop, na web e no celular: comece uma tarefa no computador e aprove o próximo passo pelo telefone.

O que é

O T3 Code não vende tokens: ele comanda os agentes em que você já está logado, usando as suas assinaturas. Funciona com Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro, Pi, Muse Code, fx e qualquer agente compatível com ACP.

Um servidor roda na sua máquina e todos os clientes (desktop, web e apps de iOS e Android) mostram as mesmas conversas. Os criadores dizem que se inspiraram no app do Codex, no Conductor, no Claude Desktop e no Cursor, e que desempenho é prioridade.

Principais recursos

  • Todos os agentes num lugar só. Dá para trocar de modelo no meio da conversa e passar uma tarefa do Claude para o Codex.
  • Desktop, web e celular sincronizados.
  • Acesso remoto pela rede local, Tailscale ou T3 Connect.
  • Git integrado: cada conversa pode ter seu próprio worktree. Você revisa o diff e faz commit, push e pull request com um botão.
  • Modos de permissão para aprovar ações.
  • Conexão de agentes externos via MCP.

Pré-requisitos

  • Pelo menos um agente instalado e logado, por exemplo Claude Code (claude auth login) ou Codex CLI (codex login).

Instalação

Desktop: baixe em t3.codes/download ou use um gerenciador de pacotes:

winget install T3Tools.T3Code        # Windows (ou: scoop install extras/t3code)
brew install --cask t3-code          # macOS
yay -S t3code-bin                    # Arch Linux

Linha de comando (instala o comando t3, que sobe o servidor e abre o app web):

curl -fsSL https://t3.codes/install.sh | sh

No Windows (PowerShell): irm https://t3.codes/install.ps1 | iex. Para testar sem instalar: npx t3@latest.

Celular: baixe na App Store ou no Google Play e siga o guia de acesso remoto.

Comandos e uso

t3    # sobe o servidor e abre o app web

No app, abra uma conversa, escolha o agente e o projeto e acompanhe pelo desktop ou pelo celular.

Quando usar

  • Usar vários agentes de código sem trocar de janela.
  • Deixar o agente trabalhando no computador e aprovar os passos pelo celular.
  • Trabalhar em várias tarefas em paralelo, cada uma no seu worktree.

Observações

  • Os scripts curl … | sh e irm … | iex rodam código direto da internet. Se preferir, baixe e leia o script antes, ou use o winget.
  • O acesso remoto expõe os agentes da sua máquina a outros dispositivos: siga o guia de acesso remoto e prefira Tailscale ou T3 Connect a abrir portas.
  • Forks precisam usar outro nome e outra marca; o README diz que o uso indevido da marca T3 Code será processado.
  • O time tem pouca capacidade de revisão: novas funcionalidades precisam de discussão aprovada antes do PR.
  • Relacionados no catálogo: o Paperclip gerencia equipes de agentes como uma empresa.
