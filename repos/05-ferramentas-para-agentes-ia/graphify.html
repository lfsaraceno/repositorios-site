Graphify

O que é

O Graphify mapeia um projeto inteiro em um grafo de conhecimento que você consulta em vez de varrer arquivos com grep. Você digita /graphify no assistente e ele gera o grafo com código, documentação, esquemas SQL, configs, PDFs, imagens e vídeos.

O código é analisado localmente com AST do tree-sitter (cerca de 40 linguagens): determinístico, sem LLM e sem enviar nada para fora da máquina. Docs, PDFs, imagens e vídeo passam por uma etapa semântica que usa o modelo do seu assistente ou uma chave de API configurada. Não há embeddings nem banco vetorial: é um grafo real que se percorre.

Cada aresta é explicada e marcada como EXTRACTED (explícita na fonte) ou INFERRED (resolvida pelo Graphify), o que permite distinguir o que foi lido do que foi deduzido. Existe também o Graphify Cloud, serviço pago com teste de 14 dias, para manter o grafo ativo em vários repositórios.

Principais recursos

  • Saída em três arquivos em graphify-out/: graph.html (interativo), GRAPH_REPORT.md (resumo) e graph.json (grafo completo).
  • "God nodes" (conceitos mais conectados) e comunidades (subsistemas detectados por Leiden).
  • Consultas query, path e explain sobre o graph.json, sem reler os arquivos.
  • Ligações entre arquivos (calls, imports, inherits, mixes_in) resolvidas via tree-sitter.
  • Comentários # NOTE:/# WHY: e citações de ADR/RFC viram nós ligados ao código.
  • Extras opcionais por pacote: PDF, Office, vídeo/áudio, MCP, Neo4j, SQL, Postgres, backends Ollama/OpenAI/Gemini/Anthropic/Bedrock e outros.
  • Instalação para 20+ assistentes e modo "sempre usar o grafo" por hook ou arquivo de configuração.

Pré-requisitos

  • Python 3.10 ou superior.
  • uv (recomendado) ou pipx.

Instalação

O pacote oficial no PyPI é graphifyy (com dois "y"); outros pacotes graphify* não são afiliados. O comando continua sendo graphify.

uv tool install graphifyy      # recomendado (ambiente isolado)
# alternativas:
pipx install graphifyy
pip install graphifyy          # pode exigir ajuste de PATH

graphify install               # detecta o assistente e registra a skill

Se graphify não for encontrado depois do uv, rode uv tool update-shell.

Windows

winget install astral-sh.uv
uv tool install graphifyy
graphify install

No Claude Code para Windows, graphify install detecta o sistema automaticamente (ou use graphify install --platform windows).

Outros assistentes e instalação no projeto

graphify install --platform codex      # Codex (usa $graphify em vez de /graphify)
graphify install --platform gemini     # Gemini CLI
graphify cursor install                # Cursor
graphify antigravity install           # Google Antigravity
graphify install --project             # grava a skill no repositório atual (.claude/skills/...)

Extras opcionais

uv tool install "graphifyy[pdf]"
uv tool install "graphifyy[mcp]"
uv tool install "graphifyy[all]"

Comandos e uso

No assistente:

/graphify .          # mapeia o diretório atual e gera graphify-out/

Na linha de comando, depois que o grafo existe:

graphify query "<pergunta em linguagem natural>"   # subgrafo para a pergunta
graphify path "FastAPI" "ModelField"               # caminho mais curto entre dois conceitos
graphify explain "APIRouter"                       # explica um nó e suas conexões
graphify claude install                            # faz o assistente consultar o grafo (também: graphify codex install)

Resumo: abra graph.html no navegador para explorar, leia GRAPH_REPORT.md para os destaques e use graph.json para consultas sem reler os arquivos.

Quando usar

  • Entender rapidamente uma base de código grande ou desconhecida.
  • Reduzir o gasto de tokens do agente em perguntas de arquitetura.
  • Relacionar código com documentação, esquemas SQL, PDFs e decisões (ADR/RFC).

Observações

  • A branch padrão do repositório é v8, não main.
  • A etapa semântica (docs, PDFs, mídia) usa um backend de LLM e pode consumir créditos da sua conta ou chave; o mapeamento de código é gratuito e local.
  • Cuidado com pacotes de nome parecido no PyPI: o oficial é graphifyy.
  • Graphify Cloud é um serviço comercial separado.
