Repomix

Empacota um repositório inteiro (local ou remoto) num único arquivo XML, Markdown ou texto pronto para IA, com contagem de tokens, compressão via Tree-sitter, detecção de segredos, servidor MCP e plugins para o Claude Code.

O que é

O Repomix junta todos os arquivos de um projeto num só arquivo, num formato fácil para modelos de linguagem entenderem, para você colar no Claude, ChatGPT, Gemini ou outro assistente e pedir revisão, refatoração ou documentação do código inteiro de uma vez.

Ele respeita .gitignore, .ignore e .repomixignore, conta os tokens por arquivo e no total (para caber no limite de contexto), deixa de fora arquivos que parecem conter credenciais (via Secretlint) e pode comprimir o código mantendo só a estrutura (--compress). Funciona pela linha de comando, pelo site, por extensão de navegador, como servidor MCP e como plugins do Claude Code.

Principais recursos

  • Saída em XML (padrão), Markdown ou texto puro.
  • Contagem de tokens por arquivo e do repositório.
  • Empacota repositórios remotos (--remote) por URL, atalho user/repo, branch, tag ou commit.
  • Filtros por glob (--include, --ignore) e lista de arquivos via stdin.
  • Inclui logs e diffs do git como contexto.
  • Compressão com Tree-sitter (cerca de 70% menos tokens no plugin MCP).
  • Divisão da saída para codebases grandes e níveis de inclusão por arquivo.
  • Servidor MCP com modo sandbox; plugins do Claude Code; geração de Agent Skills; GitHub Action; uso como biblioteca.
  • Extensões para Chrome/Firefox e extensão comunitária para VS Code.

Pré-requisitos

  • Node.js (para npx ou npm), ou Docker, ou Homebrew.

Instalação

npx repomix@latest          # roda sem instalar, na pasta do projeto
npm install -g repomix      # instala global (também yarn, bun ou brew install repomix)

Plugins do Claude Code

/plugin marketplace add yamadashy/repomix
/plugin install repomix-mcp@repomix         # servidor MCP (base recomendada)
/plugin install repomix-commands@repomix    # comandos de barra
/plugin install repomix-explorer@repomix    # análise de repositórios com IA

MCP em outros clientes

repomix --mcp                       # inicia como servidor MCP
repomix --mcp --sandbox             # restringe o acesso à pasta atual
code --add-mcp '{"name":"repomix","command":"npx","args":["-y","repomix","--mcp"]}'   # VS Code

Docker

docker run -v .:/app -it --rm ghcr.io/yamadashy/repomix

Comandos e uso

repomix                                      # empacota o projeto em repomix-output.xml
repomix path/to/directory                    # só uma pasta
repomix --include "src/**/*.ts,**/*.md"      # só esses arquivos
repomix --ignore "**/*.log,tmp/"             # exclui padrões
repomix --remote yamadashy/repomix           # repositório remoto
repomix --compress                           # comprime mantendo a estrutura
repomix --include-logs --include-diffs       # adiciona histórico git
git ls-files "*.ts" | repomix --stdin        # lista de arquivos via stdin
repomix --init                               # cria repomix.config.json

No Claude Code com o plugin de comandos:

/repomix-commands:pack-local
Pack this project as markdown with compression

/repomix-commands:pack-remote yamadashy/repomix

Prompt de exemplo para usar o arquivo gerado:

This file contains all the files in the repository combined into one.
I want to refactor the code, so please review it first.

Quando usar

  • Mandar um projeto inteiro para um chat de IA (Claude.ai, ChatGPT) que não acessa seu disco.
  • Analisar rapidamente um repositório de terceiros sem clonar.
  • Medir quantos tokens um projeto ocupa antes de usar como contexto.

Observações

  • Segredos: a checagem do Secretlint vem ligada; não a desligue (--no-security-check) sem necessidade. Revise o arquivo antes de compartilhar.
  • Configuração é código: um repomix.config.* pode executar comandos. Em repositórios clonados, ela não é carregada por padrão; no MCP, use --sandbox ao empacotar código de terceiros.
  • Arquivos grandes podem estourar o contexto; use --compress, filtros ou a divisão da saída.
  • A ficha cobre as partes principais do README; seções de configuração detalhada, GitHub Actions e uso como biblioteca não foram resumidas.
  • Alternativa em Python: Gitingest. Para mapear a arquitetura em grafo, veja Graphify.
