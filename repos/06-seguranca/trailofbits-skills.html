O que é

É um marketplace de plugins do Claude Code mantido pela Trail of Bits, consultoria de segurança conhecida por auditorias e pesquisa. Cada plugin empacota skills, comandos e fluxos de trabalho que ajudam um agente de IA em análise de segurança, testes e desenvolvimento. O Codex consegue carregar o marketplace pela compatibilidade com marketplaces do Claude.

Os plugins cobrem segurança de contratos inteligentes, auditoria de código (C/C++, Rust, GitHub Actions, cadeia de suprimentos), análise de malware com YARA, verificação (testes de mutação, testes baseados em propriedades, análise de tempo constante), engenharia reversa, segurança móvel e utilitários de desenvolvimento.

Destaque: plugins/insecure-defaults

O plugin insecure-defaults faz uma auditoria paralela em busca de configurações padrão inseguras ("fail-open"), rastreando cada candidato antes de reportá-lo.

Categorias que ele procura:

  • Segredos de fallback (por exemplo, SECRET = env.get('KEY') or 'dev')
  • Credenciais padrão (por exemplo, usuário admin semeado com senha fraca)
  • Chaves "fail-open" (por exemplo, getenv('REQUIRE_AUTH', 'false'))
  • Criptografia fraca (por exemplo, hashlib.md5(password))
  • Acesso permissivo (por exemplo, ACL='public-read', permissão 0o666, CORS *)
  • Vazamento por recursos de debug (por exemplo, traceback.format_exc() em resposta)

Como funciona: uma fase de reconhecimento classifica o escopo e perfila a stack; seis varreduras paralelas (uma por categoria) coletam candidatos; agentes verificadores (Opus) tentam refutar cada candidato, checando se o arquivo é alcançável em produção, se o valor inseguro é o que roda, se chega a uma decisão de segurança e se o deploy sempre define a variável; por fim, um relatório traz severidade, correção e cobertura. Traço incompleto significa candidato refutado.

Uso:

/plugin install insecure-defaults            # via marketplace
/plugin install ./plugins/insecure-defaults  # checkout local

/insecure-defaults:audit                      # repositório inteiro
/insecure-defaults:audit src/                 # subdiretório
/insecure-defaults:audit src/config/app.py    # um arquivo

Use o comando audit, não o workflow audit-pipeline diretamente (ele para imediatamente se chamado sozinho). O argumento é opcional e, por padrão, é ..

Pré-requisitos

  • Claude Code com suporte a marketplaces de plugins (ou Codex, que aceita marketplaces do Claude)
  • Dependências específicas de cada plugin (CodeQL, Semgrep, Burp Suite etc.) conforme o caso

Instalação

Claude Code

/plugin marketplace add trailofbits/skills

Para navegar e instalar plugins:

/plugin menu

Codex

codex plugin marketplace add trailofbits/skills
codex plugin list
codex plugin add <plugin-name>@trailofbits

Desenvolvimento local

Na pasta-pai do repositório clonado:

/plugins marketplace add ./skills

Workspace do ChatGPT

Use o arquivo .claude-plugin/marketplace.json do repositório para importar no workspace.

Comandos e uso

/plugin menu                          # lista os plugins disponíveis
/plugin install <nome-do-plugin>      # instala um plugin do marketplace
/insecure-defaults:audit src/         # exemplo: auditar configurações inseguras em src/

Cada plugin traz seu próprio README com comandos e gatilhos. Em geral, descreva a tarefa ao agente (por exemplo, pedir uma revisão diferencial de segurança das mudanças da branch) e a skill correspondente é acionada.

Quando usar

  • Revisar segurança de código novo ou de um diff antes do merge
  • Procurar configurações padrão inseguras e segredos de fallback em um projeto
  • Criar regras Semgrep/YARA e triar falsos positivos
  • Auditar dependências e a cadeia de suprimentos

Observações

  • Licença CC-BY-SA-4.0 (atribuição e compartilhamento pela mesma licença).
  • São ferramentas de auditoria; aplique-as em código que você possui ou tem autorização para analisar.
  • Os resultados de agentes devem ser revisados por uma pessoa antes de virarem decisões de correção.
