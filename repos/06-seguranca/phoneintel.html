O que é

PhoneIntel é uma ferramenta de código aberto voltada a OSINT (inteligência de fontes abertas) que consulta e analisa informações sobre números de telefone. Ela mostra dados como país, área ou estado e operadora, processa vários números de uma vez e consolida dados de serviços de terceiros.

Também gera Google dorks (consultas de busca) codificadas em URL para categorias como redes sociais, fóruns, classificados e diretórios telefônicos, e mostra a localização aproximada no OpenStreetMap.

O próprio README descreve a ferramenta como destinada a fins educacionais e de pesquisa, para varreduras básicas e primeiros indícios sobre números de telefone.

Principais recursos

  • Análise de número: país, área/estado e operadora
  • Processamento em lote a partir de arquivo de texto ou de uma string com vários números
  • Geração de Google dorks por categoria (social_networks, forums, classifieds, ecommerce, news, blogs, job_sites, pastes, reputation, phone_directories, people_search ou all)
  • Mapa da localização no OpenStreetMap com --map
  • Integrações com Tellows (pontuação e tipo de chamada), SpamCalls.net (risco de spam), c-qui.fr (operadoras francesas) e Neutrino API (requer credenciais)

Pré-requisitos

  • Python e pip
  • Para a Neutrino API: ID e chave de API da conta Neutrino
  • Conexão com a internet para as consultas aos serviços de terceiros

Instalação

pip install phoneintel

No Kali Linux, adicione o diretório de binários locais ao PATH:

export PATH=$PATH:/home/<username>/.local/bin

Comandos e uso

phoneintel --info +34613814500                      # consulta de um número
phoneintel --info "+34613814500" --map              # com mapa no OpenStreetMap
phoneintel --search --string "My number is +16148077641 but you can call me at +34613814500"   # números dentro de um texto
phoneintel --search --input ./example.txt           # lote a partir de arquivo
phoneintel "+34613814500" --dorks --type social_networks   # gera dorks de uma categoria
phoneintel --browser "+34613814500"                 # comando browser
phoneintel --neutrino --login --id <api-id> --key <api-key>   # autentica na Neutrino API
phoneintel --neutrino +34613814500                  # consulta pela Neutrino API
phoneintel --neutrino --show                        # exibe as credenciais salvas
phoneintel --disclaimer                             # mostra o aviso legal

Comandos disponíveis: --info, --search, --dorks, --browser, --neutrino, --credits e --disclaimer.

Quando usar

  • Verificar a reputação de um número que ligou para você (spam, golpe)
  • Pesquisa OSINT autorizada, como parte de uma investigação ou de um teste de engenharia social com escopo e consentimento
  • Estudo de técnicas de OSINT e de validação de números de telefone

Observações

  • LGPD e uso ético: número de telefone é dado pessoal. No Brasil, o tratamento de dados pessoais está sujeito à LGPD (Lei 13.709/2018): é preciso ter finalidade legítima e base legal, e evitar coleta excessiva. Não use a ferramenta para perseguir, assediar, expor ou perfilar pessoas sem consentimento ou fundamento legal.
  • O README pede autorização adequada antes de usar qualquer ferramenta em avaliações de segurança e adverte contra mau uso.
  • Os dados vêm de serviços de terceiros (Tellows, Neutrino API, SpamCalls.net, c-qui.fr), cujos termos de uso e limites se aplicam. Consultar um número envia esse dado a esses serviços.
  • Os resultados são indícios iniciais, não prova de identidade.
