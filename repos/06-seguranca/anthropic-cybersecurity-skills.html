O que é

É uma coleção de skills estruturadas, no padrão aberto agentskills.io, que ensinam agentes de IA a executar tarefas de segurança como análise de memória com Volatility3, caça a ameaças, resposta a incidentes, revisão de nuvem e testes de aplicações web. Cada skill traz um fluxo de trabalho passo a passo e uma seção de verificação.

O projeto é comunitário e independente, sem afiliação com a Anthropic PBC, apesar do nome. O README informa 818 skills (e 817 em outras partes do texto), 34 domínios e compatibilidade com mais de 20 plataformas de agentes.

Funciona com divulgação progressiva: o agente lê só o frontmatter de cada skill (cerca de 30 tokens) para escolher as relevantes e só então carrega o fluxo completo (500 a 2.000 tokens).

Principais recursos

  • Mais de 800 skills em 34 domínios: nuvem, SOC, caça a ameaças, inteligência de ameaças, segurança web, forense digital, análise de malware, red team, contêineres, OT/ICS, resposta a incidentes, entre outros
  • Mapeamento para seis frameworks: MITRE ATT&CK, NIST CSF 2.0, MITRE ATLAS, MITRE D3FEND, NIST AI RMF e MITRE F3 (Fight Fraud Framework)
  • Cada skill segue a estrutura SKILL.md + references/ + scripts/ + assets/
  • Seções padronizadas: Quando usar, Pré-requisitos, Fluxo de trabalho e Verificação
  • Compatível com Claude Code, GitHub Copilot, Codex CLI, Cursor, Gemini CLI, Cline, Aider e outros
  • Camada de arquivo de layer do ATT&CK Navigator nos assets da release v1.0.0

Pré-requisitos

  • Um agente compatível com o padrão agentskills.io (por exemplo, Claude Code)
  • Node.js/npx para a instalação recomendada, ou Git para clonar o repositório
  • Ferramentas específicas de cada skill (Volatility3, Sigma etc.) quando o fluxo as exigir

Instalação

Opção recomendada com npx:

npx skills add mukul975/Anthropic-Cybersecurity-Skills

Alternativa com Git:

git clone https://github.com/mukul975/Anthropic-Cybersecurity-Skills.git
cd Anthropic-Cybersecurity-Skills

O README informa que funciona imediatamente com as plataformas compatíveis, sem configuração adicional. As skills ficam em skills/<nome-da-skill>/.

Comandos e uso

O README não define comandos próprios: o agente descobre e carrega as skills pelo frontmatter. Exemplos de prompts do estilo mostrado no projeto:

Analise este dump de memória em busca de sinais de roubo de credenciais

Nesse fluxo, o agente identifica skills como performing-memory-forensics-with-volatility3, hunting-for-credential-dumping-lsass e analyzing-windows-event-logs-for-credential-access, executa o fluxo e valida o resultado mapeando para as técnicas ATT&CK.

Outros prompts úteis, em linha com os domínios da biblioteca:

Monte um playbook de resposta a incidentes de ransomware
Revise a configuração de segurança desta conta AWS
Crie regras Sigma para detectar este comportamento

Quando usar

  • Dar a um agente de IA conhecimento procedural de analista de segurança (SOC, DFIR, threat hunting)
  • Padronizar playbooks defensivos mapeados a ATT&CK e NIST CSF
  • Estudo e treinamento em segurança, com fluxos documentados
  • Apoiar auditorias e avaliações de conformidade

Observações

  • Projeto comunitário, não afiliado à Anthropic.
  • A biblioteca inclui técnicas ofensivas e de uso duplo (por exemplo, C2 de red team, simulação de phishing, exploração). O próprio README restringe o uso a testes de intrusão autorizados, pesquisa, defesa e educação, em sistemas que você possui ou para os quais tem permissão escrita explícita.
  • Skills com scripts auxiliares devem ser revisadas antes de serem executadas em ambientes reais.
  • Os números de skills e domínios variam entre trechos do README (817 e 818); trate-os como aproximados.
