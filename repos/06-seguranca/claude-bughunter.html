O que é

O pacote transforma o Claude Code num caçador de bugs com método. Você descreve em linguagem natural o que está testando e as skills certas carregam sozinhas.

São quatro camadas:

  • Pensar: metodologia de bug bounty e mentalidade de red team.
  • Caçar em apps web: 58 skills hunt-* com padrões de detecção, payloads e encadeamentos por classe de falha (XSS, SQLi, SSRF, IDOR, OAuth, JWT, upload, GraphQL e outras).
  • Atacar o perímetro: cadeias atuais contra plataformas corporativas expostas na internet (M365/Entra, Okta, vCenter, VPNs SSL, SharePoint, IAM de nuvem).
  • Entregar: validação com um portão de 7 perguntas, severidade conforme cada plataforma, relatório e limpeza de evidências (remove cookies e dados pessoais dos prints).

O fluxo é: recon → mapear e priorizar → caçar → validar → relatar, com o escopo checado em código.

Principais recursos

  • 84 skills: 58 de caça, 10 de plataformas corporativas, 7 de relatório e validação, 5 de recon e OSINT e 4 de metodologia.
  • 15 comandos, como /hunt, /recon e /report.
  • Modelos de relatório para HackerOne, Bugcrowd, Intigriti e Immunefi, e entregável de red team para cliente.
  • MCP do HackerOne: busca de duplicatas, escopo e estatísticas dos programas.
  • CLI cbh para orquestrar recon, classificação, triagem e relatório.
  • Integração opcional com o MCP do Burp Suite.
  • Funciona também no OpenCode, Codex CLI, Hermes Agent e Antigravity.

Pré-requisitos

  • Claude Code (ou outro agente compatível).
  • Ferramentas de recon que as skills usam, como as da ProjectDiscovery (subfinder, httpx, nuclei) e, opcionalmente, o Burp Suite.
  • Conta no HackerOne é opcional (só para programas privados e seus relatórios).

Instalação

Plugin (recomendado), dentro do Claude Code:

/plugin marketplace add elementalsouls/Claude-BugHunter
/plugin install claude-bughunter@elementalsouls

A instalação pede usuário e token da API do HackerOne. Deixe em branco se não precisar.

Cópia (traz também o organizador de projetos hunt):

git clone https://github.com/elementalsouls/Claude-BugHunter.git
cd Claude-BugHunter
bash scripts/install.sh          # macOS / Linux
pwsh ./scripts/install.ps1       # Windows

CLI cbh separada:

pipx install git+https://github.com/elementalsouls/Claude-BugHunter

Comandos e uso

Descreva o alvo e o escopo:

Testing acme.com — an in-scope HackerOne target. Run recon and rank the surface.

Ou comece com /hunt, que já declara o contexto do trabalho (autorizado, com escopo definido).

Quando usar

  • Programas de bug bounty em que você está inscrito.
  • Pentests e red teams externos com contrato e escopo por escrito.
  • Testar a superfície externa da sua própria empresa.

Observações

  • Autorização: use só em ativos seus ou com autorização por escrito (escopo de bug bounty, contrato de pentest, CTF). Atacar sistemas de terceiros sem permissão é crime.
  • O pacote deixa de fora, de propósito: ataques internos a Active Directory, C2, pós-exploração, persistência e evasão de antivírus.
  • As salvaguardas de cibersegurança da Anthropic podem bloquear ou redirecionar pedidos ofensivos, mesmo autorizados. Para trabalho ofensivo autorizado, o README indica o programa CVP da Anthropic.
  • Parte das skills vem de outros projetos (claude-bug-bounty); veja o NOTICE.
  • Relacionados no catálogo: a Security Audit Skill da Cloudflare revisa código; o PentAGI é um agente de pentest autônomo.
