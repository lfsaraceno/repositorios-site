Craft Anything

Motor de engenharia reversa em Rust que estuda como qualquer site, app ou jogo funciona e põe um agente de IA (Claude Code) para construir sua própria versão, comparando o resultado com o original até ficar parecido.

O que é

O Craft Anything aponta para um alvo (site, app desktop, app de celular, jogo ou arquivo), você diz o que quer ("Recreate this website", "Recreate this game's gameplay in Rust") e ele trabalha em quatro etapas:

  1. Study: inspeciona o original com ferramentas reais: páginas em várias larguras, código, arquivos, comportamento em execução.
  2. Build: um agente de programação cria um projeto novo na linguagem, framework ou engine pedida.
  3. Check: compara a construção com o original e lista o que ainda não bate.
  4. Ready: você abre, joga ou visualiza o resultado, ou pede ajustes e ele refina.

Por baixo há um motor de engenharia reversa em Rust puro com 320 ferramentas para binários nativos, .NET, Java, Android, Apple, Electron/JavaScript, sites, firmware, capturas de pacotes, bancos de dados e arquivos de jogos, com decodificadores, disassembler e decompilador próprios (e o Ghidra, se instalado). Cada ferramenta também é um comando de CLI e uma ferramenta MCP, então qualquer agente pode usar o mesmo motor sem o app. Inspecionar não exige IA.

É do mesmo time do ArtCraft, que mantém uma suíte de apps "Craft" (PhotoCraft, FilmCraft, PdfCraft etc.).

Principais recursos

  • Dois modos de interface: Simple (descreve o que quer e aperta Start; mostra etapas, cartões de pergunta e aprovação e o grau de semelhança) e Advanced (bancada completa com funções, strings, pseudo-C, disassembly, hex, grafo de chamadas e console do agente).
  • Clean room (padrão): não lê nada de dentro do original (código, arquivos, fonte da página); trabalha só com o que um visitante vê (screenshots, texto visível, layout, cores, fontes).
  • Deep: usa todas as ferramentas, para uso privado: lê código e arquivos do programa, o JavaScript do site e usa o Ghidra quando instalado.
  • Checagem real: sites comparados em três larguras de tela; jogos pelo autoteste; apps pelas execuções.
  • Recria jogos em Unity, Unreal ou Godot.
  • Agentes: Claude Code é o principal (usa o seu claude com o seu login); Codex, GitHub Copilot CLI e Grok via ACP; Gemini CLI, Qwen Code, opencode, goose e outros via ACP. Para perguntas e análise: Anthropic, OpenAI, OpenRouter, xAI e servidores locais compatíveis com OpenAI.
  • Servidor MCP, plugins (servidores MCP e componentes WASM), visualizador web em WebAssembly.
  • Imagens e modelos 3D gerados (opcional, com sua chave fal.ai).

Pré-requisitos

  • Um agente de programação logado no computador (Claude Code recomendado) para construir.
  • Para compilar do código-fonte: Rust 1.97 ou mais novo (rustup update).
  • No Debian/Ubuntu, o app desktop precisa de bibliotecas do sistema (abaixo).
  • Opcional: Ghidra para o modo Deep; chave fal.ai para imagens e 3D.

Instalação

Instaladores prontos (recomendado)

Baixe na última release. O SHA256SUMS.txt traz o checksum de cada arquivo.

  • Windows: craft-anything-<ver>-windows-x64.msi (também arm64 e x86, e versões portable .zip). Instaladores assinados.
  • macOS: craft-anything-<ver>-macos-universal.dmg (assinado e notarizado). Versões após 0.2.0 já trazem a CLI dentro do app.
  • Linux: AppImage, .deb, .rpm, tarball (x86_64 e aarch64) e Flatpak. O Flatpak não consegue abrir navegador, então não serve para estudar sites.
  • FreeBSD: tarball x86_64.

No AppImage, a CLI roda com <AppImage> --cli <command> (ex.: <AppImage> --cli mcp).

A partir do código-fonte

No Debian/Ubuntu, antes:

sudo apt-get install build-essential libxkbcommon-dev libxkbcommon-x11-0 libwayland-dev libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libgtk-3-dev

Depois:

git clone https://github.com/storytold/craft-anything && cd craft-anything
cargo run --release -p craft-anything                # o app desktop
cargo install --path apps/craft-anything-cli         # a CLI, como `craft-anything-cli`
craft-anything-cli doctor                            # confere instalação, agentes e engines

Comandos e uso

App

Escolha site, app ou jogo, digite o endereço, escolha Clean room ou Deep, diga o que quer e aperta Start. "Just look inside" abre o alvo só para perguntas, sem construir (no modo Deep). No modo Advanced, Ctrl/Cmd+K lista todas as ferramentas.

CLI

craft-anything-cli commands                                   # todas as ferramentas, por grupo
craft-anything-cli mcp                                        # serve as ferramentas para qualquer cliente MCP
craft-anything-cli setup                                      # conecta o Craft Anything aos apps de agente
craft-anything-cli doctor                                     # diagnóstico
craft-anything-cli rebuild https://example.com "Recreate this website"            # recria um site
craft-anything-cli rebuild - "A snake game in Rust" --rounds 1                    # cria do zero, uma rodada
craft-anything-cli rebuild https://example.com "Make the header blue" --continue-in "<project folder>"   # continua um projeto
craft-anything-cli rebuild - "Add a contact form" --project-folder "<your folder>" --existing edit       # edita um app existente

Para trocar de modo numa execução: --deep ou --clean-room; de forma permanente: settings_set deep_mode true ou Settings.

Estrutura de um projeto

Projetos novos vão para Documents/Craft Anything. Cada pasta tem craft.json (pedido, alvo, status, histórico), capture/ (o que foi capturado do alvo), app/ (o projeto gerado), checks/ (comparações com o original), investigation.cany/ (evidências) e inbox/ (perguntas abertas).

Quando usar

  • Entender como um site, app ou jogo é construído, com evidência para cada resposta.
  • Prototipar rapidamente a partir de uma referência visual (clean room), por exemplo recriar o layout de uma landing page no seu stack.
  • Dar a um agente de IA ferramentas de engenharia reversa via MCP para analisar binários, APKs ou apps Electron que você tem direito de examinar.

Observações

  • Alpha inicial. Funciona hoje: app, CLI, MCP e o fluxo completo com Claude Code. Parcial: construção com chaves de API e outros agentes (implementado, não testado ao vivo), checagens de comportamento de apps e jogos.
  • Uso responsável e direitos autorais: use só em software que é seu ou que você tem permissão para examinar. Não contorna DRM, login nem anti-cheat. Recriar produtos de terceiros pode violar direitos autorais, marcas e termos de uso, mesmo no modo clean room; o agente é instruído a não copiar logos, fotos e textos sem sua confirmação.
  • Clean room não é sandbox: o agente que você roda age como você, com as permissões dele no seu computador.
  • Instalar dependências executa código: o app pede aprovação para cada tipo novo de comando (npm, cargo). Evite "always allow" para npm em projetos cujas dependências você não confia; use npm install --ignore-scripts para pular scripts de instalação.
  • Os nomes e logos ArtCraft são marca registrada e não estão cobertos pela licença; forks precisam removê-los.
  • Ferramentas relacionadas no catálogo: Ghidra (usado no modo Deep) e REA, outro MCP de engenharia reversa para agentes, sem a etapa de reconstrução.
