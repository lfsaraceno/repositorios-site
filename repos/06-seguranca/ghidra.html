O que é

O Ghidra é o framework de engenharia reversa de software criado e mantido pela diretoria de pesquisa da NSA (Agência de Segurança Nacional dos EUA). Ele analisa programas já compilados (executáveis .exe, .dll, ELF, Mach-O, firmware) e mostra o que eles fazem: desmonta o código de máquina em assembly e, principalmente, descompila para um pseudocódigo parecido com C, bem mais fácil de ler.

É a principal alternativa gratuita ao IDA Pro. Suporta uma grande variedade de arquiteturas de processador (x86, ARM, MIPS, PowerPC e muitas outras) e formatos de executável. Funciona tanto com interface gráfica quanto em modo automatizado pela linha de comando, e pode ser estendido com scripts e extensões em Java ou Python.

A NSA o usa para analisar código malicioso e encontrar vulnerabilidades. Ele também tem servidor para equipes trabalharem juntas no mesmo projeto, depurador integrado e o BSim, que encontra funções parecidas entre vários binários.

Principais recursos

  • Desmontagem (assembly) e descompilação para pseudocódigo C.
  • Suporte a muitas arquiteturas de processador e formatos de executável.
  • Grafos de fluxo de controle e de chamadas entre funções.
  • Scripts em Java e em Python 3 nativo (PyGhidra).
  • Modo headless (sem interface) para analisar muitos arquivos em lote.
  • Ghidra Server para trabalho em equipe num repositório compartilhado.
  • Depurador integrado que se conecta aos depuradores nativos do sistema.
  • BSim, para achar funções estruturalmente parecidas em coleções de binários.

Pré-requisitos

  • Windows 10 (build 1809 ou mais novo), Linux ou macOS 10.13+, sempre 64 bits.
  • JDK 25 de 64 bits, por exemplo o Adoptium Temurin ou o Amazon Corretto.
  • Python 3.9 a 3.15, para PyGhidra. Para o depurador, Python 3.7 a 3.14.
  • 4 GB de RAM e 1 GB de disco. Dois monitores são fortemente recomendados.

Instalação

O Ghidra não tem instalador: é só extrair um zip. Não precisa de administrador para uso pessoal, e para desinstalar basta apagar a pasta.

  1. Instale o JDK 25 de 64 bits.
  2. Na página de releases, abra Assets e baixe o arquivo ghidra_<versão>_PUBLIC_<data>.zip. A versão atual é a 12.1.4, de set/2026. Não baixe os arquivos "Source Code".
  3. Extraia numa pasta nova, nunca por cima de uma instalação anterior. Evite caminhos com o caractere ^, que impede o Ghidra de abrir.
  4. Abra o Ghidra:
ghidraRun.bat

No Linux e no macOS, o comando é ./ghidraRun. O Ghidra não cria atalho no menu Iniciar; se quiser, crie um manualmente apontando para o ghidraRun.bat.

No Windows, versões antigas do 7-Zip podem falhar ao extrair o zip. Atualize o 7-Zip ou use o extrator do próprio Windows.

Comandos e uso

Interface gráfica: abra com ghidraRun.bat, crie um projeto (File → New Project), importe o binário (File → Import File), dê dois cliques nele para abrir o CodeBrowser e aceite a análise automática. O pseudocódigo aparece na janela Decompile.

Python 3 (PyGhidra):

support\pyghidraRun.bat

Na primeira vez, o script oferece instalar o módulo pyghidra. Para instalar manualmente:

python3 -m pip install --no-index -f <GhidraInstallDir>/Ghidra/Features/PyGhidra/pypkg/dist pyghidra

Depois de instalado, dá para importar o pyghidra em outros scripts Python ou abrir pelos comandos pyghidra e pyghidraw.

Modo headless (lote, sem interface):

# importa e analisa um arquivo num projeto novo e roda um script ao final
support/analyzeHeadless <pasta_do_projeto> <nome_do_projeto> -import <arquivo_ou_pasta> -postScript <NomeDoScript>

# reprocessa os arquivos de um projeto existente
support/analyzeHeadless <pasta_do_projeto> <nome_do_projeto> -process -recursive

Opções úteis: -scriptPath (pastas de scripts), -recursive (importa subpastas), -deleteProject (apaga o projeto ao terminar) e -processor (força a arquitetura). A referência completa fica em support/analyzeHeadlessREADME.html, dentro da instalação.

Scripts e extensões: pelo Script Manager, que tem um botão para editar no VS Code, ou criando um projeto completo em Tools → Create VSCode Module project. Também há o plugin GhidraDev para Eclipse em Extensions/Eclipse/GhidraDev/.

Ghidra num arquivo só: support/buildGhidraJar gera um ghidra.jar para usar na linha de comando ou como biblioteca em outra aplicação Java.

Quando usar

  • Analisar malware ou executáveis suspeitos com segurança, sem executá-los.
  • Entender como funciona um programa ou firmware sem código-fonte, para interoperabilidade, auditoria ou correção de software legado.
  • Pesquisa de vulnerabilidades e CTFs.
  • Como motor de análise de outras ferramentas: o REA usa o Ghidra (ou Hopper, ou IDA) para dar a agentes de IA acesso a binários nativos.

Observações

  • Mantenha o Ghidra atualizado. O próprio README alerta que algumas versões têm vulnerabilidades conhecidas. Confira os avisos de segurança.
  • Malware: importar e analisar um arquivo no Ghidra não executa o programa, mas o depurador executa. Analise malware numa máquina virtual isolada.
  • Aspecto legal: a engenharia reversa de software de terceiros pode ser proibida pela licença do programa. No Brasil, a Lei de Software (Lei 9.609/98) permite certos usos, como a interoperabilidade, mas avalie caso a caso.
  • Na primeira abertura de projetos de versões antigas, o Ghidra pede para atualizar o arquivo. Depois disso, versões anteriores não conseguem mais abri-lo.
  • No macOS, o Gatekeeper pode bloquear componentes nativos. Rode xattr -d com.apple.quarantine no zip antes de extrair.
