O que é

RAPTOR (Recursive Autonomous Penetration Testing and Observation Robot) é um framework de pesquisa de segurança criado por Gadi Evron, Daniel Cuthbert, Thomas Dullien (Halvar Flake), Michael Bargury e John Cartwright. Ele usa o Claude Code como camada de orquestração, com CLAUDE.md, regras, sub-agentes e skills, para conduzir fluxos de análise de vulnerabilidades em código-fonte e binários.

O pipeline combina ferramentas como Semgrep, CodeQL, Ghidra e AFL++ com validação de achados por LLM, análise de exploitabilidade e geração de patches. Também é possível usar outros modelos (OpenAI, Gemini, modelos locais) na camada de análise ou rodar os CLIs de forma independente, sem o Claude Code.

Os próprios autores descrevem o projeto como software não polido, feito em tempo livre e majoritariamente escrito por IA, com verificação mecânica (testes, análise estática) para manter a qualidade.

Principais recursos

  • Comando /scan para análise estática com Semgrep (e CodeQL opcional), gerando relatório SARIF
  • Comando /agentic para o fluxo completo: varredura, deduplicação, validação, e geração de exploit e patch
  • /understand para mapear superfície de ataque e fluxos de dados; /validate para o pipeline de validação de exploitabilidade
  • Análise de binários (/binary, /ghidra), fuzzing com AFL++ (/fuzz) e análise de crashes (/crash-analysis)
  • /sca para análise de composição de software (dependências, advisories OSV/CISA KEV/EPSS, SBOM)
  • /cve-diff, /oss-forensics, /threat-model e /project para organizar execuções e acompanhar achados
  • Modelo de segurança com sandbox (namespaces Linux, Landlock, seccomp) para subprocessos que tratam conteúdo não confiável
  • Suporte a execução offline e em ambientes isolados (air-gapped)

Pré-requisitos

  • Claude Code com assinatura ativa (Max, Pro, Team ou Enterprise) ou chave de API da Anthropic (opcional se usar só os CLIs standalone)
  • uv, Python 3.12+ e Node.js 18+
  • Semgrep (uv tool install semgrep); CodeQL é opcional, mas recomendado
  • Para análise multi-modelo ou local: configurar os demais provedores (veja "Using a different LLM" no README)
  • Docker, se optar pela instalação em contêiner (imagem de cerca de 6 GB)

Instalação

Opção 1: manual

git clone https://github.com/gadievron/raptor.git
cd raptor

uv sync --locked
source .venv/bin/activate

npm install -g @anthropic-ai/claude-code   # se ainda não tiver o Claude Code
uv tool install semgrep                    # necessário para varreduras

# Adicione o launcher ao PATH (coloque no perfil do shell para persistir)
export PATH="$PATH:$PWD/bin"

raptor

O launcher raptor funciona de qualquer diretório e executa as verificações prévias antes de entregar o controle ao Claude Code. Rodar claude em outro diretório abre o Claude Code comum, não o RAPTOR.

Opção 2: contêiner (recomendada pelos autores)

Contêineres limitam o acesso do agente ao seu sistema de arquivos e o alcance de código malicioso.

docker pull danielcuthbert/raptor:latest
# ou construa localmente:
docker build -f .devcontainer/Dockerfile -t raptor:latest .

docker run -it \
  -v "$(pwd):/workspaces/raptor" \
  raptor:latest

Para montar também uma pasta-alvo, adicione -v "/caminho/do/alvo:/workspaces/target". Use --privileged apenas se precisar do depurador determinístico rr. Há suporte a devcontainer do VS Code.

Comandos e uso

Dentro do shell raptor:

/scan /caminho/do/codigo           # Semgrep (e Coccinelle, se disponível); adicione --codeql para CodeQL
/agentic /caminho/do/codigo        # pipeline completo com validação por LLM
/project create myapp --target /caminho/do/codigo   # cria um projeto
/project use myapp                 # define como ativo
/understand --map                  # mapeia a superfície de ataque
/agentic --threat-model --validate # mapeia, modela, varre e valida
/project findings                  # revisa todos os achados

Execução standalone, sem Claude Code:

python3 raptor.py doctor

Estimativa do README: um /agentic em base média (~50 achados) leva 10 a 30 minutos e custa US$ 2 a 8 em chamadas de LLM da camada de análise; o teto padrão é US$ 10 por execução (ajustável com --max-cost-usd).

Quando usar

  • Auditar código próprio ou de projetos que você tem autorização para analisar
  • Triar resultados de análise estática com validação por LLM para reduzir falsos positivos
  • Pesquisa de vulnerabilidades, análise de CVEs e investigação de crashes
  • Gerar patches para vulnerabilidades confirmadas

Observações

  • Ferramenta de pesquisa dual-use: inclui geração de prova de conceito de exploit (/exploit). Use apenas em alvos que você possui ou para os quais tem autorização expressa.
  • O RAPTOR executa código gerado por LLM e analisa repositórios não confiáveis; os autores recomendam o contêiner para limitar o impacto.
  • Vários comandos estão em estado Beta, Experimental ou Alpha, conforme a tabela do README.
  • Custos de LLM da camada de análise são cobrados por token; o Claude Code usa sua assinatura.
  • O CodeQL não permite uso comercial; revise as licenças das dependências antes de uso comercial.
