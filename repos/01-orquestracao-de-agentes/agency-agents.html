O que é

"The Agency" nasceu de uma thread no Reddit e é uma coleção crescente de personas de agentes em arquivos Markdown. Cada agente tem identidade e estilo próprios, missão, fluxos de trabalho, entregáveis técnicos com exemplos de código e métricas de sucesso. A ideia é montar um "time dos sonhos" de especialistas que você ativa conforme a necessidade.

Os agentes são organizados em divisões (engenharia, segurança, design, marketing e outras). O repositório traz scripts para converter e instalar o mesmo conjunto em várias ferramentas de agentes, e há um app desktop que faz isso com um clique.

Principais recursos

  • Dezenas de agentes especializados por divisão (por exemplo, Frontend Developer, Backend Architect, DevOps Automator, Incident Response Commander, Technical Writer).
  • Cada agente com identidade, processos, entregáveis e métricas de sucesso.
  • App nativo para macOS, Linux e Windows que navega o catálogo e instala nas ferramentas.
  • Scripts convert.sh e install.sh para múltiplas ferramentas.
  • Instalação seletiva por divisão ou por agente (--division, --agent, --agents-file).
  • Runbooks com rosters prontos em strategy/runbooks.json.
  • Também serve como referência: copie e adapte só os agentes de que precisa.

Pré-requisitos

  • Para os scripts: shell POSIX (bash) e, no exemplo de runbooks, python3.
  • A ferramenta de destino instalada (Claude Code, Cursor etc.).
  • Para o app: macOS, Linux ou Windows; no Mac também há instalação via Homebrew.

Instalação

Opção 1: app desktop (recomendada)

Baixe a última versão em agency-agents-app/releases. No Mac:

brew install --cask msitarzewski/agency-agents/agency-agents

Opção 2: Claude Code via script

./scripts/install.sh --tool claude-code

Ou copie uma categoria manualmente:

cp engineering/*.md ~/.claude/agents/

Opção 3: outras ferramentas

./scripts/convert.sh
./scripts/install.sh                 # assistente interativo
./scripts/install.sh --tool cursor   # ou antigravity, gemini-cli, opencode, copilot, openclaw, aider, windsurf, kimi, codex, osaurus, hermes, vibe, dsh

No Windows, os scripts são shell: use Git-Bash ou WSL, ou prefira o app.

Comandos e uso

./scripts/install.sh --tool claude-code --division engineering,security

Instala só as divisões escolhidas.

./scripts/install.sh --tool cursor --agent frontend-developer,ui-designer

Instala agentes específicos.

./scripts/install.sh --list teams

Lista as equipes e a quantidade de agentes.

./scripts/install.sh --tool opencode --division engineering --dry-run

Simula a instalação.

Ativação no Claude Code, por prompt:

Hey Claude, activate Frontend Developer mode and help me build a React component

Quando usar

  • Quando você quer personas de especialistas prontas em vez de escrever prompts de agente do zero.
  • Para montar equipes de agentes por projeto (MVP de startup, revisão de segurança etc.).
  • Como biblioteca de referência para criar seus próprios agentes.

Observações

  • O OpenCode registra apenas cerca de 119 agentes e descarta o resto (bug upstream); instale um subconjunto com --division. O instalador avisa quando a seleção excede o limite.
  • Instalar todos os agentes polui o contexto; prefira instalação seletiva.
  • Os arquivos de agente são prompts: revise o conteúdo antes de adotar.
