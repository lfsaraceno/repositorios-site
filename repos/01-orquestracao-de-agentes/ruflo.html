O que é

O Ruflo (antigo Claude Flow, criado por Reuven Cohen, o "rUv") parte da ideia de que "agente = modelo + harness". O modelo escreve o código; o harness fornece ferramentas, memória, loops, sandboxes e controles. O Ruflo é essa camada de execução em volta do Claude Code e do Codex.

Depois de um init, você usa o Claude Code normalmente e os hooks roteiam tarefas, aprendem com padrões bem-sucedidos e coordenam agentes em segundo plano. O README cita mais de 100 agentes especializados, enxames coordenados, memória com aprendizado, comunicação federada entre máquinas e controles de segurança.

Além do CLI e do servidor MCP, há um console visual ("cockpit") e um marketplace com cerca de 35 plugins.

Principais recursos

  • Enxames de agentes (swarm) e agentes autônomos em loop (autopilot).
  • Memória persistente e vetorial (AgentDB, RAG, RuVector) que alimenta o roteamento.
  • Aprendizado a partir de tarefas concluídas (plugin de inteligência).
  • Federação: agentes em máquinas diferentes colaboram com segurança.
  • Console/cockpit para acompanhar workflows, agentes, tokens e custo; também há TUI (npx ruflo tui).
  • Controle do console pelo Claude com níveis de permissão (read, write, manage, full) e aprovação ask ou auto.
  • Servidor MCP e cerca de 35 plugins no marketplace (core, swarm, autopilot, memória, testes etc.).
  • Instalação por plugin ou por CLI, com o CLI trazendo agentes, comandos, skills, hooks e daemon.

Pré-requisitos

  • Claude Code 2.1.287 ou superior, para o console e os mods.
  • Node.js com npx para o CLI e o servidor MCP.
  • Shell POSIX (Git-Bash, WSL, MSYS) somente se usar o instalador curl ... | bash.

Instalação

Caminho A: plugins do Claude Code

Dentro do Claude Code:

/plugin marketplace add ruvnet/ruflo
/plugin install ruflo-core@ruflo
/plugin install ruflo-console@ruflo
/plugin install ruflo-mods@ruflo
/reload-plugins
/ruflo

Isso dá comandos slash e definições de agentes, sem arquivos no workspace. Os mods rodam com as permissões da sua conta e não são isolados: leia o código antes de instalar.

Caminho B: CLI (instalação completa)

npx ruflo@latest init wizard

Funciona em PowerShell e cmd (Windows). Alternativas:

npx ruflo@latest init
npm install -g ruflo@latest

Em macOS, Linux, WSL ou Git-Bash existe também o instalador de uma linha:

curl -fsSL https://cdn.jsdelivr.net/gh/ruvnet/ruflo@main/scripts/install.sh | bash

O CLI cria .claude/, .claude-flow/, CLAUDE.md, helpers e settings no projeto.

Servidor MCP

claude mcp add claude-flow -- npx ruflo@latest mcp start

Para outros clientes MCP stdio: comando npx, argumentos ["-y", "ruflo@latest", "mcp", "start"].

Comandos e uso

npx ruflo@latest init wizard

Assistente interativo de configuração do projeto.

/ruflo

Abre o console no Claude Code (após instalar os plugins).

npx ruflo tui

Console em terminal puro, sem Claude Code (--plain imprime um quadro para scripts).

/plugin install ruflo-swarm@ruflo

Adiciona plugins avulsos, como swarm, rag-memory ou autopilot.

Depois do init, basta trabalhar normalmente no Claude Code: os hooks fazem o roteamento e a coordenação.

Quando usar

  • Projetos grandes em que vários agentes precisam trabalhar em paralelo com memória compartilhada.
  • Quando você quer observabilidade (custo, tokens, logs de agentes) ao lado do Claude Code.
  • Cenários com Codex e Claude Code usando o mesmo servidor MCP.

Observações

  • O README é extenso e cita números grandes (agentes, ferramentas MCP, downloads); confira na documentação o que se aplica à sua versão.
  • O caminho por plugins é "lite"; o conjunto completo exige o init via CLI.
  • Os mods não são sandboxed.
  • O repositório se chamava claude-flow; alguns comandos ainda usam esse nome (como no claude mcp add claude-flow).
