O que é

O Oh My Antigravity (OMA) transforma o Antigravity IDE em um ambiente multiagente, com 28 agentes especializados definidos como skills (Sisyphus como orquestrador, Prometheus como planejador, Oracle como arquiteto, CodeSmith no backend, Pixel no frontend, Tester, Debugger, Security Guard e outros). É inspirado no Oh My Claude Code e no Oh My OpenCode.

A ideia era delegar tarefas por um protocolo explícito entre agentes e rotear cada tarefa para o backend de IA mais adequado (Codex, Claude ou Gemini), com uma CLI oma multiplataforma e uma memória local de longo prazo por projeto (Project Cortex).

Hoje o projeto não funciona com as versões atuais do Antigravity (veja Observações).

Principais recursos

  • 28 definições de agentes (skills), do orquestrador a especialistas em dados, banco e segurança.
  • Roteamento por backend de IA: Claude Opus para planejamento, Codex para arquitetura, testes e depuração, Gemini para frontend, Claude Code para backend.
  • Protocolo de delegação entre agentes.
  • CLI oma para Windows, macOS e Linux.
  • SubAgents isolados com sessões consultáveis (oma spawn, oma session).
  • Memória persistente por projeto (oma memory).

Pré-requisitos

  • Google Antigravity IDE (em versão antiga, compatível com os caminhos ~/.gemini/antigravity/skills e .agent/skills).
  • Node.js para o npx, ou PowerShell/Bash para os instaladores locais.
  • Para o roteamento multi-IA, as CLIs de Codex, Claude e Gemini (integração listada como "em andamento" no README).

Instalação

Formas documentadas no README (não recomendadas hoje, veja Observações):

# via npm
npx oh-my-antigravity

# clonando o repositório
git clone https://github.com/turnabouthero/oh-my-antigravity.git
cd oh-my-antigravity

# Windows
.\lib\install.ps1

# macOS/Linux
bash lib/install.sh

O README usa o placeholder YOUR_USERNAME na URL do git clone; acima foi usado o dono real do repositório. O README também lista o pacote npm como item "em andamento", então não há garantia de que o npx funcione.

Comandos e uso

oma "Analyze the project and design a new logo"   # o Sisyphus planeja e executa a tarefa
oma list                                          # lista agentes/skills disponíveis
oma install oracle                                # instala um agente (global)
oma install oracle --project                      # instala só no projeto
oma remove oracle                                 # remove um agente
oma update                                        # atualiza o OMA
oma spawn oracle "Research best practices for Next.js auth"   # cria um SubAgent isolado
oma session list                                  # lista sessões de SubAgents
oma session result <id>                           # resultado de uma sessão
oma memory save "Use TailwindCSS v3.4 for this project"       # salva uma informação
oma memory recall <consulta>                      # busca nas memórias
oma memory list                                   # memórias recentes

Quando usar

  • Como referência de como estruturar um conjunto de agentes e um protocolo de delegação em formato de skills.
  • Para estudar a ideia de roteamento por backend de IA.
  • Para uso real no Antigravity, prefira a CLI oficial e o sistema de skills nativo.

Observações

  • Arquivado e sem manutenção (flag de arquivado no GitHub; último push em set/2026). Apenas ~13 estrelas, ou seja, quase nenhuma adoção ou validação pela comunidade.
  • Incompatível com o Antigravity atual: o OMA instala skills em ~/.gemini/antigravity/skills, mas o Antigravity agora lê ~/.gemini/config/skills, e o escopo de projeto mudou de .agent/skills para .agents/skills. Segundo o README, a CLI não funciona nas versões atuais.
  • O README indica que várias partes eram incompletas (configs de SubAgent 5/28, integração com CLIs externas, extensão do VS Code e pacote npm em andamento).
  • Para o mesmo propósito, use a CLI oficial do Antigravity e seu sistema de skills.
