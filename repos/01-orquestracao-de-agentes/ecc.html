O que é

O ECC é um conjunto grande de configurações e automações para agentes de programação, construído a partir de mais de 10 meses de uso diário pelo autor. Não é só um pacote de dotfiles: reúne subagentes, skills, comandos slash, regras por linguagem, hooks, scripts multiplataforma e configs de MCP.

Funciona com Claude Code, Codex, Cursor, OpenCode, Gemini e outros harnesses. A ideia é elevar a qualidade do trabalho do agente com planejamento, TDD, revisão de código, aprendizado contínuo (instincts), persistência de memória entre sessões e verificação de segurança.

É indicado para quem quer um "kit completo" opinativo em vez de montar agentes, regras e hooks do zero.

Principais recursos

  • 28 agentes especializados (planner, architect, tdd-guide, code-reviewer, security-reviewer, build-error-resolver etc.), 116 skills e 59 comandos segundo o README em português.
  • Regras por linguagem (TypeScript, Python, Go, Swift, PHP, Java, Kotlin, C++, Rust e outras) além de regras comuns.
  • Hooks com perfis de rigor: ECC_HOOK_PROFILE=minimal|standard|strict e ECC_DISABLED_HOOKS.
  • Aprendizado contínuo com "instincts" (/instinct-status, /evolve).
  • AgentShield: auditor de segurança de configurações de agentes (npx ecc-agentshield scan).
  • Instalação seletiva baseada em manifesto e suporte a Windows, macOS e Linux (hooks em Node.js).
  • Detecção automática do gerenciador de pacotes (npm, pnpm, yarn, bun).
  • Comandos de harness: /harness-audit, /loop-start, /quality-gate, /model-route.

Pré-requisitos

  • Claude Code CLI v2.1.0 ou superior (claude --version).
  • Node.js (os scripts e hooks são em Node) e um gerenciador de pacotes (npm, pnpm, yarn ou bun).
  • Git, para clonar o repositório e instalar as regras.

Instalação

1. Plugin do Claude Code

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

Ou via ~/.claude/settings.json:

{
  "extraKnownMarketplaces": {
    "ecc": { "source": { "source": "github", "repo": "affaan-m/ECC" } }
  },
  "enabledPlugins": { "ecc@ecc": true }
}

2. Regras (obrigatório, manual)

Plugins do Claude Code não distribuem rules, então instale à parte:

git clone https://github.com/affaan-m/ECC.git
cd ECC
npm install        # ou pnpm / yarn / bun
./install.sh typescript    # macOS/Linux; também python, golang, swift, php

No Windows (PowerShell):

.\install.ps1 typescript
# ou, multiplataforma:
npx ecc-universal install typescript

Outros alvos: ./install.sh --target cursor typescript e --target antigravity.

3. Instalação manual (alternativa)

cp ECC/agents/*.md ~/.claude/agents/
cp -r ECC/rules/common ~/.claude/rules/common
cp -r ECC/rules/typescript ~/.claude/rules/typescript
cp ECC/commands/*.md ~/.claude/commands/
cp -r ECC/.agents/skills/* ~/.claude/skills/

Comandos e uso

/ecc:plan "Adicionar autenticação de usuário"

Planeja a funcionalidade (agente planner). Com instalação manual, use /plan.

/tdd

Aplica escrita de testes primeiro (tdd-guide).

/code-review

Revisa o código recém-escrito.

/build-fix

Corrige builds que falham.

/security-scan

Auditoria de segurança (OWASP Top 10).

npx ecc-agentshield scan

Verificação de segurança sem instalação; --fix corrige problemas seguros.

/skill-create

Gera skills a partir da análise do repositório atual.

/setup-pm

Define o gerenciador de pacotes preferido.

Quando usar

  • Montar rapidamente um ambiente completo de Claude Code com agentes, regras e hooks.
  • Padronizar TDD, revisão e verificação em equipe.
  • Auditar a segurança da configuração dos seus agentes.
  • Compartilhar o mesmo conjunto de práticas entre Claude Code, Codex, Cursor e OpenCode.

Observações

  • O volume de componentes é grande; instale de forma seletiva para não poluir o contexto.
  • As contagens (agentes, skills, comandos) variam entre versões e idiomas do README.
  • As regras precisam ser instaladas manualmente, o plugin não as inclui.
  • Os guias do autor (links no README) são o material recomendado para entender a filosofia.
