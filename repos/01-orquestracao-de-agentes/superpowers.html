O que é

O Superpowers é uma metodologia completa de desenvolvimento de software para agentes de código, implementada como um conjunto de skills combináveis mais instruções iniciais que garantem que o agente as use. Como as skills disparam automaticamente, você não precisa fazer nada de especial: o agente simplesmente "tem Superpowers".

O fluxo começa antes de qualquer código: o agente pergunta o que você realmente quer, extrai uma especificação e a mostra em pedaços fáceis de ler. Depois de aprovada, gera um plano de implementação detalhado e executa tarefa por tarefa com subagentes, revisão e TDD de verdade (RED-GREEN-REFACTOR), seguindo YAGNI e DRY.

Foi criado por Jesse Vincent e pela Prime Radiant, e funciona em muitos harnesses (Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode e outros).

Principais recursos

  • Skills disparadas automaticamente antes de cada tarefa, como fluxos obrigatórios e não sugestões.
  • brainstorming: levanta a intenção e produz um design aprovado antes de codar.
  • writing-plans: divide o trabalho em tarefas de 2 a 5 minutos com caminhos de arquivo, código e verificação.
  • subagent-driven-development e executing-plans: execução com subagente por tarefa ou inline.
  • test-driven-development: aplica RED-GREEN-REFACTOR e descarta código escrito antes dos testes.
  • systematic-debugging e verification-before-completion: depuração em 4 fases e prova antes de declarar sucesso.
  • using-git-worktrees, requesting-code-review, finishing-a-development-branch.
  • diagnosing-superpowers: analisa uma sessão que deu errado, com evidências.

Pré-requisitos

  • Um dos agentes de código suportados (Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode, Antigravity, Qwen Code, Hermes e outros).
  • A instalação é feita separadamente em cada harness que você usar.

Instalação

Claude Code (marketplace oficial)

/plugin install superpowers@claude-plugins-official

Claude Code (marketplace do Superpowers)

/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

Outros agentes

# Gemini CLI
gemini extensions install https://github.com/obra/superpowers

# Antigravity
agy plugin install https://github.com/obra/superpowers

# Devin CLI
devin plugins install obra/superpowers

# Qwen Code
qwen extensions install obra/superpowers

# Hermes Agent
hermes plugins install obra/superpowers --enable

# Pi
pi install git:github.com/obra/superpowers

No Cursor, use /add-plugin superpowers no chat do agente. No Codex (app e CLI) instale pelo marketplace oficial de plugins (/plugins, busque "superpowers"). Para Copilot CLI, Factory Droid, Grok Build, Kimi Code, OpenCode e Muse, veja o README do repositório.

Atualização

Depende do agente e costuma ser automática; no Gemini CLI, por exemplo, gemini extensions update superpowers.

Comandos e uso

Não há comandos a memorizar: as skills ativam sozinhas. Para testar a instalação, abra uma sessão nova e envie:

Let's make a react todo list

Uma instalação funcional dispara brainstorming antes de qualquer código.

figure out what went wrong with superpowers in this session

Invoca a skill diagnosing-superpowers para investigar uma sessão problemática.

Fluxo básico: brainstorming, worktree isolada, plano, execução com subagentes, TDD, revisão entre tarefas e finalização do branch.

Quando usar

  • Projetos novos em que você quer design e plano aprovados antes do código.
  • Execução longa e autônoma (o README fala em horas sem desvio do plano).
  • Equipes que querem disciplina de TDD e revisão em dois estágios (conformidade com a spec e qualidade).

Observações

  • O projeto não costuma aceitar contribuições de novas skills.
  • Há telemetria opcional mínima: o logotipo do "visual companion" é carregado do site e informa a versão. Desative com SUPERPOWERS_DISABLE_TELEMETRY (também respeita DISABLE_TELEMETRY do Claude Code).
  • Há oferta de serviços comerciais para empresas (contato no README).
