O que é

O AG Kit instala no seu projeto um contrato de workspace .agents/ completo: regras, skills, agentes especialistas, workflows (comandos slash), tópicos de memória e um hook nativo de segurança. O runtime de produção suportado é o Google Antigravity; outras ferramentas podem ler os arquivos Markdown, mas o comportamento fora do Antigravity não é garantido.

Os componentes são em Markdown, com versionamento SemVer, manifesto e lockfile para detectar divergências. A orquestração acontece por comandos como /coordinate e /orchestrate, combinados com /agents e /tasks do Antigravity.

É para quem usa o Antigravity e quer um conjunto estruturado e revisável de práticas de agentes por projeto.

Principais recursos

  • 20 agentes especialistas, 47 skills, 13 workflows e 6 regras (contagens do README).
  • Memória persistente em .agents/memory/ (convenções, decisões, preferências, feedback).
  • Hook PreToolUse que bloqueia comandos destrutivos de alta confiança (apagar raiz, formatar disco, sobrescrever disco bruto), sem atrapalhar limpezas normais como dist/.
  • Atualização com merge seguro, backup e rollback (ag-kit update, ag-kit rollback).
  • Sincronização de MCP explícita e com backup (sync-mcp.mjs).
  • Empacotamento como plugin local do Antigravity, com inventário SHA-256.
  • Verificações: check:agents, check:antigravity, test:antigravity e o Antigravity Doctor.

Pré-requisitos

  • Node.js 22 ou superior para as ferramentas de repositório do Antigravity (o CLI publicado aceita Node 18 ou superior).
  • Python 3.10 ou superior para validadores e scripts.
  • Workspace confiável do Google Antigravity.
  • Git, para atualização, revisão e rollback.

Instalação

npx @vudovn/ag-kit init

Ou globalmente:

npm install -g @vudovn/ag-kit
ag-kit init

Não coloque .agents/ no .gitignore se o Antigravity precisa indexá-lo; para manter local, use .git/info/exclude.

Verifique o workspace:

npm run check:agents
npm run check:antigravity
npm run test:antigravity

Abra o repositório no Antigravity como workspace confiável e confirme que /plan, /coordinate e /orchestrate foram descobertos.

Comandos e uso

ag-kit update --dry-run

Mostra o plano de atualização sem aplicar.

ag-kit update

Atualiza com merge seguro e cria backup.

ag-kit rollback

Restaura o backup mais recente anterior à atualização.

node .agents/hooks/sync-mcp.mjs --check

Revisa o plano de configuração MCP sem escrever no diretório home.

npm run build:antigravity-plugin

Gera o bundle em dist/antigravity-plugin/, instalável com agy plugin install ./dist/antigravity-plugin.

Workflows no chat do agente: /brainstorm, /plan, /create, /enhance, /debug, /test, /verify, /deploy, /coordinate, /orchestrate, /preview, /remember, /status.

Quando usar

  • Projetos no Google Antigravity que precisam de agentes especialistas e fluxos repetíveis.
  • Equipes que querem atualizações revisáveis e reversíveis das regras de agentes.
  • Quando você quer um hook de segurança básico contra comandos destrutivos.

Observações

  • O suporte de produção é apenas para o Antigravity.
  • O exemplo de MCP contém YOUR_API_KEY; o doctor avisa até você configurar. Nunca versione credenciais reais.
  • O hook de segurança é propositalmente estreito e não substitui permissões, sandbox ou aprovação humana.
  • Nada é mesclado, implantado ou sincronizado automaticamente.
