O que é

O oh-my-claudecode (OMC) é um plugin para o Claude Code que adiciona uma camada de orquestração multiagente. O lema do projeto é "curva de aprendizado zero": você descreve o que quer em linguagem natural e o OMC distribui o trabalho entre agentes especializados (arquitetura, pesquisa, design, testes, ciência de dados etc.).

A superfície canônica de orquestração é o modo Team, um pipeline em estágios (team-plan → team-prd → team-exec → team-verify → team-fix) em que agentes coordenados trabalham sobre uma lista de tarefas compartilhada. Há ainda modos como Autopilot (execução autônoma), Ralph (loop persistente de verificar/corrigir) e utilitários como HUD na statusline, skills reaproveitáveis e roteamento de modelos (Haiku para tarefas simples, Opus para raciocínio complexo).

É voltado a quem já usa o Claude Code e quer mais automação, paralelismo e persistência sem montar a orquestração à mão.

Principais recursos

  • Modo Team com pipeline em estágios e agentes coordenados em lista de tarefas compartilhada.
  • 32 agentes especializados (segundo o README) e delegação automática ao agente certo.
  • Roteamento inteligente de modelos (Haiku/Opus) com economia de tokens declarada de 30% a 50%.
  • Magic keywords opcionais: autopilot, ralph, ulw, plan, ralplan, deep-interview.
  • deep-interview: entrevista socrática que mede ambiguidade antes de escrever código.
  • Skills próprias (.omc/skills/ por projeto, ~/.omc/skills/ por usuário), com /skill e /skillify para extrair padrões.
  • HUD na statusline com métricas de orquestração em tempo real.
  • Utilitários: espera de rate limit (omc wait), notificações (Telegram/Discord/Slack) e integração com OpenClaw.

Pré-requisitos

  • Claude Code instalado.
  • Para o modo Team nativo: variável CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 em ~/.claude/settings.json.
  • tmux, apenas para omc wait e para os trabalhadores CLI (/omc-teams).
  • CLIs codex e/ou gemini, apenas se for usar workers desses provedores.

Instalação

Plugin do Claude Code (principal)

  1. Adicione o marketplace e instale o plugin:
/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode
/plugin install oh-my-claudecode
  1. Execute o setup:
/omc-setup
  1. Para usar o modo Team, habilite os times nativos em ~/.claude/settings.json:
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}

CLI via npm

O nome do pacote npm é diferente da marca do projeto:

npm install -g oh-my-claude-sisyphus

Atualização

/plugin marketplace update omc
/omc-setup

Se algo quebrar após atualizar, rode /omc-doctor.

Comandos e uso

autopilot: build a REST API for managing tasks

Execução autônoma de ponta a ponta.

/deep-interview "I want to build a task management app"

Esclarece requisitos com perguntas socráticas antes de qualquer código.

/team 3:executor "fix all TypeScript errors"

Orquestração Team com 3 agentes executores.

/omc-teams 2:codex "review auth module for security issues"

Sobe workers CLI reais em painéis tmux (também 2:gemini, 1:claude).

omc wait --start

Ativa o daemon que retoma sessões do Claude Code quando o rate limit é resetado (requer tmux).

/skill list

Gerencia skills (list | add | remove | edit | search).

Outras palavras-gatilho: ralph: refactor auth (modo persistente), ulw fix all errors (paralelismo máximo), ralplan this feature (planejamento por consenso).

Quando usar

  • Tarefas grandes que se beneficiam de vários agentes em paralelo (correções em massa, refatorações).
  • Quando os requisitos ainda estão vagos e você quer uma entrevista antes de implementar.
  • Fluxos longos que precisam de verificação e correção até a conclusão real (Ralph).
  • Revisões com mais de um modelo (Claude, Codex, Gemini) via tmux.

Observações

  • O README em português cita modos como swarm, ultrapilot, ultrawork, omc-teams e ccg. Versões recentes do projeto reorganizaram ou aposentaram parte deles; confira o guia de migração e a documentação para a versão que você instalar.
  • O pacote npm (oh-my-claude-sisyphus) não tem o mesmo nome do repositório.
  • O README tem trechos marcados como tradução ainda por revisar.
  • Existe uma versão equivalente para o Codex CLI: oh-my-codex.
