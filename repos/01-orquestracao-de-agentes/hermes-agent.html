O que é

O Hermes Agent é um agente de IA de uso geral, feito pela Nous Research, que funciona como um assistente pessoal sempre disponível. Ele não fica preso ao seu notebook: você pode instalá-lo num VPS de US$ 5, num cluster de GPU ou em infraestrutura serverless e conversar com ele pelo terminal ou por apps de mensagem enquanto ele trabalha numa máquina na nuvem.

O diferencial que o projeto destaca é o ciclo de aprendizado fechado. Depois de tarefas complexas, o agente cria skills (procedimentos reutilizáveis) a partir da experiência e as aprimora com o uso. Ele também mantém uma memória curada por ele mesmo, com lembretes periódicos para registrar conhecimento. Para recuperar contexto, faz busca textual (SQLite FTS5) nas conversas antigas com resumo por LLM. E monta um modelo de quem você é ao longo das sessões, usando a modelagem dialética de usuário do Honcho.

Ele não depende de um provedor: funciona com Nous Portal, OpenRouter, OpenAI, endpoints próprios e muitos outros, e a troca de modelo é feita com hermes model, sem mudar código. As skills seguem o padrão aberto agentskills.io, o mesmo usado por várias ferramentas deste catálogo.

Principais recursos

  • TUI completa no terminal: edição multilinha, autocompletar de slash commands, histórico, interromper e redirecionar o agente no meio da tarefa, saída de ferramentas em streaming.
  • Gateway de mensagens: um único processo atende Telegram, Discord, Slack, WhatsApp, Signal e e-mail, com transcrição de áudio e continuidade da conversa entre plataformas.
  • Memória e skills que evoluem: criação autônoma de skills, melhoria delas durante o uso, busca nas sessões antigas e perfil do usuário entre sessões.
  • Automações agendadas: cron embutido, configurado em linguagem natural, com entrega do resultado em qualquer plataforma (relatórios diários, backups noturnos, auditorias semanais).
  • Subagentes e paralelismo: cria subagentes isolados para frentes paralelas e permite escrever scripts Python que chamam ferramentas via RPC, juntando pipelines de vários passos num turno só.
  • Seis backends de terminal: local, Docker, SSH, Modal, Daytona e Vercel Sandbox, além de plugins como Singularity/Apptainer. Daytona e Modal hibernam o ambiente quando ocioso, então o custo entre sessões fica perto de zero.
  • Mais de 40 ferramentas, integração com servidores MCP, arquivos de contexto de projeto e personalidades configuráveis.
  • Pesquisa: geração de trajetórias em lote e compressão de trajetórias para treinar modelos de tool calling.

Pré-requisitos

  • Linux, macOS, WSL2 ou Windows nativo (PowerShell). Há também pacote APT para Android/Termux (aarch64).
  • O instalador cuida das dependências: Python 3.14, Node.js, npm, pnpm, ripgrep, FFmpeg e as bibliotecas Python. No Windows, se o Git não existir, ele baixa uma cópia verificada para a pasta de ferramentas do Hermes, sem mexer no Git do sistema.
  • Chave de API de algum provedor de modelo, ou assinatura do Nous Portal.

Instalação

Linux, macOS e WSL2

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc    # recarrega o shell (ou: source ~/.zshrc)
hermes              # começa a conversar

Windows (nativo, PowerShell)

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

No Windows nativo a instalação fica em %LOCALAPPDATA%\hermes; no WSL2, em ~/.hermes, como no Linux. CLI, gateway, TUI e ferramentas funcionam sem WSL. Existe ainda um pacote MSIX/App Installer separado, descrito na página de instalação.

Android (Termux)

Use o guia do Termux, que tem repositório APT assinado com canais stable e canary. Não use o script de desktop/servidor.

Atalho: Nous Portal

Se não quiser juntar várias chaves (modelo, busca web, geração de imagem, TTS, navegador na nuvem), o Nous Portal cobre tudo numa assinatura, com mais de 300 modelos e um Tool Gateway:

hermes setup --portal   # login via OAuth, define a Nous como provedor e liga o Tool Gateway
hermes portal info      # mostra o que está configurado

Dá para continuar usando chaves próprias por ferramenta; o gateway não é tudo-ou-nada.

Comandos e uso

CLI

hermes              # CLI interativa: inicia uma conversa
hermes setup        # assistente de configuração completo
hermes model        # escolhe provedor e modelo de LLM
hermes tools        # liga e desliga ferramentas
hermes config set   # define um valor de configuração
hermes config get   # mostra um valor de configuração
hermes gateway      # inicia o gateway de mensagens (Telegram, Discord etc.)
hermes update       # atualiza para a versão mais recente
hermes doctor       # diagnostica problemas

Conversar pelo celular

hermes gateway setup   # configura as plataformas de mensagem
hermes gateway start   # sobe o gateway; depois é só mandar mensagem para o bot

Slash commands (CLI e mensageiros)

/new ou /reset              # nova conversa
/model [provider:model]     # troca o modelo
/personality [nome]         # aplica uma personalidade
/retry, /undo               # refaz ou desfaz o último turno
/compress, /usage           # comprime o contexto / mostra o consumo
/insights [--days N]        # estatísticas de uso
/skills ou /<nome-da-skill> # navega pelas skills ou chama uma
/stop                       # interrompe a tarefa (no mensageiro; na CLI, Ctrl+C)
/platforms                  # status das plataformas (CLI); no mensageiro: /status, /sethome

Migrar de outro agente

O hermes setup detecta ~/.openclaw, ~/.claude, ~/.codex e ~/.cursor e oferece importar configurações, memórias e skills, com prévia. Depois da instalação:

hermes plugins install agent-importers          # uma vez por perfil
hermes import-agent openclaw --dry-run          # prévia do que seria migrado
hermes import-agent openclaw                    # migração interativa
hermes import-agent openclaw --migrate-secrets  # também traz chaves de API da lista permitida
hermes import-agent claude-code                 # ou codex / cursor

Quando usar

  • Você quer um assistente pessoal que roda 24/7 num servidor e responde pelo Telegram, WhatsApp ou Discord.
  • Precisa de tarefas recorrentes (relatórios, backups, auditorias) descritas em linguagem natural, sem montar cron e scripts à mão.
  • Quer um agente que acumule memória e skills ao longo do tempo, em vez de começar do zero a cada sessão.
  • Está saindo do OpenClaw, Claude Code, Codex ou Cursor e quer levar memórias e skills junto.

Observações

  • Agente com acesso a terminal: ele executa comandos no backend que você escolher. A documentação de segurança cobre aprovação de comandos, pareamento por DM e isolamento em contêiner. Para uso 24/7 exposto a mensageiros, prefira Docker ou sandbox em vez do backend local.
  • Antivírus no Windows: o Windows Defender e o Bitdefender às vezes colocam em quarentena o uv.exe em %LOCALAPPDATA%\hermes\bin. Segundo o README é falso positivo (é o uv da Astral); o README traz um passo a passo com gh attestation verify para conferir o binário. Para liberar, adicione a pasta às exclusões, não o hash, porque o hash muda a cada atualização.
  • Custos: o agente é MIT e gratuito, mas o uso de modelos, busca, TTS e navegador na nuvem é pago, via chaves próprias ou pela assinatura do Nous Portal.
  • Migração de segredos: --migrate-secrets copia chaves de API (Telegram, OpenRouter, OpenAI, Anthropic, ElevenLabs) do OpenClaw. Use só se quiser mesmo essas chaves no Hermes.
  • Ecossistema no catálogo: várias ferramentas daqui já suportam o Hermes como alvo, entre elas Superpowers (hermes plugins install obra/superpowers --enable), Impeccable, OpenSpec, Planning with Files e CC Switch. O GBrain oferece memória externa explícita para o Hermes, enquanto a memória nativa do Hermes é curada pelo próprio agente.
