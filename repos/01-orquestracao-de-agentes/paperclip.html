Paperclip

Plataforma open source para gerenciar equipes de agentes de IA como uma empresa. Tem organograma, tarefas, metas, orçamentos, aprovações e histórico, num painel web self-hosted. Funciona com Claude Code, Codex, Cursor, OpenClaw e outros.

O que é

O Paperclip parece um gerenciador de tarefas, mas por baixo organiza uma "empresa" de agentes. O fluxo é:

  1. defina a meta, por exemplo "levar o app de notas a US$ 1 milhão de receita recorrente";
  2. "contrate" a equipe (CEO, CTO, engenheiros, designers, marketing), cada um com o agente e o modelo que você quiser;
  3. aprove a estratégia, defina orçamentos e acompanhe pelo painel.

O lema do projeto: "se consegue receber um heartbeat, está contratado". Qualquer agente que acorde por chamada entra no organograma.

Principais recursos

  • Traga seu agente: Claude Code, Codex, Cursor, Gemini, bash, bots via HTTP e webhook (como o OpenClaw) e adaptadores externos.
  • Tarefas com trava atômica: só um agente pega cada tarefa. Conversas, planos, bloqueios, arquivos e histórico ficam presos à tarefa e sobrevivem a reinicializações.
  • Metas em cascata: cada tarefa carrega o contexto do projeto e da meta da empresa.
  • Organograma: papéis, cargos, chefes, permissões e orçamentos por agente. Humanos e agentes no mesmo organograma.
  • Controle de custo: gastos por empresa, agente, projeto, meta, provedor e modelo, com alertas e parada automática.
  • Governança:
    • etapas de revisão e aprovação;
    • configuração versionada, com rollback;
    • pausar ou encerrar agentes.
  • Rotinas agendadas por cron, webhook ou API.
  • Skill Studio: skills compartilhadas, avaliações e histórico de versões.
  • Gateway de ferramentas MCP, com aprovação por chamada.
  • Segredos criptografados, com acesso por agente.
  • Várias empresas numa só instalação, com dados separados.
  • Exportar e importar empresas inteiras como modelo.
  • Plugins, sandboxes na nuvem (e2b, Cloudflare, Daytona, Modal e outros) e uso pelo celular.

Pré-requisitos

  • Node.js 24.11+.
  • Para usar a assinatura do Claude ou do ChatGPT localmente: Python 3 e a CLI do provedor (claude ou codex) instalados no servidor. A imagem Docker já inclui.
  • Para desenvolver a partir do código: pnpm 9.15+ e Rust (para o Paperclip Runner).

Instalação

Rápida:

npx paperclipai@latest onboard --yes

Esse comando sobe em modo local confiável, só no próprio computador (loopback). Para modo autenticado, acessível pela rede:

npx paperclipai@latest onboard --yes --bind lan       # rede local
npx paperclipai@latest onboard --yes --bind tailnet   # Tailscale

Instância de teste, já com um agente CEO. Ela roda em primeiro plano e não instala serviço:

ANTHROPIC_API_KEY=... npx paperclipai test-drive
OPENAI_API_KEY=... npx paperclipai test-drive --harness codex

A partir do código:

git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev

A interface e a API sobem em http://localhost:3100, com PostgreSQL embutido criado automaticamente. Para produção, aponte para o seu próprio Postgres ou use Docker.

Se o npx der E404 e você usa um registro npm privado, rode com --registry https://registry.npmjs.org.

Comandos e uso

  1. Abra o painel e crie a empresa e a meta.
  2. Adicione agentes, escolhendo o adaptador (Claude Code, Codex etc.), o modelo, o cargo e o orçamento.
  3. Crie tarefas ou rotinas. Os agentes acordam quando recebem trabalho, executam e registram o resultado.
  4. Revise, aprove ou devolva pelo painel ou pelo celular.
npx paperclipai configure    # muda a configuração de uma instalação existente

Quando usar

  • Coordenar vários agentes (Claude Code, Codex, Cursor) num objetivo comum sem perder o controle.
  • Trocar "20 terminais do Claude Code abertos" por tarefas rastreáveis.
  • Rodar agentes 24/7 com orçamento, aprovação humana e auditoria.
  • Automatizar trabalho recorrente (suporte, relatórios, redes sociais) com rotinas.
  • Comparação no catálogo:
    • o Ruflo e o Oh My ClaudeCode orquestram agentes dentro do terminal;
    • o Paperclip é um servidor com painel, organograma, orçamento e governança para várias equipes e empresas.

Observações

  • Telemetria ligada por padrão. O projeto diz que não coleta dados pessoais, prompts nem segredos. Para desligar, use PAPERCLIP_TELEMETRY_DISABLED=1 ou DO_NOT_TRACK=1.
  • Custos: agentes autônomos 24/7 gastam tokens sem parar. Configure orçamentos com parada automática antes de soltar a equipe. O próprio projeto avisa que o gasto em andamento pode atrasar a parada.
  • Assinaturas: usar o plano Claude Pro/Max ou ChatGPT para agentes contínuos pode esbarrar nos termos de uso do plano. Confira antes, ou use chaves de API.
  • Acesso remoto: o modo padrão é local e confiável. Para acessar de fora, use o modo autenticado com rede privada (Tailscale) ou Docker. Não exponha o modo local na internet.
  • Exportar empresas: os valores de segredos são omitidos, mas variáveis de ambiente comuns e caminhos locais podem ir junto. Revise o pacote antes de compartilhar.
  • Projeto muito ativo, com releases diárias (última: v2026.1106.0). Leia as notas antes de atualizar.
