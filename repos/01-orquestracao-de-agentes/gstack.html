O que é

O gstack transforma o Claude Code (e outros agentes) num time de engenharia virtual, todo em comandos de barra e Markdown. É um processo, não uma coleção solta: as skills seguem a ordem de um sprint (Think → Plan → Build → Review → Test → Ship → Reflect) e cada uma alimenta a próxima. O /office-hours escreve um documento de design que o /plan-ceo-review lê; o /plan-eng-review gera um plano de testes que o /qa usa; o /review acha bugs que o /ship confere.

É pensado para fundadores técnicos, quem está começando no Claude Code (papéis estruturados em vez de prompt em branco) e tech leads que querem revisão, QA e release automatizados em todo PR.

Principais recursos

  • Planejamento: /office-hours (seis perguntas que reformulam o produto), /plan-ceo-review, /plan-eng-review, /plan-design-review, /plan-devex-review, /autoplan (todas as revisões em sequência) e /spec.
  • Design: /design-consultation (cria um DESIGN.md), /design-shotgun (4 a 6 variações de mockup), /design-html, /design-review, /design-motion.
  • Código e testes: /review (bugs que passam no CI mas quebram em produção), /verify, /test-audit, /qa e /qa-only (navegador real, APIs, CLIs, webhooks).
  • Segurança: /cso (auditoria com OWASP e STRIDE) e travas /careful, /freeze, /guard.
  • Entrega: /ship (testes, revisão e PR), /land-and-deploy, /canary, /benchmark, /document-release.
  • Navegador: /browse, /scrape, /pair-agent, usando o navegador Aside (macOS) ou um Chromium próprio.
  • Outros: /retro, /learn (memória entre sessões), /make-pdf, /diagram, /codex (segunda opinião do Codex), QA em iPhone/iPad.
  • Integração com o GBrain (base de conhecimento persistente) via /setup-gbrain.

Pré-requisitos

  • Claude Code, Git e Bun 1.4.2+ (o setup recusa Bun anterior a 1.3.3).
  • Node.js no Windows e para o modo time.
  • Recomendado no macOS 15+: navegador Aside.
  • /cso exige toolchain nativo; auditorias em contêiner precisam de Docker.

Instalação

Na sua máquina (cole no Claude Code)

Install gstack: run git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup then add a "gstack" section to CLAUDE.md that says to use the /browse skill from gstack for all web browsing and never use mcp__claude-in-chrome__* tools. Then ask the user if they also want to add gstack to the current project so teammates get it.

Modo time (repositório compartilhado, com atualização automática)

(cd ~/.claude/skills/gstack && ./setup --team) && ~/.claude/skills/gstack/bin/gstack-team-init required && git add .claude/ CLAUDE.md && git commit -m "require gstack for AI-assisted work"

Troque required por optional para só sugerir aos colegas.

Outros agentes

git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/gstack
cd ~/gstack && ./setup --host auto      # ou --host codex, opencode, cursor, gemini, copilot, kiro...
./setup --status

Só o Claude Code tem suporte completo (certificado); os demais são experimentais.

Comandos e uso

Comece por quatro comandos:

/office-hours                     # descreva o que vai construir; ele questiona e escreve o design doc
/review                           # numa branch com mudanças: acha e corrige bugs de produção
/qa https://staging.myapp.com     # abre navegador real, reproduz e corrige bugs
/ship                             # testes, revisão e abertura do PR

Para o sprint inteiro: /autoplan revisa o plano de ponta a ponta. Atualizar: /gstack-upgrade. Canal de atualizações: ~/.claude/skills/gstack/bin/gstack-config set update_channel stable (releases) ou main (todo merge).

Quando usar

  • Fundadores e devs solo que querem revisão de produto, design, engenharia e QA antes de cada entrega.
  • Padronizar o fluxo de PR do time com Claude Code (modo time).
  • Começar no Claude Code com papéis claros em vez de prompts soltos.

Observações

  • A instalação edita o seu CLAUDE.md e pede para não usar as ferramentas do Claude in Chrome; revise antes de aceitar se você usa essa extensão.
  • Muitas skills: o contexto inicial cresce; instale só onde fizer sentido.
  • O modo time adiciona um hook que verifica atualizações a cada sessão.
  • A ficha cobre a primeira parte do README (instalação e lista de skills); a parte sobre GBrain, Capy e detalhes avançados não foi lida inteira.
  • Relacionados no catálogo: GBrain (mesmo autor), Superpowers e oh-my-claudecode (outras metodologias completas).
