O que é

O GBrain é o "cérebro" de memória que Garry Tan (CEO do Y Combinator) construiu para rodar os próprios agentes. Ele guarda fatos explícitos com suas fontes, permite correções e retirada de informações, e disponibiliza a mesma memória para vários agentes. Começa sem chaves de API (busca por palavra-chave) e pode ganhar busca semântica, síntese e enriquecimento em segundo plano.

Em vez de devolver uma lista de páginas, a camada opcional de síntese responde com texto citado e aponta o que o cérebro ainda não sabe. Há também um grafo de conhecimento tipado (pessoas, empresas, relações) e um "dream cycle" que consolida memória enquanto você dorme.

Serve tanto como memória pessoal para um agente de código quanto como "cérebro de empresa" compartilhado, com concessões de acesso por fonte e operação.

Principais recursos

  • Memória com proveniência, correção e retirada, portátil entre agentes.
  • Início sem chaves de API: gbrain init --pglite --no-embedding, sem servidor nem Docker.
  • Busca por palavra-chave, semântica e híbrida; camada de síntese com citações e análise de lacunas.
  • Grafo de conhecimento tipado com extração de referências em escritas locais.
  • Servidor MCP (stdio e HTTP com OAuth 2.1 e painel admin) e publicação remota via Tailscale (gbrain mcp expose).
  • Setup guiado para Claude Code e Codex (gbrain setup claude-code), com hooks e teste de fumaça.
  • Skills de memória que acompanham o cérebro local; plugin para Claude Code e Codex.
  • Caminhos para Postgres/Supabase em escala e para OpenClaw/Hermes com crons 24/7.

Pré-requisitos

  • Bun 1.4.0 ou superior.
  • Para o caminho sempre ativo (OpenClaw/Hermes): servidor com 8 GB ou mais de RAM e uso de API que escala com a carga (é o caminho mais caro, segundo o README).

Instalação

Atenção: o GBrain NÃO é distribuído no npm. O pacote gbrain do npm é outro projeto e pode sobrepor o binário. Nunca rode npm install -g gbrain nem bun add -g gbrain.

Claude Code ou Codex (caminho mais rápido)

bun install -g github:garrytan/gbrain
gbrain setup claude-code   # ou: codex

O setup mostra o cérebro, a fonte e o dono resolvidos antes de escrever, cria um cérebro keyless se não houver um, registra o MCP stdio e os hooks de leitura de contexto e faz um teste de fumaça. Use --dry-run para pré-visualizar e --remove para desfazer.

CLI standalone (sem agente)

bun install -g github:garrytan/gbrain
gbrain init --pglite --no-embedding
gbrain doctor
gbrain import ~/notes/ --no-embed
gbrain search "uma frase de uma nota" --json

Plugin do Claude Code

/plugin marketplace add garrytan/gbrain
/plugin install gbrain@gbrain

Ou, só o MCP local: claude mcp add gbrain -- "$(command -v gbrain)" serve.

Plugin do Codex

codex plugin marketplace add garrytan/gbrain@codex-plugin
codex plugin add gbrain@gbrain

Se instalou o pacote errado do npm: npm uninstall -g gbrain (ou bun remove -g gbrain), reinstale e rode gbrain doctor.

Comandos e uso

gbrain doctor

Verifica a saúde da instalação (também detecta o pacote errado do npm).

gbrain serve

Sobe o servidor MCP via stdio, para Claude Code, Cursor e Windsurf.

gbrain serve --http

Servidor MCP HTTP com OAuth 2.1 e painel admin em /admin.

gbrain mcp expose

Publica o cérebro via MCP na sua rede Tailscale (--funnel para agentes em nuvem).

gbrain connect https://seu-host/mcp --token gbrain_xxx

Gera o bloco de conexão para um cérebro remoto (--install configura e testa).

Exemplo de prompt ao agente: "What do I need to know before my meeting with Alice tomorrow?"

Quando usar

  • Dar memória durável e auditável ao Claude Code ou Codex entre sessões.
  • Manter uma base pessoal ou de equipe de pessoas, empresas e notas com respostas citadas.
  • Compartilhar a mesma memória entre vários agentes e clientes MCP.

Observações

  • Instale somente via bun install -g github:garrytan/gbrain ou clone + bun install && bun link.
  • Provedores de embedding, reranking, extração e síntese configurados podem receber texto, e o modelo do harness vê a memória recuperada mesmo no modo keyless.
  • A exportação em Markdown não é um backup completo do banco.
  • Arquivos locais e credenciais compartilhadas de banco são outra fronteira de confiança; as fontes sozinhas não isolam esses chamadores.
  • Há versão hospedada paga em gbrain.io.
