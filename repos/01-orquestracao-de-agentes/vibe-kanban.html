O que é

A ideia é que, com agentes escrevendo o código, o engenheiro passa a maior parte do tempo planejando e revisando. O Vibe Kanban acelera essas duas partes: você planeja em issues num quadro kanban (sozinho ou com o time) e, na hora de executar, cria workspaces onde um agente trabalha com branch, terminal e servidor de desenvolvimento próprios.

Depois você revisa o diff com comentários inline que voltam para o agente, vê o app num navegador embutido e abre o PR.

Principais recursos

  • Issues em quadro kanban: criar, priorizar e atribuir.
  • Workspace por tarefa com branch git (worktree), terminal e dev server.
  • Revisão de diff com comentários inline enviados ao agente.
  • Navegador embutido com devtools, modo de inspeção e emulação de dispositivos.
  • Mais de 10 agentes: Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor, OpenCode, Droid, CCR e Qwen Code.
  • PRs com descrição gerada por IA e merge.
  • Self-hosting da versão cloud com Docker.

Pré-requisitos

  • Node.js (para npx).
  • Um agente de programação já autenticado no computador.
  • Para desenvolver: Rust estável, Node.js 20+ e pnpm 8+.

Instalação

npx vibe-kanban

Self-hosting: guia com Docker. Atrás de proxy reverso ou domínio próprio, defina VK_ALLOWED_ORIGINS=https://vk.example.com (senão as chamadas à API dão 403).

Comandos e uso

  1. Rode npx vibe-kanban e abra a interface.
  2. Crie issues no quadro descrevendo o trabalho.
  3. Inicie um workspace escolhendo o agente; ele trabalha na própria branch.
  4. Revise o diff, comente, visualize o app e abra o PR.

Desenvolvimento a partir do código:

pnpm i
pnpm run dev    # backend e web app, com banco em branco

Quando usar

  • Rodar vários agentes em paralelo, cada um na sua branch, sem conflitos.
  • Organizar o trabalho de agentes num quadro visível para o time.

Observações

  • Descontinuado (sunsetting): prefira alternativas mantidas para uso de longo prazo.
  • Analytics PostHog ficam desligados se as variáveis POSTHOG_* estiverem vazias no build.
  • Alternativas no catálogo para orquestrar agentes: oh-my-claudecode, Paperclip.
