O que é

O OpenCut é um editor de vídeo open source que se apresenta como alternativa ao CapCut, cujos recursos básicos passaram a ser pagos. A proposta é privacidade (os vídeos ficam no seu dispositivo), recursos gratuitos e simplicidade.

Atenção ao estado do projeto: o repositório principal está sendo reescrito do zero. O README informa que a versão anterior está em opencut-app/opencut-classic (arquivada e sem manutenção) e que ela ainda é a indicada para uso hoje. O site opencut.app continua rodando a versão clássica, e a reescrita fica em new.opencut.app até estar pronta.

Principais recursos

Planejados para a reescrita, segundo o README:

  • API do editor e plugins de terceiros (arquitetura plugin-first).
  • Desktop, mobile e navegador a partir de uma base de código, com núcleo em Rust.
  • Servidor MCP para agentes de IA.
  • Modo headless para automação e renderização em lote.
  • Aba de scripts dentro do editor.

Na versão clássica: editor web em Next.js, timeline, app desktop nativo em andamento (GPUI) e núcleo em Rust/WASM para compositor de GPU, efeitos e máscaras.

Pré-requisitos

  • Reescrita (repo principal): proto para instalar as ferramentas fixadas em .prototools, e o sistema de build moon.
  • Versão clássica: Bun e, opcionalmente, Docker com Docker Compose (banco e Redis).

Instalação

O projeto principal só documenta o ambiente de desenvolvimento (não há instalador final ainda).

Reescrita (repositório principal)

Instale o proto. No Windows (PowerShell):

irm https://moonrepo.dev/install/proto.ps1 | iex

Se os shims não rodarem, permita scripts locais: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned. No Linux, macOS ou WSL:

bash <(curl -fsSL https://moonrepo.dev/install/proto.sh)

Na raiz do repositório:

proto use              # instala as ferramentas fixadas em .prototools
moon run web:dev       # web em localhost:5173
moon run api:dev       # API em localhost:8787
moon run desktop:dev   # app desktop (veja apps/desktop/README.md)

Versão clássica (indicada para uso hoje)

Do README do opencut-classic:

cp apps/web/.env.example apps/web/.env.local     # no PowerShell: Copy-Item
docker compose up -d db redis serverless-redis-http
bun install
bun dev:web                                      # http://localhost:3000

Auto-hospedagem completa em Docker (app em http://localhost:3100):

docker compose up -d

Comandos e uso

Para uso final, o caminho mais simples é abrir opencut.app no navegador (roda a versão clássica). Os comandos acima servem para desenvolver ou hospedar por conta própria.

Quando usar

  • Edição de vídeo simples no navegador, sem marca d'água ou paywall.
  • Acompanhar o projeto para plugins, automação e MCP quando a reescrita ficar pronta.

Observações

  • O repositório principal está em reescrita e não aceita contribuições externas por enquanto; a versão clássica está arquivada.
  • A funcionalidade do repositório principal pode estar incompleta; para uso hoje, siga o opencut-classic.
  • Licença MIT.
