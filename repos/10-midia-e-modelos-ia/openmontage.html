OpenMontage

Sistema open-source de produção de vídeo conduzido por agente de IA: o Claude Code, Cursor, Codex ou Copilot pesquisa, roteiriza, gera ou busca imagens e vídeos, narra, edita e renderiza o vídeo final a partir de um pedido em linguagem natural.

O que é

O OpenMontage transforma um assistente de programação com IA em um estúdio de produção de vídeo. Você descreve o vídeo em português ou inglês e o agente faz pesquisa na web, proposta, roteiro, plano de cenas, geração ou busca de mídia, edição e composição final.

Não existe orquestrador em código: o próprio agente é o orquestrador. Ele lê manifestos YAML de pipeline (pipeline_defs/) e "skills de diretor" em Markdown para cada etapa (skills/), chama ferramentas Python com seleção de provedor pontuada, revisa o próprio trabalho, salva checkpoints e pede sua aprovação nas decisões criativas.

Funciona sem nenhuma chave de API paga: narração com Piper TTS (offline), imagens e vídeos de bancos gratuitos (Pexels, Pixabay, Unsplash) e acervos abertos (Archive.org, NASA, Wikimedia Commons), composição com Remotion ou HyperFrames e pós-produção com FFmpeg. Com chaves de provedores (fal.ai, Kling, Veo, Runway, ElevenLabs, Suno etc.) gera clipes, imagens, vozes e músicas com IA. Os exemplos do README custam de US$ 1,33 a cerca de US$ 5 por vídeo.

Um diferencial é o caminho de vídeo com filmagem real: o pipeline de documentário monta um acervo pesquisável por CLIP a partir de bancos gratuitos e arquivos abertos e edita clipes de movimento de verdade, sem só animar fotos.

Principais recursos

  • Pipelines prontos: explicativo animado, animação, avatar apresentador, cinematográfico (trailer/teaser), Clip Factory (cortes curtos a partir de vídeo longo), documentário com filmagem real, híbrido, localização e dublagem, podcast para vídeo, demonstração de tela e talking head.
  • Partir de um vídeo de referência: cole um link do YouTube, Short, Reel, TikTok ou um arquivo local e o agente analisa ritmo, cenas e estilo, propõe 2 ou 3 conceitos com estimativa de custo e mostra uma amostra antes da produção.
  • Backlot: storyboard local que se preenche ao vivo durante a produção, com portões de aprovação por cena (takes, prompts, custo por asset) e replay da execução.
  • Mais de 100 ferramentas e 60 integrações: geração de vídeo (Kling, Veo 3.1, Runway, Seedance, MiniMax, WAN, Hunyuan, LTX), imagem (FLUX, Imagen, GPT Image 2, Recraft), voz (ElevenLabs, Google TTS, OpenAI, Piper), música (Suno, ElevenLabs), legendas, upscale, remoção de fundo, lip sync.
  • Seleção de provedor pontuada em 7 dimensões (adequação, qualidade, controle, confiabilidade, custo, latência, continuidade), com log de decisões auditável.
  • Portões de qualidade: validação antes de compor (bloqueia vídeo com cara de slideshow) e autorrevisão após renderizar (ffprobe, amostragem de frames, análise de áudio, checagem de legendas).
  • Controle de orçamento: estimativa antes de gastar, teto total (padrão US$ 10), aprovação por ação acima de US$ 0,50 e modos observe, warn e cap.
  • Perfis de saída para YouTube (incluindo 4K e Shorts), Instagram Reels e Feed, TikTok, LinkedIn e 21:9 cinematográfico.
  • Geração local de vídeo com GPU (WAN 2.1/2.2, Hunyuan, LTX, CogVideo) sem custo de API.

Pré-requisitos

  • Python 3.10+.
  • FFmpeg.
  • Node.js em versão corrigida das linhas 22.x (22.23.4+), 24.x (24.22.1+) ou 26.x (26.12.1+); o .node-version seleciona 22.23.4.
  • Um assistente de IA que leia arquivos e rode código: Claude Code, Cursor, Copilot, Windsurf ou Codex.
  • Opcional: GPU para geração local de vídeo; chaves de API para provedores pagos.

Instalação

Com make

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup

O repositório foi transferido para OpenMontageInc/OpenMontage; o link antigo do README redireciona.

Windows (PowerShell, sem make)

py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1; python -m pip install 'pip>=26.2.2'; python -m pip install -r requirements.txt; cd remotion-composer; npm install; cd ..; python -m pip install piper-tts; Copy-Item .env.example .env

Se o npm install falhar com ERR_INVALID_ARG_TYPE, use npx --yes npm install.

macOS/Linux sem make

python3 -m venv .venv && source .venv/bin/activate && python -m pip install 'pip>=26.2.2' && python -m pip install -r requirements.txt && cd remotion-composer && npm install && cd .. && python -m pip install piper-tts && cp .env.example .env

Ambientes já instalados

Atualize pip e certifi por causa do comprometimento da CA intermediária eMudhra e reinicie processos Python longos:

python -m pip install --upgrade 'pip>=26.2.2' 'certifi>=2026.10.19'

Chaves de API (opcionais)

Edite o .env; cada chave liga mais ferramentas. Exemplos: FAL_KEY (FLUX, Veo, Kling, MiniMax), PEXELS_API_KEY, PIXABAY_API_KEY e UNSPLASH_ACCESS_KEY (gratuitas), ELEVENLABS_API_KEY, OPENAI_API_KEY, GOOGLE_API_KEY, SUNO_API_KEY, RUNWAY_API_KEY, KLING_API_KEY. Lista completa com preços em docs/PROVIDERS.md.

GPU local (opcional)

make install-gpu

Depois, no .env:

VIDEO_GEN_LOCAL_ENABLED=true
VIDEO_GEN_LOCAL_MODEL=wan2.2-ti2v-5b  # ou wan2.1-1.3b, wan2.1-14b, hunyuan-1.5, ltx2-local, cogvideo-5b

Comandos e uso

Abra a pasta do projeto no Claude Code (ou outro assistente) e peça o vídeo. Exemplos de prompt do README:

Make a 60-second animated explainer about how neural networks learn

Make a 75-second documentary montage about city life in the rain. Use real footage only, no narration, elegiac tone, with music.

Here's a YouTube Short I love. Make me something like this, but about quantum computing.

Create a cinematic 30-second trailer for a sci-fi concept: humanity receives a warning from 1000 years in the future

Para filmagem real sem custo, peça documentary montage, tone poem ou stock-footage collage e diga explicitamente use real footage only.

Backlot e utilitários

python -m backlot open                  # biblioteca com todas as produções no disco
python -m backlot open <project-id>     # board ao vivo de uma produção
python scripts/backlot_simulate_run.py  # simula uma produção para ver o board
make demo                               # renderiza vídeos de demonstração sem chaves
make test-contracts                     # testes de contrato (sem chaves de API)
make test                               # todos os testes

O vídeo final fica em projects/<project-name>/renders/final.mp4. Mais prompts testados, com custo esperado, em PROMPT_GALLERY.md.

Quando usar

  • Produzir vídeos explicativos, documentários curtos ou teasers de produto para YouTube, Reels e TikTok com o Claude Code fazendo o trabalho pesado.
  • Recriar o estilo de um vídeo de referência com outro tema, sabendo o custo antes de gerar.
  • Fazer vídeos sem gastar com APIs, usando narração offline, bancos gratuitos e acervos abertos.
  • Cortar podcasts ou vídeos longos em clipes curtos, ou legendar e dublar conteúdo em outros idiomas.

Observações

  • Licença AGPL-3.0: se você modificar e oferecer como serviço a terceiros, precisa publicar o código das modificações.
  • Provedores de vídeo e imagem por IA são pagos por uso; o controle de orçamento ajuda, mas confira os preços em docs/PROVIDERS.md.
  • Geração local de vídeo exige GPU.
  • Usar vídeos de terceiros como referência ou como fonte (YouTube, TikTok, Reels) pode esbarrar em direitos autorais e termos de uso; o material de acervos abertos e bancos gratuitos tem licenças próprias que devem ser respeitadas.
  • Suporte a LLM local (Ollama, LM Studio) está anunciado como "em breve".
  • Usa o HyperFrames e o FFmpeg como motores de composição; para cortes verticais automáticos de um vídeo longo, o SupoClip é uma alternativa mais focada.
