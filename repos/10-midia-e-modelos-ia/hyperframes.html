O que é

No HyperFrames, um vídeo é uma página HTML. Cada elemento (vídeo, título, áudio) recebe atributos data-start, data-duration e data-track-index, que dizem quando aparece e em qual faixa. As animações usam GSAP, CSS, Lottie, Three.js, Anime.js ou WAAPI, desde que dê para avançar quadro a quadro.

Para renderizar, o HyperFrames abre a página num Chrome sem interface, avança quadro a quadro e codifica com o FFmpeg. A mesma entrada gera sempre o mesmo vídeo.

É inspirado no Remotion, mas usa HTML puro em vez de componentes React. Por isso fica mais fácil para um agente escrever.

Principais recursos

  • Skills para agentes (Claude Code, Codex, Cursor, Gemini CLI, OpenCode):
    • núcleo: /hyperframes, /hyperframes-cli, /hyperframes-registry e /media-use;
    • sob demanda: /figma, /slideshow, /remotion-to-hyperframes, /reverse-any-video e /style-sampling (os dois últimos são do plano Pro).
  • CLI: cria o projeto, pré-visualiza no navegador com recarga automática, valida e renderiza.
  • Catálogo com cerca de 450 blocos prontos: transições, overlays, títulos animados, legendas, gráficos, mapas e 3D.
  • Studio: editor no navegador e app desktop gratuito (macOS, Windows e Linux).
  • frame.md: adapta o design system da marca (DESIGN.md) para vídeo.
  • Renderização distribuída na AWS Lambda.
  • Player embutível (<hyperframes-player>).

Pré-requisitos

  • Node.js 22+.
  • FFmpeg instalado (veja o FFmpeg).
  • Para usar com agente: Claude Code, Codex, Cursor ou outro que aceite skills.

Instalação

Plugin para o Claude Code:

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Depois, use /hyperframes:hyperframes.

Skills avulsas (outros agentes, inclusive OpenCode):

npx hyperframes skills update        # instala só o núcleo, na versão da sua CLI
npx skills add heygen-com/hyperframes   # seletor interativo

Só a CLI:

npx hyperframes init meu-video
cd meu-video
npx hyperframes preview      # pré-visualiza no navegador
npx hyperframes render       # renderiza para MP4

Comandos e uso

Com o agente, peça algo como:

Using /hyperframes, create a 10-second product intro with a fade-in title, a background video, and subtle background music.

Blocos do catálogo:

npx hyperframes add flash-through-white   # transição com shader
npx hyperframes add instagram-follow      # overlay de rede social
npx hyperframes add data-chart            # gráfico animado

Quando usar

  • Vídeos de lançamento de produto, anúncios de funcionalidade e explicações animadas.
  • Visualizações de dados, corridas de gráficos e mapas animados.
  • Vídeos para redes sociais com legendas animadas, overlays e música.
  • Gerar vídeos em lote, por script ou em CI, com resultado sempre igual.
  • Comparação no catálogo:
    • o OpenCut é um editor manual com linha do tempo;
    • o SupoClip corta vídeos longos que já existem;
    • o HyperFrames cria o vídeo do zero a partir de código.

Observações

  • Licença: Apache 2.0, sem taxa por renderização nem limite de uso comercial. O Remotion, por comparação, tem licença própria, que cobra de empresas acima de certo tamanho.
  • Plano Pro: o Studio é gratuito, mas o plano Pro cobra pelos modelos de vídeo, imagem, voz e música da HeyGen e pelas skills /reverse-any-video e /style-sampling.
  • /reverse-any-video recria qualquer vídeo como projeto editável. Recriar vídeos de terceiros pode violar direitos autorais.
  • Contribuir: o clone completo usa Git LFS, com cerca de 240 MB de vídeos de teste. Para só ler o código, use GIT_LFS_SKIP_SMUDGE=1.
  • Projeto muito ativo, com releases quase diárias (última: v0.9.19, nov/2026). A API ainda está na série 0.x.
