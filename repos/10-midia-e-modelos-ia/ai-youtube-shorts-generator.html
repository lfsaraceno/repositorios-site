AI YouTube Shorts Generator

Alternativa open source ao Opus Clip, Vidyo.ai e Klap: transforma um vídeo longo do YouTube (ou um arquivo local) em cortes verticais 9:16 com nota de viralização, gancho e motivo de cada corte, usando Whisper para transcrever e um LLM para escolher os melhores trechos.

O que é

Uma ferramenta de linha de comando (e biblioteca Python) que faz o que os serviços pagos de "cortes com IA" fazem, sem assinatura, sem limite de minutos e sem marca d'água. Você passa a URL de um vídeo longo e recebe os N melhores trechos já recortados na vertical.

O pipeline:

  1. baixa o vídeo;
  2. transcreve com Whisper, com marcação de tempo;
  3. o LLM classifica o tipo de vídeo (podcast, entrevista, tutorial, vlog) para ajustar a análise;
  4. vídeos com mais de 30 minutos são divididos em blocos de 20 minutos com sobreposição;
  5. o LLM avalia a transcrição com critérios de viralização (ganchos, picos emocionais, opiniões fortes, revelações, conflito, frases de efeito, valor prático) e dá nota de 0 a 100;
  6. trechos sobrepostos são unidos, mantendo o de maior nota;
  7. os melhores são recortados na proporção pedida.

Tem dois modos: API (padrão, usa o serviço pago MuAPI para tudo) e local (yt-dlp, faster-whisper, ffmpeg e OpenCV no seu computador; só a etapa do LLM vai para a OpenAI ou o Gemini).

Principais recursos

  • Nota, título, gancho e motivo para cada corte.
  • Recorte vertical inteligente: no modo local, rastreia rostos com OpenCV e suaviza o movimento.
  • Qualquer proporção: 9:16, 1:1 ou outra.
  • Vídeos longos divididos automaticamente, sem perder trechos na divisão.
  • Arquivos locais no modo local (caminho ou file://), sem passar pelo YouTube.
  • Cache: reaproveita a transcrição (.srt) e o download já feitos.
  • Lote com xargs sobre uma lista de URLs.
  • Saída em JSON com transcrição, todos os candidatos e os cortes finais.
  • Critérios editáveis em shorts_generator/highlights.py.

Pré-requisitos

  • Python 3.10+.
  • Modo API: chave do MuAPI (pago por uso).
  • Modo local: ffmpeg no PATH e chave da OpenAI ou do Gemini. GPU NVIDIA opcional para o Whisper.

Instalação

git clone https://github.com/Anil-matcha/AI-Youtube-Shorts-Generator.git
cd AI-Youtube-Shorts-Generator
python3.10 -m venv venv
source venv/bin/activate                    # Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-local.txt       # só para o --mode local

O README clona pelo nome antigo do repositório (SamurAIGPT/AI-Youtube-Shorts-Generator), que o GitHub redireciona.

Crie um .env na raiz. Para o modo local:

LLM_PROVIDER=openai          # openai ou gemini
OPENAI_API_KEY=...           # ou GEMINI_API_KEY
LOCAL_WHISPER_MODEL=base     # tiny / base / small / medium / large-v3
LOCAL_WHISPER_DEVICE=auto    # auto / cpu / cuda
LOCAL_OUTPUT_DIR=output

Para o modo API, basta MUAPI_API_KEY.

Comandos e uso

python main.py "https://www.youtube.com/watch?v=VIDEO_ID"                    # modo API (padrão), 3 cortes
python main.py "https://www.youtube.com/watch?v=VIDEO_ID" --mode local       # tudo local, menos o LLM
python main.py "C:/Videos/live.mp4" --mode local --num-clips 5 --language pt # arquivo local, 5 cortes, em português
python main.py "<url>" --aspect-ratio 1:1 --format 1080 --output-json result.json
xargs -a urls.txt -I{} python main.py "{}"                                   # lote (Linux/macOS/Git Bash)

No modo local, os cortes saem em ./output/short_01.mp4, short_02.mp4 etc.

Como biblioteca:

from shorts_generator import generate_shorts
result = generate_shorts("live.mp4", num_clips=5, aspect_ratio="9:16", mode="local")
for short in result["shorts"]:
    print(short["score"], short["title"], short["clip_url"])

Quando usar

  • Cortar podcasts, lives, aulas e entrevistas para TikTok, Reels e Shorts.
  • Agências que processam muitos vídeos e não querem pagar por minuto.
  • Integrar cortes automáticos num sistema próprio (biblioteca Python e saída JSON).

Observações

  • O padrão é pago: o modo API usa o MuAPI, do mesmo grupo do autor, e o README promove a API de cortes deles. Para custo mínimo, use --mode local (você paga só a chamada ao LLM).
  • Sem legendas animadas: a ferramenta recorta, mas não adiciona legenda queimada no vídeo nem título na tela.
  • Direitos autorais: cortar vídeos de terceiros do YouTube para republicar pode violar direitos e os termos da plataforma. Use com conteúdo próprio ou autorizado.
  • Relacionados no catálogo: o SupoClip faz o mesmo com interface web, rosto centralizado e legendas sincronizadas por palavra. O Short Video Factory monta vídeos novos a partir de clipes. O yt-dlp e o Whisper são usados no modo local.
