O que é

O FFmpeg é o "canivete suíço" de mídia. Ele lê e grava centenas de formatos e codecs, aplica filtros e transmite por rede. Ferramentas como o yt-dlp, o Whisper, o HyperFrames, o OpenCut e o SupoClip dependem dele.

O repositório no GitHub é só um espelho. O desenvolvimento acontece no Forgejo do projeto e na lista de e-mail ffmpeg-devel. Pull requests no GitHub são ignorados.

Principais recursos

  • Ferramentas:
    • ffmpeg: converte, manipula e transmite mídia;
    • ffprobe: inspeciona arquivos (codecs, duração, streams);
    • ffplay: player mínimo.
  • Bibliotecas que outros programas usam:
    • libavcodec: codecs;
    • libavformat: contêineres e protocolos de streaming;
    • libavfilter: filtros de áudio e vídeo;
    • libswscale e libswresample: escala, cor e reamostragem de áudio;
    • libavdevice: dispositivos de captura e reprodução.
  • Aceleração por hardware (NVENC, Quick Sync, VAAPI, VideoToolbox), conforme a build.

Pré-requisitos

Nenhum além do sistema operacional. Use uma build pronta, ou compile se precisar de codecs específicos.

Instalação

sudo apt update && sudo apt install ffmpeg   # Ubuntu/Debian
brew install ffmpeg                           # macOS
choco install ffmpeg                          # Windows (Chocolatey)
scoop install ffmpeg                          # Windows (Scoop)

Builds prontas para Windows, macOS e Linux estão na página de download. O yt-dlp mantém builds próprias, hoje iguais às oficiais.

Confira com ffmpeg -version.

Comandos e uso

ffprobe video.mp4                                      # mostra codecs, duração e streams
ffmpeg -i entrada.mov saida.mp4                        # converte de formato
ffmpeg -i video.mp4 -vn -c:a libmp3lame audio.mp3      # extrai o áudio em MP3
ffmpeg -i video.mp4 -ss 00:01:00 -t 30 -c copy corte.mp4   # corta 30 s a partir de 1 min, sem recodificar
ffmpeg -i video.mp4 -vf scale=1280:-2 menor.mp4        # redimensiona para 1280 px de largura
ffmpeg -i video.mp4 -c:v libx264 -crf 28 comprimido.mp4    # comprime (CRF maior = arquivo menor)

Para juntar arquivos, gerar GIFs, embutir legendas e muito mais, veja a documentação e a wiki.

Quando usar

  • Converter, cortar, comprimir ou extrair áudio de vídeos, em lote ou por script.
  • Preparar mídia para outras ferramentas (por exemplo, áudio para o Whisper).
  • Como dependência de quase toda ferramenta de vídeo do catálogo.

Observações

  • Licença: a base é LGPL. Ao ativar componentes GPL (como o libx264) ou não livres (--enable-nonfree), a build inteira passa a ser GPL ou não redistribuível. Quem distribui o FFmpeg junto com um produto precisa conferir a página legal.
  • Patentes de codecs (H.264, HEVC, AAC) podem exigir licenciamento em uso comercial, conforme o país.
  • Arquivos de mídia de terceiros são entrada não confiável. O FFmpeg tem histórico de falhas de segurança em decodificadores. Num servidor, mantenha-o atualizado e processe com limites.
  • O FFmpeg não publica releases no GitHub; versões e notas ficam no site.
  • Não consegui abrir o ffmpeg.org daqui ao verificar os links (tempo esgotado). Ele é o site oficial indicado pelo próprio repositório.
