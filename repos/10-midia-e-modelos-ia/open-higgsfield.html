O que é

O OpenHiggsfield AI é um estúdio web para gerar imagens e vídeos a partir de uma única barra de prompt. O modelo escolhido define se o resultado é imagem ou vídeo, e cada modelo expõe as suas próprias configurações (proporção, resolução, duração, formato, áudio, lote e melhoria de prompt).

Ele não roda modelos localmente: usa uma API externa de geração, acessada com a sua própria chave de plataforma (id:secret). O estúdio é gratuito e auto-hospedável; o custo da geração depende da plataforma da chave. Também há uma versão hospedada em openhiggsfield.ai, sem instalação.

Principais recursos

  • Catálogo de 38 modelos (8 de imagem e 30 de vídeo), incluindo Soul, Seedance, Kling, Wan, Flux, Ideogram, Recraft, LTX, MiniMax, PixVerse, Grok e Qwen, com seletor pesquisável.
  • Entradas de mídia por função: quadro inicial, quadro final, referências, vídeo e áudio.
  • Lotes de até 4 resultados por envio, com acompanhamento do estado de cada geração.
  • Galeria com abas (Imagem, Vídeo, Assets, Favoritos), grade tipo masonry, visualizador, reuso de configurações e ações em massa (baixar, favoritar, excluir) com desfazer.
  • Histórico salvo no IndexedDB do navegador (60 registros; favoritos nunca expiram).
  • Chave de API guardada em cookie httpOnly por server action; o navegador nunca chama a API de geração diretamente.

Pré-requisitos

  • Node.js e pnpm.
  • Uma chave de plataforma de geração (formato id:secret).
  • Para uploads de mídia: um token de leitura e escrita do Vercel Blob.

Instalação

git clone https://github.com/wide-trace/open-higgsfield.git
cd open-higgsfield
pnpm install
pnpm dev            # http://localhost:3000

Abra o estúdio, clique em Add key e cole a sua chave no formato id:secret.

Variáveis de ambiente (veja .env.example):

HF_API_BASE_URL=                      # origem da API de geração, só no servidor
OPEN_HIGGSFIELD_READ_WRITE_TOKEN=     # token de leitura e escrita do Vercel Blob

Comandos e uso

pnpm dev      # servidor de desenvolvimento na porta 3000
pnpm build    # build de produção
pnpm start    # serve o build de produção
pnpm brand    # reconstrói ícones e o card OG em public/

Uso: escolha um modelo, escreva o prompt, ajuste as configurações do modelo, anexe mídias se precisar e envie com Ctrl/Cmd + Enter. Os resultados aparecem na galeria, onde dá para reutilizar, favoritar ou baixar.

Quando usar

  • Ter uma interface única para vários modelos de vídeo e imagem comerciais, sem assinar um estúdio fechado.
  • Testar e comparar modelos (Kling, Seedance, Wan, Flux etc.) com os mesmos prompts.

Observações

  • O repositório não declara licença; sem ela, o direito de reutilizar ou redistribuir o código não é claro. Confirme com o autor antes de uso comercial.
  • Não é geração local: exige uma chave de plataforma de terceiros e a geração é cobrada por ela.
  • O histórico fica só no navegador, e as URLs dos resultados pertencem à plataforma de geração (podem expirar).
  • O README não identifica qual plataforma emite a chave id:secret; veja o site para detalhes.
