O que é

O ACE-Step 1.5 é um modelo de música open source que, segundo os autores, tem qualidade entre o Suno v4.5 e o Suno v5, rodando no seu computador. Ele combina duas partes:

  • um modelo de linguagem (baseado no Qwen3) que funciona como planejador: transforma um pedido simples num "projeto" da música, com metadados, letra e descrição;
  • um Diffusion Transformer (DiT) que gera o áudio a partir desse projeto.

Vem com interface web (Gradio), API REST, API Python, CLI e um plugin VST3 para usar dentro de DAWs. Os modelos são baixados sozinhos na primeira execução.

Principais recursos

  • Rápido: menos de 2 s por música numa A100 e menos de 10 s numa RTX 3090.
  • Duração flexível: de 10 segundos a 10 minutos, até 8 músicas de uma vez.
  • Mais de 1.000 instrumentos e estilos, com descrição fina de timbre.
  • Letra em mais de 50 idiomas, com marcação de estrutura e estilo.
  • Áudio de referência para guiar o estilo.
  • Cover a partir de um áudio existente.
  • Repaint: edita e regenera só um trecho.
  • Separação de faixas (stems) e multitrack (adicionar camadas, como no Suno Studio).
  • Vocal2BGM: cria o acompanhamento para uma voz gravada.
  • Controle de metadados: duração, BPM, tom, escala e compasso.
  • Modo simples: música completa a partir de uma descrição curta, com reescrita automática de tags e letra.
  • Entende áudio: extrai BPM, tom, compasso e descrição de uma música.
  • Letra sincronizada (LRC) e nota automática de qualidade.
  • Treino de LoRA: com 8 músicas, em cerca de 1 hora numa 3090 (12 GB), direto na interface.
  • Modelos XL (4B) desde abr/2026, com mais qualidade (precisam de 12 GB+ de VRAM).

Pré-requisitos

  • Python 3.11 ou 3.12 e o gerenciador uv.
  • GPU recomendada: NVIDIA (CUDA). Também funciona com AMD (ROCm), Intel, Apple Silicon (MPS/MLX) e CPU.
  • VRAM: com 6 GB ou menos, roda só o DiT 2B turbo; com 8 a 16 GB, o 2B com o modelo de linguagem; com 24 GB ou mais, o XL com a melhor qualidade. A interface escolhe a configuração conforme a sua GPU.

Instalação

Windows (pacote portátil)

Baixe o pacote portátil para Windows, com as dependências já instaladas, e siga o guia de instalação.

A partir do código

# 1. instalar o uv
curl -LsSf https://astral.sh/uv/install.sh | sh                                    # macOS / Linux
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"  # Windows

# 2. clonar e instalar
git clone https://github.com/ACE-Step/ACE-Step-1.5.git
cd ACE-Step-1.5
uv sync

# 3. iniciar
uv run acestep          # interface Gradio em http://localhost:7860
uv run acestep-api      # API REST em http://localhost:8001

No Windows também há scripts prontos: start_gradio_ui.bat e start_api_server.bat (CUDA) ou as versões _rocm.bat (AMD; ROCm no Windows exige Python 3.12).

Comandos e uso

Personalize modelos e porta num .env (copie de .env.example):

ACESTEP_CONFIG_PATH=acestep-v15-turbo        # modelo DiT
ACESTEP_LM_MODEL_PATH=acestep-5Hz-lm-1.7B    # modelo de linguagem
PORT=7860
LANGUAGE=en

python profile_inference.py                   # mede o tempo de cada etapa na sua máquina
python profile_inference.py --mode benchmark  # compara configurações

Na interface, escreva a descrição (estilo, instrumentos, clima) e, se quiser, a letra com marcações de estrutura. O tutorial explica como controlar o resultado.

Quando usar

  • Trilha sonora original para vídeos, podcasts e jogos, sem pagar assinatura.
  • Testar ideias de música e letra rapidamente.
  • Criar acompanhamento para uma voz gravada ou fazer covers.
  • Treinar um modelo com o estilo de uma banda ou produtora (com os direitos das músicas usadas).

Observações

  • Direitos autorais: o próprio projeto alerta para o risco de semelhança com obras protegidas. Verifique a originalidade, informe o uso de IA e tenha permissão para usar estilos ou músicas protegidos, principalmente em covers e no treino de LoRA.
  • Sites falsos: o README avisa que existem domínios falsos do projeto e pede para não pagar nada neles. O README promove o acemusic.ai, mas também diz que o único site oficial é o GitHub Pages do projeto. Na dúvida, use só os links do repositório.
  • A comparação com o Suno é dos próprios autores.
  • Os modelos XL são mais pesados: com menos de 20 GB de VRAM, precisam de offload para a CPU.
  • Relacionado no catálogo: o Kokoro gera voz falada; o ACE-Step gera música cantada e instrumental.
