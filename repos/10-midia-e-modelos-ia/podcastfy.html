Podcastfy

Alternativa open source ao recurso de podcast do NotebookLM: um pacote Python que transforma sites, PDFs, imagens, vídeos do YouTube ou um tema em um podcast conversado entre duas vozes, curto ou longo, em vários idiomas (inclusive português do Brasil).

O que é

O Podcastfy faz o que o "Audio Overview" do NotebookLM faz, mas como código aberto e programável. Você passa uma ou mais fontes, um LLM escreve o roteiro de uma conversa entre apresentadores, e um modelo de voz (TTS) gera o áudio.

Por ser uma biblioteca, dá para personalizar o formato, o estilo, o idioma e as vozes e gerar podcasts em escala. O autor é brasileiro, e o README traz um exemplo em português sobre pesquisas eleitorais em São Paulo. Projetos como OpenNotebook e SurfSense usam o Podcastfy por baixo.

Principais recursos

  • Fontes: sites, PDFs, imagens, vídeos do YouTube, texto puro ou um tema (com busca na web em tempo real).
  • Duração: podcasts curtos (2 a 5 minutos) ou longos (30 minutos ou mais, opção longform).
  • LLMs: mais de 100 modelos (OpenAI, Anthropic, Google etc.) ou modelos locais, para mais privacidade.
  • Vozes: OpenAI TTS, Google (inclusive TTS multi-falante), ElevenLabs e Microsoft Edge.
  • Personalização da conversa: formato, estilo, estrutura, idioma e nomes e papéis dos apresentadores, via arquivo YAML.
  • Só o roteiro: dá para gerar só a transcrição, revisar e depois gerar o áudio a partir dela.
  • Formas de uso: biblioteca Python, CLI e uma API FastAPI em beta (via Docker).

Pré-requisitos

  • Python 3.11 ou mais novo.
  • ffmpeg, para processar o áudio.
  • Chaves de API conforme os modelos: no padrão, GEMINI_API_KEY (roteiro com gemini-2.5-flash) e OPENAI_API_KEY (voz). Com LLM local e vozes do Edge, não precisa de chave nenhuma.

Instalação

pip install podcastfy

Crie um .env na pasta do projeto com as chaves:

GEMINI_API_KEY=...
OPENAI_API_KEY=...
ELEVENLABS_API_KEY=...     # só se usar ElevenLabs

O README indica pip install ffmpeg para o áudio. Se der erro ao gerar áudio, instale o programa ffmpeg no sistema.

Comandos e uso

from podcastfy.client import generate_podcast
audio_file = generate_podcast(urls=["https://exemplo.com/artigo1", "https://exemplo.com/artigo2"])

CLI:

python -m podcastfy.client --url https://exemplo.com/artigo1 --url https://exemplo.com/artigo2   # podcast de dois links
python -m podcastfy.client --url https://exemplo.com/artigo1 --tts-model elevenlabs              # outra voz
python -m podcastfy.client --file urls.txt                                                       # lista de URLs
python -m podcastfy.client --image foto1.jpg --image foto2.png                                   # a partir de imagens
python -m podcastfy.client --text "Texto que vira podcast"                                       # texto puro
python -m podcastfy.client --url https://exemplo.com/artigo1 --transcript-only                   # só o roteiro
python -m podcastfy.client --transcript roteiro.txt                                              # áudio a partir do roteiro
python -m podcastfy.client --url https://exemplo.com/artigo1 --longform                          # podcast longo
python -m podcastfy.client --url https://exemplo.com/artigo1 --transcript-only --local           # roteiro com LLM local
python -m podcastfy.client --url https://exemplo.com/artigo1 --conversation-config custom.yaml   # estilo personalizado

Configurações recomendadas pela documentação: Gemini + vozes geminimulti (só a GEMINI_API_KEY), ou LLM local + Edge, sem nenhuma chave.

Quando usar

  • Transformar posts de blog, artigos e PDFs em versão em áudio.
  • Material de estudo ou aula em formato de conversa.
  • Gerar muitos episódios automaticamente, a partir de uma lista de links.
  • Incluir um gerador de podcast dentro de um produto próprio.

Observações

  • Atividade: o último commit é de mai/2026. Confira as issues antes de depender dele em produção.
  • Custos: o padrão usa APIs pagas (Gemini e OpenAI TTS). Para custo zero, use LLM local com vozes do Edge, que é um serviço online da Microsoft de uso não oficial.
  • Direitos autorais: transformar conteúdo de terceiros (livros, vídeos, artigos) em podcast para publicar pode violar direitos.
  • O README tem um guia de licença para quem quiser usar o Podcastfy dentro de outro software.
  • Relacionados no catálogo: o Kokoro é um TTS local e leve. O VoiceStudio clona vozes. O OpenCreator também gera narração, mas de uma voz só.
