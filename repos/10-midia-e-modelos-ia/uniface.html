O que é

O UniFace junta numa API única os modelos mais usados de visão computacional para rostos. Em vez de instalar e integrar um projeto diferente para cada tarefa, você faz pip install e chama classes como RetinaFace (detecção), ArcFace (reconhecimento) ou BlurFace (anonimização).

A classe FaceAnalyzer roda detecção, alinhamento e reconhecimento numa chamada só e devolve, para cada rosto, a caixa, a confiança, os pontos faciais e o vetor de identidade (embedding). Atributos como idade, sexo, emoção e qualidade entram só quando você passa o modelo correspondente.

Os modelos rodam com ONNX Runtime em CPU, Apple Silicon ou GPU NVIDIA. Os pesos são baixados no primeiro uso e conferidos por SHA-256. O projeto não tem relação com o Uniface da Rocket Software.

Principais recursos

  • 15 tarefas: detecção, reconhecimento, rastreamento em vídeo, landmarks (até 478 pontos em 3D), segmentação do rosto, recorte de retrato (matting), direção do olhar, pose da cabeça, idade e sexo, emoção, estados do rosto (olhos, óculos, máscara), qualidade da imagem, anti-spoofing, anonimização e busca vetorial.
  • Vários modelos por tarefa. Detecção: RetinaFace, SCRFD, CenterFace, YOLOv5/v8-Face, BlazeFace. Reconhecimento: AdaFace, ArcFace, EdgeFace, MobileFace, SphereFace.
  • FaceAnalyzer para o pipeline completo numa linha.
  • Rastreamento com IDs persistentes entre quadros de vídeo (BYTETracker).
  • Anti-spoofing (MiniFASNet), que distingue rosto real de foto ou tela.
  • 5 métodos de anonimização: pixelate, gaussian, blackout, elliptical e median.
  • Busca de rostos por similaridade com FAISS.

Pré-requisitos

  • Python 3.10 a 3.14.
  • Windows, Linux ou macOS.
  • Opcional: GPU NVIDIA com CUDA (veja a matriz de compatibilidade do ONNX Runtime).
  • Para os exemplos com imagens: OpenCV (cv2).

Instalação

Escolha um dos extras. Os pacotes onnxruntime (CPU) e onnxruntime-gpu (CUDA) entram em conflito, então não instale os dois:

pip install "uniface[cpu]"          # CPU e Apple Silicon
pip install "uniface[gpu]"          # GPU NVIDIA (CUDA)
pip install --pre "uniface[cpu]"    # pré-lançamento mais recente

Extras opcionais:

pip install faiss-cpu      # busca vetorial (ou faiss-gpu com CUDA)
pip install torch          # necessário para o modelo de emoção
pip install torchvision    # NMS mais rápido nos detectores YOLO

Conferir se a GPU está sendo usada:

import onnxruntime as ort
print(ort.get_available_providers())   # com NVIDIA deve aparecer 'CUDAExecutionProvider'

Comandos e uso

Pipeline completo:

import cv2
from uniface import FaceAnalyzer, FairFace

analyzer = FaceAnalyzer(predictors=[FairFace()])   # padrão: RetinaFace + EdgeFace; FairFace adiciona idade, sexo e etnia

for face in analyzer.analyze(cv2.imread("photo.jpg")):
    print(face.bbox, face.sex, face.age_group, face.embedding.shape)

Comparar dois rostos (mesma pessoa?):

import cv2
from uniface import compute_similarity
from uniface.detection import RetinaFace
from uniface.recognition import ArcFace

detector, recognizer = RetinaFace(), ArcFace()
img1, img2 = cv2.imread("person1.jpg"), cv2.imread("person2.jpg")
f1, f2 = detector.detect(img1), detector.detect(img2)

emb1 = recognizer.get_normalized_embedding(img1, f1[0].landmarks)
emb2 = recognizer.get_normalized_embedding(img2, f2[0].landmarks)
print(compute_similarity(emb1, emb2, normalized=True))   # > 0.6 mesma pessoa; 0.4 a 0.6 incerto; < 0.4 pessoas diferentes

Borrar rostos (privacidade):

import cv2
from uniface.detection import RetinaFace
from uniface.privacy import BlurFace

image = cv2.imread("group_photo.jpg")
faces = RetinaFace().detect(image)
cv2.imwrite("anonymized.jpg", BlurFace(method="pixelate").anonymize(image, faces))

Rosto real ou foto/tela (anti-spoofing):

from uniface.spoofing import MiniFASNet

spoofer = MiniFASNet()
for face in faces:
    result = spoofer.predict(image, face.bbox)
    print("Real" if result.is_real else "Fake", f"{result.confidence:.1%}")

O Quickstart traz exemplos de landmarks, olhar, pose da cabeça, segmentação, recorte com fundo transparente, qualidade, webcam e rastreamento em vídeo.

Quando usar

  • Anonimizar rostos em fotos e vídeos antes de publicar ou armazenar.
  • Controle de acesso ou verificação de identidade (comparação de rosto com anti-spoofing).
  • Organizar acervos de fotos por pessoa (embeddings + FAISS).
  • Prototipar funcionalidades de visão computacional sem integrar um modelo por vez.

Observações

  • Licença dos pesos: o código é MIT, mas SCRFD, ArcFace, AgeGender e Landmark106 (da InsightFace) são só para pesquisa não comercial. YOLOv5-Face e YOLOv8-Face são GPL-3.0. Para uso comercial, prefira modelos permissivos, como RetinaFace, AdaFace (MIT) ou EdgeFace (BSD-3), e confira a página de licenças. O exemplo de reconhecimento acima usa o ArcFace, que é não comercial.
  • Mesmo com licença permissiva, muitos modelos foram treinados em bases de dados restritas a pesquisa. Para uso comercial, faça a sua própria análise.
  • LGPD: dado biométrico é dado pessoal sensível (art. 5º, II, e art. 11). Reconhecimento facial de pessoas exige base legal adequada, normalmente consentimento específico, além de transparência e segurança. A anonimização ajuda a reduzir esse risco.
  • Os modelos de idade, sexo, etnia e emoção podem ter vieses. Não use para decisões automáticas sobre pessoas.
  • Na primeira execução, os pesos são baixados da internet. Em servidor sem acesso externo, baixe-os antes.
