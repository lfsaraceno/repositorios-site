O que é

O Short Video Factory ("fábrica de vídeos curtos") é um app chinês para produzir vídeos curtos em série sem editar na mão. Você dá um prompt e uma pasta de clipes (as "cenas"). O app gera o roteiro com um LLM, transforma o texto em narração, corta e junta os clipes no ritmo da fala, adiciona legendas e exporta o vídeo.

No modo em lote, ele segue gerando vídeos sem parar a partir de uma predefinição, o que serve para canais de cortes, frases motivacionais e vídeos de produto em quantidade.

Principais recursos

  • Roteiro por IA: compatível com qualquer API no formato da OpenAI.
  • Narração com Edge TTS (vozes da Microsoft).
  • Edição automática: junta texto, vídeo, áudio e legendas e faz a montagem com os seus clipes.
  • Lote: uma tarefa gera vídeos continuamente a partir de uma predefinição.
  • Interface em chinês, inglês e japonês.
  • Roda local no Windows, macOS e Linux.
  • Planejado (ainda não feito): mais parâmetros, mais APIs de voz e efeitos de legenda.

Pré-requisitos

  • Windows x64, macOS ou Linux x86_64.
  • Uma chave de API de LLM compatível com OpenAI, para gerar os textos.
  • Seus próprios clipes de vídeo para a montagem.

Instalação

Baixe o instalador na página de releases:

  • Windows: short-video-factory-<versão>-win-x64-setup.exe
  • macOS: short-video-factory-<versão>-mac-universal-installer.dmg
  • Linux: short-video-factory-<versão>-linux-x86_64.AppImage

O manual de uso fica na documentação oficial.

Comandos e uso

É um app gráfico, sem linha de comando documentada. Fluxo típico:

  1. Configure a API do LLM e escolha a voz.
  2. Escreva o prompt do tema e aponte a pasta de clipes.
  3. Gere um vídeo, ou crie uma tarefa em lote com uma predefinição.

Quando usar

  • Produzir muitos vídeos curtos de produto ou de frases com os mesmos clipes.
  • Canais que publicam todo dia no TikTok, Reels ou Shorts.

Observações

  • Licença AGPL-3.0: quem modificar e distribuir, ou oferecer como serviço, precisa liberar o código.
  • Foco no público chinês: o README principal e a comunidade (grupo de WeChat) são em chinês. A interface não tem português.
  • Clipes de terceiros: os vídeos de exemplo usam material da internet. Use clipes próprios ou licenciados para não violar direitos autorais.
  • Edge TTS usa o serviço online da Microsoft, então precisa de internet, e o uso é não oficial.
  • O README divulga um patrocinador (provedor de tokens de modelos).
  • Relacionados no catálogo: o AI YouTube Shorts Generator e o SupoClip fazem cortes a partir de vídeos longos. Este app monta vídeos novos a partir de clipes soltos. O OpenMontage produz vídeos guiado por um agente de código.
