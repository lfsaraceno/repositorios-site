O que é

O OpenFilm deixa seu agente de programação fazer vídeos e deixa você editá-los. Você pede um filme ao Claude Code ou ao Codex; ele escreve o filme como páginas web, e o Studio, um editor local que roda no navegador, mostra o vídeo tomando forma. Depois você muda o que quiser, à mão ou pedindo ao agente.

A ideia é ser simples:

  • Um arquivo HTML. O film.html junta páginas animadas, vídeos, imagens e sons em trilhas, com estilo em CSS. O agente já conhece a web, então não há formato novo para aprender.
  • Uma função. Cada cena é uma página web que desenha qualquer instante com frame(t), usando o que o navegador desenha: three.js, WebGL, canvas, SVG, CSS, GSAP, vídeo. Não depende de framework como Remotion ou HyperFrames.
  • Um editor de verdade. Mover, redimensionar e girar elementos dentro de uma página, trocar texto, cor e estilo; posicionar, recortar e cortar clipes na linha do tempo.

Fazer, editar e renderizar não exige conta, e a biblioteca de músicas, sons, vozes, stickers, transições, efeitos e templates é gratuita. Para gerar voz, música, imagem e vídeo com IA, conecte seus serviços (ElevenLabs, OpenAI, Google, OpenRouter, fal e outros) com suas próprias chaves, ou entre com uma conta OpenFilm para usar sem chaves próprias.

Principais recursos

  • Funciona como skill em qualquer agente de programação (Claude Code, Codex etc.), ou pelo app desktop com chat integrado.
  • Studio no navegador (Chrome ou Edge): edita texto e camadas, clipes, volume, velocidade e legendas; as edições vão para os arquivos do filme, então o agente as enxerga e preserva; versões nomeadas via git.
  • Exportação em MP4 (até 4K, com motion blur), vídeo transparente (.webm/.mov), GIF, áudio e stems, legendas, stills, slides e linha do tempo para Final Cut Pro, Premiere Pro e DaVinci Resolve.
  • Canvas: quadro ao lado da edição onde você e o agente organizam notas, imagens, clipes, narração e música, e mandam para a linha do tempo; também vira storyboard.
  • Checagem do filme: o look desenha cada frame duas vezes em ordens embaralhadas e aponta frames instáveis, erros de página, fontes que não carregaram, sons faltando e texto cortado.
  • Skills de filme da comunidade em openfilm/skills, instaláveis pelo Studio ou por link.
  • Exemplos prontos em openfilm/examples.

Pré-requisitos

  • Node.js 22.2+ e ffmpeg, em macOS, Windows ou Linux.
  • git (para as versões salvas do Studio).
  • Navegador baseado em Chromium (Chrome, Edge) para o Studio.
  • A primeira execução baixa um Chromium headless (~100 MB).
  • O app desktop (macOS e Windows) já traz ffmpeg e o navegador headless.

Instalação

Como skill do agente

npx skills add openfilm/openfilm

Se o seu agente não tem suporte a skills, diga a ele: "Run npx -y openfilm@latest and follow what it prints."

App desktop (macOS e Windows)

Baixe em openfilm.dev ou em Releases. É o Studio com um chat ao lado para Claude Code, Codex e outros agentes, ou com o agente próprio usando sua chave.

CLI global

npm i -g openfilm

A partir do código-fonte

Requer Node 22.18+, pnpm 9 (corepack enable), ffmpeg no PATH e git.

git clone https://github.com/openfilm/openfilm && cd openfilm
pnpm install
pnpm dev            # Studio a partir do checkout, com um filme de exemplo
pnpm test

Comandos e uso

Peça ao agente em linguagem natural:

Make a 20-second launch video for my CLI, with music.

Ele abre o filme no Studio e você acompanha. Para partir de um exemplo pronto:

npx -y openfilm@latest open https://github.com/openfilm/examples/tree/main/one-prompt

Comandos da CLI (o agente roda; você também, com npx -y openfilm@latest <comando> ou após npm i -g openfilm):

openfilm                          # explica o que é um filme e lista as skills do OpenFilm
openfilm open   [folder | url]    # abre um filme no Studio: novo, existente, do GitHub ou o último
openfilm look   [what] [t | a-b]  # confere o filme, uma página ou mídia: contact sheet, um frame ou um intervalo
openfilm render [a-b]             # gera o MP4; --4k, --blur, --alpha (.webm/.mov), --loudness=-14
openfilm get    [what]            # mídia: da biblioteca gratuita primeiro, senão de um serviço conectado
openfilm canvas [apply <steps>]   # lê ou organiza o canvas ao lado da edição
openfilm skills                   # lista skills; `openfilm skill <name>` mostra uma
openfilm skill add <link>         # instala uma skill de um link ou pasta
openfilm doctor                   # diagnóstico do computador para colar numa issue

openfilm <comando> --help lista as opções de cada comando. No Studio, ⌘E alterna entre a edição e o canvas.

Estrutura de um filme

Um filme é uma pasta com um film.html. Cada <section> é uma trilha; cada elemento é um clipe:

<section>
  <iframe src="title.html#t=0,4"></iframe>
</section>
<section>
  <video src="assets/footage.mp4#t=12,18" at="4" speed="0.5"></video>
</section>
<section>
  <audio src="assets/music.mp3" volume="0.6"></audio>
</section>

Cada página define window.film = { frame(t) { ... } }. A única regra: o mesmo t sempre desenha a mesma imagem, independentemente do que veio antes.

Quando usar

  • Fazer vídeos de lançamento, demos de produto e motion graphics pedindo ao Claude Code, com a possibilidade de ajustar tudo à mão depois.
  • Quando você quer o vídeo do agente editável num editor de verdade, ou exportado para Premiere, DaVinci ou Final Cut.
  • Animações com three.js, WebGL ou GSAP sem aprender Remotion ou HyperFrames.

Observações

  • O código é MIT, mas o nome e o logo OpenFilm são marca registrada: um fork publicado como produto próprio precisa de outro nome (ver TRADEMARK.md).
  • Geração de voz, música, imagem e vídeo por IA usa serviços pagos com suas chaves, ou a conta OpenFilm.
  • Projeto recente (criado em out/2026) e em evolução rápida.
  • Comparado ao OpenMontage, que orquestra pipelines completos de produção (pesquisa, roteiro, geração, edição), o OpenFilm foca no formato de filme em HTML e no editor visual. O HyperFrames é outro motor de vídeo em HTML/GSAP; o OpenFilm dispensa framework e usa só frame(t).
