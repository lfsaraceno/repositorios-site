O que é

O VoiceStudio é um estúdio de voz com IA que roda na sua máquina, sem depender de serviço na nuvem. Num app desktop (Electron) ou numa interface web via Docker, você clona uma voz a partir de uma gravação de referência, cria uma voz nova descrevendo-a em texto, dubla vídeos com fala sincronizada, dita em qualquer campo de texto com um widget flutuante, transcreve áudio e gera audiolivros e histórias em lote.

O motor padrão é o próprio VoiceStudio (baseado no k2-fsa/OmniVoice), mas dá para escolher entre vários outros motores de voz, como CosyVoice 3, IndexTTS 2.5, KittenTTS, MOSS-TTS e sherpa-onnx. Para transcrição, o padrão é o WhisperX, com alternativas como Faster-Whisper, Parakeet e Moonshine. Os modelos são baixados e gerenciados dentro do app.

Também funciona como serviço local de fala para outros programas: tem API HTTP compatível com a da OpenAI, WebSocket para transcrição ao vivo e um servidor MCP, que deixa agentes como Claude Code, Codex e Cursor gerarem fala, clonarem vozes e transcreverem áudio.

Principais recursos

  • Clonagem de voz a partir de uma gravação limpa de referência.
  • Design de voz por descrição em texto (gênero, idade, tom, estilo, sotaque).
  • Dublagem de vídeo com fala no tempo certo.
  • Widget de ditado flutuante com atalho global, que funciona em qualquer campo de texto.
  • Transcrição, isolamento de voz e separação de falantes (diarização).
  • Fila de lotes, receitas reutilizáveis e pastas monitoradas para produção de audiolivros.
  • Servidor MCP e API local (OpenAI-compatible e WebSocket).
  • Marca d'água de IA, detecção automática de GPU e app complementar para iOS e Android (prévia).

Pré-requisitos

  • Windows 10 ou 11 (x64), macOS com Apple Silicon ou Linux. O Windows em ARM é experimental, e o Mac Intel só roda a interface, conectada a um backend remoto.
  • Cerca de 10 GB livres para o app, o ambiente Python e os modelos (cerca de 5 GB numa máquina sem GPU NVIDIA).
  • Opcional: GPU NVIDIA com driver comum para aceleração CUDA (não precisa do CUDA Toolkit). Sem GPU, tudo funciona na CPU, só que mais devagar.
  • Python, FFmpeg e os modelos são instalados pelo próprio app na primeira execução.

Instalação

Windows

Opção 1: baixe o VoiceStudio-Electron-<versão>-win-x64.exe na página de releases e rode. A instalação é só para o seu usuário e não pede administrador. Compare o arquivo com o SHA256SUMS.txt da release.

Opção 2: num PowerShell comum (sem administrador), o script escolhe o instalador certo, confere e abre o assistente:

irm https://voicestudio.sh/install | iex

Para não encher o C:, aponte os motores para outro disco antes de abrir o app:

[Environment]::SetEnvironmentVariable('OMNIVOICE_ENGINES_DIR', 'D:\VoiceStudio\engines', 'User')

macOS e Linux

curl -fsSL https://voicestudio.sh/install | sh                          # última versão
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall        # remove o app, mantendo os dados

Também há pacotes .dmg, .AppImage e .deb nas releases.

Docker (servidor, interface pelo navegador)

As imagens são só linux/amd64. CPU:

docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY="$OMNIVOICE_API_KEY" \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable

Com GPU NVIDIA, acrescente --gpus all (exige o NVIDIA Container Toolkit no host). Depois, abra http://localhost:3900. A primeira execução baixa cerca de 2,4 GB de modelos.

A forma recomendada é o Docker Compose do repositório, com perfis cpu, gpu e rocm:

docker compose -f deploy/docker-compose.yml --profile gpu up -d

Use a tag :stable em produção. A :latest acompanha a branch main e é uma prévia.

Comandos e uso

No app: abra Voice cloning, escolha uma voz ou adicione uma gravação limpa de referência, digite o texto e gere. Instale o modelo quando o app pedir. Em PCs sem GPU, escolha um motor leve (KittenTTS, Supertonic-3, PocketTTS) e um Whisper pequeno no catálogo de modelos.

Servidor MCP para agentes: com o VoiceStudio aberto, o MCP já está no ar em:

http://localhost:3900/mcp/

Em Integrations, o app exporta a configuração pronta para Claude Code (.mcp.json), Cursor (.cursor/mcp.json) e Codex CLI (~/.codex/config.toml). As ferramentas expostas são generate_speech, clone_voice, design_voice, describe_voice, transcribe, list_voices e check_health. Cada agente pode ter uma voz própria, definida pelo cabeçalho X-OmniVoice-Client-Id.

API local:

curl http://127.0.0.1:3900/.well-known/voicestudio-speech      # lista as capacidades do serviço
python -m backend.speech_client transcribe recording.wav       # transcreve um arquivo (a partir do código-fonte)

Endpoints principais: POST :3900/v1/audio/transcriptions (compatível com a OpenAI) e ws://127.0.0.1:3900/v1/audio/transcriptions/stream (transcrição ao vivo).

Skills para agentes:

npx skills add debpalash/VoiceStudio    # escolha "voicestudio" para fluxos de áudio

Quando usar

  • Narrar vídeos, cursos e anúncios com voz natural sem pagar ElevenLabs e sem mandar áudio para a nuvem.
  • Dublar vídeos para outros idiomas.
  • Ditar textos e prompts em qualquer app, inclusive no Claude Code, com transcrição local.
  • Dar voz e transcrição a agentes de IA via MCP.
  • Produzir audiolivros e conteúdo em lote.

Observações

  • AGPL-3.0: se você oferecer o VoiceStudio modificado como serviço na rede, precisa disponibilizar o código-fonte. Os pesos dos modelos, as vozes e as condições de uso do áudio gerado têm licenças separadas: confira no Model Manager antes de uso comercial.
  • Clone vozes só com permissão da pessoa dona da voz.
  • GPU AMD no Windows não acelera os motores PyTorch, que rodam na CPU. Uma exceção é o motor audio.cpp, que tem build Vulkan. O ROCm só funciona no Linux.
  • Em placas com menos de 16 GB de VRAM, alguns motores (IndexTTS 2.5, CosyVoice) podem estourar memória no Windows. Ative Settings → Performance → Disable torch.compile.
  • Alguns modelos pedem um token do Hugging Face. Cadastre em Settings → API Keys.
  • As estatísticas de uso são opcionais e pedem consentimento. No Docker, -e OMNIVOICE_ANALYTICS_DISABLED=1 desliga de vez.
  • O projeto é novo (criado em abr/2026) e muda rápido. A versão 0.5.3 foi a última com o app Tauri; quem a usa precisa migrar para o Electron.
