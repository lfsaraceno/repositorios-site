O que é

O yt-dlp é o sucessor ativo do youtube-dl. Você passa uma URL, e ele descobre os formatos disponíveis, baixa o melhor (ou o que você pedir) e junta vídeo e áudio. Também baixa legendas, miniaturas, capítulos e playlists ou canais inteiros.

É a base de muitas outras ferramentas. O SupoClip, por exemplo, usa o yt-dlp para baixar os vídeos que vai cortar.

Principais recursos

  • Milhares de sites, com seleção fina de formato, resolução, codec e idioma (-f, -S).
  • Só o áudio: extrai e converte para mp3, aac e outros (-x).
  • Legendas: baixa as normais e as automáticas, escolhe idiomas e embute no vídeo.
  • Playlists e canais, com modelo de nome de arquivo e pastas (-o).
  • Trechos: baixa só capítulos ou intervalos (--download-sections) ou divide por capítulo.
  • SponsorBlock: marca ou remove trechos patrocinados.
  • Lives: baixa transmissões desde o início (--live-from-start).
  • Login e cookies: importa cookies do navegador (--cookies-from-browser) para conteúdo que exige conta.
  • Uso como biblioteca Python e sistema de plugins.

Pré-requisitos

  • Python 3.11+, se instalar via pip. Os executáveis prontos não precisam de Python.
  • Fortemente recomendados:
    • ffmpeg e ffprobe (o programa, não o pacote Python de mesmo nome). São necessários para juntar vídeo e áudio separados e para conversões. Veja o FFmpeg;
    • yt-dlp-ejs e um runtime JavaScript (Deno, recomendado, ou Node.js, Bun ou QuickJS). Sem eles o suporte ao YouTube fica incompleto. Veja a wiki do EJS.
  • Opcional: curl_cffi, para sites que bloqueiam por impressão digital TLS (--impersonate).

Instalação

Executável pronto (recomendado no Windows e no macOS): baixe yt-dlp.exe ou yt-dlp_macos em Releases.

Via pip:

python -m pip install -U "yt-dlp[default]"

Outros gerenciadores estão na wiki de instalação.

Atualizar: yt-dlp -U nos executáveis; no pip, rode de novo o comando de instalação. O canal stable sai mais ou menos uma vez por mês e quebra quando os sites mudam. O próprio projeto recomenda o canal nightly para uso normal:

yt-dlp --update-to nightly                          # executável
python -m pip install -U --pre "yt-dlp[default]"    # pip

Comandos e uso

yt-dlp URL                                   # baixa no melhor formato
yt-dlp -F URL                                # lista os formatos disponíveis
yt-dlp -t mp4 URL                            # preset: MP4 com H.264 e AAC
yt-dlp -t mp3 URL                            # preset: só o áudio em MP3
yt-dlp -x --audio-format aac URL             # extrai o áudio
yt-dlp --write-subs --sub-langs "pt.*,en" --embed-subs URL
yt-dlp -o "%(title)s-%(id)s.%(ext)s" URL     # modelo de nome do arquivo
yt-dlp --cookies-from-browser firefox URL    # usa a sessão do navegador
yt-dlp -t sleep URL_DA_PLAYLIST              # pausas entre downloads

Opções fixas podem ir num arquivo de configuração (veja a seção CONFIGURATION do README).

Quando usar

  • Baixar vídeos ou áudios seus, de aulas, palestras e conteúdo com licença livre, para guardar ou editar.
  • Extrair o áudio de um vídeo para transcrever com o Whisper.
  • Alimentar pipelines de vídeo, como o SupoClip.

Observações

  • Termos e direitos autorais: o yt-dlp é legal, mas o uso pode não ser. Baixar conteúdo protegido sem permissão ou contornar bloqueios pode violar termos e leis.
  • Bloqueios do YouTube: a partir de servidores em datacenter, o YouTube costuma pedir a verificação "não sou robô". Em uso pesado, use o preset -t sleep para não ser bloqueado.
  • Cookies do navegador dão acesso à sua conta. Não compartilhe arquivos de cookies, e prefira uma conta secundária para automação.
  • Licença dos executáveis: o código é Unlicense, mas os executáveis do PyInstaller incluem código GPLv3+. O conjunto distribuído fica sob GPLv3+.
  • O projeto não faz download de conteúdo com DRM.
  • Projeto muito ativo, com release a cada poucas semanas (última: 2026.10.26).
