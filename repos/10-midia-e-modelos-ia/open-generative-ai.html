O que é

Uma interface única para gerar mídia com IA: texto para imagem, imagem para imagem, texto para vídeo, imagem para vídeo e lip sync guiado por áudio. Os modelos de nuvem são acessados pela API da Muapi.ai (com sua chave, pagando por uso); o app desktop também roda modelos locais de imagem (stable-diffusion.cpp) e se conecta a uma instalação do WanGP para vídeo local.

Está organizado em estúdios: Imagem, Vídeo, Áudio, AI Clipping, Vibe Motion, Lip Sync, Cinema, Marketing, Workflows, Agentes, Design Agent e Apps. Pode ser usado na versão hospedada, no app desktop ou self-hosted (Next.js ou Docker).

O projeto se anuncia como "sem filtros de conteúdo".

Principais recursos

  • Centenas de modelos de imagem e vídeo (Flux, Midjourney, Kling, Sora, Veo, Seedream, Wan 2.2, Nano Banana e outros).
  • Até 14 imagens de referência em modelos compatíveis.
  • Lip Sync Studio com 9 modelos dedicados.
  • Modelos locais no app desktop: Z-Image Turbo/Base, Dreamshaper 8, Realistic Vision, Anything v5, SDXL (via sd.cpp, com GPU Metal, CUDA, Vulkan ou ROCm), sem chave de API.
  • Integração com WanGP para vídeo local (Wan, Hunyuan, LTX-2) numa máquina com GPU NVIDIA/AMD.
  • Workflows, agentes, MCP e CLI na versão hospedada.

Pré-requisitos

  • App desktop: macOS (Apple Silicon ou Intel), Windows x64 ou Linux x64.
  • Chave da Muapi.ai para modelos na nuvem (dispensável só com modelos locais).
  • Do código: Node.js 18+.

Instalação

App desktop

Baixe em Releases: .dmg (macOS), Setup .exe (Windows), .AppImage ou .deb (Linux).

  • macOS: o app não é notarizado; depois de copiar para /Applications, rode xattr -cr "/Applications/Open Generative AI.app" e abra com botão direito → Abrir.
  • Windows: o instalador não é assinado; no SmartScreen, clique em More info → Run anyway.
  • Ubuntu 24.04+: prefira o .deb (traz o perfil AppArmor necessário).

Do código-fonte

git clone --recurse-submodules https://github.com/Anil-matcha/Open-Generative-AI.git
cd Open-Generative-AI
npm run setup          # obrigatório: instala e compila os workspaces
npm run electron:dev   # app desktop
npm run dev            # versão web em http://localhost:3000

Docker

git clone --recurse-submodules https://github.com/Anil-matcha/Open-Generative-AI.git
cd Open-Generative-AI
docker compose up --build    # http://localhost:3001

Comandos e uso

  1. Abra o app e informe a chave da Muapi (ou pule para usar só modelos locais).
  2. Escolha o estúdio (Imagem, Vídeo, Lip Sync...) e o modelo.
  3. Para modelos locais: Settings → Local Models, instale o motor sd.cpp, baixe o modelo e ative o seletor ⚡ Local no Image Studio.

Builds desktop: npm run electron:build (macOS), npm run electron:build:win, npm run electron:build:linux.

Quando usar

  • Testar e comparar muitos modelos de imagem e vídeo numa só interface, pagando por uso.
  • Gerar imagens localmente num Mac M-series sem API.
  • Base para um estúdio de IA próprio e customizado.

Observações

  • "Sem filtros de conteúdo": a responsabilidade pelo que for gerado é sua. Deepfakes, uso de rosto ou voz de terceiros sem consentimento e conteúdo ilegal podem gerar responsabilização civil e criminal, e violam a LGPD e os termos dos provedores de modelo.
  • Os modelos de nuvem passam pela Muapi (serviço pago do mesmo autor); o README tem bastante propaganda do plano white label (a partir de US$ 49/mês).
  • Instaladores sem assinatura de código (macOS e Windows): baixe só do repositório oficial.
  • O OpenHiggsfield AI, já no catálogo, segue proposta parecida.
