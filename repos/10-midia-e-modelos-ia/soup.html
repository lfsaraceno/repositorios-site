O que é

O Soup simplifica o fine-tuning de LLMs: uma configuração em YAML, um comando e pronto. Ele cuida de tamanho de lote, detecção de GPU e quantização, e funciona localmente com QLoRA, sem precisar de SSH em máquinas de nuvem.

O destaque é o layer streaming (opt-in e ainda em BETA, stream_layers: true): mantém o modelo base congelado fora da VRAM e o envia para a GPU uma camada por vez. Segundo o README, isso permitiu treinar o Llama-3.1-8B-Instruct em NF4 em uma RTX 3050 Laptop de 4 GB, com pico de 3,32 GB.

Principais recursos

  • Treino a partir de um YAML (soup.yaml): SFT, DPO, GRPO, PPO, KTO, ORPO, SimPO, IPO e outros.
  • Templates prontos: chat, code, tool-calling, medical, reasoning, vision, rlhf, pretrain, moe, embedding, audio e mais.
  • Layer streaming para treinar modelos grandes em GPUs com pouca VRAM.
  • Painel web local (soup ui) para experimentos, métricas, datasets e chat com o modelo.
  • Exportação para GGUF (Ollama e llama.cpp), merge de LoRA, push para o Hugging Face e servidor compatível com a API da OpenAI (soup serve).
  • Ferramentas de dados (soup data inspect, soup data clean), avaliação (soup eval) e diagnóstico (soup doctor).

Pré-requisitos

  • Python 3.10 a 3.12 (versões 3.13 ou superiores não são suportadas).
  • Para treinar: GPU compatível e o extra [train] (PyTorch, transformers, peft, trl, datasets).
  • pipx ou uv recomendados para instalar o CLI isolado.

Instalação

Núcleo leve (CLI, configuração e ferramentas de dados, sem PyTorch):

pipx install soup-cli
# ou
uv tool install soup-cli

Com a pilha de treino, ou tudo (treino, serve, ui e dados):

pipx install "soup-cli[train]"
pipx install "soup-cli[all]"

Dentro de um virtualenv, Colab ou Docker, use pip com os mesmos nomes (pip install "soup-cli[train]"). Use aspas duplas em "soup-cli[train]": é o único formato que funciona em cmd.exe, PowerShell, bash e zsh. Versão de desenvolvimento:

pipx install "git+https://github.com/MakazhanAlpamys/Soup.git"

Se aparecer externally-managed-environment (PEP 668), use pipx, uv tool ou um venv.

Comandos e uso

soup init --template chat                       # cria o soup.yaml a partir de um template
soup train --config soup.yaml                   # treina (LoRA, quantização e lotes automáticos)
soup chat --model ./output                      # conversa com o modelo treinado
soup infer --model ./output --input prompts.jsonl --output results.jsonl   # inferência em lote
soup serve --model ./output                     # API compatível com a OpenAI
soup merge --adapter ./output                   # une o LoRA ao modelo base
soup export --model ./output --format gguf --quant q4_k_m   # exporta para GGUF
soup push --model ./output --repo voce/meu-modelo           # publica no Hugging Face
soup eval benchmark --model ./output            # avalia
soup data inspect ./data/train.jsonl            # estatísticas do dataset
soup doctor --config soup.yaml                  # valida a configuração
soup ui                                         # painel web em http://127.0.0.1:7860 (pip install "soup-cli[ui]")

Exemplo mínimo de soup.yaml:

base: meta-llama/Llama-3.1-8B-Instruct
task: sft
data:
  train: ./data/train.jsonl
  format: alpaca
  val_split: 0.1

Quando usar

  • Ajustar (fine-tune) um LLM com seus dados em uma GPU doméstica ou de notebook.
  • Padronizar experimentos de treino com um arquivo de configuração versionável.
  • Exportar o modelo treinado para rodar localmente (Ollama, llama.cpp).

Observações

  • O layer streaming é BETA e opt-in.
  • A versão 0.76 trouxe mudanças que quebram configurações antigas (configurações que nunca tinham efeito agora são recusadas ao carregar). Rode soup doctor --config soup.yaml antes de reutilizar um YAML.
  • soup export --format awq e gptq serão removidos na v0.77.
  • Os números de desempenho do README vêm de medições do autor e de colaboradores em placas específicas.
