Remotion

Framework para criar vídeos com código em React: cada quadro é um componente, renderizado para MP4 localmente, em servidor, no AWS Lambda ou no navegador. Tem skills oficiais para agentes e licença gratuita para pessoas e empresas pequenas.

O que é

O Remotion permite fazer vídeos escrevendo componentes React. O vídeo vira código: animações, texto, imagens, áudio e efeitos são definidos em função do número do quadro, e o Remotion renderiza tudo para MP4 (ou imagem).

Serve para três formas de trabalho: com um agente de IA (que escreve o código do vídeo), de forma interativa no Remotion Studio (edição e animação como num editor de vídeo) ou de forma programática (templates com dados, renderização em lote de milhares de vídeos).

A documentação tem mais de 1.200 páginas e cobre elementos, efeitos, transições, efeitos sonoros, legendas, fontes, correção de cor e formas. Para apps, há o Player (para embutir vídeos editáveis num site) e o Editor Starter.

Principais recursos

  • Vídeos como componentes React, com tudo que a web oferece (CSS, SVG, Canvas, WebGL, three.js via @remotion/three).
  • Remotion Studio para pré-visualizar e editar.
  • Renderização local, em servidor Node, no AWS Lambda, no Vercel ou no navegador.
  • Renderização em lote para vídeos personalizados com dados.
  • Legendas, transições, efeitos sonoros, fontes e correção de cor prontos.
  • Player para embutir vídeos em apps.
  • Skills oficiais para agentes (Claude Code, Codex, Cursor etc.).

Pré-requisitos

  • Node.js.

Instalação

npx create-video@latest            # cria um projeto novo
npx create-video@latest --skills   # cria o projeto já com as skills para agentes

Detalhes na página de instalação.

Comandos e uso

Dentro de um projeto Remotion:

npx remotion skills add                                     # instala as skills para agentes
npx remotion render src/index.ts <Composição> out/video.mp4   # renderiza uma composição

Com as skills instaladas, peça ao agente:

/remotion-create Make a promo video for a record store

Quando usar

  • Vídeos de produto, explicativos e motion graphics feitos por um agente de IA.
  • Vídeos personalizados em massa (um por cliente, por produto, por dado).
  • Apps de edição de vídeo ou geradores de vídeo como serviço.

Observações

  • Licença: não é open source tradicional. É grátis (inclusive para uso comercial) para pessoas físicas, empresas com fins lucrativos de até 3 funcionários, ONGs e para avaliação. Acima disso, exige a Company License paga. Também é proibido revender um derivado do Remotion. A licença muda um pouco na versão 5.0.
  • Renderizar vídeos longos ou em 2K/4K consome CPU, disco e tempo. Cada bundle copia a pasta public/ para a pasta temporária.
  • Relacionados no catálogo: as Remotion Skills são as skills oficiais; o HyperFrames foi inspirado no Remotion, mas usa HTML puro em vez de React, tem licença Apache 2.0 sem cobrança para empresas e traz /remotion-to-hyperframes para migrar projetos; o Claude Animated Shorts e o Anidoodle renderizam com o Remotion.
