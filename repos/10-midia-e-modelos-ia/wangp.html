O que é

O WanGP, de DeepBeepMeep, é um aplicativo "tudo em um" para modelos generativos open source de vídeo, imagem, áudio e texto para fala, acessível a quem tem GPU modesta ("GPU poor"). O repositório é um fork do Wan2.1 que evoluiu para um app próprio, com interface web completa para gerar, gerenciar e reutilizar resultados.

Ele otimiza memória e velocidade para rodar modelos grandes em placas com pouca VRAM, e baixa automaticamente os arquivos de modelo adequados à sua arquitetura de GPU.

Principais recursos

  • Vídeo: Wan 2.1/2.2, MiniMax H3, LTX-2/2.3/2.5, Hunyuan Video 1/1.5, LongCat, Kandinsky e outros.
  • Imagem: Krea 2, Qwen Image, Z-Image, Flux 1/2, HiDream e outros.
  • Áudio e TTS: Qwen3 TTS, Ace Step, Index TTS, Chatterbox, Stable Audio e outros.
  • Baixa exigência de VRAM: alguns modelos rodam com a partir de 6 GB; suporte a GTX 10XX, RTX 20XX em diante e GPUs AMD (RDNA 2, 3, 3.5 e 4).
  • Customização com LoRAs e vários formatos quantizados (int8, fp8, gguf, NV FP4, Nunchaku).
  • Modo headless para processar filas em lote e agente offline "Deepy" para tarefas auxiliares.
  • Workspaces para organizar mídias geradas por projeto.

Pré-requisitos

(Conforme docs/INSTALLATION.md.)

  • GPU NVIDIA (ou AMD suportada). Recomendação: Python 3.11.14 com PyTorch 2.10 e CUDA 13.0/13.1 para RTX 20XX a 50XX; Python 3.10.9 com PyTorch 2.7.1 e CUDA 12.8 para GTX 10XX.
  • O guia desaconselha PyTorch 2.8.0 e 2.9.0.
  • Conda (Anaconda ou Miniconda) para a instalação manual.
  • Windows ou Linux.

Instalação

Instalador de um clique (recomendado)

Os scripts automáticos instalam o WanGP e os kernels de aceleração disponíveis para a sua configuração (Triton, Sage, Flash, GGUF, Lightx2v, Nunchaku).

  • Windows: clique duas vezes em scripts\install.bat.
  • Linux/macOS: execute scripts/install.sh.

Escolha entre Auto Install (instala a pilha recomendada para a sua GPU) e Manual Install (escolhe o gerenciador de pacotes, o nome do ambiente e o modo). Para executar: scripts\run.bat (Windows) ou scripts/run.sh. Para atualizar: scripts\update.bat ou scripts/update.sh (Update atualiza o código; Upgrade permite atualizar PyTorch, Triton e Sage Attention).

Para passar argumentos ao iniciar, crie scripts/args.txt, por exemplo:

--advanced --open-browser

Instalação manual (RTX 20XX a 50XX)

Requer CUDA 13.1 instalado.

git clone https://github.com/deepbeepmeep/Wan2GP.git
cd Wan2GP
conda create -n wan2gp python=3.11.14
conda activate wan2gp
pip install torch==2.10.0 torchvision==0.25.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt

Para GTX 10XX, o guia usa Python 3.10.9, PyTorch 2.7.1 e CUDA 12.8 (veja docs/INSTALLATION.md).

Outras opções

  • Pinokio: o README recomenda os scripts da comunidade wan2gp ou wan2gp-amd (por Morpheus) em vez do instalador oficial do Pinokio.
  • Docker (Debian/Ubuntu): ./run-docker-cuda-deb.sh, que detecta a GPU, instala o runtime NVIDIA Docker se preciso, constrói a imagem e executa o app.

Comandos e uso

python wgp.py                       # inicia a interface web
python wgp.py --process my_queue.zip   # processa uma fila salva, sem abrir a UI

Fluxo típico: abra a interface no navegador, escolha o modelo, escreva o prompt, ajuste resolução e duração e gere. Para economizar VRAM, em Config > RAM/VRAM Management use um MMGP Optimized VRAM Allocator e ative Smart Memory Pinning; desativar a aceleração por GPU do navegador libera de 1 a 5 GB (use scripts/start-chrome-no-gpu.bat ou .sh).

Quando usar

  • Gerar vídeos e imagens com modelos open source em placas com pouca VRAM.
  • Testar vários modelos de vídeo, imagem e áudio em uma única interface.
  • Processar filas de geração em lote.

Observações

  • A licença é própria (WanGP Community License 2.0): em resumo, uso livre, inclusive em empresas, e saídas podem ser vendidas; leia o LICENSE.txt para as restrições.
  • Exige GPU; sem uma placa compatível a geração é inviável.
  • Os modelos baixados ocupam muito espaço em disco.
  • Após atualizar o PyTorch, pode ser preciso reinstalar Sage Attention, Triton e Flash Attention.
