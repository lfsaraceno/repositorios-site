O que é

O PixelFX é uma coleção de efeitos visuais de pixel art para jogos, mantida pela Patch (plataforma de jogos de navegador). Nenhum efeito é imagem: cada um é um pequeno arquivo JavaScript em src/fx/<categoria>/<nome>.js, que desenha o quadro a partir do tempo ou simula partículas, faíscas e luz a 120 Hz.

Os efeitos que envolvem um personagem são "atuados": ele se prepara, ataca, congela no impacto e se recupera, e um alvo reage ao golpe. Doze "moves" encadeiam os efeitos em ataques completos.

O método vem de um artigo de Hugo Duprez (Sprite Fusion) sobre fazer bons efeitos de pixel art com o Claude: o código é argila, confie nos olhos, alimente com referências. A skill incluída aplica esse processo: rascunhar, renderizar, olhar e refinar.

Principais recursos

  • 244 efeitos em 21 categorias: moves, fogo, explosões, água, gelo, raios, sci-fi, corpo a corpo, impactos, projéteis, surgimento e morte, arcano, sagrado, sombra, status, natureza, clima, UI, itens, transições e criaturas.
  • Uso direto em jogos de navegador (canvas, Phaser, PixiJS, Kaplay, three.js), sem dependências.
  • Sprite sheets em PNG transparente com JSON no estilo Aseprite, que os importadores de Godot, Unity e Phaser leem.
  • Paletas: qualquer efeito aceita uma rampa de cores, então o fogo pode queimar azul sem mexer no código.
  • Atuação: poses, preparação, congelamento no impacto, tremor de tela e reação do alvo, com os tempos como dados para você aplicar no seu personagem.
  • Esqueleto 3D do boneco, para pendurar seus próprios elementos.
  • Determinístico: todo número aleatório vem de uma semente, então o quadro 40 é sempre igual.
  • Ferramentas: criar efeito novo, renderizar (contact sheet, GIF, MP4), checar problemas e rodar a galeria localmente.
  • Skill do Claude Code para achar, usar, exportar e criar efeitos.

Pré-requisitos

  • Node.js para as ferramentas de linha de comando.
  • Claude Code, para a skill.

Instalação

Biblioteca:

npm i github:patch-gg/pixelfx

Ou copie src/core e os efeitos que quiser.

Skill do Claude Code:

/plugin marketplace add patch-gg/pixelfx
/plugin install pixelfx@pixelfx

Ou copie skills/pixelfx para ~/.claude/skills/.

Comandos e uso

No jogo:

import { createFrame, clearFrame, createFx, composite } from "pixelfx";
import * as frostNova from "pixelfx/fx/ice/frost-nova";

const frame = createFrame(320, 180);
const fx = createFx(frostNova, { x: 160, y: 140 });   // também: flip, angle, seed, palette, light
// a cada quadro: fx.update(dt); fx.draw(frame, "back"); ... composite(...)

Troque createFx por createAct para tocar o golpe inteiro, com personagem e alvo.

Ferramentas:

node tools/render.mjs ice/frost-nova --sheet     # sprite sheet + JSON para qualquer engine
node tools/sheets.mjs                            # exporta a biblioteca inteira para sheets/
node tools/render.mjs fire/torch --gif --opts '{"palette": ["#102","#215","#43a","#8cf","#cff","#fff"]}'   # recolorir
node tools/new.mjs arcane/my-spell               # novo efeito (--loop para efeito em loop)
node tools/render.mjs arcane/my-spell            # gera a contact sheet para olhar
node tools/check.mjs arcane/my-spell             # vazamentos, emendas, aleatoriedade sem semente, quadros lentos
node tools/act.mjs arcane/my-spell               # mostra a atuação em passos de 12 fps
node tools/serve.mjs                             # galeria local com os seus efeitos

Pedidos à skill (exemplos do README):

"Add a frost nova to my mage's ultimate."
"Make five takes on a coin pickup sparkle and show me the best two."
"Export the fire and explosions categories as sprite sheets for Godot."

Quando usar

  • Jogos 2D em pixel art, no navegador ou em engines como Godot e Unity.
  • Prototipar efeitos de magia, golpes e UI rapidamente.
  • Criar efeitos próprios com o Claude seguindo um processo de revisão visual.

Observações

  • Licença MIT para código e efeitos, inclusive uso comercial. A fonte Patch Pixel da galeria não é coberta (veja o NOTICE.md).
  • O README também divulga a Patch, plataforma onde dá para publicar jogos de navegador. Publicar lá exige o Patch Desktop aberto num PC Windows.
  • Existem portes não oficiais para Godot e Unity e uma tradução chinesa, mantidos por terceiros.
  • Relacionados no catálogo: o Teardown gera simuladores 3D interativos. As Blender Skills cobrem 3D no Blender.
