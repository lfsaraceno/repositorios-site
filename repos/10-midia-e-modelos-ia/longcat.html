LongCat (Meituan)

Família de modelos abertos da Meituan, com pesos liberados para uso comercial (MIT ou Apache-2.0): geração de vídeo longo e avatares falantes (LongCat-Video), imagem e edição com texto bem escrito (LongCat-Image), fala com clonagem de voz (LongCat-AudioDiT), modelos de linguagem gigantes para código e agentes (LongCat-2.0 e Flash) e um harness de pesquisa profunda.

O que é

A organização reúne os modelos da equipe LongCat, da Meituan, com pesos no Hugging Face e no ModelScope e relatório técnico de cada um. Os mais úteis fora da pesquisa:

Repositório O que faz Estrelas
LongCat-Video Vídeo de 13,6B parâmetros: texto para vídeo, imagem para vídeo e continuação de vídeo, em 720p a 30 fps, com vídeos de minutos sem perder a cor. Inclui o LongCat-Video-Avatar (1.6 em nov/2026), que anima uma pessoa a partir de um áudio, com sincronia labial ~9,8k
LongCat-Image Imagem de 6B parâmetros, chinês e inglês, foco em fotorrealismo e texto dentro da imagem. Tem versão de edição e uma Edit-Turbo 10 vezes mais rápida. Funciona no Diffusers e no ComfyUI ~730
LongCat-AudioDiT Texto para fala por difusão, com clonagem de voz a partir de uma amostra curta. Versões de 1B e 3,5B, avaliadas em chinês e inglês ~600
LongCat-2.0 Modelo de linguagem MoE de 1,6 trilhão de parâmetros (~48B ativos), contexto de 1M tokens, voltado a código e agentes; os autores citam integração com Claude Code, OpenClaw e Hermes ~575
LongCat-Flash-Chat Modelo MoE de 560B (~27B ativos) sem raciocínio, forte em tarefas de agente. Há variantes Thinking, Omni (áudio e vídeo em tempo real) e Prover (provas em Lean 4) ~1,4k
LongCat-Next Modelo multimodal nativo (texto, imagem e áudio como tokens) de 3B ativos ~495
LongCat-DeepResearch Harness multiagente de pesquisa profunda: planeja, pesquisa cada seção em separado e revisa o relatório. Só biblioteca padrão do Python; você liga o seu modelo e a sua busca ~30

O resto da organização são benchmarks (WBench, VitaBench, AMO-Bench, UNO-Bench e outros) e forks de bibliotecas de inferência.

Principais recursos

  • Pesos abertos sob MIT ou Apache-2.0, com uso comercial permitido.
  • Vídeo longo por continuação e geração interativa, com suporte a várias GPUs.
  • Avatar falante guiado por áudio, com um ou vários personagens.
  • Edição de imagem por instrução e texto renderizado com precisão.
  • Clonagem de voz zero-shot.
  • LLMs servidos por SGLang e vLLM.

Pré-requisitos

  • GPU NVIDIA com CUDA. Os modelos de mídia pedem muita memória de vídeo: o README do LongCat-Image fala em ~17 GB mesmo descarregando parte para a CPU.
  • Python 3.10 e conda (Video e Image).
  • Os LLMs (2.0, Flash) exigem clusters de várias GPUs.

Instalação

LongCat-Video:

git clone --single-branch --branch main https://github.com/meituan-longcat/LongCat-Video
cd LongCat-Video
conda create -n longcat-video python=3.10
conda activate longcat-video
pip install torch==2.6.0+cu124 torchvision==0.21.0+cu124 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
pip install ninja psutil packaging
pip install flash_attn==2.7.4.post1
pip install -r requirements.txt
pip install "huggingface_hub[cli]"
huggingface-cli download meituan-longcat/LongCat-Video --local-dir ./weights/LongCat-Video

Para o Avatar, instale também librosa, ffmpeg e o requirements_avatar.txt, e baixe meituan-longcat/LongCat-Video-Avatar-1.6.

LongCat-Image:

conda create -n longcat-image python=3.10
conda activate longcat-image
pip install -r infer_requirements.txt
pip install -U diffusers

LongCat-AudioDiT: pip install -r requirements.txt dentro do repositório.

Comandos e uso

# Vídeo a partir de texto (uma GPU)
torchrun run_demo_text_to_video.py --checkpoint_dir=./weights/LongCat-Video --enable_compile
# Imagem para vídeo e vídeo longo
torchrun run_demo_image_to_video.py --checkpoint_dir=./weights/LongCat-Video --enable_compile
torchrun run_demo_long_video.py --checkpoint_dir=./weights/LongCat-Video --enable_compile
# Interface web do LongCat-Video
streamlit run ./run_streamlit.py --server.fileWatcherType none --server.headless=false

# Fala e clonagem de voz (LongCat-AudioDiT)
python inference.py --text "Hello world" --output_audio output.wav --model_dir meituan-longcat/LongCat-AudioDiT-1B
python inference.py --text "Texto novo" --prompt_text "Transcrição da amostra" --prompt_audio amostra.wav \
  --output_audio output.wav --model_dir meituan-longcat/LongCat-AudioDiT-1B --guidance_method apg

No LongCat-Image, ponha entre aspas o texto que deve aparecer na imagem. Sem as aspas, o modelo não ativa a codificação por caractere e erra o texto.

Quando usar

  • Gerar vídeos longos ou avatares falantes com modelo aberto e liberado para uso comercial.
  • Criar imagens com texto legível, como posters e banners.
  • Clonar uma voz para narração em inglês ou chinês.
  • Estudar ou servir LLMs MoE de ponta, se você tem infraestrutura para isso.

Observações

  • Não é para GPU pequena. Nenhum dos modelos de mídia roda bem com pouca memória de vídeo; para máquinas modestas, o WanGP, feito para pouca VRAM, já roda o LongCat.
  • O AudioDiT foi avaliado só em chinês e inglês; o README não cita português. Para narração em PT-BR, o VoiceStudio e o Kokoro estão no catálogo.
  • Clonagem de voz e avatar a partir do áudio de outra pessoa só com autorização dela.
  • A licença dos modelos MIT não dá direito às marcas nem às patentes da Meituan.
  • Os modelos de linguagem também podem ser usados no site longcat.chat.
