O que é

O Whisper é um modelo Transformer treinado em muitas horas de áudio variado. Um só modelo faz quatro coisas:

  • reconhecimento de fala em vários idiomas;
  • tradução da fala para o inglês;
  • identificação do idioma falado;
  • detecção de voz.

Tudo roda na sua máquina, sem API e sem custo por minuto. É a referência de transcrição aberta, e muitas ferramentas usam o Whisper por baixo.

Principais recursos

  • Seis tamanhos de modelo, para escolher entre velocidade e precisão:

    Tamanho Parâmetros VRAM aprox. Velocidade relativa
    tiny 39 M ~1 GB ~10×
    base 74 M ~1 GB ~7×
    small 244 M ~2 GB ~4×
    medium 769 M ~5 GB ~2×
    large 1550 M ~10 GB 1×
    turbo 809 M ~6 GB ~8×

  • Versões só em inglês (.en), que são mais precisas para inglês nos modelos pequenos.

  • turbo é o padrão: versão otimizada do large-v3, bem mais rápida e quase tão precisa.

  • CLI e API Python, com acesso de baixo nível (detecção de idioma, decodificação).

Pré-requisitos

  • Python 3.8–3.11 e PyTorch.
  • ffmpeg instalado no sistema (veja o FFmpeg).
  • GPU NVIDIA recomendada para os modelos maiores. Em CPU funciona, mas é lento.
  • Pode precisar de Rust se o tiktoken não tiver wheel pronto para a sua plataforma.

Instalação

pip install -U openai-whisper

Instale o ffmpeg:

sudo apt update && sudo apt install ffmpeg   # Ubuntu/Debian
brew install ffmpeg                           # macOS
choco install ffmpeg                          # Windows (Chocolatey)
scoop install ffmpeg                          # Windows (Scoop)

Se a instalação falhar com No module named 'setuptools_rust', rode pip install setuptools-rust.

Comandos e uso

Linha de comando:

whisper audio.mp3 --model turbo                       # transcreve
whisper aula.mp3 --language Portuguese                # informa o idioma
whisper entrevista.wav --model medium --language Portuguese --task translate   # traduz para inglês
whisper --help

Python:

import whisper

model = whisper.load_model("turbo")
result = model.transcribe("audio.mp3")
print(result["text"])

Na primeira execução, o modelo escolhido é baixado automaticamente.

Quando usar

  • Transcrever reuniões, aulas, podcasts e entrevistas sem mandar o áudio para a nuvem.
  • Gerar legendas para vídeos (com o FFmpeg para embutir).
  • Transcrever o áudio baixado com o yt-dlp.
  • Substituir APIs pagas de transcrição. O SupoClip aceita o Whisper como alternativa local à AssemblyAI.

Observações

  • turbo não traduz. Mesmo com --task translate, ele devolve o texto no idioma original. Para traduzir, use medium ou large.
  • A qualidade varia por idioma. O português costuma ir bem nos modelos maiores. O artigo traz as taxas de erro por idioma.
  • Áudio de terceiros: transcrever gravações de pessoas envolve dados pessoais. Tenha base legal na LGPD e o consentimento de quem foi gravado.
  • Alucinações: em trechos de silêncio ou ruído, o modelo às vezes inventa texto. Revise transcrições importantes.
  • O repositório recebe poucas mudanças (última release: v20250625). Existem implementações mais rápidas mantidas por terceiros, como faster-whisper e whisper.cpp.
