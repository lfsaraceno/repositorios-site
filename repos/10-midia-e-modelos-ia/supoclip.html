SupoClip

Alternativa open source ao OpusClip: transforma vídeos longos (podcast, palestra, live) em cortes verticais 9:16 com IA, com rosto centralizado, legendas sincronizadas por palavra, título de gancho e nota de viralidade.

O que é

Você dá um vídeo longo ao SupoClip, e ele:

  1. transcreve o áudio;
  2. pede a um LLM os trechos com mais potencial de viralizar;
  3. dá uma nota a cada trecho;
  4. renderiza cada trecho como corte vertical, com o rosto de quem fala centralizado, legendas sincronizadas por palavra e um título de gancho no início.

É uma alternativa ao OpusClip: dá para hospedar no seu servidor, sem marca d'água e sem limite de uso além do seu hardware. Também existe a versão hospedada paga em supoclip.com e um app para iOS.

Principais recursos

  • Entradas: vídeo do YouTube, VOD ou clipe da Twitch e do Kick, ou upload de arquivo. Não aceita lives em andamento.
  • Seleção por IA: um LLM (Gemini, GPT, Claude, OpenRouter ou Ollama local) escolhe os melhores trechos. Cada corte recebe notas de gancho, engajamento, valor e compartilhamento.
  • Corte vertical inteligente: detecção de rosto mantém quem fala no centro do quadro 9:16.
  • Legendas sincronizadas por palavra (AssemblyAI). Há fontes próprias e modelos de legenda animada, como hormozi e mrbeast.
  • Título de gancho escrito pela IA e gravado nos primeiros segundos do corte.
  • B-roll e transições opcionais: imagens de banco do Pexels e efeitos de transição.
  • Editor embutido: cortar, dividir e juntar clipes. Exporta com presets para TikTok, Reels e Shorts.
  • Publicação direta: conecte suas contas do YouTube, TikTok e Instagram para postar ou agendar. As métricas de cada post voltam e ajustam a escolha dos próximos cortes.
  • Progresso em tempo real no navegador.
  • API REST com chaves de API e servidor MCP (pasta mcp/), para usar no Claude, no Cursor e em outros clientes MCP.

Pré-requisitos

  • Docker e Docker Compose.
  • Chave da AssemblyAI para a transcrição (obrigatória no fluxo padrão, e paga).
  • Uma chave de LLM (Google, OpenAI, Anthropic ou OpenRouter) ou um Ollama local.
  • Opcionais:
    • Pexels, para B-roll;
    • apps OAuth próprios do YouTube, do TikTok e do Instagram, para publicar;
    • proxy residencial ou Apify, para baixar do YouTube a partir de um servidor em datacenter.
  • Para rodar tudo local com Whisper e Ollama, veja o tutorial de self-hosting.

Instalação

git clone https://github.com/FujiwaraChoki/supoclip.git
cd supoclip

Crie um .env na raiz com as chaves:

ASSEMBLY_AI_API_KEY=your_assemblyai_api_key
LLM=google-gla:gemini-3-flash-preview
GOOGLE_API_KEY=your_google_api_key

O LLM segue o formato provedor:modelo, por exemplo openai:..., anthropic:..., openrouter:... ou ollama:gpt-oss:20b. Para o Ollama, defina também OLLAMA_BASE_URL.

docker-compose up -d        # sobe frontend, backend, PostgreSQL e Redis
docker-compose logs -f      # a primeira subida leva alguns minutos

Também há o script ./start.sh, que confere os pré-requisitos, gera as imagens e sobe tudo.

Endereços:

  • interface: http://localhost:3107. Crie uma conta e comece;
  • API: http://localhost:8000, com documentação interativa em /docs.

Instalações antigas sem FRONTEND_PORT continuam na porta 3001.

Comandos e uso

Na interface: cole o link do vídeo ou envie o arquivo, escolha o modelo de legenda e a duração, e acompanhe o processamento. Depois revise os cortes no editor e exporte ou publique.

docker-compose down          # para tudo
docker-compose up -d --build # reconstrói depois de mudar código ou .env
make test                    # testes (pytest, Vitest e Playwright)

MCP no Claude Code. O servidor MCP usa por padrão a API hospedada (https://api.supoclip.com). Para usar a sua instalação, adicione SUPOCLIP_API_URL=http://localhost:8000. A chave vem de Settings → API Keys.

claude mcp add supoclip -e SUPOCLIP_API_KEY=sk_your_key_here \
  -- uv --directory /absolute/path/to/supoclip/mcp run supoclip-mcp

Exemplo de prompt do README do MCP:

Use supoclip to make clips from https://youtu.be/… with the hormozi caption template, then wait for it and download the top clip.

A duração do corte é um destes valores:

  • auto (padrão, 15–60 s);
  • short (15–30 s);
  • medium (30–60 s);
  • long (1–2 min).

Quando usar

  • Gerar cortes para TikTok, Reels e Shorts a partir de podcasts, entrevistas, aulas e lives gravadas.
  • Ter o fluxo do OpusClip na própria máquina, sem marca d'água e sem pagar por minuto da plataforma (você ainda paga a transcrição e o LLM).
  • Automatizar cortes por API ou por um agente via MCP.
  • Comparação no catálogo: o OpenCut é um editor de vídeo manual, no estilo CapCut. O SupoClip escolhe e monta os cortes sozinho e tem só um editor simples para ajustes.

Observações

  • Licença AGPL-3.0: se você oferecer o SupoClip modificado como serviço na rede, precisa disponibilizar o código-fonte das modificações aos usuários. Quem contribui concede ao dono do projeto o direito de relicenciar o código, inclusive em licenças comerciais.
  • Custos externos: a AssemblyAI e as APIs de LLM são pagas por uso. A transcrição é cobrada uma vez por tarefa; o sistema guarda checkpoints para não pagar de novo ao repetir a geração.
  • Downloads do YouTube, Twitch e Kick:
    • baixar vídeos de terceiros pode violar os termos dessas plataformas e direitos autorais. Use em conteúdo seu ou com permissão;
    • num servidor em datacenter, o YouTube bloqueia o yt-dlp com a verificação "não sou robô". A documentação sugere proxy residencial (cerca de US$ 1/GB) ou Apify, ambos pagos.
  • Publicação nas redes: quem opera o servidor precisa registrar apps OAuth próprios no Google, no TikTok e na Meta. Os tokens dos usuários ficam criptografados com APP_SETTINGS_ENCRYPTION_KEY.
  • Produção:
    • troque o BETTER_AUTH_SECRET (o padrão é um segredo de desenvolvimento);
    • use senhas fortes no banco;
    • coloque HTTPS com proxy reverso;
    • SELF_HOST=true (padrão) desliga a cobrança com Stripe.
  • Analytics: o PostHog fica desligado se NEXT_PUBLIC_POSTHOG_KEY estiver vazio. Instalações self-hosted não enviam nada por padrão.
  • Limites padrão: vídeos de até 90 min (MAX_VIDEO_DURATION=5400), upload de até 4 GB, no máximo 10 cortes por tarefa e saída limitada a 1080p e 60 fps.
  • Projeto muito ativo, sem releases publicados no GitHub. O docker-compose down -v apaga todos os dados.
