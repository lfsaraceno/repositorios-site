FLUX.2

Código oficial de inferência dos modelos abertos FLUX.2 da Black Forest Labs, para gerar e editar imagens com uma ou várias imagens de referência. A família [klein] gera em menos de um segundo e o 4B roda em GPUs com ~8 GB de VRAM.

O que é

O FLUX.2 é a segunda geração dos modelos de imagem da Black Forest Labs (a empresa dos criadores do Stable Diffusion original). Todos os modelos fazem três coisas: gerar imagem a partir de texto, editar uma imagem e combinar várias imagens de referência numa nova.

Este repositório tem o código mínimo para rodar os modelos de pesos abertos no seu computador, com uma CLI interativa. Os pesos ficam no Hugging Face e são baixados automaticamente na primeira vez.

Há duas linhas:

  • FLUX.2 [klein] (jan/2026): a família mais rápida, com 4B e 9B parâmetros. As versões "destiladas" geram em 4 passos, em menos de um segundo em hardware moderno.
  • FLUX.2 [dev] (nov/2025): modelo de 32B parâmetros, a maior qualidade, mas exige GPU de data center (equivalente a H100) ou versões quantizadas.

Principais recursos

Modelo Uso indicado Licença
[klein] 4B Máxima velocidade, GPU de consumo (~8 GB, RTX 3090/4070 ou superior) Apache-2.0
[klein] 9B Alta qualidade em texto para imagem Não comercial
[klein] 9B KV Melhor relação qualidade/latência; edição com várias referências via cache KV Não comercial
[klein] 4B Base Fine-tuning em hardware limitado Apache-2.0
[klein] 9B Base Pesquisa e treino de LoRA Não comercial
[dev] Qualidade máxima, sem pressa Não comercial
  • Destilado x Base: destilado (4 passos) para produção e tempo real; Base (50 passos) para fine-tuning e LoRA.
  • Prompt upsampling no [dev]: reescreve o prompt com o Mistral Small local ou com qualquer modelo via OpenRouter.
  • Autoencoder novo, em Apache-2.0.
  • Marca d'água invisível opcional nas imagens geradas.

Pré-requisitos

  • GPU NVIDIA com CUDA. O código foi testado em GB200, CUDA 12.9 e Python 3.12.
  • [klein] 4B: cerca de 8 GB de VRAM.
  • [dev]: GPU equivalente a H100, ou as versões quantizadas do diffusers (o README mostra uma RTX 4090 com codificador de texto remoto).

Instalação

python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e . --extra-index-url https://download.pytorch.org/whl/cu129 --no-cache-dir

Opcionalmente, aponte para pesos já baixados com variáveis de ambiente (FLUX2_MODEL_PATH, AE_MODEL_PATH, KLEIN_4B_MODEL_PATH, KLEIN_9B_MODEL_PATH etc.). Sem elas, os pesos são baixados sozinhos.

Comandos e uso

PYTHONPATH=src python scripts/cli.py     # sessão interativa: gerar e editar imagens (uma ou várias referências)

Para rodar o [dev] em GPU de consumo com quantização, veja o guia do diffusers.

Quando usar

  • Gerar e editar imagens localmente, sem pagar por imagem.
  • Apps em tempo real ou fluxos interativos de criação ([klein] destilado).
  • Treinar LoRAs com o seu estilo ou produto ([klein] Base).

Observações

  • Licença varia por modelo: só os modelos 4B são Apache-2.0 e liberados para uso comercial. Os 9B e o [dev] usam a FLUX Non-Commercial License; para uso comercial, consulte a BFL.
  • Exige GPU NVIDIA: o código oficial é feito para CUDA. O README não documenta Windows; no Windows, a forma prática costuma ser por interfaces como o ComfyUI ou pelo diffusers.
  • Este repositório é só a inferência mínima. Não traz interface gráfica.
  • Relacionados no catálogo: o WanGP roda vários modelos de imagem e vídeo com interface e pouca VRAM. O Open Generative AI reúne geração de imagem e vídeo.
