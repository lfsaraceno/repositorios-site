Atenção: desde agosto de 2026 o Chatterbox é pesquisa aposentada e não recebe mais manutenção. O código segue público como arquivo, sob MIT, sem suporte nem atualizações. A Resemble AI passou a trabalhar com detecção de deepfakes.

O que é

O Chatterbox é uma família de modelos de síntese de voz (TTS) que roda localmente em Python. A partir de um trecho de áudio de referência de cerca de 10 segundos, ele clona a voz e gera fala com ela (clonagem zero-shot). Também há conversão de voz (voice conversion).

A família tem cinco opções: Turbo (350M, inglês, baixa latência para agentes de voz), Nano (110M, inglês, roda em CPU 3x mais rápido que o tempo real em 8 núcleos), Multilingual V3 (500M, 23 idiomas, incluindo português), o Single Language Pack (ajustes dedicados por idioma, incluindo português do Brasil) e o Chatterbox original (500M, inglês, com controles de exagero e CFG).

Todo áudio gerado leva uma marca d'água neural imperceptível (PerTh), que resiste a compressão MP3 e edição e pode ser detectada depois.

Principais recursos

  • Clonagem de voz zero-shot a partir de um clipe de referência.
  • Tags paralinguísticas no Turbo e no Nano: [cough], [laugh], [chuckle] e outras no meio do texto.
  • Multilingual V3 em 23 idiomas: árabe, dinamarquês, alemão, grego, inglês, espanhol, finlandês, francês, hebraico, hindi, italiano, japonês, coreano, malaio, holandês, norueguês, polonês, português, russo, sueco, suaíli, turco e chinês.
  • Single Language Pack: modelos dedicados para chinês, espanhol latino-americano, português do Brasil, espanhol da Espanha, português de Portugal e hindi.
  • Decoder destilado em um passo no Turbo e no Nano (antes eram 10), com menos VRAM.
  • Roda em cuda, cpu ou mps (Mac).
  • Marca d'água PerTh em todo áudio gerado, com script para extração.
  • Avaliações públicas comparando o Turbo com ElevenLabs Turbo v2.5, Cartesia Sonic 3 e VibeVoice 7B.

Pré-requisitos

  • Python 3.11 (testado no Debian 11; dependências fixadas no pyproject.toml).
  • GPU NVIDIA recomendada para Turbo e Multilingual; o Nano roda bem em CPU.
  • Os pesos são baixados do Hugging Face no primeiro uso.

Instalação

Via pip

pip install chatterbox-tts

A partir do código-fonte

conda create -yn chatterbox python=3.11
conda activate chatterbox

git clone https://github.com/resemble-ai/chatterbox.git
cd chatterbox
pip install -e .

Comandos e uso

Turbo (inglês, com tags)

import torchaudio as ta
from chatterbox.tts_turbo import ChatterboxTurboTTS

model = ChatterboxTurboTTS.from_pretrained(device="cuda")
text = "Hi there, Sarah here from MochaFone calling you back [chuckle], have you got one minute to chat about the billing issue?"
wav = model.generate(text, audio_prompt_path="your_10s_ref_clip.wav")  # exige clipe de referência
ta.save("test-turbo.wav", wav, model.sr)

Nano (CPU)

from chatterbox.tts_turbo import ChatterboxTurboTTS

model = ChatterboxTurboTTS.from_pretrained(device="cpu", nano=True)  # mesma classe do Turbo, com nano=True

Multilingual V3 (inclui português)

import torchaudio as ta
from chatterbox.mtl_tts import ChatterboxMultilingualTTS

multilingual_model = ChatterboxMultilingualTTS.from_pretrained(device="cuda", t3_model="v3")  # omita t3_model para usar o V2
wav = multilingual_model.generate("Bonjour, comment ça va?", language_id="fr")  # use language_id="pt" para português
ta.save("test-french.wav", wav, multilingual_model.sr)

Para clonar outra voz, passe audio_prompt_path="SEU_ARQUIVO.wav" no generate. Para português do Brasil com mais qualidade, use o modelo dedicado ResembleAI/Chatterbox-Multilingual-pt-br (demo).

Ajustes (Chatterbox original)

  • Padrão exaggeration=0.5, cfg_weight=0.5 funciona para a maioria dos casos.
  • Falante rápido: baixe cfg_weight para ~0.3.
  • Fala dramática: cfg_weight ~0.3 e exaggeration ~0.7 ou mais.
  • Se o clipe de referência estiver em outro idioma e o sotaque vazar, use cfg_weight=0.

Verificar a marca d'água

import perth
import librosa

watermarked_audio, sr = librosa.load("SEU_ARQUIVO.wav", sr=None)
watermarker = perth.PerthImplicitWatermarker()
print(watermarker.get_watermark(watermarked_audio, sample_rate=sr))  # 0.0 = sem marca, 1.0 = com marca

O repositório traz exemplos (example_tts.py, example_tts_turbo.py, example_tts_nano.py, example_vc.py, example_for_mac.py) e interfaces Gradio (gradio_tts_app.py, gradio_tts_turbo_app.py, gradio_vc_app.py, multilingual_app.py).

Quando usar

  • Gerar narração em português com voz clonada, localmente e sem pagar API.
  • Agentes de voz em inglês com baixa latência (Turbo) ou rodando em CPU/dispositivo (Nano).
  • Dublagem e localização de conteúdo em vários idiomas mantendo a mesma voz.

Observações

  • Projeto aposentado e sem manutenção (ago/2026): sem correções, suporte nem atualizações. O README ainda menciona um serviço pago de TTS, mas o aviso no topo diz que a Resemble AI não vende mais TTS.
  • Clonagem de voz e ética: só clone vozes com autorização da pessoa. Usar a voz de alguém sem consentimento pode configurar fraude e violar a LGPD (voz é dado biométrico, ou seja, dado pessoal sensível). A marca d'água PerTh permite identificar áudio gerado.
  • Para uma interface pronta e 100% local com clonagem, dublagem e transcrição, veja o VoiceStudio; para transcrever áudio, o Whisper.
