Kokoro

O que é

O Kokoro-82M é um modelo de síntese de voz pequeno, baseado na arquitetura StyleTTS 2. Por ter só 82M parâmetros, roda rápido até em CPU e custa pouco em servidor, mantendo uma qualidade que compete com modelos bem maiores. Os pesos são Apache-2.0, então pode ser usado em produção e em projetos comerciais.

Este repositório é a biblioteca de inferência (kokoro no PyPI). Ela converte o texto em fonemas com a biblioteca misaki (usando o espeak-ng como apoio) e gera áudio a 24 kHz, dividindo textos longos em trechos.

Principais recursos

  • Idiomas: inglês americano e britânico, espanhol, francês, hindi, italiano, japonês, mandarim e português do Brasil (lang_code='p').
  • Várias vozes prontas (a lista fica no Hugging Face), com controle de velocidade.
  • Textos longos: divide por um padrão (por exemplo, quebra de linha) e gera um áudio por trecho.
  • Pronúncia controlada: dá para indicar a pronúncia de uma palavra com fonemas entre colchetes, como [Kokoro](/kˈOkəɹO/).
  • Voz própria: aceita carregar um tensor de voz (.pt).
  • Aceleração no Mac Apple Silicon via MPS.

Pré-requisitos

  • Python e pip.
  • espeak-ng, usado para palavras fora do vocabulário em inglês e para alguns idiomas (incluindo português).
  • Japonês e mandarim pedem extras: pip install misaki[ja] / misaki[zh].

Instalação

pip install kokoro>=0.9.4 soundfile
apt-get -y install espeak-ng          # Linux

No Windows, instale o espeak-ng pelo instalador .msi:

  1. Abra as releases do espeak-ng.
  2. Baixe o .msi da versão mais recente (x64).
  3. Execute o instalador.

Se tiver problemas de dependência, o README traz um environment.yml para Conda.

Comandos e uso

from kokoro import KPipeline
import soundfile as sf

pipeline = KPipeline(lang_code='p')        # 'p' = português do Brasil; o código precisa bater com a voz
generator = pipeline("Olá, este é um teste do Kokoro.", voice='<voz>', speed=1, split_pattern=r'\n+')
for i, (gs, ps, audio) in enumerate(generator):
    sf.write(f'{i}.wav', audio, 24000)     # um arquivo .wav por trecho

O exemplo do README usa a voz em inglês af_heart com lang_code='a'. Os nomes das vozes de cada idioma estão no Hugging Face. No Mac, rode com PYTORCH_ENABLE_MPS_FALLBACK=1 para usar a GPU.

Quando usar

  • Narração de vídeos, audiolivros e conteúdos em lote, de graça e local.
  • Voz em apps e agentes onde latência e custo importam.
  • Servidores sem GPU, já que o modelo é leve.

Observações

  • Sem clonagem de voz: o Kokoro usa vozes prontas. Para clonar uma voz, veja o Chatterbox ou o VoiceStudio.
  • Pouca atividade: o último commit no repositório é de ago/2025.
  • A qualidade varia por idioma; o inglês é o mais treinado. Teste a voz em português antes de usar em produção.
  • Relacionados no catálogo: o VoiceStudio é uma alternativa completa ao ElevenLabs (clonagem, dublagem, 646 idiomas). O Podcastfy gera podcasts a partir de conteúdo e pode usar vozes de vários provedores.
