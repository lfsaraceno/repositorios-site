O que é

Brazilian Utils é uma organização que mantém bibliotecas para resolver problemas do dia a dia de quem desenvolve software para o Brasil: validar, formatar, interpretar e gerar documentos e dados como CPF, CNPJ, CEP, telefone, placa de veículo, PIS, título de eleitor e outros.

As duas versões principais são a de JavaScript/TypeScript (pacote npm @brazilian-utils/brazilian-utils) e a de Python (pacote PyPI brutils). A organização também tem versões em Go, Ruby, Rust, .NET (F#) e Erlang, com menos atividade.

O README aponta que as funções de validação verificam apenas o formato e os dígitos verificadores, e não a existência real do documento.

Principais recursos

  • JavaScript: zero dependências, tree-shakeable (cada util também é um subpath), escrito em TypeScript, com tipos incluídos; roda em Node.js, Bun, Deno e navegadores
  • JavaScript: utilitários para CPF, CNPJ, CEP, boleto, Pix, feriados e mais; documentação em inglês e português, com llms.txt para assistentes de IA
  • Python: CPF, CNPJ, CEP (inclusive consulta de endereço), telefone, e-mail, data, CNH, placa de carro (inclusive conversão para padrão Mercosul), PIS, processo jurídico, RENAVAM, título eleitoral, IBGE, feriados, valores monetários, natureza jurídica e passaporte
  • Funções por família: validar (is_valid_*), formatar (format_*), remover símbolos (remove_symbols_*) e gerar (generate_*)
  • Testes extensos; a versão JS cita testes de mutação

Pré-requisitos

  • JavaScript: Node.js ^20.19.0 || >=22.12.0, Bun mais recente, Deno 2.x ou navegador moderno
  • Python: pip e um Python compatível com o pacote brutils (veja as versões suportadas no PyPI)

Instalação

JavaScript / TypeScript

npm install @brazilian-utils/brazilian-utils

Também funciona com yarn add, pnpm add e bun add. Em uma tag <script> simples, o pacote expõe o global BrazilianUtils:

<script src="https://unpkg.com/@brazilian-utils/brazilian-utils/dist/brazilian-utils.umd.cjs"></script>

Python

pip install brutils

Comandos e uso

JavaScript:

import { isValidCpf } from "@brazilian-utils/brazilian-utils";

isValidCpf("1232454233345"); // false

Cada utilitário também existe como subpath, para carregamento sob demanda (exemplo do README: @brazilian-utils/brazilian-utils/get-cities).

Python:

>>> from brutils import is_valid_cpf
>>> is_valid_cpf('00011122233')
False
>>> from brutils import format_cpf
>>> format_cpf('82178537464')
'821.785.374-64'

Funções Python documentadas no README (exemplos): is_valid_cpf, format_cpf, remove_symbols_cpf, generate_cpf, is_valid_cnpj, format_cnpj, generate_cnpj, is_valid_cep, get_address_from_cep, is_valid_phone, format_phone, is_valid_license_plate, convert_license_plate_to_mercosul, is_holiday, format_currency, convert_real_to_text.

Quando usar

  • Validar e formatar CPF, CNPJ, CEP e telefone em formulários e APIs
  • Gerar dados de teste (CPF, CNPJ e placas fictícios) para ambientes de desenvolvimento
  • Consultar feriados e códigos IBGE em aplicações brasileiras
  • Evitar reimplementar o cálculo de dígitos verificadores

Observações

  • Validar um CPF ou CNPJ com a biblioteca não confirma que o documento existe nem pertence a alguém; apenas checa a estrutura.
  • Documentos gerados pelas funções generate_* são para testes; não os use para fraudar cadastros.
  • get_address_from_cep consulta serviços externos de CEP, o que exige internet e está sujeito a disponibilidade.
  • O repositório old-python está marcado como DEPRECATED; use brazilian-utils/python (pacote brutils).
  • CPF, CNPJ e CEP de pessoas são dados pessoais; trate-os conforme a LGPD.
