O que é

Lista no estilo "awesome" que compila blogs da comunidade de desenvolvimento brasileira. O critério principal é que o blog tenha, ou tenha tido, uma quantidade considerável de posts em português do Brasil.

As entradas ficam em ordem alfabética, agrupadas por letra inicial, no formato [Nome do Blog / Mantenedor](link) - Tema, tema, tema. É um bom ponto de partida para encontrar conteúdo em português sobre Front-End, Back-End, Cloud, dados, carreira e comunidade.

Principais recursos

  • Índice por letra (A a Z, sem algumas letras) para navegação rápida
  • Cada blog traz os temas cobertos, como Front-End, JavaScript, Python, C#/.NET, DevOps, Google Cloud, Machine Learning e carreira
  • Mistura blogs pessoais, comunidades e portais (por exemplo, C# Brasil e Curso em Vídeo)
  • Regras de contribuição claras: ordem alfabética, posts em português, link disponível e formato padrão
  • Licença MIT e contribuições por pull request

Pré-requisitos

  • Nenhum. Basta um navegador.

Instalação

Não se aplica: é uma lista de leitura.

Como navegar:

  1. Abra o README no GitHub e use o Índice para pular para a letra desejada.
  2. Use a busca do navegador (Ctrl+F) com o tema de interesse, como "DevOps", "Python" ou "Carreira".
  3. Abra o link do blog e, se tiver feed RSS, assine em um leitor de feeds.

Comandos e uso

Não há comandos. Para sugerir um blog, abra um pull request seguindo o formato do README:

- [Nome do Blog / Mantenedor](link) - Tema, tema, tema, tema

Regras de contribuição: manter a ordem alfabética, o blog precisa ter posts em português, o link deve estar disponível e a formatação deve seguir o modelo.

Quando usar

  • Encontrar fontes de estudo em português sobre desenvolvimento
  • Acompanhar a comunidade brasileira de tecnologia e seguir profissionais da área
  • Montar uma lista de leitura ou de feeds RSS
  • Descobrir autores para indicar a quem está começando na carreira

Observações

  • Alguns links podem estar quebrados ou ter blogs inativos; o README convida a abrir PR para corrigir.
  • Nem todo blog é atualizado com frequência; confira a data dos posts mais recentes.
