O que é

O Public APIs é um repositório curado por membros da comunidade e por pessoas da APILayer, com uma lista extensa de APIs públicas de vários domínios que você pode usar em seus próprios projetos, protótipos e estudos.

O README abre com uma divulgação da suíte comercial da APILayer (IPstack, Mediastack, Aviationstack e outras) e, em seguida, apresenta as tabelas por categoria. Cada linha informa nome com link, descrição curta e três atributos: tipo de autenticação, suporte a HTTPS e suporte a CORS.

Principais recursos

  • Cerca de 50 categorias, entre elas Animals, Anime, Authentication & Authorization, Blockchain, Books, Business, Cryptocurrency, Currency Exchange, Data Validation, Development, Email, Finance, Food & Drink, Geocoding, Government, Health, Machine Learning, Music, News, Open Data, Security, Sports & Fitness, Test Data, Transportation, Weather
  • Colunas de Auth (No, apiKey, OAuth), HTTPS e CORS para filtrar o que funciona no navegador
  • Índice no topo para navegar por categoria
  • Coleção Postman da APILayer
  • Servidor Discord da comunidade

Pré-requisitos

  • Nenhum para consultar a lista. Para usar uma API específica, valem os requisitos dela (chave de API, cadastro, limites de uso).

Instalação

Não se aplica: é uma lista de referência, não um pacote.

Como navegar:

  1. Abra o README e vá ao Index para escolher a categoria.
  2. Na tabela, filtre mentalmente pela coluna Auth: No significa que não exige chave.
  3. Se for chamar a API direto do navegador (front-end), prefira as que têm CORS = Yes.
  4. Confirme HTTPS = Yes antes de enviar qualquer dado sensível.
  5. Abra o link da API e leia a documentação oficial para limites e termos.

Comandos e uso

Não há CLI nem comandos. Formato das tabelas do README (exemplo real da categoria Animals):

| [Cat Facts](https://catfact.ninja/) | Random cat facts | No | Yes | Yes |

Leia assim: API "Cat Facts", sem autenticação (No), com HTTPS e com CORS. Os endpoints devem ser consultados na documentação de cada serviço. Para contribuir com uma API nova, siga as regras do repositório (veja o guia de contribuição) e mantenha a ordem alfabética da categoria.

Quando usar

  • Encontrar uma API gratuita para um protótipo, tutorial ou projeto de estudo
  • Buscar dados abertos (governo, clima, finanças, saúde) para visualizações
  • Gerar dados de teste e integrações de exemplo
  • Descobrir alternativas quando um serviço pago é desnecessário

Observações

  • A lista é mantida pela comunidade: APIs podem sair do ar, mudar de termos ou passar a exigir chave. Verifique o status antes de depender de uma.
  • O repositório tem conteúdo promocional da APILayer no topo.
  • Use APIs de terceiros com cuidado em produção: respeite limites de uso e termos, e não envie dados pessoais sem avaliar a política de privacidade (LGPD).
