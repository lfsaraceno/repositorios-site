O que é

Um acervo organizado em pastas, uma por produto, com os system prompts (as instruções que a empresa dá ao modelo antes da sua mensagem) e as definições de ferramentas internas de dezenas de assistentes e agentes de IA. Também tem uma pasta de prompts de projetos open source.

Serve como material de estudo para quem escreve prompts, skills ou agentes: mostra como produtos maduros estruturam papel, regras, formato de resposta e uso de ferramentas.

Principais recursos

Pastas atuais (nov/2026):

  • Agentes de código: Amp, Augment Code, CodeBuddy, Cursor, Devin AI, Junie, Kiro, Qoder, Replit, Same.dev, Trae, Traycer AI, VSCode Agent, Warp.dev, Windsurf, Xcode, Z.ai Code.
  • Construtores de apps: Emergent, Leap.new, Lovable, Orchids.app, v0.
  • Assistentes e outros: Anthropic, Google, Cluely, Comet Assistant, Dia, Manus, NotionAI, Perplexity, Poke.
  • Open Source prompts: prompts de projetos abertos.

Pré-requisitos

  • Nenhum: é só leitura.

Instalação

Não há instalação. Navegue pelo GitHub ou clone:

git clone https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools.git

Comandos e uso

  • Abra a pasta do produto e leia os arquivos de prompt e de ferramentas.
  • Compare como produtos diferentes resolvem o mesmo problema (ex.: regras de edição de arquivos no Cursor, Windsurf e Claude Code).
  • Use como inspiração para o seu CLAUDE.md, skills ou prompts de agentes.

Exemplo de pedido ao Claude Code depois de clonar:

Compare how Cursor Prompts and Windsurf instruct the model to edit files, and summarize the patterns I could reuse in my CLAUDE.md.

Quando usar

  • Aprender técnicas de prompt de produtos em produção.
  • Projetar agentes e skills próprios com estrutura testada.
  • Pesquisa sobre segurança de prompts (extração, injeção).

Observações

  • Origem e termos de uso: os prompts foram extraídos de produtos comerciais; reutilizar o texto literalmente em produto próprio pode violar direitos autorais e termos de uso dos fornecedores. Use como referência de estudo.
  • A licença GPL-3.0 cobre o repositório, mas não dá direitos sobre o conteúdo de terceiros.
  • Não há garantia de que os prompts estejam completos ou atualizados (última atualização indicada: 12/07/2026).
  • O README traz propaganda de um serviço do autor e pedidos de doação em cripto.
