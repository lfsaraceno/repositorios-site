O que é

É uma lista curada (awesome list) de vídeos que viralizaram, todos feitos pedindo ao Claude Opus 5.5 que escrevesse a animação como código: uma página HTML com Canvas, SVG, Three.js, GLSL, GSAP ou Web Audio, que depois é gravada como vídeo. Nenhum vídeo foi feito com modelo de geração de vídeo.

Cada item traz uma prévia, o link para o post original do criador (quase sempre no X/Twitter) e um arquivo com o prompt compartilhado. Quando o criador não publicou o prompt, ou publicou só uma parte, o arquivo avisa. São 703 prompts na pasta prompts/ e no data/videos.json; 418 deles têm um "remake" ao vivo no site Skillry, que mostra o original ao lado da recriação.

O README destaca 100 vídeos, separados por tipo, e é atualizado com frequência. A última atualização é de 12/out/2026.

Principais recursos

  • 703 prompts em Markdown (prompts/<autor>-<id>.md) e em JSON estruturado (data/videos.json).
  • Organização por tipo: motion graphics, explainers (vídeos explicativos), cenas 3D, jogos e interativos, além de uma seção com os prompts mais recentes.
  • Cada item indica as tecnologias usadas: Canvas, SVG, GSAP, Three.js, GLSL/WebGL, partículas, Web Audio, CSS.
  • Link para o post original de cada criador.
  • Galeria no Skillry com o original e a recriação lado a lado.

Pré-requisitos

  • Acesso ao Claude Opus 5.5: Claude Code, o app do Claude ou outro agente rodando esse modelo.
  • Um navegador para abrir o HTML gerado.
  • Opcional: um gravador de tela, para transformar a animação em vídeo.

Instalação

Não há o que instalar: é uma lista para consultar. Para ter os prompts no computador e pesquisar offline:

git clone https://github.com/yihui-dev/awesome-opus5-5-videos.git

Comandos e uso

O fluxo indicado no README:

  1. Abra um arquivo em prompts/ e copie o bloco que fica abaixo de Prompt.
  2. Cole no Claude Opus 5.5 (Claude Code, app do Claude ou outro agente).
  3. Peça para gerar o resultado como um único arquivo HTML e, se quiser um vídeo, grave a página.

Exemplo de pedido complementar, para colar depois do prompt copiado:

Render the result as a single self-contained HTML file.

Para buscar por tema ou tecnologia na cópia local:

grep -ril "three.js" prompts/ | head      # prompts que usam Three.js
grep -ril "gsap" prompts/ | head          # prompts com animação GSAP

Quando usar

  • Achar inspiração e prompts prontos para vídeos de lançamento, explicativos, intros de marca e motion graphics sem editor de vídeo.
  • Aprender como pedir animações complexas a um modelo: estrutura do prompt, nível de detalhe, tecnologias citadas.
  • Criar conteúdo para redes sociais, landing pages e apresentações, usando o HTML direto na página ou gravado como vídeo.
  • Combinar com o OpenCut para editar as gravações, ou com o VoiceStudio para narrar.

Observações

  • Direitos: a licença MIT vale para a lista. Cada vídeo e prompt pertence ao criador. Para uso comercial, use o prompt como ponto de partida e não copie o vídeo de outra pessoa.
  • Vários prompts são incompletos: alguns criadores só descreveram o resultado. O arquivo do prompt avisa quando é o caso.
  • Os prompts foram pensados para o Opus 5.5. Com outros modelos, o resultado pode ser bem diferente.
  • Os links do README apontam para o Skillry, um site de terceiros, com parâmetros de rastreamento (UTM). Os prompts em si ficam no próprio repositório.
  • Coleção recente (criada em set/2026) e em crescimento rápido.
