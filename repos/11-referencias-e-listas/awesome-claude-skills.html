O que é

Uma lista "awesome" de skills: pacotes de instruções (SKILL.md com nome e descrição, mais scripts e referências opcionais) que ensinam um agente a fazer uma classe de tarefas. O README explica o conceito: no início da sessão o agente vê só o nome e a descrição de cada skill (cerca de 100 tokens); o corpo completo carrega apenas quando a skill é relevante. Skills não são servidores MCP nem ferramentas: o MCP dá acesso, as ferramentas agem e as skills definem o fluxo.

Além de links para skills de terceiros e da Anthropic, o repositório guarda algumas skills próprias e o plugin connect-apps, que liga o Claude a mais de mil apps (e-mail, Slack, issues) pela plataforma da Composio, mantenedora da lista.

Principais recursos

Categorias da lista:

  • Document Processing: docx, pdf, pptx, xlsx (da Anthropic), conversor de Markdown para EPUB, pacote para times jurídicos.
  • Development & Code Tools: artifacts-builder, AWS, changelog a partir de commits, automação do Chrome e muitas outras.
  • Data & Analysis, Business & Marketing, Communication & Writing, Creative & Media.
  • Productivity & Organization, Collaboration & Project Management, Security & Systems, Assistive Technology.
  • App Automation via Composio: skills que agem em apps externos.
  • Guia de criação de skills com modelo de SKILL.md e boas práticas.

Pré-requisitos

  • Claude.ai, Claude Code ou outro agente com suporte a skills.
  • Para o connect-apps: chave gratuita da Composio.

Instalação

A lista em si não se instala; cada skill tem seu repositório e instruções. Formas gerais:

  • Claude.ai: ícone de skills (🧩) no chat → adicionar do marketplace ou enviar skill própria.
  • Claude Code: copie a pasta da skill para a pasta de skills pessoais (o README indica ~/.config/claude-code/skills/; na documentação oficial do Claude Code, skills pessoais ficam em ~/.claude/skills/) ou use o Skills CLI (npx skills add ...) quando a skill indicar.

Plugin connect-apps

claude --plugin-dir ./connect-apps-plugin

Depois, no Claude Code:

/connect-apps:setup

Cole a chave da Composio quando pedir e reinicie o claude.

Comandos e uso

  1. Navegue pela categoria que interessa no README.
  2. Abra o repositório da skill, leia o SKILL.md e instale conforme as instruções dela.
  3. A skill ativa sozinha quando a tarefa combina com a descrição.

Modelo mínimo para criar a sua:

---
name: my-skill-name
description: A clear description of what this skill does and when to use it.
---

# My Skill Name

## When to Use This Skill
## Instructions
## Examples

Quando usar

  • Descobrir skills prontas para uma área antes de escrever uma do zero.
  • Inspiração e exemplos para criar skills da empresa.

Observações

  • Qualidade variável: as skills são de autores diversos; leia o SKILL.md e os scripts antes de instalar, porque skills podem executar código.
  • A lista é mantida pela Composio e promove os produtos dela (MCP Gateway, connect-apps); o connect-apps envia ações para a plataforma da Composio.
  • O exemplo de uso via API no README usa um modelo antigo; consulte a documentação oficial de skills na API.
  • A ficha não lista as skills individualmente (são mais de mil).
  • Coleções relacionadas no catálogo: Anthropic Skills (oficial), Agentic Awesome Skills e Awesome Claude Code.
