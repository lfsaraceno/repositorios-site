O que é

O MCP é um protocolo aberto que permite a modelos de IA acessar recursos locais e remotos (arquivos, bancos de dados, APIs) por servidores padronizados. Esta é a maior lista de servidores MCP que você instala e roda por conta própria, de implementações oficiais a experimentais.

Cada item traz ícones de legenda: 🎖️ implementação oficial; linguagem (🐍 Python, 📇 TypeScript/JavaScript, 🏎️ Go, 🦀 Rust, #️⃣ C#, ☕ Java, 🌊 C/C++, 💎 Ruby); escopo (☁️ serviço na nuvem, 🏠 serviço local, 📟 embarcado); e sistema (🍎 macOS, 🪟 Windows, 🐧 Linux). Há também um diretório web sincronizado, com notas de qualidade por servidor.

Principais recursos

Algumas das categorias:

  • Aggregators (vários apps num servidor), Browser Automation, Cloud Platforms, Code Execution, Coding Agents, Command Line.
  • Communication, Databases, Data Platforms, Developer Tools, Data Science, Data Visualization.
  • File Systems, Finance & Fintech, Knowledge & Memory, Legal, Marketing, Monitoring.
  • Multimedia, OS Automation, Research, Search & Data Extraction, Security, Social Media.
  • Text-to-Speech, Speech-to-Text, Version Control, Workplace & Productivity e outras.
  • Seções de clientes MCP, servidores remotos (lista separada), tutoriais, frameworks e dicas.

Pré-requisitos

  • Um cliente MCP (Claude Code, Claude Desktop, Cursor, VS Code etc.).

Instalação

A lista não se instala. Escolha um servidor, abra o repositório dele e siga as instruções. No Claude Code, a forma geral é:

claude mcp add <nome> -- <comando do servidor>

Para servidores hospedados (acessados por URL), veja a lista irmã awesome-remote-mcp-servers.

Comandos e uso

  1. Procure a categoria (ou use o diretório em glama.ai/mcp/servers, que tem busca e nota de qualidade).
  2. Prefira itens com 🎖️ (oficiais) quando houver.
  3. Confira escopo (🏠 local x ☁️ nuvem) e compatibilidade com seu sistema.
  4. Leia o README e o código do servidor antes de configurar no cliente.

Quando usar

  • Encontrar um servidor MCP para integrar o Claude a um banco, API ou ferramenta específica.
  • Comparar opções para a mesma integração.

Observações

  • Segurança: servidores MCP rodam com suas credenciais e podem ler arquivos e executar ações; muitos são experimentais e de autores desconhecidos. Revise o código, dê permissões mínimas e desconfie de conteúdo externo (risco de prompt injection).
  • A lista é mantida em parceria com o Glama e tem anúncios.
  • O README tem mais de 500 KB; a ficha resume a estrutura, não os servidores individuais.
  • Servidores MCP já fichados no catálogo: Playwright MCP, Chrome DevTools MCP, GitHub MCP Server, Context7 e Serena.
