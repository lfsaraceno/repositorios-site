O que é

É um repositório que reúne a legislação brasileira em texto simples (Markdown), de graça e num lugar só. Os textos vêm de fontes oficiais (Planalto, Senado/normas.leg.br e os sistemas das Assembleias Legislativas) e são convertidos por scripts. Cada arquivo traz um cabeçalho com os dados da norma e o link para a fonte original.

A base inicial tem 323.849 normas: a Constituição Federal (texto vigente), 29 mil normas federais de 1822 até hoje e 294 mil estaduais e distritais. Coletas posteriores, como os 153 mil decretos federais, estão contabilizadas no PROGRESSO.md. O objetivo declarado é cobrir todo o ordenamento jurídico: decretos, atos das agências reguladoras (CONTRAN, ANVISA, Receita, CMN), jurisprudência vinculante, tratados e, por fim, as leis municipais.

Um detalhe curioso: o histórico do Git é uma linha do tempo da legislação. Cada norma da base inicial entrou num commit próprio, em ordem cronológica, "assinado" por quem a promulgou (5.414 autores).

Principais recursos

  • Constituição Federal vigente em constituicao.md.
  • Normas federais: leis ordinárias, complementares, delegadas e decretos-lei.
  • Normas de 25 estados e do DF, incluindo constituições estaduais e emendas. PR e RJ estão pendentes.
  • Pastas reservadas para atos de órgãos reguladores, jurisprudência, tratados e leis municipais, preenchidas conforme o progresso.
  • Cabeçalho YAML padronizado em cada arquivo: título, tipo, número, data, ementa, situação (em vigor ou revogada), publicação, URN e link da fonte.
  • Página de estatísticas (estatisticas.html): normas por estado, por década, por tema e quem mais assinou.
  • Scripts que baixam, convertem, corrigem o OCR e auditam o acervo, todos retomáveis e idempotentes.

Pré-requisitos

  • Para consultar: só o navegador (GitHub) ou um editor de texto.
  • Para reproduzir a coleta: macOS, Python 3 e pdftotext (poppler). O OCR usa o framework Vision do macOS; para imagens, o Tesseract 5 com o modelo português.

Instalação

Não precisa instalar nada para consultar: navegue pelas pastas no GitHub.

Para ter o acervo no computador:

git clone https://github.com/ctresb/leis.git

O repositório é muito grande (cerca de 4 GB e meio milhão de commits). Se não precisar do histórico, uma cópia rasa é bem mais leve. Este é um recurso geral do Git, não uma instrução do README:

git clone --depth 1 https://github.com/ctresb/leis.git

Comandos e uso

Estrutura das pastas:

constituicao.md                     Constituição Federal de 1988 (texto vigente)
federal/leis-ordinarias/AAAA/*.md   Leis federais, de 1822 a hoje
federal/leis-complementares/  federal/decretos-lei/  federal/leis-delegadas/
estaduais/UF/                       constituição, emendas, leis e decretos-lei por estado
reguladores/<orgao>/<tipo>/         atos infralegais (CONTRAN, ANVISA, RFB, CMN...)
jurisprudencia/<tribunal>/          súmulas e temas vinculantes
tratados/   municipais/UF/<municipio>/

Formato de cada arquivo (exemplo do Código Civil):

---
titulo: "Lei nº 10.406 de 10/01/2002"
tipo: "Lei Ordinária"
numero: "10406"
data: 2002-01-10
ementa: "Institui o Código Civil."
situacao: "Em vigor"
revogada: false
fonte: "https://normas.leg.br/?urn=urn:lex:br:federal:lei:2002-01-10;10406"
---
# Lei nº 10.406 de 10/01/2002
...

Buscar na cópia local (ex.: normas que citam "LGPD" ou "proteção de dados"):

grep -ril "proteção de dados" federal/ | head
grep -l "revogada: false" estaduais/SP/leis-ordinarias/2024/*.md   # leis de SP de 2024 ainda vigentes

Reproduzir ou atualizar a coleta (macOS):

python3 -I scripts/baixar_federal.py              # normas federais
python3 -I scripts/estados/sp.py                  # um estado por script
python3 -I scripts/estados/sapl.py baixar PB      # estados que usam o SAPL
python3 -I scripts/relatorio.py                   # atualiza o COBERTURA.md
python3 -I scripts/progresso.py                   # atualiza o PROGRESSO.md

Os scripts de manutenção rodam em modo simulação por padrão e só gravam com --aplicar.

Quando usar

  • Base de conhecimento (RAG) para agentes de IA jurídicos ou de atendimento: os arquivos já vêm em Markdown limpo, com metadados para filtrar por esfera, tipo, data e vigência. Combina com o RAG do Kiln ou com o Graphify.
  • Consultar o texto de uma lei estadual que é difícil de achar no site da Assembleia.
  • Pesquisa, análise de dados e jornalismo sobre legislação (volume por estado, por década, por tema).
  • Acompanhar mudanças: pelo histórico do Git dá para ver quando cada norma entrou no acervo.

Observações

  • Não substitui o Diário Oficial. Os textos são conversões automáticas, e parte veio de OCR de documentos escaneados, que pode ter erros. Confira sempre a fonte indicada no cabeçalho antes de citar ou usar juridicamente.

  • Lacunas conhecidas:

    • RJ não tem nada coletado.
    • PR foi destravado em 15/10/2026 e está sendo coletado.
    • AC só tem normas até 2009, e TO só a partir de 2020.
    • Há 5.569 leis antigas do RS sem texto digitalizado.
    • MG não atualiza mais pela fonte.

    O detalhe completo está no COBERTURA.md.

  • Nem todas as normas trazem a versão compilada (vigente). Algumas são o texto original publicado; veja o campo versao_texto.

  • O repositório é enorme. No Windows, com centenas de milhares de arquivos, o clone e as buscas podem ser lentos.

  • Projeto recente (criado em out/2026), em expansão acelerada. As contagens mudam a cada commit.
