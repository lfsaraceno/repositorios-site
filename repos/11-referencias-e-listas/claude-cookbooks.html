O que é

O Claude Cookbooks reúne código e guias para desenvolvedores que constroem com o Claude, com trechos prontos para copiar e integrar em seus projetos. Os exemplos são majoritariamente em Python, mas os conceitos podem ser adaptados para qualquer linguagem que consiga chamar a API do Claude.

O README funciona como um índice de receitas organizado por tema. Os links do índice ainda apontam para o caminho anterior do repositório (anthropics/anthropic-cookbook), então se algum link falhar, procure a receita pelo nome no repositório atual.

Principais recursos

  • Capabilities: classificação, RAG (geração aumentada por recuperação) e sumarização
  • Tool use e integração: agente de atendimento ao cliente, calculadora, consultas SQL
  • Integrações de terceiros: Pinecone, Wikipedia, páginas web e embeddings com Voyage AI
  • Multimodal: primeiros passos com imagens, boas práticas de visão, leitura de gráficos e extração de formulários
  • Técnicas avançadas: sub-agentes (Haiku com Opus), upload de PDFs, avaliações automatizadas, modo JSON, filtro de moderação, prompt caching e otimização de custos
  • Recursos adicionais com exemplos da AWS (Anthropic on AWS)

Pré-requisitos

  • Chave de API do Claude
  • Python para rodar os notebooks (Jupyter) na maioria dos exemplos
  • Para iniciantes, o README recomenda o curso "Claude API Fundamentals" da Anthropic

Instalação

O README não define um passo de instalação. Fluxo comum, sem comandos próprios do projeto: clone o repositório, abra o notebook desejado em um ambiente Jupyter e configure sua chave de API conforme o notebook indicar.

git clone https://github.com/anthropics/claude-cookbooks.git

Comandos e uso

Não há CLI. O uso é abrir a receita de interesse e executar as células. Exemplos de receitas citadas no índice:

tool_use/customer_service_agent.ipynb         # agente de atendimento com tool use
tool_use/calculator_tool.ipynb                # integração de calculadora
misc/prompt_caching.ipynb                     # técnicas de prompt caching
misc/building_evals.ipynb                     # avaliações automatizadas
misc/how_to_enable_json_mode.ipynb            # saída JSON consistente
cost_optimization/cost_optimization.ipynb     # checklist de otimização de custo

Os caminhos acima vêm do índice do README e podem ter mudado no repositório; confirme no GitHub.

Quando usar

  • Aprender padrões de uso da API do Claude com exemplos executáveis
  • Copiar trechos de tool use, RAG, visão ou prompt caching para o seu projeto
  • Montar avaliações e reduzir custos de um agente
  • Consultar boas práticas oficiais antes de implementar uma integração

Observações

  • O consumo de tokens nos notebooks é cobrado na sua conta da API.
  • Os links do README apontam para o nome antigo do repositório (anthropic-cookbook); confirme se o caminho ainda existe.
  • Verifique nomes de modelos nos notebooks, pois podem estar desatualizados frente à documentação atual.
