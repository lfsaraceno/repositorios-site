O que é

É uma lista no estilo "awesome" que reúne recursos para quem usa o Claude Code, o agente de código da Anthropic (o projeto declara não ter afiliação com a empresa). Cada entrada traz o nome, o autor, uma descrição curta e links, e muitas vêm acompanhadas de selos com data de criação e último commit.

O README destaca uma seleção recente de recursos e um "ticker" com projetos de destaque no GitHub. Não há instalação: o repositório é um catálogo para consulta e contribuição.

Principais recursos

Seções principais do índice do README:

  • Start Here: porta de entrada com guias e quick wins
  • From Anthropic: materiais oficiais (Agent Skills, Building Effective Agents etc.)
  • Documentation, Knowledge & Learning (com Obsidian e Data Visualization)

Pré-requisitos

  • Nenhum para consultar a lista. Para usar os itens listados, valem os requisitos de cada projeto (geralmente o Claude Code instalado).

Instalação

Não se aplica: é uma lista curada, não um pacote. Para navegar, abra o README no GitHub.

Como navegar:

  1. Comece por Start Here e From Anthropic.
  2. Use o Table of Contents do README para ir direto à categoria de interesse (por exemplo, Skills, Agent Orchestration, Status Lines).
  3. Em cada entrada, abra o link do projeto e leia o README dele antes de instalar.
  4. Confira os selos de data de criação e último commit para avaliar se o projeto está ativo.
  5. Use a busca do navegador (Ctrl+F) para localizar termos como "hooks", "MCP" ou "worktree".

Comandos e uso

Como é uma lista, o uso é de consulta. Exemplos de buscas úteis dentro do README:

Agent Orchestration      # frameworks de multiagentes e fluxos de trabalho
Skills                   # coleções de skills para o Claude Code
Status Lines             # barras de status para o terminal
Usage & Cost             # monitoramento de uso e custo
Memory & Context         # persistência de memória e contexto

Para sugerir um recurso, siga o guia de contribuição do repositório (abra uma issue ou PR conforme as instruções do README e do CONTRIBUTING).

Quando usar

  • Descobrir skills, plugins e agentes para turbinar o Claude Code
  • Comparar alternativas de orquestração, memória e observabilidade
  • Encontrar guias e leituras recomendadas, incluindo materiais da Anthropic
  • Acompanhar o que a comunidade está construindo ao redor do Claude Code

Observações

  • Itens são de terceiros e não foram necessariamente auditados. Leia o código e as permissões de skills, hooks e plugins antes de instalar, especialmente em projetos com credenciais.
  • A lista muda com frequência, e a curadoria atual privilegia recursos que não estavam na versão anterior.
  • Projeto independente, sem afiliação com a Anthropic.
