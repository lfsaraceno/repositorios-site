O que é

É uma coleção de Agent Skills para construir na Cloudflare: Workers, o Agents SDK e a plataforma de desenvolvedores em geral. As skills são contextuais e carregadas automaticamente: quando o seu pedido combina com os gatilhos de uma skill, o agente aplica a orientação atualizada daquele produto.

Onde há suporte, o repositório é instalado como plugin nativo, que traz tanto as skills quanto o servidor MCP principal da Cloudflare (acesso à API e à documentação atual via "Code Mode"). Agentes que só suportam o padrão Agent Skills podem instalar apenas as skills.

Principais recursos

  • Skill cloudflare para descobrir quais produtos servem à sua necessidade.
  • wrangler para deploy e gestão de Workers, KV, R2, D1, Vectorize, Queues e Workflows.
  • workers-best-practices e workers-profiling para código de produção e análise de CPU/alocações.
  • agents-sdk e durable-objects para agentes com estado, agendamento, RPC, MCP, e-mail e WebSockets.
  • sandbox-next, sandbox-stable e sandbox-migrate-to-next para o Cloudflare Sandbox.
  • web-perf (Core Web Vitals), turnstile-spin (verificação de bots) e cloudflare-email-service.
  • cloudflare-one e cloudflare-one-migrations para Zero Trust/SASE; nextjs-on-cloudflare para Next.js com vinext.
  • Servidor MCP cloudflare incluído no plugin.

Pré-requisitos

  • Um agente compatível: Claude Code, Codex, VS Code/GitHub Copilot, Cursor, OpenCode ou Pi.
  • Para npx skills, Node.js/npm.

Instalação

Claude Code

/plugin marketplace add cloudflare/skills
/plugin install cloudflare@cloudflare

Codex

codex plugin marketplace add cloudflare/skills
codex plugin add cloudflare@cloudflare

Inicie uma nova sessão depois.

VS Code / GitHub Copilot

  1. Habilite chat.plugins.enabled nas configurações do VS Code.
  2. Na paleta de comandos, execute Chat: Install Plugin From Source.
  3. Informe https://github.com/cloudflare/skills.

Cursor

Instale pelo Cursor Marketplace ou adicione manualmente em Settings > Rules > Add Rule > Remote Rule (Github) com cloudflare/skills.

Qualquer agente (npx skills)

npx skills add https://github.com/cloudflare/skills

Clonar e copiar

Clone o repositório e copie as pastas de skills para o diretório do seu agente, por exemplo ~/.claude/skills/ (Claude Code), ~/.cursor/skills/ (Cursor), ~/.config/opencode/skills/ (OpenCode), ~/.codex/skills/ (Codex) ou ~/.pi/agent/skills/ (Pi).

Comandos e uso

Não há comandos próprios: as skills são acionadas pelo contexto da conversa. Exemplos de pedidos:

Crie um Worker com D1 e faça o deploy usando wrangler
Audite os Core Web Vitals da minha página e liste recursos que bloqueiam a renderização
Monte um agente com estado usando o Agents SDK e Durable Objects

Quando usar

  • Desenvolver ou migrar aplicações para Workers, R2, D1, KV, Queues e Workflows.
  • Construir agentes de IA com estado na Cloudflare.
  • Configurar Cloudflare One (Access, Gateway, WARP, Tunnel) ou planejar migração de SASE/VPN.

Observações

  • O plugin inclui apenas o servidor MCP principal cloudflare; os servidores MCP específicos de cada produto não vêm junto.
  • A skill sandbox-next usa a prévia 1.0 (@cloudflare/sandbox@next) e é recomendada para projetos novos; a estável é sandbox-stable.
