Scroll Craft

Skill para Codex, Claude Code e outros agentes que constrói sites imersivos guiados pelo scroll, com padrão de design rígido (tipografia, contraste, uma "jogada" exclusiva por site) e verificação automática em navegador headless.

O que é

Uma skill de Nate Herk para fazer landing pages em que o scroll é a linha do tempo: vídeo avança quadro a quadro com a roda do mouse, seções ficam fixas enquanto o conteúdo muda, faixas deslizam para o lado, títulos se montam linha por linha e a cor de fundo muda ao longo da página.

O autor parte de um diagnóstico: página feita por IA costuma ser ou certinha e esquecível, ou cheia de efeito com texto ilegível. A skill trata interação e acabamento como um trabalho só. Ela traz o procedimento (SKILL.md), referências de design, um motor pronto (scrollcraft.js + .css) e scripts que encodam vídeo e verificam o resultado.

A versão 0.3.0 inclui o processo por trás de dez sites aprovados pelo autor (AI Automation Society, PERKFORM, Glaido, Serein, NOEMA e outros), usados como exemplos de trabalho.

Principais recursos

  • Oito "gramáticas" de página que se excluem: one-shot filmado, editorial em capítulos, superfície ao vivo, mundo contínuo, pôster tipográfico, galeria, palco dividido e cortes ritmados.
  • Jogada exclusiva obrigatória: cada site inventa uma interação que só existe nele.
  • Registro de impressões digitais: um site novo precisa diferir dos anteriores em pelo menos 4 de 6 dimensões (gramática, navegação, hero, forma dos atos, final, jogada). Assim você não repete a mesma página.
  • Curva de sensação e um pico só: antes de construir, define a emoção de cada ato. O pico recebe o orçamento de assets e o maior espaço de scroll.
  • Piso de design: no máximo duas famílias de fonte, medida de 45 a 75 caracteres, escala de espaçamento de 4px, cor com seis papéis e um acento, sem preto puro.
  • Lista de recusas: grades de cards idênticas, contadores 01 / 06, indicadores de scroll, texto com gradiente, travessões, estatísticas inventadas, dashboards falsos, gradiente roxo de IA.
  • Guia de marca manda: se você passar um brand kit, as regras dele vencem as da skill.
  • Verificação automática: um navegador headless percorre a página em cada posição de scroll e aponta scroll morto, texto que nunca chega à opacidade total, contraste medido linha a linha sobre o quadro mais claro e vídeos que não decodificaram. No fim gera uma folha de contato com capturas.
  • Assets próprios ou gerados: funciona só com suas fotos e vídeos, sem custo. Opcionalmente gera imagem e vídeo pela API do kie.ai (paga).

Pré-requisitos

  • Um agente que leia instruções, edite arquivos, rode comandos e inspecione navegador (Claude Code, Codex etc.).
  • Node 18 ou mais novo.
  • ffmpeg completo (versões reduzidas sem o filtro scale causam erros enganosos); a variável SCROLLCRAFT_FFMPEG aponta outro executável.
  • playwright-core instalado na pasta do build e o Chrome, para a verificação.
  • Opcional: KIE_AI_API_KEY (kie.ai), só para gerar imagens e vídeos.

Instalação

Plugin do Claude Code

/plugin marketplace add nateherkai/scroll-craft
/plugin install nateherk-design

Se aparecer Run /reload-plugins to activate., rode /reload-plugins.

Codex e outros agentes

Clone o repositório e copie a pasta inteira plugins/nateherk-design/skills/scroll-craft/ (com references, scripts, templates e engine):

  • Codex: para .agents/skills/ do projeto.
  • Outros agentes com skills: para o diretório de skills do agente.
  • Qualquer agente com acesso a arquivos: deixe o repositório no workspace e peça para ler o SKILL.md (prompt abaixo).

Primeira execução

Na raiz do repositório (ou na pasta scripts/ onde a skill foi instalada):

node plugins/nateherk-design/skills/scroll-craft/scripts/doctor.mjs                 # checa ffmpeg, muxer WebP e playwright-core
node plugins/nateherk-design/skills/scroll-craft/scripts/workspace.mjs --ensure     # cria o workspace e o registro

Comandos e uso

/nateherk-design:scroll-craft      # chama a skill direto no Claude Code

Ou descreva o site que quer. Para agentes sem suporte a skills:

Read plugins/nateherk-design/skills/scroll-craft/SKILL.md and use it to build
my website. Follow the referenced design and verification workflow.

Os builds ficam em <workspace>/builds/<nome>/ e o registro em <workspace>/FINGERPRINTS.md. O workspace é resolvido nesta ordem: variável SCROLLCRAFT_HOME, arquivo .scrollcraft.json ({ "workspace": "caminho" }) mais próximo, ou <raiz do projeto>/scrollcraft.

Para mexer na skill sem instalar: claude --plugin-dir ./plugins/nateherk-design.

Quando usar

  • Landing page de lançamento, produto, portfólio ou marca que precisa impressionar.
  • Quando os sites gerados por IA estão saindo todos iguais.
  • Quando você tem vídeo ou fotos do produto e quer uma página que "conte" o produto com o scroll.

Observações

  • Feito e testado no Windows: o autor só rodou no Windows; o Mac nunca foi testado. SCROLLCRAFT_FFMPEG e SCROLLCRAFT_CHROME corrigem a busca dos executáveis.
  • Geração de assets custa: pelo .env.example, a tabela do kie.ai é de 28 créditos por imagem e 160 por clipe de 5 s. Uma página de seis atos fica perto de 520 créditos, e um "mundo contínuo" de dez trechos perto de 2.000. Com assets próprios, custo zero.
  • Opinativa de propósito: recusa layouts e paletas comuns e questiona seu pico. Não serve para quem quer uma página padrão.
  • O motor não é editado por projeto: você personaliza com seis cores, duas fontes e HTML próprio, usando a variável CSS --sc-p que o motor publica.
  • Os exemplos aprovados descrevem comportamento de design; assets de clientes não vêm no repositório.
  • Relacionados no catálogo: as GSAP Skills ensinam a biblioteca de animação em si, para qualquer projeto. As WebGL Animation Skills cobrem 3D e shaders.
