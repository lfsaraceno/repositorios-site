O que é

O Claude SEO é um plugin open source de análise de SEO para o Claude Code. Ele executa 26 sub-skills e 19 agentes especialistas em paralelo, cobrindo SEO técnico, qualidade de conteúdo (E-E-A-T), marcação Schema.org, otimização para busca por IA (GEO/AEO), SEO local, e-commerce e SEO internacional.

Cada auditoria gera um plano de ação priorizado, com recomendações testáveis baseadas em orientações primárias do Google. Auditorias de site completo disparam até 17 agentes ao mesmo tempo. O foco declarado é ser "falseável, não promocional": cada recomendação traz a observação em que se apoia e como saber se falhou.

É voltado a agências de SEO com vários clientes, líderes de SEO in-house e consultores freelancers. O autor mantém também um espelho privado para membros de uma comunidade paga, mas a versão pública é MIT e não exige assinatura.

Principais recursos

  • /seo audit com sub-agentes paralelos e plano de ação priorizado, com nota de 0 a 100.
  • SEO técnico, conteúdo (E-E-A-T), schema (detectar, validar, gerar) e Core Web Vitals (LCP, INP, CLS).
  • GEO/AEO e prontidão para agentes (/seo agentic): llms.txt, Lighthouse Agentic Browsing, WebMCP.
  • SEO local e mapas, hreflang/i18n, e-commerce, backlinks, clusters semânticos, monitoramento de drift com SQLite.
  • Integração com APIs do Google (Search Console, PageSpeed, CrUX, GA4) e relatórios em PDF/Excel.
  • 9 extensões MCP opcionais para dados ao vivo (por exemplo SE Ranking, Profound, Bing Webmaster).
  • Modo local por padrão: sem chamadas a terceiros, além de buscar as URLs que você auditar.

Pré-requisitos

  • Claude Code CLI (a instalação por plugin pede Claude Code 1.0.33 ou superior).
  • Python 3.10+ (o README recomenda 3.11 ou mais novo, pois o 3.10 chega ao fim de vida em out/2026).
  • Opcional: Playwright Chromium (renderização de SPA e capturas de tela).
  • Opcional: credenciais da API do Google para dados reais de CWV, GSC e GA4.

Instalação

Plugin (recomendado)

/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup

O /seo setup cria um ambiente Python isolado nos dados persistentes do plugin e instala o Chromium do Playwright. Verifique a qualquer momento com /seo doctor.

Manual (Linux/macOS)

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
bash claude-seo/install.sh

Windows (PowerShell)

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1

O README recomenda git clone em vez de irm | iex, para você poder inspecionar o install.ps1 antes de rodar.

Comandos e uso

/seo audit https://example.com        # auditoria completa do site com sub-agentes paralelos
/seo page https://example.com/about   # análise profunda de uma página
/seo technical <url>                  # SEO técnico em 9 categorias
/seo content <url>                    # E-E-A-T e qualidade de conteúdo
/seo schema <url>                     # detectar, validar e gerar Schema.org
/seo geo <url>                        # otimização para AI Overviews e busca generativa
/seo agentic <url>                    # prontidão para agentes (llms.txt, WebMCP)
/seo sitemap generate                 # gerar sitemap com modelos por setor
/seo local <url>                      # SEO local (GBP, citações, avaliações)
/seo google [comando]                 # APIs do Google (GSC, PageSpeed, CrUX, GA4)
/seo doctor                           # checa o ambiente sem alterar o sistema

São 34 comandos /seo no total; a referência completa está em docs/COMMANDS.md.

Quando usar

  • Auditar rapidamente um site antes de uma proposta ou revisão executiva.
  • Otimizar conteúdo e schema para aparecer em respostas de IA (GEO).
  • Monitorar mudanças de SEO ao longo do tempo (drift) em vários clientes.

Observações

  • Cinco agentes de julgamento (seo-content, seo-geo, seo-sxo, seo-cluster, seo-drift) rodam em Opus desde a v2.3.1 e os outros treze em Sonnet: uma auditoria completa custa mais tokens.
  • Sem credenciais do Google, os Core Web Vitals são estimativas de laboratório e a indexação é inferida.
  • Algumas extensões dependem de contas e serviços de terceiros.
