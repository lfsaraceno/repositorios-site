O que é

O Claude SEO é um plugin open source de análise de SEO para o Claude Code. Ele tem 29 sub-skills e 20 agentes especialistas, cobrindo SEO técnico, qualidade de conteúdo (E-E-A-T), marcação Schema.org, otimização para busca por IA (GEO/AEO), SEO local, e-commerce e SEO internacional.

Uma auditoria completa leva de 10 a 15 minutos. Primeiro ele detecta o tipo de negócio (SaaS, local, e-commerce, publisher ou agência) e ajusta as checagens. Depois dispara até 17 agentes ao mesmo tempo e entrega um plano de ação priorizado. Cada recomendação diz em que se baseia, do que depende e como saber se funcionou. As checagens seguem a documentação do próprio Google, incluindo o guia de otimização para IA.

É voltado a agências de SEO com vários clientes, líderes de SEO in-house e consultores freelancers. O autor mantém também um espelho privado para membros de uma comunidade paga, mas a versão pública é MIT e não exige assinatura.

Principais recursos

  • /seo audit com sub-agentes paralelos e plano de ação priorizado, com nota de 0 a 100.
  • SEO técnico, conteúdo (E-E-A-T), schema (detectar, validar, gerar) e Core Web Vitals (LCP, INP, CLS).
  • GEO/AEO e prontidão para agentes (/seo agentic): llms.txt, Lighthouse Agentic Browsing, WebMCP.
  • SEO local e mapas, hreflang/i18n, e-commerce, backlinks, clusters semânticos, monitoramento de drift com SQLite.
  • Integração com APIs do Google (Search Console, PageSpeed, CrUX, GA4) e relatórios em PDF/Excel.
  • Estratégia e conteúdo: /seo plan por tipo de negócio, briefings de conteúdo, páginas comparativas com concorrentes, SEO programático, framework FLOW e otimização da experiência de busca (SXO).
  • Sites em JavaScript (Next.js, React, Vue) são abertos num navegador headless e auditados como o visitante vê.
  • Relatórios em Markdown, PDF e JSON, salvos na sua máquina.
  • Extensões opcionais para dados ao vivo e outros serviços: SE Ranking, Profound, Bing Webmaster com IndexNow, Unlighthouse, imagens com IA (Banana) e rastreamento de loja Shopify que você administra.

Pré-requisitos

  • Claude Code 1.0.33 ou superior.
  • Python 3.11 a 3.14 (o /seo setup cria um ambiente isolado).
  • O navegador headless é instalado pelo /seo setup.
  • Opcional: credenciais da API do Google para dados reais de CWV, GSC e GA4.

Instalação

Plugin (recomendado)

/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup

O /seo setup cria um ambiente Python isolado nos dados persistentes do plugin e instala o Chromium do Playwright. Verifique a qualquer momento com /seo doctor.

Manual (Linux/macOS)

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
bash claude-seo/install.sh

Windows (PowerShell)

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1

O README recomenda git clone em vez de irm | iex, para você poder inspecionar o install.ps1 antes de rodar.

Desinstalar

/plugin uninstall claude-seo@agricidaniel-claude-seo

Na instalação manual, rode bash claude-seo/uninstall.sh.

Comandos e uso

/seo audit https://example.com        # auditoria completa do site com sub-agentes paralelos
/seo page https://example.com/about   # análise profunda de uma página
/seo technical <url>                  # SEO técnico em 9 categorias
/seo content <url>                    # E-E-A-T e qualidade de conteúdo
/seo schema <url>                     # detectar, validar e gerar Schema.org
/seo geo <url>                        # otimização para AI Overviews e busca generativa
/seo agentic <url>                    # prontidão para agentes (llms.txt, WebMCP)
/seo sitemap generate                 # gerar sitemap com modelos por setor
/seo local <url>                      # SEO local (GBP, citações, avaliações)
/seo google [comando]                 # APIs do Google (GSC, PageSpeed, CrUX, GA4)
/seo google setup                     # conecta as APIs gratuitas do Google
/seo google report                    # transforma os relatórios em PDF
/seo plan saas                        # planejamento (saas, local, ecommerce, publisher, agency)
/seo content-brief <tema>             # briefing: palavras-chave, estrutura, links internos
/seo cluster <palavra-chave>          # agrupamento semântico pela SERP
/seo drift baseline <url>             # tira uma foto do SEO; depois compare / history
/seo backlinks <url>                  # perfil de backlinks (Moz, Bing, Common Crawl)
/seo ecommerce <url>                  # SEO de e-commerce e marketplaces
/seo doctor                           # checa o ambiente sem alterar o sistema

São 30 comandos principais e de extensões, mais alguns extras; a referência completa está em docs/COMMANDS.md. Digite /seo no Claude Code para ver todos.

Quando usar

  • Auditar rapidamente um site antes de uma proposta ou revisão executiva.
  • Otimizar conteúdo e schema para aparecer em respostas de IA (GEO).
  • Monitorar mudanças de SEO ao longo do tempo (drift) em vários clientes.

Observações

  • Cinco agentes de julgamento (seo-content, seo-geo, seo-sxo, seo-cluster, seo-drift) rodam em Opus e os outros em Sonnet. Por isso um /seo audit completo gasta bem mais do seu plano do Claude que a análise de uma página. O modelo de cada agente pode ser trocado no arquivo dele em agents/.
  • Dados: as páginas analisadas vão para o Claude, como qualquer coisa no Claude Code. Nenhum serviço de SEO de terceiros recebe os dados, a menos que você conecte uma extensão ou API. Algumas checagens leem fontes públicas (Wikipedia, Reddit, Common Crawl). Detalhes no PRIVACY.md.
  • Sem credenciais do Google, os Core Web Vitals são estimativas de laboratório e a indexação é inferida. Páginas que só carregam o conteúdo depois de rolar ou clicar podem dar resultados imprecisos.
  • Algumas extensões dependem de contas pagas de terceiros.
  • Duas versões: a pública é MIT e gratuita. Membros da comunidade paga AI Marketing Hub Pro têm uma versão privada com acesso antecipado a novidades.
  • Relacionadas no catálogo: as Marketing Skills também têm seo-audit e ai-seo, dentro de um pacote de marketing mais amplo. O Claude SEO é mais profundo só em SEO.
