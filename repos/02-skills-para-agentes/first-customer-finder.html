First Customer Finder

Skill para Claude Code, claude.ai e Cowork que encontra possíveis primeiros clientes de uma startup a partir de sinais públicos verificados, com perfil de cliente ideal, pontuação, rascunhos de abordagem e relatório HTML.

O que é

Você passa a URL da sua startup para o Claude e recebe uma lista curta de possíveis primeiros clientes. Cada um vem ligado a um sinal público real (uma discussão, um post, uma reclamação) que você pode abrir e ler, com pontuação, canal sugerido, rascunho de mensagem e um relatório HTML.

A skill só pesquisa. Ela define o perfil de cliente ideal (ICP), procura em discussões públicas sinais de dor e de intenção de compra, verifica cada fonte na página original e rascunha aberturas de mensagem. Nunca envia mensagem nenhuma.

É uma reescrita independente para Claude da skill original para Codex, a codex-first-customer-finder-skill de Francesco Mistero (~1,3k estrelas). A versão do Claude acrescenta uma etapa de verificação de fontes antes da qualificação, pesquisa em subagentes paralelos e um novo design de relatório.

Principais recursos

  • Análise de ICP primário e adjacente, com critérios de exclusão.
  • Pesquisa paralela em cinco frentes: demanda explícita, dor, gambiarras (workarounds), troca de fornecedor e momento.
  • Verificação de fontes: todo prospect tem link para a página pública original.
  • Pontuação de 0 a 100 ponderada por dor, encaixe, momento, alcance e qualidade da evidência.
  • Rascunhos de abordagem personalizados, baseados só na fonte citada.
  • Plano de validação manual de sete dias.
  • Relatório HTML independente (tema claro/escuro, pronto para impressão).

Pré-requisitos

  • Claude Code, claude.ai ou Cowork (app desktop do Claude).
  • Node.js para os instaladores via npx; Python para o gerador de relatório (só biblioteca padrão).

Instalação

Skills CLI (mais rápido)

npx skills add carolinacherry/claude-first-customer-finder-skill

Instalador npm

Copia para ~/.claude/skills (respeita CLAUDE_CONFIG_DIR; use --skills-dir para outro destino):

npx --yes claude-first-customer-finder-skill

Plugin do Claude Code

/plugin marketplace add carolinacherry/claude-first-customer-finder-skill
/plugin install first-customer-finder@carolinacherry

App desktop do Claude / Cowork

Baixe first-customer-finder.zip em Releases e vá em Settings → Skills → Add → Upload a skill.

Manual

git clone https://github.com/carolinacherry/claude-first-customer-finder-skill.git
node claude-first-customer-finder-skill/scripts/install.js

Comandos e uso

Abra uma sessão nova e peça em linguagem natural:

Find ten potential first customers for https://yourstartup.com

Modos (basta mencionar no pedido, ex.: "run it in b2b mode"):

  • quick: 5 prospects.
  • standard: 10 prospects (padrão).
  • deep: 20 prospects e mapa de padrões de dor.
  • design-partners, b2b, community: focos específicos.

Para encurtar no meio da execução:

quick mode is fine — wrap up with what's verified

No Claude Code, o relatório HTML é salvo em outputs/; no Cowork e no claude.ai, vem como download.

Tempo: uma execução standard leva uns 10 a 15 minutos no Claude Code e 20 a 30 minutos ou mais no Cowork, que pede permissão de acesso a cada domínio novo. No Cowork, escolha "Allow all for this website" para cada domínio perguntar só uma vez.

Quando usar

  • Validar uma ideia ou um produto novo buscando quem já reclama publicamente do problema que você resolve.
  • Montar uma lista inicial de design partners ou clientes B2B com evidência, antes de sair prospectando.
  • Preparar mensagens de abordagem baseadas em algo que a pessoa realmente escreveu.

Observações

  • Regras de privacidade embutidas: só informação profissional pública e compartilhada de propósito; nada atrás de login ou paywall, nada de data brokers, bases de contatos raspadas ou busca de contato pessoal; nada de segmentação por características sensíveis.
  • Os prospects são rotulados como "possíveis clientes com base em sinais públicos", nunca como interessados. Antes de abordar alguém no Brasil, avalie a base legal pela LGPD (veja LGPD Skills).
  • Existem outros repositórios com o mesmo nome (RAAAAAGEEEEE/ e Shodev7/claude-first-customer-finder-skill), ports menores da mesma skill original. Esta ficha documenta o da carolinacherry, que tem mais estrelas.
  • Projeto pequeno e recente.
