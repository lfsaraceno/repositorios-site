O que é

Uma biblioteca de skills de marketing criada por Corey Haines, voltada para fundadores e profissionais de marketing técnicos que usam agentes de código. Cada skill é um arquivo Markdown com frameworks e boas práticas de uma área (conversão, copy, SEO, anúncios etc.), e o agente aciona a skill certa quando você pede uma tarefa daquele tipo.

A base de tudo é a skill product-marketing: ela cria o arquivo .agents/product-marketing.md com produto, público e posicionamento, e todas as outras skills leem esse arquivo antes de agir. As skills também se referenciam entre si (por exemplo, copywriting ↔ cro ↔ ab-testing).

Segue o padrão Agent Skills, então funciona em Claude Code, OpenAI Codex, Cursor, Windsurf e outros agentes compatíveis. Também há ZIPs prontos para o Claude na web e para o Perplexity Computer.

Principais recursos

  • Conversão: cro (páginas e formulários), signup, onboarding, popups, paywalls.
  • Conteúdo e copy: content-strategy (planejamento de conteúdo), copywriting, copy-editing, cold-email, emails (sequências automáticas), social, image, video, sms (inclui WhatsApp).
  • SEO e descoberta: seo-audit, ai-seo (ser citado no ChatGPT, Perplexity e AI Overviews), link-building, programmatic-seo, site-architecture, schema, competitors (páginas "X vs Y"), aso (lojas de apps).
  • Mídia paga e medição: ads (Google, Meta, LinkedIn), ad-creative, analytics, conversion-tracking, attribution, ab-testing.
  • Crescimento e retenção: referrals, free-tools, lead-magnets, co-marketing, community-marketing, influencer-marketing, churn-prevention, events, public-relations.
  • Estratégia e vendas: pricing, offers, launch, marketing-plan, marketing-ideas (140 ideias para SaaS), marketing-psychology, marketing-council, marketing-loops, reverse-engineer-marketing, customer-research, competitor-profiling, prospecting, revops, sales-enablement, directory-submissions.
  • Conexão com contas de marketing: um fluxo guiado para dar ao agente credenciais com escopo e leitura somente.

Pré-requisitos

  • Um agente compatível com Agent Skills (Claude Code, Codex, Cursor, Windsurf etc.).
  • Node (npx) para a instalação via CLI.

Instalação

CLI (recomendado)

npx skills add coreyhaines31/marketingskills                       # instala todas
npx skills add coreyhaines31/marketingskills --skill cro copywriting   # só algumas
npx skills add coreyhaines31/marketingskills --list                # lista as disponíveis

Se for o próprio agente rodando o comando, passe o agente explicitamente; senão a CLI pode instalar só em .agents/skills/, que o Claude Code não lê:

npx skills add coreyhaines31/marketingskills -a claude-code

Plugin do Claude Code

/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills

Fora de uma sessão interativa:

claude plugin marketplace add coreyhaines31/marketingskills
claude plugin install marketing-skills@marketingskills

Codex

codex plugin marketplace add coreyhaines31/marketingskills   # depois, dentro do Codex: /plugins
codex plugin marketplace upgrade                             # atualiza

Outras formas

  • Clonar e copiar: git clone https://github.com/coreyhaines31/marketingskills.git e cp -r marketingskills/skills/* .agents/skills/.
  • Submódulo git ou fork para customizar.
  • SkillKit: npx skillkit install coreyhaines31/marketingskills.
  • Claude na web: baixe <nome>-claude-web.zip nas Releases e envie em Customize → Skills.
  • Perplexity Computer: baixe <nome>-perplexity.zip nas Releases.

Comandos e uso

Peça a tarefa em linguagem natural e o agente escolhe a skill:

"Help me optimize this landing page for conversions"   → cro
"Write homepage copy for my SaaS"                      → copywriting
"Set up GA4 tracking for signups"                      → analytics
"Create a 5-email welcome sequence"                    → emails

Ou chame a skill direto:

/product-marketing   # cria o contexto do produto (rode primeiro)
/cro
/emails
/seo-audit

Quando usar

  • Revisar landing pages, cadastro e onboarding para aumentar conversão.
  • Escrever copy, e-mails, cold emails e posts com frameworks consistentes.
  • Auditar SEO, preparar o site para buscas por IA e criar páginas comparativas.
  • Planejar lançamento, preço, anúncios e medição de um produto SaaS.

Observações

  • Atualização da v1 para a v2.0: 17 skills mudaram de nome e page-cro + form-cro viraram cro. As pastas antigas ficam junto das novas e precisam ser removidas à mão; o arquivo de contexto foi de .claude/product-marketing-context.md para .agents/product-marketing.md. O README traz o mapa completo.
  • Parceiros pagos: o projeto é financiado por "Verified Partners" (ferramentas de tracking, SEO, webinars), listados no README com guias de integração. O autor afirma que eles não influenciam as recomendações das skills.
  • Credenciais: ao conectar contas de marketing, use o fluxo com escopo e somente leitura do tools/SETUP.md.
  • Foco em SaaS e mercado norte-americano; adapte exemplos e regras (como SMS/WhatsApp e LGPD) para o Brasil.
  • Relacionados no catálogo: a Founder Skill valida um negócio antes do lançamento (conselho, painel de compradores, CFO); o OpenSEO fornece dados de SEO reais via MCP, que estas skills podem usar.
