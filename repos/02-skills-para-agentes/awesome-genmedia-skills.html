O que é

Uma biblioteca de skills que ensina o agente a chamar a API da each::labs. São três níveis:

  • 14 skills básicas: gerar e editar imagem, aumentar resolução, remover fundo, trocar rosto, gerar e editar vídeo, música com e sem voz, letra, voz, texto para fala, transcrição e efeitos sonoros.
  • 117 skills por caso de uso, em 20 áreas: retratos, design (logos, thumbnails, posters), redes sociais, e-commerce, marketing, jogos, moda, imóveis, fotografia, educação e outras.
  • 431 skills de modelo, uma para cada modelo da plataforma.

As skills por caso de uso chamam o each::sense, um endpoint compatível com a OpenAI que escolhe o modelo sozinho. As de modelo usam a API de predição.

Principais recursos

  • Imagem: Flux 2, Nano Banana Pro, Imagen 4, Seedream, GPT Image, Ideogram e outros.
  • Vídeo: Veo 3, Kling, Sora 2, Pixverse, Wan, Runway, Seedance e Hailuo.
  • Áudio: ElevenLabs, Mureka (músicas), Stable Audio, Google TTS e Whisper.
  • Avatares falantes e lip sync (OmniHuman, Kling Avatar, Sync).
  • Edição: upscale, legenda automática, tradução de vídeo e junção de áudio e vídeo.

Pré-requisitos

  • Conta na each::labs e uma chave de API (o uso é cobrado).
  • Um agente que aceite skills.

Instalação

npx skills add awesome-genmedia/skills@image-generation
npx skills add awesome-genmedia/skills@flux-2-max

O README também cita /plugin install awesome-genmedia dentro do Claude Code.

Depois, defina a chave no ambiente (nunca num arquivo do projeto):

export EACHLABS_API_KEY="sua-chave"

Comandos e uso

Peça ao agente em linguagem natural, por exemplo "gere um logo para uma marca de café". Exemplo direto na API de predição:

curl -X POST https://api.eachlabs.ai/v1/prediction \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $EACHLABS_API_KEY" \
  -d '{"model": "flux-2-max", "version": "0.0.1", "input": {"prompt": "A professional headshot, studio lighting", "aspect_ratio": "1:1"}}'

Quando usar

  • Dar ao agente acesso a muitos modelos de imagem, vídeo e áudio com uma única conta e uma única chave.
  • Testar vários modelos para o mesmo pedido sem integrar cada fornecedor.

Observações

  • É material de um fornecedor: todas as skills dependem da API paga da each::labs. Confira os preços antes de gerar vídeo em lote.
  • O repositório tem pouca atividade: o último commit é de mar/2026.
  • Há skills de troca de rosto e uma categoria de conteúdo adulto. Use troca de rosto só com autorização das pessoas envolvidas.
  • Relacionados no catálogo: o Open Generative AI e o Open Higgsfield são estúdios open source com muitos modelos.
