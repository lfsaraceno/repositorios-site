O que é

Um marketplace de plugins escrito uma vez, em Markdown no formato de plugin do Claude Code, e convertido por adaptadores para o formato de cada ferramenta de agente (Codex, Cursor, OpenCode, Antigravity, Copilot, Pi). O CI regenera e valida tudo para cada ferramenta.

Cada plugin agrupa subagentes especialistas, skills (conhecimento carregado quando relevante) e comandos (fluxos nomeados, como scaffolding ou varredura de segurança). Por exemplo, python-development traz 3 agentes, 16 skills e um comando de scaffolding. Você instala só os plugins que usa.

Principais recursos

  • 94 plugins (92 locais e 2 externos), 202 agentes, 185 skills e 105 comandos.
  • Plugins de destaque: python-development (Django, FastAPI, testes, empacotamento), javascript-typescript, developer-essentials (code review, debug, Git, testes) e security-scanning.
  • Agentes com alias de modelo (opus, sonnet, haiku, fable, inherit) mapeados para os modelos de cada ferramenta.
  • Instalação de skills avulsas via gh skill ou npx skills, sem os agentes e comandos.
  • plugin-eval: checagem estática de skills sem chamar modelo (camadas de juiz LLM são experimentais).

Pré-requisitos

  • Claude Code, Codex CLI ou Cursor (via marketplace) ou OpenCode, Antigravity CLI, Copilot ou Pi (via clone).
  • Para instalar via clone: uv e Python 3.12+.
  • Para skills avulsas: GitHub CLI 2.90+ (gh skill) ou Node.js (npx skills).

Instalação

Claude Code

/plugin marketplace add wshobson/agents
/plugin install python-development@claude-code-workflows

Codex CLI

codex plugin marketplace add wshobson/agents
codex plugin add python-development@claude-code-workflows

Só uma skill

gh skill install wshobson/agents python-testing-patterns
npx skills add wshobson/agents --skill python-testing-patterns

OpenCode, Antigravity CLI, Copilot e Pi

gh repo clone wshobson/agents ~/agents
cd ~/agents
make install-opencode      # ou install-antigravity, install-copilot, install-pi

No Pi, os agentes exigem a extensão subagent.

Comandos e uso

Depois de instalar um plugin, peça ao Claude para usar os agentes dele na tarefa, ou rode os comandos com o prefixo do plugin:

/python-development:python-scaffold Create a FastAPI service with tests

Para quem contribui:

make generate-all          # gera os artefatos de cada ferramenta
make validate STRICT=1     # valida estrutura e artefatos
uv run --project plugins/plugin-eval plugin-eval score plugins/python-development/skills/python-testing-patterns --depth quick

Quando usar

  • Ter subagentes especialistas prontos (backend, testes, segurança, infra) sem escrever do zero.
  • Padronizar o mesmo conjunto de agentes entre Claude Code, Codex e Cursor no time.
  • Pegar só uma skill específica de um domínio.

Observações

  • Instale apenas os plugins necessários: muitos plugins ativos ocupam contexto e deixam a escolha de agentes mais confusa.
  • As notas do plugin-eval com juiz LLM são experimentais e, com ANTHROPIC_API_KEY definida, cobram na sua conta da API.
  • O plugin externo Pensyve é do mantenedor; o Pensyve Cloud foi encerrado em 1º/out/2026 e só funciona self-hosted.
