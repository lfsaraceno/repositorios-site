GEO Optimizer

Ferramenta open source de GEO/AEO que dá nota de 0 a 100 para o quanto o seu site está pronto para ser citado pelo ChatGPT, Perplexity, Gemini, Claude e AI Overviews do Google, e gera as correções (robots.txt, llms.txt, schema JSON-LD, meta tags). Roda como CLI, MCP, plugin do Claude Code e GitHub Action.

O que é

Estar bem no Google não garante que uma IA cite o seu site: um mecanismo de resposta dá uma resposta só e cita poucas fontes. O GEO Optimizer audita os sinais que deixam um site alcançável, legível e citável por esses mecanismos: acesso dos robôs de IA, dados estruturados, conteúdo e arquivos de descoberta.

Ele dá uma nota, lista o que falta por prioridade e escreve os arquivos de correção. É o motor por trás do GeoReady (geoready.dev), que oferece a mesma auditoria no navegador. O autor, Juan Camilo Auriti, também escreveu um livro sobre o tema, e os pesos da nota se baseiam em artigos científicos (KDD 2024, C-SEO Bench, AutoGEO).

Principais recursos

  • Nota de 0 a 100 em 9 categorias: prontidão para a IA do Google, robots.txt, schema JSON-LD, conteúdo, marca e entidade, meta tags, llms.txt, sinais de atualização e descoberta por IA.
  • 27 robôs de IA verificados (GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Claude-SearchBot, Googlebot, Google-Extended e outros), inclusive se o CDN (Cloudflare, Akamai, Vercel) está bloqueando.
  • Citabilidade: nota separada com 47 checagens de conteúdo.
  • Checagens extras: sinais negativos (excesso de CTA, popups, keyword stuffing), conteúdo que depende de JavaScript, detecção de prompt injection, confiança, prontidão para RAG e WebMCP.
  • geo fix: gera robots.txt, llms.txt, schema e meta tags; mostra antes e só grava com --apply.
  • geo citations: pergunta a IAs reais se sua marca é mencionada e seu domínio citado (com sua chave de API).
  • 16 comandos, 8 formatos de saída (texto, JSON, HTML, PDF, SARIF etc.), 12 ferramentas MCP, API Python e integração com Astro.

Pré-requisitos

  • Python 3.10 a 3.14, ou o uv para rodar sem instalar.
  • Para o plugin do Claude Code: uv no PATH.
  • Para geo citations: chave de API de um provedor (Perplexity, OpenAI, Anthropic, Groq, Gemini, MiniMax, DeepSeek ou SerpBase), cobrada pelo provedor.

Instalação

Sem instalar:

uvx --from geo-optimizer-skill geo audit --url https://seusite.com

CLI:

pip install -U geo-optimizer-skill

Plugin do Claude Code (instala a skill e o servidor MCP):

/plugin marketplace add Auriti-Labs/geo-optimizer-skill
/plugin install geo-optimizer@geoready

No Claude Code 2.1.275 ou mais novo, um passo basta: /plugin install geo-optimizer --marketplace Auriti-Labs/geo-optimizer-skill. O plugin não instala a CLI geo que a skill usa; instale com o pip acima.

Só o MCP:

pip install "geo-optimizer-skill[mcp]"
claude mcp add geo-optimizer -- geo-mcp

Depois peça: "audit my site and fix what's missing."

Sem terminal: cole a URL em geoready.dev, grátis e sem conta.

Comandos e uso

geo audit --url https://seusite.com                       # nota 0–100 + correções por prioridade
geo fix --url https://seusite.com                         # mostra robots.txt, llms.txt, schema e meta (--apply grava)
geo audit --url https://seusite.com --threshold 70        # sai com erro abaixo de 70 (para CI)
geo audit --sitemap https://seusite.com/sitemap.xml --max-urls 25
geo citations --brand "SuaMarca" --domain seusite.com --topic "sua categoria" --runs 5
geo llms --base-url https://seusite.com --output ./public/llms.txt
geo schema --type website --name "Seu Site" --url https://seusite.com
geo access --url https://seusite.com                      # navegador x robô de IA
geo perception --url https://seusite.com                  # o que uma IA extrairia da página
geo track --url https://seusite.com --report --output ./geo-track-report.html

GitHub Action (falha o build se a nota cair):

- uses: Auriti-Labs/geo-optimizer-skill@v4.23.0
  with:
    url: https://seusite.com
    min-score: 70
    format: sarif

Quando usar

  • Antes de lançar um site, para ele ser lido e citado por buscas com IA.
  • Criar llms.txt, regras de robots.txt para robôs de IA e schema JSON-LD sem escrever à mão.
  • Conferir se o Cloudflare ou outro CDN está bloqueando o ChatGPT e o Claude.
  • Vigiar a nota a cada deploy no CI.

Observações

  • Não garante citação: mede sinais de prontidão. Se uma IA vai citar você depende da pergunta, da concorrência e do mecanismo. O próprio README diz isso.
  • geo fix mostra antes de gravar. Revise o robots.txt gerado antes de usar --apply, porque ele decide quais robôs acessam o site.
  • Privacidade: a CLI só acessa a URL auditada e os provedores que você configurar. Não tem telemetria.
  • Plano pago opcional: o GeoReady hospedado tem plano grátis e Pro/Agency a partir de US$ 19/mês, com monitoramento e alertas. A CLI é grátis e de uso comercial livre.
  • llms.txt não é fator de ranking comprovado. A ferramenta pontua porque é barato e ajuda as IAs a ler a estrutura do site.
  • Relacionados no catálogo: o Claude SEO tem /seo geo dentro de uma auditoria de SEO completa. O Search Console MCP traz os dados reais do Google. O Open SEO faz pesquisa de palavras-chave e backlinks.
