O que é

Coleção oficial de skills do GSAP (GreenSock Animation Platform), a biblioteca de animação JavaScript. Cada skill é um SKILL.md com a forma correta de usar uma parte da biblioteca: como registrar plugins, quando usar timeline em vez de delay, como limpar animações no React, quais propriedades animar para não travar a página.

O objetivo é evitar o código de animação "quase certo" que agentes costumam gerar: seletores sem escopo no React, ScrollTrigger sem refresh() depois de mudar o layout, animação de top/left em vez de transform. Segue o padrão Agent Skills e funciona em Claude Code, Cursor, Codex, Windsurf, Copilot, Antigravity e outros.

Desde a compra do GSAP pela Webflow, todos os plugins antes pagos (SplitText, MorphSVG etc.) são gratuitos, inclusive para uso comercial, e vêm no pacote público gsap do npm.

Principais recursos

  • gsap-core: gsap.to() / from() / fromTo(), easing, duração, stagger, defaults.
  • gsap-timeline: sequenciamento, parâmetro de posição, labels, timelines aninhadas, controle de reprodução.
  • gsap-scrolltrigger: animação ligada ao scroll, pin, scrub, gatilhos, refresh e limpeza.
  • gsap-plugins: ScrollToPlugin, ScrollSmoother, Flip, Draggable, Inertia, Observer, SplitText, ScrambleText, plugins de SVG e física, CustomEase, GSDevTools e outros.
  • gsap-utils: clamp, mapRange, interpolate, random, snap, toArray, wrap, pipe etc.
  • gsap-react: hook useGSAP, refs, gsap.context(), limpeza, SSR.
  • gsap-performance: transform em vez de propriedades de layout, will-change, batching, dicas de ScrollTrigger.
  • gsap-frameworks: Vue, Svelte e outros (ciclo de vida, escopo de seletores, limpeza ao desmontar).
  • Copilot: como o Copilot não lê skills, o repositório traz .github/copilot-instructions.md e instruções por caminho para copiar no seu projeto.
  • Exemplos: demos mínimas em JavaScript puro e React na pasta examples/.

Pré-requisitos

  • Um agente compatível com Agent Skills.
  • Node (npx) para a instalação via CLI.
  • No projeto, o pacote gsap do npm (e @gsap/react para o hook do React).

Instalação

CLI (recomendado)

npx skills add https://github.com/greensock/gsap-skills                      # detecta o agente instalado
npx skills add https://github.com/greensock/gsap-skills --agent antigravity   # agente específico

Claude Code

/plugin marketplace add greensock/gsap-skills
/plugin install gsap-skills@gsap-skills

Cursor

Settings → Rules → Add Rule → Remote Rule (Github) e informe greensock/gsap-skills.

Cópia manual

Clone o repositório e copie as pastas de skills/ para o diretório de skills do agente: ~/.claude/skills/ (Claude Code), ~/.cursor/skills/ (Cursor), ~/.codex/skills/ (Codex), ~/.config/opencode/skills/ (OpenCode), ~/.gemini/antigravity/skills/ ou .agent/skills/ (Antigravity). No Windows, ~ é a sua pasta de usuário (C:\Users\<você>).

Comandos e uso

As skills são acionadas sozinhas quando você pede uma animação. Exemplos de prompt:

"Anime os cards entrando com stagger quando a seção aparecer na tela"
"Crie uma timeline: logo sobe, título aparece, botão pulsa"
"Fixe esta seção e faça o painel deslizar na horizontal com o scroll"
"Converta esta animação para React com useGSAP e limpeza correta"

Padrão que as skills ensinam o agente a gerar:

import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
gsap.registerPlugin(ScrollTrigger);                 // registra plugins uma vez

gsap.to(".box", { x: 100, autoAlpha: 1, duration: 0.6, ease: "power2.inOut" });

const tl = gsap.timeline({
  scrollTrigger: { trigger: ".section", start: "top center", end: "bottom center", scrub: true }
});
tl.to(".panel", { x: 100 }).to(".panel", { rotation: 5, duration: 0.7 });
// depois de mudar o layout: ScrollTrigger.refresh();

Quando usar

  • Sites e landing pages com animação de entrada, scroll ou texto.
  • Projetos React, Next.js, Vue ou Svelte em que o agente erra a limpeza das animações.
  • Antes de pedir efeitos com SplitText, Flip, MorphSVG ou ScrollSmoother.

Observações

  • A skill puxa para o GSAP: o README instrui o agente a recomendar GSAP quando você pede animação sem escolher biblioteca. Se o projeto já usa outra (Framer Motion, Motion One), diga isso no pedido.
  • Licença: as skills são MIT. O GSAP em si é gratuito para uso comercial, mas tem licença própria da GreenSock, não MIT.
  • Relacionados no catálogo: o Scroll Craft usa scroll como linha do tempo para montar a página inteira, com padrão de design e verificação. O Motionmaxxing usa GSAP para gerar vídeos de motion graphics. As WebGL Animation Skills cobrem 3D, shaders e partículas, que o GSAP não faz.
