O que é

É um marketplace de plugins para o Claude Code, construído sobre a especificação Agent Skills, com três plugins para dados, visualização e design. Cada skill é uma pasta com um SKILL.md (frontmatter com nome e descrição), podendo incluir evals/, scripts/, references/ e assets/.

Os plugins são: opendata (consulta e análise de datasets públicos pela API do OpenData), openchart (gráficos, tabelas, grafos e diagramas sankey com o OpenChart) e opendesign (logos, ícones e gráficos em SVG).

Principais recursos

  • Plugin opendata com a skill opendata-api: buscar linhas de datasets, filtrar, ordenar, agregar, inspecionar colunas, compor joins entre datasets e explorar inteligência de grafos.
  • Plugin openchart com a skill openchart: gráficos, tabelas, grafos e sankey.
  • Plugin opendesign com a skill svg-design: logos, ícones e gráficos em SVG.
  • Instalação com escopo de usuário, projeto (--scope project) ou local (--scope local).
  • Cada skill é independente e pode ser copiada para outras plataformas (Codex, Gemini CLI, Cursor, VS Code/Copilot).

Pré-requisitos

  • Claude Code com suporte a marketplaces de plugins.
  • Para as skills de dados, acesso à plataforma OpenData (o README não detalha chaves de API).

Instalação

Claude Code

Adicione o marketplace e instale os plugins desejados:

/plugin marketplace add tryopendata/skills
/plugin install opendata@opendata-skills
/plugin install openchart@opendata-skills
/plugin install opendesign@opendata-skills

Ou pela linha de comando:

claude plugin marketplace add tryopendata/skills
claude plugin install opendata@opendata-skills

Outras plataformas (Codex, Gemini CLI, Cursor, VS Code/Copilot)

Copie o diretório da skill para o local de skills da plataforma (normalmente .agents/skills/):

cp -r plugins/opendesign/skills/svg-design .agents/skills/svg-design

Comandos e uso

As skills são acionadas pelo contexto. Exemplos de pedidos, no espírito do que cada skill faz:

Consulte o dataset X na OpenData e agregue por ano
Gere um gráfico de barras com esses dados usando OpenChart
Crie um logo em SVG para o meu projeto

Quando usar

  • Pesquisa e análise de dados públicos diretamente na conversa com o agente.
  • Visualizações rápidas (gráficos, tabelas, sankey) a partir dos dados consultados.
  • Geração de ícones e logos SVG.

Observações

  • Projeto pequeno e mantido por uma empresa específica (OpenData); a skill de dados depende da plataforma deles.
  • Migração pré-1.0: a skill svg-design saiu do plugin openchart e foi para o novo plugin opendesign na versão 1.0.0.
