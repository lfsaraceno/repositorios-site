Scroll World

Skill para agentes que transforma qualquer marca numa landing page de "voo" 3D guiado pelo scroll: a câmera entra em cada cena de um pequeno mundo isométrico gerado por IA e segue para a próxima sem cortes.

O que é

É a técnica das páginas de produto da Apple aplicada a qualquer negócio. A IA gera cenas em estilo diorama isométrico e os vídeos de câmera entre elas, e a página toca esses vídeos conforme a rolagem. Rolar só controla o tempo; a câmera de fato se move.

A skill funciona em três passos:

  1. Entrevista: pergunta o setor e a proposta, a marca (importada de uma URL, enviada por você ou proposta pela skill), a direção de arte, as cenas em ordem, se quer a versão mobile em 9:16 e o orçamento. Mostra o custo estimado e só gera depois da sua aprovação.
  2. Gera os assets: uma imagem por cena, um vídeo de "mergulho" por cena e os vídeos de ligação entre cenas, feitos a partir dos quadros reais das vizinhas para as emendas ficarem idênticas.
  3. Monta a página: um motor de scroll em JavaScript puro, configurável, que serve os vídeos verticais no celular.

Principais recursos

  • Voo contínuo pela página inteira, sem cortes entre cenas.
  • Versão mobile própria em 9:16, não um recorte da versão desktop.
  • Motor de scroll portátil (HTML puro, Next.js, Vue ou página servida por Python).
  • Templates de prompt e scripts de pipeline prontos (gerar, extrair quadros, ligar, codificar).
  • Estimativa de custo antes de gastar.

Pré-requisitos

  • Monid CLI com chave de API e saldo: o gerador de vídeo padrão (Seedance 2.0, cobrado por clipe).
  • Higgsfield CLI autenticada (higgsfield auth login) e com créditos: gera as imagens das cenas e é o plano B de vídeo.
  • ffmpeg e ffprobe.
  • Python 3 com Pillow.
  • Opcional: Codex CLI, para gerar as imagens pela assinatura do ChatGPT em vez dos créditos do Higgsfield.

Instalação

Claude Code (plugin):

/plugin marketplace add oso95/scroll-world
/plugin install scroll-world@scroll-world

Outros agentes:

npx skills add oso95/scroll-world            # escolha o agente quando perguntar
npx skills add oso95/scroll-world -a codex   # direto no Codex

Manual:

git clone https://github.com/oso95/scroll-world
cp -R scroll-world/skills/scroll-world ~/.claude/skills/

Comandos e uso

Peça uma landing page de "scroll-through world" ou chame:

/scroll-world

No Codex, use $scroll-world.

Quando usar

  • Landing page de impacto para qualquer setor ou marca.
  • Campanhas e lançamentos em que a página precisa ser uma experiência.

Observações

  • Custo: gerar os assets custa dinheiro. Pelo README, uma sequência de 6 cenas em 1080p sai por cerca de US$ 27 no Monid; a versão mobile dobra os vídeos. A skill informa a estimativa antes de gerar.
  • A geração demora e roda em segundo plano.
  • Vídeos pesados na página: cuide do desempenho e do consumo de dados no celular.
  • Último commit em jul/2026.
  • Relacionados no catálogo: o Scroll Craft também constrói sites imersivos guiados pelo scroll; o GSAP é a base de muitas animações por scroll.
