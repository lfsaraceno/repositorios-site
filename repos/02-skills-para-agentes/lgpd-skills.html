LGPD Skills

Pacote de Agent Skills em português para conformidade com a LGPD, as resoluções da ANPD e o ECA Digital. Um maestro (lgpd-audit) orquestra 18 sub-skills, que auditam o código e geram documentos versionáveis. Funciona no Claude Code, Codex, Gemini CLI, Cursor e OpenCode.

Atenção: o próprio projeto avisa que não é aconselhamento jurídico. Comunicação à ANPD, contratos, política de privacidade e resposta a fiscalização devem passar pelo encarregado (DPO) e por um advogado de proteção de dados.

O que é

O pacote transforma "preciso adequar isso à LGPD" num roteiro executável pelo agente. Em vez de uma skill gigante, são 19 skills coordenadas:

  • 1 maestro, lgpd-audit: escolhe o roteiro, guarda o estado e pausa em pontos de revisão;
  • 18 sub-skills especializadas: cada uma roda sozinha ou sob comando do maestro.

Tudo o que as skills produzem fica na pasta .lgpd/ do projeto, versionado em Git: status, mapa de dados, ROPA, RIPDs, política, runbook de incidente, lacunas e outros.

Principais recursos

  • Quatro roteiros:

    Cenário Roteiro Prazo estimado pelo autor
    Projeto novo, privacidade desde o início A 1–2 semanas
    Sistema legado em produção B 2–6 semanas
    Código híbrido C 3–8 semanas
    Incidente de segurança em andamento D 3 dias úteis (Res. ANPD 15/2024)

  • Sub-skills, entre outras:

    • lgpd-legal-basis (bases legais, art. 7 e 11);
    • lgpd-data-mapping (inventário de dados);
    • lgpd-ropa (registro de operações, art. 37);
    • lgpd-ripd (relatório de impacto, art. 38);
    • lgpd-consent-schema (registro de consentimento);
    • lgpd-dsar (direitos do titular, art. 18);
    • lgpd-privacy-policy;
    • lgpd-incident-response;
    • lgpd-dpo-encarregado;
    • lgpd-dpa (contrato com operador);
    • lgpd-international-transfer;
    • lgpd-vendor-audit;
    • lgpd-audit-logging;
    • lgpd-encryption-keys;
    • lgpd-anonymization;
    • lgpd-retention-erasure;
    • lgpd-eca-digital-minors;
    • lgpd-legacy-retrofit.

  • Gatilhos em português: "veja como estamos de LGPD", "tivemos um incidente", "preciso de uma RIPD", "endpoint de exclusão de conta".

  • Cita artigo e fonte em cada recomendação.

Pré-requisitos

  • Um agente compatível: Claude Code, Codex, Gemini CLI, Cursor ou OpenCode.
  • O código e os exemplos assumem Next.js, Prisma e PostgreSQL, Better Auth, React Native, AWS ou GCP, e Stripe ou Pagar.me. Os princípios valem para outras stacks, adaptando a sintaxe.

Instalação

Claude Code (recomendado):

/plugin marketplace add goul4rt/lgpd-skills
/plugin install lgpd-skills@lgpd-skills

Para atualizar: /plugin marketplace update lgpd-skills.

Codex:

codex plugin marketplace add goul4rt/lgpd-skills
codex plugin add lgpd-skills@lgpd-skills

Gemini CLI:

gemini extensions install https://github.com/goul4rt/lgpd-skills

Cursor: rode /add-plugin e cole a URL do repositório.

OpenCode: adicione "lgpd-skills@git+https://github.com/goul4rt/lgpd-skills.git" ao array plugin do opencode.json. No OpenCode, as skills não disparam sozinhas: peça "use a skill lgpd-audit".

Manual (copiar as pastas skills/lgpd-* para ~/.claude/skills/ ou .claude/skills/):

git clone https://github.com/goul4rt/lgpd-skills.git /tmp/lgpd-skills
cp -r /tmp/lgpd-skills/skills/lgpd-* ~/.claude/skills/
rm -rf /tmp/lgpd-skills

Comandos e uso

Converse com o agente:

veja como estamos de LGPD

O lgpd-audit pergunta o cenário (A, B, C ou D) e começa o roteiro. Ele para em pontos de revisão antes de seguir.

Também dá para chamar uma skill direto:

implementa o endpoint de exclusão de conta
tivemos um vazamento de e-mails, preciso comunicar a ANPD

Quando usar

  • Auditar um sistema em produção e montar um plano de adequação priorizado.
  • Começar um projeto novo com privacidade desde a concepção.
  • Gerar ROPA, RIPD, política de privacidade e contratos com operadores como rascunhos, para revisão jurídica.
  • Guiar a resposta a um incidente dentro do prazo de comunicação à ANPD.
  • Comparação no catálogo:
    • o Leis Brasil dá acesso ao texto das leis;
    • o Security Audit Skill foca em vulnerabilidades técnicas;
    • o LGPD Skills foca em conformidade legal e na documentação exigida.

Observações

  • Não é parecer jurídico. As skills lembram disso nos pontos críticos.
  • As normas mudam. A ANPD publica resoluções com frequência. O último release é v1.1.1 (mai/2026), e o repositório não recebe commits desde então. Confira se a referência normativa está atualizada antes de confiar nos prazos e artigos.
  • Os artefatos em .lgpd/ podem conter informações sensíveis sobre o tratamento de dados, as lacunas e os incidentes da empresa. Cuidado ao versionar num repositório público.
  • Projeto pequeno e recente, de um único autor.
