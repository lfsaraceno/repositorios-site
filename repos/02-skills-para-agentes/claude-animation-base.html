Kit inicial para o Claude animar desenhos com cara de pintados à mão em p5.js + p5.brush: o personagem Clawd com 31 emoções prontas, regras de animação e um renderizador que gera o MP4.

O que é

Um pequeno kit com código, instruções e recursos para o Claude animar um personagem em p5.js e p5.brush, com visual de pintura à mão (pinceladas, aquarela, traço "tremido"). Nasceu do clipe I'm Upping My P(doom) e de uma análise do que o modelo fez bem e mal nele.

Não é uma skill instalável: você clona o repositório, abre no Claude Code (ou outro agente) e pede o vídeo. O arquivo ANIMATION_GUIDE.md traz as regras que o modelo segue: feito à mão, vivo, uma peça só, sem texto, sempre com transições, algo acontecendo em toda cena, e os princípios de animação de personagem.

O modelo faz o storyboard primeiro, constrói plano a plano, gera folhas de contato para conferir o próprio trabalho e grava out/video.mp4. O autor testou com o Claude Opus 5.5 em raciocínio xhigh e notou que quanto maior o nível de raciocínio, mais detalhada fica a cena.

Principais recursos

  • Personagem Clawd pronto: vistas, 31 emoções, olhos, bocas, chapéus, emotes e danças.
  • Biblioteca de pintura, tempo, movimento, câmera, luz e papel (src/core.js).
  • Linha do tempo com planos, loops e transição de "pincelada" (src/timeline.js).
  • Renderizador sem interface: folhas de contato, tiras de quadros, recortes, stills e MP4.
  • studio.html para navegar pelo vídeo no Chrome.
  • Dá para pedir troca de personagem, novas emoções, figurinos ou imagens de referência suas.

Pré-requisitos

  • Node.js, Google Chrome e ffmpeg.
  • GPU dedicada recomendada: sem ela, os preenchimentos de aquarela do p5.brush levam segundos por quadro.

Instalação

git clone https://github.com/JohnHeibel/ClaudeAnimationBase.git
cd ClaudeAnimationBase
npm install

Abra a pasta no Claude Code.

Comandos e uso

Peça ao agente:

Read ANIMATION_GUIDE.md, then make a 15-second video of Clawd trying to catch a butterfly.

Rodar o demo você mesmo:

node render.mjs --clip --out=out/video.mp4    # renderiza o demo de 11 s de src/scenes/demo.js

Opções do renderizador citadas no README:

--chrome=<caminho>         # Chrome fora do lugar padrão (ou a variável CHROME_PATH)
--soft-gl                  # sem GPU: WebGL por software (lento nas aquarelas)
--gpu-angle=gl-egl         # Linux sem interface com GPU NVIDIA (ou vulkan)
node gpu_probe.mjs <chrome>   # mostra qual renderizador cada conjunto de flags usa

Abra studio.html no Chrome para navegar pelo vídeo; acrescente ?loop=emotions ou ?loop=views para ver as folhas de modelo.

Quando usar

  • Fazer curtas animados com cara de desenho pintado à mão.
  • Aprender a dirigir o Claude em animação de personagem (storyboard, planos, autocorreção).
  • Criar um personagem próprio a partir da base do Clawd.

Observações

  • Sem atualizações desde set/2026: é um kit de exemplo, não um projeto mantido.
  • Sem GPU dedicada, peça ao modelo para trocar os preenchimentos de aquarela por outra técnica, senão a renderização fica muito lenta.
  • O Clawd é o mascote do Claude Code, da Anthropic. Para uso comercial, troque o personagem.
  • Relacionados no catálogo: o Anidoodle e o JavaScript Animation Skills seguem a mesma ideia (tudo desenhado em código), mas como skills completas, com vários estilos e trilha sonora.
