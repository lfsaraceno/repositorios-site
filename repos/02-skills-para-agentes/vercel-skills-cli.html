O que é

O skills é a CLI da Vercel para o ecossistema aberto de agent skills: instruções reutilizáveis que ensinam agentes de código a fazer tarefas, como revisar código, seguir boas práticas de uma biblioteca ou fazer deploy. Funciona como um "npm de skills": você busca, instala, atualiza e remove skills de qualquer repositório do GitHub, e a CLI coloca os arquivos na pasta certa de cada agente instalado.

O catálogo público fica em skills.sh, com ranking por número de instalações. A CLI detecta os agentes que você tem (Claude Code, Codex, Cursor, OpenCode e mais de 75 outros) e deixa você escolher onde instalar.

O repositório também traz a skill find-skills, uma das mais instaladas do skills.sh (cerca de 4 milhões de instalações). Com ela, quando você pergunta "como faço X?" ou "tem alguma skill para X?", o próprio agente consulta o ranking, busca com npx skills find, verifica a qualidade e oferece o comando de instalação.

Principais recursos

  • Instala skills de qualquer repositório do GitHub, inclusive privados, no projeto ou de forma global (-g).
  • Busca interativa ou por palavra-chave (npx skills find).
  • Lista, verifica atualizações, atualiza e remove skills instaladas.
  • Usa uma skill sem instalar (npx skills use), gerando o prompt ou abrindo o agente já com ela.
  • Cria o modelo de uma skill nova (npx skills init).
  • Experimental: sincroniza skills que vêm junto com pacotes npm e restaura as skills do projeto a partir do skills-lock.json.
  • find-skills: busca e recomenda skills seguindo critérios de qualidade (mais de 1 mil instalações, fonte confiável, estrelas do repositório).

Pré-requisitos

  • Node.js 22.20 ou mais novo.
  • Pelo menos um agente compatível instalado (ex.: Claude Code).

Instalação

Não precisa instalar a CLI: ela roda via npx. Para instalar a find-skills no seu agente:

npx skills add https://github.com/vercel-labs/skills --skill find-skills

Para instalar de forma global (em todos os projetos), sem perguntas:

npx skills add vercel-labs/skills@find-skills -g -y

Comandos e uso

npx skills add vercel-labs/agent-skills                                   # escolhe interativamente skills e agentes de um repositório
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a claude-code   # uma skill específica, só no Claude Code
npx skills find                                                           # busca interativa
npx skills find react performance                                         # busca por palavra-chave
npx skills find pr review --owner vercel-labs                             # busca só num autor
npx skills list                                                           # skills instaladas
npx skills check                                                          # verifica atualizações
npx skills update                                                         # atualiza as instaladas
npx skills remove <skill>                                                 # remove
npx skills use vercel-labs/agent-skills@web-design-guidelines --agent claude-code   # usa sem instalar
npx skills init minha-skill                                               # cria o modelo de uma skill nova
npx skills --help                                                         # todas as opções

Usando a find-skills: depois de instalada, é só perguntar ao agente, por exemplo: "tem alguma skill para testes com Playwright?" ou "como deixo meu app React mais rápido?". Ele busca, mostra as opções com o número de instalações e o link do skills.sh, e oferece o comando para instalar.

Quando usar

  • Instalar e manter atualizadas as skills de vários agentes num comando só, em vez de copiar pastas à mão.
  • Descobrir skills prontas antes de escrever uma do zero.
  • Instalar skills citadas neste catálogo, como a Vercel Agent Skills (react-best-practices) e a skill do VoiceStudio.
  • Criar e distribuir as suas próprias skills para a equipe.

Observações

  • Telemetria: a CLI coleta dados de uso anônimos. Para desligar, defina DISABLE_TELEMETRY=1 ou DO_NOT_TRACK=1. Isso também desliga as consultas de auditoria de segurança.
  • Skills são instruções que o agente vai seguir. Antes de instalar skills de autores desconhecidos, leia o SKILL.md. A própria find-skills recomenda desconfiar de skills com menos de 100 instalações ou de repositórios com menos de 100 estrelas.
  • Os comandos experimental_ podem mudar ou sumir sem aviso.
  • Não confunda com o vercel-labs/agent-skills: aquele é uma coleção de skills; este é a ferramenta que instala skills.
