earshot

Efeitos sonoros para agentes de código: você pede em palavras ("um som de sucesso suave", "passos no cascalho") e o earshot renderiza o som em código a partir de um catálogo de 922 sons, roda só na CPU, sem modelo que gera áudio, e o som gerado é seu para qualquer uso.

O que é

Um agente de código não ouve. O earshot faz esse papel: escolhe no catálogo o som que melhor responde ao pedido e renderiza uma versão nova dele. Quando o catálogo não tem o som, ele avisa e o earshot build monta o som com partes gravadas.

Os sons realistas vêm de 692 gravações em domínio público, guardadas como números (não há arquivo de áudio no repositório). Com um extra opcional, o earshot também "escuta": descreve um arquivo de áudio, diz se combina com uma descrição e acha o melhor trecho numa gravação longa.

É do mesmo autor da Taste Skill.

Principais recursos

  • make: 922 sons em 384 famílias, entre eles sons de interface, ruídos do dia a dia, ambientes em loop, jogos, 8-bit, bateria, efeitos de cinema e motion e três loops curtos de música.
  • Conjuntos prontos: ui (17 sons de interface), game (22), arcade (16) e film (17), com manifest.json e sprite para a web.
  • build: monta um som que falta a partir de partes descritas em palavras e ajusta o resultado ouvindo com um modelo. Vem com 99 receitas.
  • Escuta (extra listen): descrever, comparar, ranquear, achar trechos, dizer se é gravação real ou som sintetizado e analisar a trilha de um vídeo.
  • Cinema: banco de 252 efeitos em código, kits por papel (launch, calm, crisp, minimal) e o fit, que transforma uma gravação em código.
  • Saída em wav, flac, ogg, webm, mp3 e m4a, com volume já ajustado.
  • Servidor MCP com 20 ferramentas, plugin do Claude Code com 2 comandos e 2 skills.

Pré-requisitos

  • Python 3.10 ou mais novo. Só CPU.
  • FFmpeg no PATH só para gravar ogg, mp3, m4a e webm e para ler vídeo.
  • Extra listen: cerca de 1,1 GB de download (2,2 GB em disco) com os dois modelos de escuta.

Instalação

npx skills add Leonxlnx/earshot                                     # skills
pip install "earshot @ git+https://github.com/Leonxlnx/earshot"     # ferramenta
pip install "earshot[listen,mcp] @ git+https://github.com/Leonxlnx/earshot"   # com escuta e MCP

Instale pelo GitHub: o nome earshot no PyPI é de outro projeto.

Plugin no Claude Code (precisa do earshot com o extra mcp instalado antes):

/plugin marketplace add Leonxlnx/earshot
/plugin install earshot@earshot

Ou só o MCP:

claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- earshot mcp

Comandos e uso

earshot make "a soft success sound" -o success.wav
earshot make "a campfire" -o fire.ogg --dur 24
earshot make --set ui -o public/sounds --format webm,mp3 --sprite sprite
earshot build "a stampede of horses" -o stampede.wav --part "hundreds of hoofbeats, for 6 s, getting louder"
earshot sounds --search door      # lista o catálogo
earshot doctor                    # o que está instalado

No Claude Code: /earshot:make <palavras> e /earshot:make-set ui|game|arcade|film [tema].

Quando usar

  • Dar sons de clique, sucesso, erro e notificação a um app ou site.
  • Sonorizar jogos, vídeos de lançamento e motion graphics feitos em código.
  • Conferir por medição e escuta se um áudio tem o que você queria.

Observações

  • Peça em inglês. Além dele, só entende palavras comuns de som em alemão.
  • Não faz fala, canto nem melodias.
  • O próprio autor diz que vários sons novos foram medidos, mas ainda não avaliados por uma pessoa. O build funciona bem para texturas e pulsos (fogueira, enxame) e mal para chuva em superfícies novas, veículos e vozes.
  • O llm é opcional, manda o áudio ao Gemini e exige a sua chave e o seu consentimento (--yes-upload).
