O que é

É o marketplace oficial de plugins do Claude Code. Um plugin empacota extensões como comandos de barra, agentes, skills e servidores MCP em uma estrutura padrão, que você instala com um comando.

O repositório se divide em duas pastas principais:

  • /plugins: plugins internos, desenvolvidos e mantidos por pessoas da Anthropic.
  • /external_plugins: plugins de terceiros, vindos de parceiros e da comunidade.

A pasta external_plugins

external_plugins reúne os plugins que não são da Anthropic: parceiros e comunidade submetem seus plugins, que precisam cumprir padrões de qualidade e segurança para serem aprovados (há um formulário de submissão no README). Na leitura, a pasta continha, entre outros: asana, context7, discord, fakechat, firebase, github, gitlab, imessage, laravel-boost, linear, playwright, serena, telegram e terraform.

Cada plugin externo segue a estrutura padrão (por exemplo, o context7 tem .claude-plugin/, .mcp.json e README.md). Como a Anthropic não controla o que esses plugins contêm, o próprio README alerta para confiar no plugin antes de instalar, atualizar ou usar. Já os plugins internos em /plugins incluem, por exemplo, code-review, feature-dev, frontend-design, hookify, plugin-dev, pr-review-toolkit, security-guidance, skill-creator e servidores de linguagem (LSP) como typescript-lsp e pyright-lsp.

Principais recursos

  • Instalação por um comando: /plugin install {nome}@claude-plugins-official.
  • Navegação visual em /plugin > Discover.
  • Estrutura padrão de plugin: .claude-plugin/plugin.json, .mcp.json, commands/, agents/, skills/ e README.md.
  • Nomes de plugin imutáveis (slug); para mudar o rótulo use displayName, e para renomear de fato use o mapa renames do marketplace.json.
  • "Skill-bundle plugins": plugins que declaram skills de outro repositório com strict: false e uma lista skills.

Pré-requisitos

  • Claude Code com suporte a plugins.

Instalação

O diretório é o marketplace padrão do Claude Code. Para instalar um plugin:

/plugin install {plugin-name}@claude-plugins-official

Ou procure o plugin em /plugin > Discover.

Comandos e uso

/plugin                                           # abre o gerenciador de plugins
/plugin install code-review@claude-plugins-official   # exemplo de instalação (nome da pasta /plugins)

Cada plugin traz seus próprios comandos, agentes e skills, documentados no README.md dele.

Quando usar

  • Descobrir extensões oficiais e de parceiros para o Claude Code.
  • Integrar serviços como GitHub, GitLab, Linear, Asana ou Playwright via plugin.
  • Estudar a estrutura de plugins (/plugins/example-plugin) para criar o seu.

Observações

  • A Anthropic não controla nem verifica o que os plugins externos incluem (servidores MCP, arquivos, software). Confie antes de instalar.
  • Os plugins podem mudar com o tempo; consulte a página de cada plugin.
