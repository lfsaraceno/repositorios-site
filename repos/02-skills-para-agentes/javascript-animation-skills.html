O que é

Um pacote de skills para o agente criar curtas animados em que cada quadro é desenhado por código num canvas HTML: nenhuma imagem, fonte ou biblioteca externa. A própria página sintetiza a música e os efeitos sonoros com Web Audio. O exemplo principal é um único HTML de 81 KB.

O agente escolhe um visual a partir do tema, escreve na página uma grade de batidas, uma lista de planos e a marcação de cena como dados, e tudo (imagem, câmera e trilha) lê esses dados, então o som cai em cada ação. Um navegador sem interface gera o MP4 quadro a quadro, e o áudio é renderizado e juntado ao vídeo.

Antes de entregar, o agente confere o próprio trabalho: ausência de arquivos externos, sincronia de áudio e vídeo (cortes na batida, sem saltos de volume), texto sem colisões e uma revisão de direção numa folha de contato a 2 quadros por segundo.

Principais recursos

  • javascript-animation: histórias, explicativos, loops e livros ilustrados a partir de fotos suas, com biblioteca de desenho (tinta à mão, livro ilustrado, impressão em cor especial, gravura de linha única, palavras como formas).
  • soundtrack: música escrita em código para cada filme, com mapa de tempo que põe cada corte na batida e checagem de sincronia que reprova o render.
  • Render determinístico para MP4 e folhas de contato.
  • Auditoria de "zero assets".
  • Funciona também com música gerada por IA ou sua.

Pré-requisitos

  • Um agente compatível com skills (Claude Code, Cursor, Codex etc.).
  • Node 18+, npm i playwright-core, ffmpeg e Chrome (ou npx playwright install chromium).
  • Modelo forte com visão: foi testado só com o Claude Opus 5.5, e a autocorreção precisa olhar imagens.

Instalação

npx skills add iart-ai/javascript-animation-skills

Ou como plugin do Claude Code:

/plugin marketplace add iart-ai/javascript-animation-skills
/plugin install javascript-animation-skills

Comandos e uso

A skill ativa com pedidos como "draw every frame of this in JavaScript", "make it with no image assets" ou "make a hand-drawn animated explainer". Exemplos:

Make a 40-second hand-drawn explainer on why babies love black-and-white cards. Every frame in code.
Animate a short wordless story about a paper boat on its first rainy day, picture-book style, with a music-box soundtrack.
Here are photos of my dog. Make a 30-second animated day-in-the-life of her.

Quando usar

  • Curtas e explicativos animados sem depender de gerador de imagem ou vídeo.
  • Vídeos com trilha sincronizada às ações, feita em código.
  • Animações leves que rodam num único arquivo HTML.

Observações

  • Modelos mais fracos que o Opus 5.5 não foram testados; o README avisa que os desenhos saem mais toscos.
  • Faz parte de uma coleção de 19 pacotes da iart.ai, que também vende um agente de motion completo em iart.ai. As skills são gratuitas.
  • Relacionados no catálogo: o WebGL Animation Skills é da mesma coleção, para 3D; o Anidoodle segue a mesma ideia com mais estilos e ferramentas; o Claude Animation Base é um kit de personagem em p5.js.
