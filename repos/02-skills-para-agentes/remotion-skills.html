O que é

O conjunto de skills que a equipe do Remotion mantém para ensinar agentes de IA a trabalhar em projetos Remotion. Seguem o padrão Agent Skills e funcionam em Claude Code, Codex, Cursor, Kimi Code, OpenCode e outros.

Há uma skill geral (remotion-best-practices), que engloba todas, e skills específicas por tarefa. O repositório é gerado a partir do monorepo do Remotion, então acompanha as versões da biblioteca.

Principais recursos

  • /remotion-best-practices: engloba todas as outras; use quando não souber qual escolher.
  • /remotion-create: cria um projeto ou composição nova.
  • /remotion-markup: boas práticas de código (composições, animações, layout, tipografia, mídia, efeitos, áudio, fontes, tempo).
  • /remotion-studio: abre o Studio para pré-visualizar.
  • /remotion-render: renderiza vídeo ou still, ou exporta uma timeline OpenTimelineIO editável.
  • /remotion-maps: animações de mapa (rotas, marcadores, Mapbox, MapLibre, GeoJSON, voos 3D com CesiumJS).
  • /remotion-captions: legendas.
  • /remotion-saas: arquitetura de apps e produtos com Remotion.
  • /remotion-interactivity: deixa o código editável no Studio.
  • /remotion-docs: busca na documentação e traz qualquer página em Markdown.
  • /remotion-license, /remotion-upgrade, /remotion-multimedia (Mediabunny).

Pré-requisitos

  • Um agente compatível com Agent Skills.
  • Node.js; um projeto Remotion para usar de fato.

Instalação

Num projeto Remotion:

npx remotion skills add

Sem Remotion instalado, pela Vercel Skills CLI ou pela GitHub CLI:

npx skills add remotion-dev/skills
gh skill install remotion-dev/skills

Ao criar um projeto novo, já instalando as skills:

npx create-video@latest --skills

Comandos e uso

/remotion-create Make a promo video for a record store
/remotion-markup Create an animated title card using Inter.
/remotion-maps Animate a route from Los Angeles to New York and make the camera follow it.
/remotion-docs How to set up Remotion Lambda?
/remotion-studio

Quando usar

  • Fazer vídeos em Remotion com um agente, com o código seguindo as práticas oficiais.
  • Consultar a API atual do Remotion sem depender do que o modelo lembra.
  • Animações de mapa e legendas em vídeos.

Observações

  • O repositório não tem arquivo de licença. O uso do Remotion em si segue a Remotion License (paga para empresas acima de 3 funcionários).
  • Relacionados no catálogo: o Remotion é a biblioteca; o HyperFrames é a alternativa em HTML com skills próprias; o Motion Design Skill ensina princípios de tempo e easing que valem para qualquer ferramenta.
