O que é

O Replica é um pacote de 11 skills para o Claude que levam você de "quero um app parecido com X" até "meu app está no ar com outra marca". Uma skill faz a engenharia reversa do app de referência; as seguintes planejam a stack e o banco, recriam o design system, constroem as telas, adicionam login e pagamentos, testam os fluxos, comparam o clone com o original e dão uma nota de paridade.

O diferencial é a skill Entrepreneur: ela lê avaliações reais do app original (App Store, G2, Capterra, Reddit), lista o que os usuários mais odeiam, com contagem e link para cada citação, e transforma isso em melhorias e num posicionamento de venda. A ideia é você não lançar uma cópia, e sim um produto melhor naquilo que incomoda os clientes do concorrente.

Ele trabalha no modo clean-room: recria o que o app faz (funcionalidades e fluxos), nunca o que ele possui, como código, logo, textos, conteúdo e APIs privadas. As skills impõem isso, e o deploy é bloqueado enquanto restar qualquer vestígio da marca original.

Principais recursos

Comando O que faz
/replica-recon Engenharia reversa: telas, fluxos, componentes e modelo de dados, a partir de páginas públicas, prints, listagem na loja e da sua própria conta
/replica-architect Planeja a stack, o schema do banco e a API
/replica-design Recria o design system (cores, tipografia, espaçamento) como tokens, com os seus próprios assets
/replica-build Constrói o app tela por tela a partir do mapa do recon
/replica-backend Login, banco, pagamentos e integrações
/replica-test Percorre todos os fluxos e registra bugs por gravidade
/replica-diff Compara o clone com o original: nota de paridade e o que falta
/replica-entrepreneur Lê avaliações reais e transforma as reclamações em melhorias e posicionamento
/replica-brand Dá nome, paleta, logo e tom de voz novos, e varre o código até não sobrar nada do original
/replica-launch Landing page, preços e listagem para App Store e Google Play
/replica-deploy Checklist final e publicação no seu domínio

Inclui também 6 ferramentas em Python puro, que não acessam a rede, e testes automatizados para cada uma.

Pré-requisitos

  • Claude Code (para o plugin e as ferramentas Python) ou qualquer chat do Claude (colando o SKILL.md, sem as ferramentas).
  • Python 3.8 ou mais novo. Não precisa instalar nenhum pacote.
  • Não precisa de cadastro, chave de API nem conexão com serviço externo.

Instalação

Plugin do Claude Code

/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill

Como plugin, os comandos ficam com prefixo: /replica-skill:replica-recon, e assim por diante.

Pastas de skills, para usar os comandos sem prefixo

git clone https://github.com/Jakeschincariol/replica-skill.git
cp -r replica-skill/replica-* ~/.claude/skills/

Para valer só num projeto, copie as pastas para o .claude/skills/ do repositório.

Pelo chat do Claude

Cole no Claude o link do repositório seguido de install skill. Sem o Claude Code, dá para colar o conteúdo de um SKILL.md no início da conversa e usar a skill como um modo, mas sem as ferramentas Python.

Comandos e uso

Rode as skills na ordem. Cada uma lê o que a anterior gravou na pasta replica/ do projeto:

recon -> architect -> design -> build -> backend -> test -> diff -> entrepreneur -> brand -> launch -> deploy

Exemplo: /replica-recon com a URL de um app de agendamentos gera o replica/recon.md (telas, fluxos, modelo de dados) e o features.csv. Depois, /replica-architect escolhe a stack e escreve o schema, e assim por diante.

Cada skill também roda sozinha. Por exemplo, /replica-entrepreneur sobre um app que você só está pensando em clonar é uma boa forma de validar a ideia antes de começar.

Ferramentas auxiliares:

python3 replica-diff/imgdiff.py original.png clone.png --out diff.png   # diferença de layout, ignora cores
python3 replica-diff/parity.py replica/features.csv                     # nota de paridade e lista do que falta
python3 replica-entrepreneur/reviews.py replica/reviews.csv             # reclamações ranqueadas, com link
python3 replica-design/contrast.py replica/design/tokens.json           # contraste WCAG dos tokens
python3 replica-brand/sweep.py . --avoid "Original App"                 # procura restos do nome original no código
python3 replica-launch/listing.py replica/launch/listing.json           # limites das lojas e checagem de cópia
python3 -m unittest discover -s tests -v                                # testes das ferramentas

Quando usar

  • Criar um SaaS ou app concorrente de um produto que já tem mercado, com diferencial baseado nas reclamações reais dos usuários.
  • Validar uma ideia de produto antes de investir (/replica-entrepreneur).
  • Agências e indie hackers que querem um processo completo, da pesquisa ao deploy.
  • Junto com o RES, que faz uma engenharia reversa mais profunda pelo navegador e gera um relatório e uma base de conhecimento. O Replica cobre o ciclo inteiro até o lançamento.

Observações

  • Questão legal: a skill trabalha com funcionalidade e fluxos, mas os termos de uso de alguns apps proíbem usá-los para criar um concorrente. O próprio README recomenda checar marca registrada e termos, e falar com um advogado antes de lançar. Não é aconselhamento jurídico.
  • Leitura limitada: usa só páginas públicas e a sua própria conta; não passa de login de terceiros nem de paywall.
  • Sem garantia de clone perfeito: um app de agendamento leva semanas, mas um editor de planilhas está fora de alcance. O /replica-recon estima a complexidade antes de começar.
  • O repositório recebeu um único push, na criação (out/2026), e não teve atualizações desde então.
