O que é

Skills são pastas com instruções, scripts e recursos que o Claude carrega quando precisa, para fazer tarefas especializadas de forma repetível. Este é o repositório da Anthropic com exemplos de skills: aplicações criativas (arte, música, design), técnicas (testar apps web, gerar servidores MCP) e corporativas (comunicação, identidade de marca).

Inclui também as skills de criação e edição de documentos que rodam por trás dos recursos de arquivos do Claude (skills/docx, skills/pdf, skills/pptx, skills/xlsx), publicadas como referência de skills complexas usadas em produção.

Principais recursos

  • ./skills: exemplos em Criativo e Design, Desenvolvimento e Técnico, Corporativo e Comunicação, e Documentos.
  • ./spec: especificação do padrão Agent Skills.
  • ./template: modelo para criar uma skill.
  • Dois plugins para o Claude Code: document-skills e example-skills.
  • Skills parceiras em destaque (ex.: Notion).

Pré-requisitos

  • Claude Code, Claude.ai (planos pagos já têm as skills de exemplo) ou a API do Claude.

Instalação

Claude Code

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills

Ou, depois de adicionar o marketplace: Browse and install plugins → anthropic-agent-skills → document-skills ou example-skills → Install now.

Claude.ai e API

No Claude.ai, siga Using skills in Claude para enviar skills próprias. Na API, veja o Skills API Quickstart.

Comandos e uso

Depois de instalado, basta mencionar a skill:

Use the PDF skill to extract the form fields from path/to/some-file.pdf

Para criar uma skill, crie uma pasta com um SKILL.md:

---
name: my-skill-name
description: A clear description of what this skill does and when to use it
---

# My Skill Name

[Add your instructions here that Claude will follow when this skill is active]

Só name (minúsculas, hífens) e description são obrigatórios no frontmatter.

Quando usar

  • Gerar e editar Word, PDF, PowerPoint e Excel no Claude Code com as mesmas skills do Claude.ai.
  • Aprender a escrever skills a partir de exemplos oficiais e da especificação.
  • Usar como base para skills da sua empresa (marca, fluxos internos).

Observações

  • As skills são para demonstração e educação; o comportamento no Claude pode ser diferente. Teste antes de depender delas.
  • O repositório não tem licença única: a maioria das skills é Apache 2.0; confira o arquivo de licença de cada pasta antes de reutilizar.
  • Para o diretório oficial de plugins, veja Claude Code Plugins Directory; para instalar skills de vários agentes, o Skills CLI.
