Teardown

Skill do Claude Code que transforma qualquer máquina num simulador 3D interativo, numa única página HTML offline, que você pode desmontar para ver como funciona, com opção de gravar um vídeo com som.

O que é

Você pergunta como algo funciona (um motor, um relógio mecânico, um braço de escavadeira) e o Claude Code constrói a máquina como uma página HTML offline: ela funciona no centro da tela, painéis ao redor mostram os números reais, um botão abre a peça que está trabalhando e, sem interação, a página faz um tour sozinha.

Também grava um filme da máquina em 60 fps com som procedural masterizado. É construída sobre o claude-motion (MIT), de onde vêm o runtime, a captura de frames, o motor de som e as regras de revisão.

Principais recursos

  • Simulador 3D em uma página HTML, com three.js e fontes embutidos, que funciona offline.
  • Painéis com valores reais, botão para abrir a peça ativa e tour automático.
  • Gravação quadro a quadro para MP4 a 60 fps, ou folhas de revisão com imagens.
  • Som procedural na linha do tempo do filme, masterizado a −14 LUFS.
  • Três máquinas de exemplo prontas: motor V8, avião Cessna e Strandbeest.

Pré-requisitos

  • Claude Code.
  • Node.js 20 ou mais novo.
  • ffmpeg para o vídeo e Python 3 para o som.

Instalação

npx skills add elvarofficial/teardown -g -a claude-code

Depois, uma vez, dentro da pasta instalada:

npm install && npx playwright install chromium

Comandos e uso

Peça em linguagem natural:

Build me a simulator of a 4-stroke motorcycle engine I can take apart.
How does a mechanical watch keep time? Show me as a simulator.
Make a teardown of a hydraulic excavator arm and record a 20-second video of it.

Para abrir um exemplo:

node sims/build.mjs v8-live          # gera teardown-out/dist/v8-live.html
node sims/build.mjs cessna-live
node sims/build.mjs strandbeest-live

Arquivos principais: SKILL.md (instruções e loop de revisão), sims/build.mjs (empacota uma máquina num HTML), sims/capture.mjs (renderiza o filme ou folhas de revisão) e run_sfx.py (som).

Quando usar

  • Explicar visualmente como uma máquina funciona em aulas, treinamentos ou conteúdo.
  • Criar vídeos curtos de "como funciona" para redes sociais.
  • Protótipos de visualização técnica interativa sem servidor.

Observações

  • Projeto pequeno e recente.
  • Os sons gravados são CC0 do Freesound (fontes em sfx/samples/SOURCES.md).
  • Para vídeos de produto e motion graphics com agente, veja também OpenFilm e HyperFrames.
