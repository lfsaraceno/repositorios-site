O que é

Um pacote pequeno de skills focado em movimento 3D e na GPU, fora do caminho comum de animação 2D/Lottie. Ele ensina o agente a escrever shaders, montar e animar cenas Three.js e criar efeitos de partículas sem vazar memória da GPU.

Faz parte de uma coleção de 19 pacotes de skills de animação e vídeo da iart.ai (TikTok, YouTube, e-commerce, mapas, tipografia cinética, Manim e outros), todos open source. O pacote também serve de vitrine para o produto pago da empresa, um agente de motion graphics.

Principais recursos

  • shader-glsl: fragment shaders com gradientes, ruído/fbm, SDFs, domain warping, transições de imagem e ligação com ShaderMaterial do Three.js.
  • threejs-animation: cenas, movimentos de câmera, clipes GLTF, instancing, 3D ligado ao scroll, React Three Fiber e descarte correto de recursos da GPU.
  • particle-system: confete, neve, fumaça, faíscas, flow fields, curl noise, redes de pontos conectados e shaders de Points na GPU.
  • Scripts de apoio (contact-sheet.sh, probe-mp4.sh, seek-shot.sh) para inspecionar vídeos gerados.

Pré-requisitos

  • Um agente compatível com Agent Skills (Claude Code, Cursor, Codex e outros).
  • Node (npx) para a instalação via CLI.
  • Os scripts de apoio são shell (.sh): no Windows, rode no Git Bash ou no WSL.

Instalação

npx skills add iart-ai/webgl-animation-skills

Como plugin do Claude Code:

/plugin marketplace add iart-ai/webgl-animation-skills
/plugin install webgl-animation-skills

Comandos e uso

As skills são acionadas quando o pedido envolve shader, cena 3D ou partículas. Exemplos do README:

"Write a GLSL fragment shader for an animated aurora gradient background and wire it into Three.js."
"Animate this GLTF model in React Three Fiber and crossfade between idle and walk clips."
"Build a connected-dot constellation background that stays fast with 2000 particles."

Outros pacotes da coleção seguem o mesmo padrão de instalação, por exemplo:

npx skills add iart-ai/web-animation-skills          # animação web para frontend
npx skills add iart-ai/kinetic-typography-skills     # texto animado
npx skills add iart-ai/data-animation-skills         # animação de dados

Quando usar

  • Fundos animados com shader ou partículas em landing pages.
  • Animar modelos GLTF ou cenas em Three.js / React Three Fiber.
  • Investigar travamentos ou vazamento de memória em páginas WebGL.

Observações

  • Projeto pequeno e comercial: poucas estrelas e só três skills. O README direciona para o iart.ai, produto pago da empresa, com links de rastreamento.
  • Relacionados no catálogo: as GSAP Skills cobrem animação 2D e de scroll no DOM. O Scroll Craft monta páginas imersivas completas. O Teardown gera simuladores 3D de máquinas, e a Blender Skills trabalha 3D fora do navegador.
