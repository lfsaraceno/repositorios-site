Diagram Design

Skill para agentes que desenha diagramas editoriais como um único arquivo HTML + SVG, nas cores e fontes da sua marca: 52 tipos (arquitetura, fluxo, sequência, ER, timeline, quadrante, Sankey e outros), sem sombras e sem a cara genérica do Mermaid.

O que é

Você pede o diagrama em linguagem natural ("um diagrama de arquitetura do meu app: frontend, backend, banco e cache Redis") e o agente escolhe o tipo, diz o plano e escreve um .html que abre com duplo clique, sem build nem JavaScript.

O estilo é fixo e editorial: uma cor de destaque para 1 ou 2 elementos, linhas finas de 1px, sem sombras e tudo alinhado numa grade de 4px. A autora criou a skill porque os diagramas que o Claude gerava pareciam genéricos e não combinavam com o blog dela.

Principais recursos

  • 52 tipos de diagrama, cada um em três variantes: claro, escuro e editorial completo.
  • Onboarding de marca: "onboard diagram-design to https://seusite.com" extrai cores e fontes do site, confere o contraste WCAG AA e aplica em todos os diagramas.
  • Perfis por cliente, para usar marcas diferentes em projetos diferentes.
  • Importação: redesenha diagramas de draw.io, Mermaid, Excalidraw e PlantUML, com ajuste de tamanho (doc, slide 16:9, post social, impressão), nível de detalhe e público (engenheiro, misto, executivo).
  • Exportação para SVG e PNG (PNG via Playwright).
  • Acessível: título e descrição no SVG, respeito a prefers-reduced-motion.
  • Animação opcional (revelar, passo a passo, loop).
  • 87 ícones de TI e nuvem.

Pré-requisitos

  • Um agente compatível com Agent Skills (Claude Code, Codex, Cursor, Copilot, Gemini CLI etc.).
  • Para exportar PNG: Python com Playwright (pip install playwright && playwright install chromium).

Instalação

Qualquer agente compatível:

npx skills add cathrynlavery/diagram-design

Claude Code (recebe atualizações e os comandos de barra):

/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

Codex:

codex plugin marketplace add cathrynlavery/diagram-design
codex plugin add diagram-design@diagram-design

O README também traz instruções para Copilot, Factory Droid, Qoder, Pi, Kiro, OpenCode e Claude Desktop (este último pede um ZIP gerado por python3 scripts/build-claude-skill-zip.py).

Comandos e uso

Peça em linguagem natural ("um quadrante dos projetos do trimestre por impacto e esforço") ou use os comandos do plugin no Claude Code:

/diagram-design:import-mermaid README.md --diagram=all
/diagram-design:import-drawio platform.drawio --size=slide-16x9 --detail=simplified --audience=executive
/diagram-design:export-diagram caminho/diagrama.html --png-only --scale=3
/diagram-design:profile

Quando usar

  • Diagramas para publicar: posts, documentação de produto, apresentações e landing pages.
  • Deixar com cara profissional diagramas que já existem em Mermaid, draw.io ou Excalidraw.
  • Diagramas com a identidade visual da empresa ou de cada cliente.

Observações

  • A própria autora diz que, para diagramas que ficam no Git e mudam toda sprint, o Mermaid ainda é melhor, porque o resultado aqui não é editável como texto.
  • O resultado depende do modelo usado e pode sair diferente para o mesmo pedido.
  • Por padrão, o diagrama carrega fontes do Google Fonts. Peça "system fonts" para um arquivo sem nenhuma requisição de rede.
  • A instalação via npx skills add não traz os comandos de barra; para eles, use o plugin.
  • Relacionados no catálogo: o Archify também transforma ideias e código em diagramas interativos; o Anatomy explica conceitos com ilustrações isométricas.
