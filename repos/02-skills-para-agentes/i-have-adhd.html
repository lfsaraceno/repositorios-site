O que é

É uma skill para o seu assistente de código que muda o formato das respostas: a ação ou o comando vem primeiro, tarefas de vários passos são numeradas e a resposta termina com um único próximo passo concreto. Some o "Ótima pergunta!", o resumo no final e o "Espero que ajude!".

Não é preciso diagnóstico de TDAH para usar. O README mostra um exemplo antes/depois: de um parágrafo longo com tangentes sobre o fluxo de autenticação para "Edite src/auth.ts:42", seguido de três passos numerados e um "Next:" com o que fazer se um teste falhar. É livremente baseada no livro The Adult ADHD Tool Kit (Ramsay e Rostain), adaptada para como um LLM deve responder.

Principais recursos

As 10 regras da skill (texto completo em skills/i-have-adhd/SKILL.md):

  1. Começar pela próxima ação.
  2. Numerar tarefas de vários passos.
  3. Terminar com um próximo passo concreto.
  4. Suprimir tangentes.
  5. Reafirmar o estado a cada turno.
  6. Estimativas de tempo específicas (minutos, não "um pouco").
  7. Tornar as conquistas visíveis.
  8. Erros em tom objetivo.
  9. Limitar listas a 5 itens.
  10. Sem preâmbulo, sem recapitulação, sem fechamentos.

Também há traduções do README (incluindo português do Brasil) e instruções de instalação para vários agentes.

Pré-requisitos

  • Um agente de código com suporte a plugins ou skills (Claude Code, Antigravity agy etc.).
  • O README não cita versões de Node ou Python.

Instalação

A forma mais simples, segundo o README, é colar este texto no prompt do seu CLI:

Install the i-have-adhd skill/plugin from https://github.com/ayghri/i-have-adhd, refer to the repo's AGENTS.md for instructions.

As instruções detalhadas por agente estão em INSTALL.md. Exemplo para o Antigravity (agy):

agy plugin install https://github.com/ayghri/i-have-adhd
agy plugin list

O INSTALL.md traz ainda um bloco "always-on" para colocar em ~/.gemini/GEMINI.md e um caminho de importação manual do SKILL.md para o AstronClaw. Para o Claude Code, o README só mostra os comandos de plugin no contexto de um fork (claude plugin marketplace add <seu-usuario>/i-have-adhd e claude plugin install i-have-adhd@i-have-adhd); consulte o INSTALL.md do repositório para o passo exato do upstream.

Comandos e uso

/i-have-adhd        # ativa a skill (reinvoque após reiniciar o assistente)
stop adhd mode      # desliga o estilo (a skill também aceita "normal mode")

Para personalizar: faça um fork, edite skills/i-have-adhd/SKILL.md e troque a cópia instalada:

claude plugin uninstall i-have-adhd
claude plugin marketplace remove i-have-adhd
claude plugin marketplace add <seu-usuario>/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

Reinicie o assistente e invoque /i-have-adhd de novo.

Quando usar

  • Você se perde em respostas longas e quer ir direto ao comando ou à edição.
  • Sessões de depuração em que cada turno deve terminar com uma única ação.
  • Equipes que querem respostas de agente mais curtas e objetivas.

Observações

  • Segundo o INSTALL.md, a skill mantém o estilo na conversa até você dizer "stop adhd mode" ou "normal mode".
  • O próprio guia avisa que o procedimento de importação no AstronClaw não foi testado com esta skill; revise o conteúdo antes de habilitar.
  • Quando você pede explicação completa, o estilo permite explicar por inteiro.
