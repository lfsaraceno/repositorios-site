FFmpeg Skill

Editor de vídeo local para agentes de código: 42 ferramentas sobre o FFmpeg (cortar, juntar, tirar silêncio, estabilizar, reduzir ruído, legendas, reenquadrar para 9:16, loudness, exportar para Reels e YouTube) que o agente usa e depois confere o próprio resultado; sem nuvem e sem chave de API.

O que é

Um agente que "sabe FFmpeg" ainda chuta: supõe a taxa de quadros, escolhe um codec que o formato não aceita, recodifica o que só precisava ser copiado e diz "pronto" sem abrir o resultado. Esta skill tira o chute.

O agente segue um fluxo fixo: medir o arquivo → editar (sem perda quando possível) → checar → verificar. Cada operação é um script com argumentos tipados; nada passa por shell. No fim, o resultado é medido de novo e, quando a imagem mudou, o agente vê uma folha de contato.

Funciona offline, no seu computador, com vídeos que você não quer enviar para a nuvem.

Principais recursos

  • Edição: cortes (inclusive com precisão de quadro), junção com transições, remoção de silêncio (cortes secos), ajuste de duração e de proporção (9:16 por corte, barras ou fundo desfocado), estabilização, redução de ruído, endireitar horizonte, câmera lenta, loop, B-roll.
  • Áudio: limpeza de voz, compressor, música com ducking, sincronização entre gravações e loudness EBU R128 (−14 LUFS).
  • Imagem: legendas queimadas (inclusive estilo karaokê e transcrição local opcional), logos, marca d'água, picture-in-picture, chroma key, lower-thirds, HDR para SDR e LUTs.
  • Entrega: presets para YouTube, Shorts, Reels, TikTok, LinkedIn, X e ProRes, e checagem PASS/WARN/FAIL contra as regras de cada plataforma.
  • Projeto inteiro descrito em project.json, processamento em lote e multicâmera.
  • Página de revisão local em HTML para apontar o que mudar.
  • Servidor MCP (12 ferramentas principais por padrão, 42 com FFMPEG_SKILL_MCP_FULL=1).
  • Protege os originais: nunca grava por cima de um arquivo de entrada.

Pré-requisitos

  • FFmpeg 6.1 ou mais novo.
  • Python 3.10 ou mais novo (só biblioteca padrão).
  • Node 16 ou mais novo (só para o instalador npx).
  • Opcional: um motor de transcrição local (pip install faster-whisper) para gerar legendas pela fala.

Instalação

Tudo de uma vez (instala a skill nos agentes encontrados, instala o FFmpeg se faltar e roda o diagnóstico):

npx ffmpeg-skill setup

No Windows, o instalador usa winget install --id Gyan.FFmpeg -e e avisa antes de rodar. Use --no-ffmpeg para não mexer no gerenciador de pacotes.

Passo a passo:

npx ffmpeg-skill            # instala para o Claude Code (--cursor, --codex ou --all)
npx ffmpeg-skill doctor     # confere ffmpeg, ffprobe e os componentes necessários

Para atualizar, rode npx ffmpeg-skill de novo.

Comandos e uso

Peça ao agente em linguagem natural:

"Take interview.mp4, keep 0:45–1:20 and 5:00–5:25, and make it a 60-second Reel."

O agente roda as ferramentas, por exemplo probe.py, cut.py, fit.py --aspect 9:16 --fit crop, export.py --preset reels e check.py --platform reels, e informa duração, tamanho e áudio medidos.

Página de revisão:

npx ffmpeg-skill review project.json --result run.json

MCP (ajuste o caminho; no Windows, troque python3 por python se o servidor não subir):

{"mcpServers": {"ffmpeg-skill": {"command": "python3", "args": ["/Users/you/.claude/skills/ffmpeg-skill/mcp/server.py"]}}}

Quando usar

  • Cortar entrevistas, podcasts e lives em Reels e Shorts.
  • Consertar vídeo de celular: tremido, granulado, escuro, áudio baixo.
  • Padronizar entregas para cada rede social sem decorar parâmetros do FFmpeg.

Observações

  • Um FFmpeg sem alguns filtros (por exemplo, sem libvidstab ou sem subtitles) faz o doctor acusar falta. As outras ferramentas continuam funcionando.
  • A lista completa de 42 ferramentas no MCP ocupa cerca de 48 mil tokens; o padrão de 12 ocupa cerca de 18 mil.
  • O autor tem outras skills que usam esta como base (cor, áudio, motion graphics, Remotion sobre vídeo real).
  • Relacionados no catálogo: o Claude Animated Shorts e o HyperFrames criam vídeos do zero; o SupoClip corta vídeos longos em clipes verticais.
