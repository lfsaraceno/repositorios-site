Karpathy Skills (Karpathy-Inspired Claude Code Guidelines)

Um único CLAUDE.md com quatro princípios, baseados nas observações de Andrej Karpathy sobre erros de LLMs ao programar, para o Claude Code assumir menos, simplificar, mexer só no necessário e trabalhar com critérios verificáveis.

O que é

Andrej Karpathy apontou três problemas recorrentes dos modelos ao programar: assumem coisas sem checar, complicam demais o código e as abstrações, e alteram comentários e código que não entendem como efeito colateral. Este repositório transforma essas observações em quatro princípios num arquivo CLAUDE.md, que você instala como plugin ou cola no projeto.

O repositório foi criado como forrestchang/andrej-karpathy-skills e hoje está em multica-ai; os comandos do README ainda usam o endereço antigo, que redireciona.

Principais recursos

  • Think Before Coding: declarar suposições, apresentar interpretações, discordar quando houver caminho mais simples, parar e perguntar quando confuso.
  • Simplicity First: só o pedido; nada de abstração para uso único, "flexibilidade" não pedida ou tratamento de erro impossível.
  • Surgical Changes: não "melhorar" código vizinho; manter o estilo; remover só o que a sua mudança deixou órfão.
  • Goal-Driven Execution: transformar tarefas em metas verificáveis (ex.: "escreva um teste que reproduz o bug e faça passar") e planos com verificação por passo.
  • Regra pronta para o Cursor (.cursor/rules/karpathy-guidelines.mdc).

Pré-requisitos

  • Claude Code (ou Cursor).

Instalação

Plugin do Claude Code (recomendado)

/plugin marketplace add forrestchang/andrej-karpathy-skills
/plugin install andrej-karpathy-skills@karpathy-skills

CLAUDE.md por projeto

# projeto novo
curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

# projeto existente (acrescenta ao final)
echo "" >> CLAUDE.md
curl https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md >> CLAUDE.md

No Windows, use o curl do Git Bash ou baixe o arquivo pelo navegador.

Comandos e uso

Não há comandos: os princípios valem em toda conversa. Sinais de que está funcionando: diffs só com o que foi pedido, menos reescritas por complicação, perguntas antes de implementar e PRs pequenos.

Combine com regras do seu projeto no mesmo CLAUDE.md:

## Project-Specific Guidelines

- Use TypeScript strict mode
- All API endpoints must have tests

Quando usar

  • O Claude Code está criando abstrações e arquivos demais ou mexendo em código que não devia.
  • Você quer um conjunto curto de regras de comportamento, sem plugin pesado.

Observações

  • As regras favorecem cautela sobre velocidade; em tarefas triviais, use bom senso.
  • Proposta parecida com o Ponytail, mais focado em escrever o mínimo de código.
