Claude Drawing Skill

Skill do Claude Code que pinta com código, sem modelo de imagem: 83 estilos (aquarela, nanquim, quadrinho, planta técnica, pixel art e outros) em Python puro, com o desenho salvo etapa por etapa.

O que é

Uma skill para o Claude Code com uma pequena biblioteca de pintura: o Claude cria ilustrações escrevendo código em Python, usando só numpy + Pillow na CPU. Não usa modelo de geração de imagem, chave de API nem GPU.

O Claude planeja a composição, escreve um roteiro curto da cena, renderiza, olha o resultado e corrige seguindo uma lista de defeitos típicos de cada estilo, geralmente em 2 a 4 rodadas. Como cada etapa pode ser salva, dá para gerar o "desenho se formando", e o repositório traz 91 GIFs desse processo.

Os 83 estilos estão em oito famílias: tinta e pintura, lápis e pastel, livros ilustrados, gravura e pôster, papel/linha/argila, antigo e histórico, telas e tecnologia retrô, e 3D/interfaces/diagramas.

Principais recursos

  • 83 estilos, entre eles: nanquim (sumi-e), aquarela, óleo com empaste, guache, lápis de cor, giz de cera, anime, quadrinho da era de ouro, ukiyo-e, linoleogravura, cianotipia, Bauhaus, Art Déco, planta técnica, colagem, bordado, vitral, pixel art, synthwave, VHS, isométrico e quadro-negro.
  • Mesma semente gera a mesma imagem (determinístico).
  • Roda offline, só na CPU.
  • Cada etapa salva em disco, para animações "desenhando".
  • Checklist de defeitos por estilo, que o Claude revisa antes de entregar.
  • Um exemplo executável por estilo.

Pré-requisitos

  • Claude Code.
  • Python 3 com numpy e Pillow.
  • Para títulos em chinês, uma fonte CJK (achada automaticamente, ou indicada em INKPAINT_FONT).

Instalação

git clone https://github.com/cloveric/claude-drawing-skill.git ~/.claude/skills/claude-drawing
pip install -r ~/.claude/skills/claude-drawing/requirements.txt   # numpy, Pillow

Windows: clone em %USERPROFILE%\.claude\skills\claude-drawing.

Comandos e uso

Peça ao Claude com frases como:

draw it yourself
paint this with code
claude绘图

E diga o estilo, se quiser (por exemplo, "uma aquarela de um farol ao entardecer").

Rodar um exemplo direto:

cd ~/.claude/skills/claude-drawing
python3 examples/moon_river.py out.png --stages stages/   # nanquim, salvando cada etapa
python3 examples/<name>.py out.png                        # um exemplo por estilo

Quando usar

  • Ilustrações para posts, apresentações e sites sem usar gerador de imagem.
  • Imagens reproduzíveis (mesma semente, mesmo resultado).
  • Vídeos ou GIFs de "desenho sendo feito" a partir das etapas salvas.

Observações

  • README e parte da documentação em inglês e chinês.
  • A galeria completa tem cerca de 57 MB e os GIFs cerca de 104 MB: o clone fica pesado.
  • A animação traço a traço (exportar cada pincelada para Motion Canvas ou Remotion) ainda está no roadmap. Hoje a animação vem das etapas salvas.
  • Relacionados no catálogo: o Anidoodle também desenha em código e com o processo animado, mas em JavaScript/TypeScript, com vídeo, música e páginas interativas; o Huashu Art Motion foca em estilos de pintura em movimento.
