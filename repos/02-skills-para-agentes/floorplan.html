Floorplan

Plugin para Claude Code e Codex que lê o código do seu app e desenha um mapa interativo em português simples (partes, arquivos, telas, endpoints e conexões, mesmo entre repositórios), com perguntas ao mapa, checagem de segurança de apps feitos com IA e destaque do que o agente acabou de mudar.

O que é

O Floorplan ("planta baixa") é para quem construiu um app com ajuda de IA, ele funciona, mas não sabe responder "o que acontece quando alguém finaliza a compra?" ou "o que quebra se eu mudar isto?".

Você pede um floorplan ao Claude Code ou ao Codex. Scripts em Node (sem dependências) varrem os arquivos, imports, rotas e requisições e ligam cada chamada do frontend ao endpoint do backend que responde. Depois o agente dá nome às partes e descreve cada arquivo em linguagem simples. O resultado é floorplan/index.html, um mapa com zoom que abre no navegador.

Também funciona antes de existir código: a partir de um PRD ou especificação, gera uma "blueprint" do que seria preciso construir.

Principais recursos

  • Mapa com zoom: do app inteiro até partes, grupos de arquivos, arquivos e endpoints, mostrando quem usa e o que é usado.
  • Linguagem simples: "recebe pagamentos com cartão no checkout" em vez de "wrapper da API do Stripe", com uma chave para a visão técnica.
  • Conexões reais entre repositórios: liga requisições do frontend aos endpoints do servidor, mesmo em repos separados.
  • Começar por uma tela: escolha uma página e veja tudo que está por trás dela, até o banco e os serviços externos.
  • Pergunte ao mapa: "como um reembolso chega ao cartão do cliente?" vira uma resposta com um mini-mapa e o passo a passo.
  • Health check: chaves no código ou enviadas ao navegador, tabelas do Supabase abertas, regras do Firebase abertas, webhooks do Stripe que dá para falsificar e endpoints sem login. Cada problema vem com um prompt de correção. É uma checagem, não uma auditoria.
  • Trabalho recente: destaca em verde o que o agente acabou de mudar e por quê.
  • Atualização incremental: relê só o que mudou.
  • Extras: fluxos guiados, tour "Start here", exportação num único HTML, versão para celular, busca e atalhos.
  • Linguagens: TypeScript, JavaScript, Python, Go, Rust, Java, Kotlin, Swift, C#, PHP e outras, com dezenas de frameworks de backend e de telas (Next.js, Express, FastAPI, Django, Laravel, Supabase Edge Functions etc.).

Pré-requisitos

  • Node.js 18+.
  • Claude Code ou Codex, no plano que você já tem (sem chave de API).
  • Recomendado: Claude Code CLI, para a barra de perguntas do mapa ler o código real.

Instalação

Claude Code

claude plugin marketplace add haydenschmitty/floorplan
claude plugin install floorplan@floorplan

Abra uma sessão nova.

Codex

No app: Plugins → Add a marketplace, informe haydenschmitty/floorplan e instale o Floorplan. Ou pelo terminal:

codex plugin marketplace add haydenschmitty/floorplan
codex plugin add floorplan@floorplan

Comandos e uso

Abra o projeto (ou a pasta que contém frontend e backend) e peça:

Make me a floorplan of this app.
Update the floorplan.
Fix the important issues from the floorplan's Health check
Add a flow showing how a new user signs up
Export the floorplan so I can send it to the team
Here's my PRD. Make me a floorplan of what we'd need to build.

No Codex, também dá para digitar $floorplan. Na barra de perguntas do mapa:

What happens when someone places an order?
If I change the users table, what breaks?
Which files handle login?

Para renomear partes, peça ao agente ou edite floorplan/architecture.json e floorplan/descriptions/; as edições são mantidas nas atualizações.

Quando usar

  • Entender um app feito com IA sem ler o código.
  • Integrar alguém novo no projeto em minutos.
  • Conferir o que o agente mudou depois de cada tarefa.
  • Fazer uma checagem rápida dos erros de segurança mais comuns em apps feitos com IA.
  • Planejar a arquitetura de um app a partir do PRD.

Observações

  • Não altera o seu código nem faz commit: cria só a pasta floorplan/, que se ignora no git, e, no Claude Code, se você aceitar, uma seção no CLAUDE.local.md.
  • Privacidade: o mapa e o servidor local rodam na sua máquina. O código é lido pelo agente pela sua conta, como em qualquer tarefa. O único envio do Floorplan é o seu e-mail, e só se você entrar na lista de espera do Floorplan Cloud.
  • Seguro de instalar: sem hooks, sem servidores MCP, sem dependências e sem downloads. Cada release traz checksums dos arquivos.
  • Custo: o primeiro mapa usa o seu plano e leva alguns minutos num app pequeno, mais num grande.
  • Health check não substitui auditoria. Para segurança mais a fundo, use as ferramentas da categoria Segurança do catálogo.
  • Relacionados no catálogo: o Archify desenha diagramas bonitos de qualquer coisa, para apresentar. O Graphify gera um grafo de conhecimento do código. O Floorplan mapeia o app que você construiu, em linguagem simples, com riscos e mudanças recentes.
