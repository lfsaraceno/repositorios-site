O que é

O Antigravity Skill Vault transforma o ecossistema de agentes e comandos do Claude Code em skills no formato do Google Antigravity. Cada skill é uma pasta com instruções que ensinam o agente a executar uma tarefa específica, como gerar manifestos Kubernetes, desenhar uma API REST ou revisar segurança.

As skills vêm de três origens: skills de domínio (ex.: k8s-manifest-generator), agentes especialistas (ex.: backend-architect, security-auditor) e comandos/fluxos de trabalho em várias etapas (ex.: conductor-implement). O Antigravity carrega apenas nome e descrição de cada skill instalada no início da sessão e ativa a skill quando seu pedido combina com a descrição.

Por isso o projeto recomenda instalação seletiva: quanto mais skills instaladas, mais tokens gastos e maior a chance de ativações irrelevantes. Há um catálogo gerado (CATALOG.md, catalog.json), pacotes temáticos (bundles) e um CLI via npm para buscar e instalar.

Principais recursos

  • Mais de 300 skills em desenvolvimento, infraestrutura, segurança, qualidade, dados e IA.
  • CLI em npm (@rmyndharis/antigravity-skills) com search, list, install, installed, update, doctor e stats.
  • Instalação por skill, por tag (--tag) ou por bundle (--bundle): core-dev, security-core, k8s-core, data-core, ops-core.
  • Escopo de workspace (.agent/skills/) ou global (--global, ~/.gemini/antigravity/skills/), com override pela variável AG_SKILLS_DIR.
  • Skill gerenciadora antigravity-skills-manager, invocável com /antigravity-skills-manager.
  • Aliases curtos (aliases.json) para nomes longos de skills.
  • Instalação não sobrescreve skill existente, a menos que use --force.

Pré-requisitos

  • Node.js e npm (o README exige, sem citar versão mínima).
  • Google Antigravity (IDE, app ou CLI agy) para usar as skills.

Instalação

Instale a skill gerenciadora e verifique:

npx @rmyndharis/antigravity-skills install antigravity-skills-manager
npx @rmyndharis/antigravity-skills doctor
npx @rmyndharis/antigravity-skills installed

Depois, inicie uma nova sessão do Antigravity.

Para instalar o executável ag-skills globalmente no PATH:

npm install --global @rmyndharis/antigravity-skills
ag-skills install antigravity-skills-manager

Para escolher outro diretório de destino:

AG_SKILLS_DIR=.agents/skills npx @rmyndharis/antigravity-skills install bash-pro

O README também descreve a instalação via agy plugin install (marcada como experimental) e o uso a partir de um clone do repositório (node /caminho/absoluto/antigravity-skills/bin/cli.js ...).

Comandos e uso

npx @rmyndharis/antigravity-skills search kubernetes      # busca skills por termo
npx @rmyndharis/antigravity-skills list                   # lista todas as skills
npx @rmyndharis/antigravity-skills install bash-pro       # instala uma skill no projeto atual
npx @rmyndharis/antigravity-skills install bash-pro --global   # instala no escopo global
npx @rmyndharis/antigravity-skills install --tag kubernetes    # instala por tag
npx @rmyndharis/antigravity-skills install --bundle core-dev   # instala um bundle
npx @rmyndharis/antigravity-skills update                 # atualiza todas as skills instaladas
npx @rmyndharis/antigravity-skills doctor                 # diagnostica a instalação

Exemplos de pedidos que ativam skills automaticamente:

  • "Help me design a REST API for a user service" ativa api-design-principles e backend-architect.
  • "Review this PR for security issues" ativa security-scanning-security-hardening ou security-auditor.

Quando usar

  • Você usa o Google Antigravity e quer skills prontas de arquitetura, DevOps e segurança.
  • Quer instalar apenas pacotes temáticos (ex.: Kubernetes) em vez de carregar tudo.
  • Precisa de fluxos estruturados de várias etapas, como o Conductor.

Observações

  • install --all é desaconselhado: aumenta o uso de tokens e pode disparar skills não relacionadas.
  • update e install --force substituem a pasta da skill inteira e descartam edições locais. Faça backup antes.
  • O destino padrão atual é .agents/skills/; o caminho .agent/skills/ é mantido por compatibilidade.
