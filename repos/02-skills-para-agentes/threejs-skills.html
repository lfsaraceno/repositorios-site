O que é

O Claude conhece three.js pelo treino, que mistura muitas versões. Entre a r160 e a r186 muita coisa mudou: RGBELoader virou HDRLoader, Clock deu lugar a Timer, PostProcessing virou RenderPipeline, o WebGL 1 saiu, e a documentação agora recomenda WebGPURenderer com TSL para shaders e materiais próprios.

Estas skills dão ao agente a API atual, exemplos que funcionam e uma lista de "erros comuns" com os padrões antigos que os modelos ainda usam. Elas miram three.js r186 (three@0.186), React Three Fiber 9.8 com drei 10.7 e gltf-transform 4.5.

Cada skill tem um início rápido executável, as seções do tema, uma seção de WebGPU e TSL e a lista de erros comuns. Os imports, classes, comandos e flags foram conferidos contra os pacotes publicados.

Principais recursos

  • threejs-fundamentals: cena, câmeras, renderer, loop de animação, hierarquia e transformações.
  • threejs-geometry: formas, BufferGeometry, merge, instancing, BatchedMesh, pontos e linhas.
  • threejs-materials e threejs-shaders: tipos de material, PBR, blending, ShaderMaterial, TSL e node materials.
  • threejs-lighting e threejs-textures: luzes com unidades físicas, sombras, HDR, espaços de cor, render targets.
  • threejs-animation: keyframes, animation mixer, animação esquelética e morph.
  • threejs-loaders e threejs-asset-pipeline: glTF com Draco, meshopt e KTX2, e compressão com gltf-transform.
  • threejs-postprocessing, threejs-interaction e threejs-performance: efeitos, raycasting, controles, draw calls e memória de GPU.
  • threejs-react-three-fiber: R3F 9 com um conjunto verificado de helpers do drei.

Pré-requisitos

  • Claude Code (ou outro agente compatível com skills).
  • Node (npx) para a instalação via CLI.

Instalação

npx skills add cloudai-x/threejs-skills

Ou manualmente:

git clone https://github.com/CloudAI-X/threejs-skills.git
mkdir -p ~/.claude/skills && cp -r threejs-skills/skills/* ~/.claude/skills/   # todos os projetos
mkdir -p .claude/skills && cp -r threejs-skills/skills/* .claude/skills/       # só um projeto (na raiz dele)

Windows: copie threejs-skills\skills\* para %USERPROFILE%\.claude\skills\.

Comandos e uso

As skills carregam sozinhas conforme o pedido:

"Create a 3D scene with orbit controls"     → threejs-fundamentals, threejs-interaction
"Add lights and shadows"                     → threejs-lighting
"Load this glTF model"                       → threejs-loaders
"Write a custom shader for a water effect"   → threejs-shaders, threejs-postprocessing
"This scene is slow, make it faster"         → threejs-performance
"Build the scene with React"                 → threejs-react-three-fiber
"Shrink this glTF before shipping"           → threejs-asset-pipeline

Quando usar

  • Qualquer projeto three.js ou React Three Fiber feito com agente, para evitar código de versões antigas.
  • Cenas 3D em sites, configuradores de produto e visualizações.
  • Animações 3D renderizadas em vídeo (three.js dentro do Remotion ou do HyperFrames).

Observações

  • As skills são atreladas à r186. Em versões bem mais novas do three.js, algumas partes podem ficar desatualizadas; o autor pede issues com o nome da skill, a linha e a versão.
  • Relacionados no catálogo: o WebGL Animation Skills foca em animação 3D (cenas, shaders GLSL, partículas), enquanto estas cobrem a API do three.js de forma ampla; o Claude Animated Shorts usa three.js dentro do Remotion.
