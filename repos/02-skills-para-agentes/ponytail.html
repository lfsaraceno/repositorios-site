Ponytail

Skill que faz o agente de IA agir como o dev sênior mais preguiçoso da sala: reaproveita o que já existe e escreve o mínimo de código, sem cortar validação, segurança, tratamento de erro nem acessibilidade; inclui revisão, auditoria e painel de custo.

O que é

O Ponytail é um prompt (skills/ponytail/SKILL.md) que coloca no agente o comportamento do veterano que troca 50 linhas por uma. Antes de escrever, ele lê o código afetado e segue uma escada: a funcionalidade precisa existir? já existe no projeto? na biblioteca padrão? numa dependência instalada? cabe numa linha? Só então escreve o mínimo.

A regra não é "menos tokens": é escrever só o que a tarefa precisa, sem nunca cortar validação em fronteiras de confiança, tratamento de erro que evita perda de dados, segurança e acessibilidade. Lógica com desvio, loop, parser, dinheiro ou segurança ganha um teste pequeno. Toda resposta termina dizendo o que foi pulado e os riscos.

No benchmark do autor (39 tarefas no Claude Code, Opus 5.5, 5 execuções cada), a versão 5 gerou 53% menos código, 41% menos tempo, 26% menos custo e 45% menos tokens, com 98% da lógica arriscada acompanhada de teste (contra 68% sem a skill).

Principais recursos

  • Níveis lite, full (padrão) e ultra, ativos em toda sessão.
  • /ponytail-review: revisão como o dev que é acionado quando quebra: bugs, segurança, carga real, código arriscado sem teste, lentidão e o que cortar.
  • /ponytail-audit: a mesma checagem no repositório inteiro, priorizada.
  • /ponytail-debt: junta os comentários shortcut: (atalhos deliberados) num registro de dívida.
  • Band (Claude Code 2.1.290+): faixa acima do prompt com custo, tokens e tempo da tarefa, reaproveitamento de código e status dos testes; Board local com histórico por projeto.
  • Funciona em Claude Code, Codex, Devin CLI, OpenCode, Gemini, Antigravity, Cursor, Copilot, Windsurf, Cline e outros (via AGENTS.md).

Pré-requisitos

  • Um agente de programação. A band exige Claude Code 2.1.290+ no terminal ou no app desktop.

Instalação

Claude Code (dois prompts separados)

/plugin marketplace add DietrichGebert/ponytail

/plugin install ponytail@ponytail

Codex

codex plugin marketplace add DietrichGebert/ponytail
codex plugin add ponytail@ponytail

Depois abra /hooks no Codex, confie nos dois hooks e inicie uma nova thread.

Outros agentes

Copie o AGENTS.md para o projeto ou peça ao agente para instalar o SKILL.md como skill. Passo a passo em INSTALL.md.

Comandos e uso

/ponytail [lite | full | ultra | off]   # muda a intensidade ou desliga
/ponytail band [on | off]               # mostra/esconde a band (Claude Code)
/ponytail band import                   # importa sessões antigas para o board
/ponytail-review                        # revisa o diff atual (ou: uncommitted, staged, branch, link de PR)
/ponytail-audit                         # audita o repositório inteiro
/ponytail-debt                          # lista os atalhos deliberados (shortcut:)
/ponytail-gain                          # mostra o placar do benchmark
/ponytail-help                          # referência rápida

No Codex, os comandos são skills do plugin: $ponytail:ponytail-review. Nível padrão opcional em ~/.config/ponytail/config.json ou na variável PONYTAIL_DEFAULT_MODE.

Quando usar

  • O agente instala bibliotecas ou cria abstrações demais para tarefas simples.
  • Reduzir custo e tempo de sessões longas mantendo testes nas partes críticas.
  • Revisar um PR ou auditar um repositório com foco em risco real.

Observações

  • Instale só do repositório DietrichGebert/ponytail ou do pacote npm @dietrichgebert/ponytail; o projeto nunca distribui .exe ou .dll, e cópias que distribuem não são oficiais.
  • A band não aparece no painel de chat do VS Code, em sessões na nuvem nem com claude -p.
  • Os dados da band ficam locais, em ~/.config/ponytail/band/.
  • Os números de economia são do benchmark do próprio autor.
  • Proposta parecida, em formato de CLAUDE.md: Karpathy Skills.
