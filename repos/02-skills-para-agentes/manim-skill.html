O que é

Uma coleção de boas práticas, padrões e exemplos para o agente escrever animações com o Manim, o motor de animação matemática criado por Grant Sanderson para o canal 3Blue1Brown. São duas skills, uma para cada versão do Manim:

  • manimce-best-practices: Manim Community Edition (manim, from manim import *), mantido pela comunidade, estável e bem documentado.
  • manimgl-best-practices: ManimGL (manimgl, from manimlib import *), a versão original do 3Blue1Brown, com renderização OpenGL, 3D e modo interativo.

As duas versões são incompatíveis entre si, e o repositório explica as diferenças. Cada regra traz exemplos de código testados por uma suíte de testes própria.

Principais recursos

  • Regras por tema: cenas, animações, objetos (mobjects), cores, texto e LaTeX, câmera, 3D e modo interativo.
  • Exemplos de código testados automaticamente.
  • Tabela de diferenças entre Manim Community e ManimGL.
  • Ativação automática quando o código importa manim ou manimlib.
  • Seção de solução de problemas (LaTeX, vídeo que não toca, versões em conflito).

Pré-requisitos

  • Python 3.7+.
  • FFmpeg.
  • LaTeX (TeX Live, MiKTeX ou MacTeX), para fórmulas.
  • O Manim em si: pip install manim ou pip install manimgl.

Instalação

As skills

npx skills add adithya-s-k/manim_skill                                         # as duas
npx skills add adithya-s-k/manim_skill/skills/manimce-best-practices           # só Manim Community
npx skills add adithya-s-k/manim_skill/skills/manimgl-best-practices           # só ManimGL

O Manim

pip install manim       # Manim Community Edition
pip install manimgl     # ManimGL
manim --version         # confere a instalação

Windows: instale o FFmpeg (por exemplo, winget install --id Gyan.FFmpeg -e) e o MiKTeX.

Comandos e uso

Peça ao agente uma animação; a skill entra quando o código usa o Manim:

Make a 3Blue1Brown-style animation showing the Pythagorean theorem proof

Renderizar uma cena:

manim -pql scene.py BasicExample            # Manim Community: -p abre a prévia, -ql qualidade baixa (-qm, -qh)
manimgl scene.py BasicExample --write_file  # ManimGL: salva o vídeo

Quando usar

  • Vídeos de matemática, física e computação com fórmulas e gráficos animados.
  • Explicar um artigo científico ou um algoritmo visualmente.
  • Material de aula e vídeos educativos.

Observações

  • O repositório não recebe atualizações desde jan/2026, mas o Manim muda pouco nas APIs cobertas.
  • O LaTeX completo é pesado (o texlive-full passa de vários GB). Sem ele, fórmulas não renderizam.
  • Há outras skills de Manim, como Yusuke710/manim-skill e iart-ai/manim-skills.
  • Relacionados no catálogo: o Huashu Art Motion tem uma gramática "3Blue1Brown" sem Manim, feita em Canvas; o Whiteboard Video faz explicativos de quadro branco narrados.
