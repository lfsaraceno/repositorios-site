O que é

Uma skill para o Claude Code que produz vídeos explicativos no estilo "quadro branco": um marcador desenha cada cena traço por traço, sincronizado com a narração, o quadro desliza para a próxima ideia e as legendas correm na parte de baixo.

O fluxo tem quatro etapas: a skill pergunta tema, público, duração, formato e idioma; escreve o roteiro cena a cena, com os fatos de cada afirmação conferidos em duas fontes, e espera sua aprovação; deixa você escolher a voz ouvindo a mesma frase em várias opções; e por fim desenha as cenas em SVG, gera prévias e renderiza o MP4.

Tudo roda na sua máquina: um Chrome sem interface desenha os quadros e o FFmpeg monta o vídeo, em qualidade de master para upload (x264 CRF 10, BT.709, AAC 320k).

Principais recursos

  • Roteiro com checagem de fatos em duas fontes, aprovado por você antes de desenhar.
  • Desenho sincronizado com cada frase da narração ("desenhe a moeda na metade da segunda frase").
  • Vozes: macOS Premium (grátis), ElevenLabs, OpenAI TTS ou gravações próprias.
  • Comparação de vozes antes de escolher.
  • Saída em 1080p, 16:9 ou 9:16 (vertical), com legendas embutidas.
  • API de desenho pequena (T para texto, P para caminhos, linhas, setas, círculos, ícones).
  • Pode ser usada sem o Claude, pelos scripts.

Pré-requisitos

  • Claude Code.
  • Node 18+, Python 3.9+, ffmpeg e Google Chrome (ou Chromium/Edge).
  • Opcional: ELEVENLABS_API_KEY ou OPENAI_API_KEY no .env do projeto, para vozes dessas plataformas.

Instalação

git clone https://github.com/Matteoikarieth96/whiteboard-video-skill ~/.claude/skills/whiteboard-video
cd ~/.claude/skills/whiteboard-video/scripts && npm install
brew install ffmpeg   # macOS; em outros sistemas, use o gerenciador de pacotes

Windows: clone em %USERPROFILE%\.claude\skills\whiteboard-video e instale o ffmpeg com winget install --id Gyan.FFmpeg -e. O script new_project.sh é shell: rode pelo Git Bash.

Comandos e uso

No Claude Code, peça em linguagem natural:

Make a 60-second whiteboard video explaining how interest rates affect mortgages, for first-time buyers.

Sem o Claude, pelos scripts:

S=~/.claude/skills/whiteboard-video/scripts
$S/new_project.sh my-video              # cria o projeto (ou --vertical para 1080x1920)
# edite my-video/script.json (o que é dito) e my-video/scenes.js (o que é desenhado)
python3 $S/make_audio.py my-video       # gera a narração e o tempo exato de cada frase
node $S/render.js my-video sheet        # um PNG por cena + previews/sheet.png com todas
node $S/render.js my-video full         # renderiza my-video/out/my-video.mp4

Comparar vozes antes de escolher:

python3 $S/make_audio.py my-video --samples "A sentence from your script." \
  --voices "say:Ava (Premium):185" "say:Samantha:190"

Quando usar

  • Explicar um conceito (finanças, produto, notícia) num vídeo curto narrado.
  • Transformar um artigo, roteiro ou apresentação em vídeo de quadro branco.
  • Fazer versões verticais para Reels, Shorts e TikTok.

Observações

  • Projeto pequeno e recente (criado em set/2026), de um único autor.
  • As vozes grátis (say) só existem no macOS. No Windows e no Linux, use ElevenLabs, OpenAI TTS ou suas próprias gravações (um arquivo de áudio por frase em audio/).
  • As chaves de API ficam num .env local, ignorado pelo git.
  • Há outra skill de quadro branco mais popular, a gnipbao/codex-whiteboard-video-skill, mas ela é feita para o Codex.
  • Relacionados no catálogo: o Huashu Art Motion tem uma gramática de "quadro branco" entre seus estilos de vídeo explicativo; o Anidoodle também gera explicativos desenhados, em 32 estilos.
