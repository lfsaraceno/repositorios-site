Archify

Skill para agentes de IA que transforma uma ideia, um plano ou um repositório em diagrama interativo num único arquivo HTML: arquitetura, fluxos, sequência, ERD, linha do tempo e páginas explicativas, com validação antes da entrega.

O que é

O Archify é uma skill para Claude Code, Codex, Cursor e OpenCode. Você descreve um sistema, um processo ou até um roteiro de viagem, e o agente gera um diagrama interativo em HTML. Também pode pedir que ele leia o repositório e desenhe a arquitetura com base no código, com links para os arquivos e linhas de origem.

Por trás, o agente escreve uma representação intermediária em JSON tipado. Validadores do Archify checam o esquema, o layout, o HTML/SVG, as rotas e o espaço entre rótulos e setas antes de gerar o arquivo final. Se algo falha, o validador devolve em JSON o erro exato e as correções permitidas, e o arquivo anterior que funcionava é preservado.

O resultado é um HTML autocontido: você abre no navegador, explora os nós, segue caminhos e manda o arquivo para outra pessoa sem instalar nada. Também exporta PNG, WebP, JPG, PDF e cards de compartilhamento.

Principais recursos

  • 10 tipos de diagrama: arquitetura, workflow, sequência, fluxo de dados, ciclo de vida (estados), ERD, classes, árvore, linha do tempo e waterfall.
  • Páginas explicativas (explainer): responde uma pergunta numa página só, com a conclusão primeiro, um painel por questão, tabelas, passos, gráficos e diagramas, com fontes numeradas.
  • Diagrama a partir do código: nós marcados com SRC n abrem trechos do repositório fixados num commit público.
  • Exploração interativa: focar um nó, rastrear dependências acima e abaixo, traçar a rota entre dois nós, comparar papéis, minimapa, modo apresentação, temas claro/escuro e quatro estilos visuais.
  • Architecture Delta: compara o antes e o depois de uma arquitetura para revisão de design ou PR.
  • Iteração por conversa: "add Redis", "move auth to the left", "highlight the rollback path"; o agente altera só o necessário.
  • Prévia ao vivo opcional: observa um JSON e recarrega só quando a nova versão passa em todas as checagens.
  • Idiomas da interface: inglês, chinês simplificado e tradicional, espanhol, coreano e árabe embutidos; outros via catálogo de tradução (o conteúdo do diagrama fica no idioma em que você escreveu).

Pré-requisitos

  • Um agente compatível: Claude Code, Codex CLI, Cursor ou OpenCode (há integrações da comunidade para Hermes Agent e DeepSeek Harness).
  • Node.js para o renderizador e os validadores (a integração com o Hermes pede Node 18 ou mais novo).

Instalação

Pedindo ao agente

Install Archify for me by reading https://raw.githubusercontent.com/tt-a1i/archify/main/llms.txt

Skills CLI

# Cursor, instalação global e não interativa
npx -y skills@latest add https://archify.si --skill archify --agent cursor --global --copy --yes

# testar sem instalar (Codex)
npx skills use tt-a1i/archify@archify --agent codex

O seletor de agente gera o comando para cursor, codex, claude-code e opencode.

Comandos e uso

Exemplos de prompt:

Use Archify to draw: Browser -> API -> Redis cache -> PostgreSQL fallback.

Analyze this repository, then use archify to create a high-level runtime architecture diagram.
Show 8–12 core components, one primary path, external dependencies, and trust boundaries.

Use Archify to answer as one page: our API's P99 went from 80 ms to 600 ms
while the mean barely moved. What is the likely cause, and how should we investigate?

CLI do repositório (sem dependências):

cd archify
node bin/archify.mjs doctor                                     # verifica o ambiente
node bin/archify.mjs guide "Show an API request with Redis cache miss"   # sugere o tipo de diagrama
node bin/archify.mjs validate workflow examples/agent-tool-call.workflow.json --quality showcase --json   # valida o JSON
node bin/archify.mjs preview workflow examples/agent-tool-call.workflow.json /tmp/workflow.html --quality showcase   # prévia ao vivo
node bin/archify.mjs deliver workflow examples/agent-tool-call.workflow.json /tmp/workflow.html --quality showcase --open --json   # gera e abre
node archify/bin/archify.mjs compare architecture base.json head.json architecture-delta.html --json   # Architecture Delta

Atalhos no HTML gerado: ? guia, / buscar nó, R rota, L comparar papéis, M minimapa, F apresentação, S estilo, T tema, E exportar.

Quando usar

  • Documentar ou entender a arquitetura de um repositório desconhecido.
  • Explicar um fluxo (cache miss, autenticação, CI/CD, incidente) para o time ou num PR.
  • Responder uma pergunta técnica com uma página visual compartilhável.
  • Planejar coisas fora do código (roteiros, mapas de estudo) em HTML interativo.

Observações

  • Checagem de atualização: a skill pode consultar um manifesto fixo no site cerca de uma vez por dia só para avisar de versão nova; nunca instala nada sozinha. Para desligar: ARCHIFY_UPDATE_CHECK_DISABLED=1.
  • Instalação por llms.txt: o método recomendado manda o agente ler instruções de uma URL externa e segui-las. Leia o arquivo antes, ou use o comando npx skills explícito.
  • Patrocinadores no README: o README divulga revendedores de API de modelos com preços muito abaixo dos oficiais. Eles não fazem parte do Archify; avalie termos de uso e privacidade antes de usar esse tipo de serviço.
  • Fora do escopo atual: importar Mermaid, auto-layout genérico, hospedagem e edição WYSIWYG.
  • Diferença para o Graphify: o Graphify monta um grafo de conhecimento consultável do código para o agente usar; o Archify gera diagramas visuais para pessoas lerem e compartilharem.
