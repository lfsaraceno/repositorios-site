Founder Skill

Onze skills para Claude que testam um negócio antes do lançamento: conselho com frameworks de Hormozi, Thiel e Jobs, concorrentes, painel com 100 compradores simulados, preço, oferta, CFO, marketing, marca, operações, lançamento e plano de negócios com veredito calculado.

O que é

Um conjunto de skills que funciona como uma equipe de executivos para quem vai abrir um negócio. Você descreve a ideia, e cada skill faz o papel de um cargo: conselho de administração, pesquisa de concorrência, painel de consumidores, estrategista de preço, arquiteto de oferta, CFO, diretor de marketing, designer de marca, gerente de operações, líder de lançamento e planejador.

As skills rodam em sequência e compartilham arquivos numa pasta founder/ dentro do projeto: cada uma lê o que as anteriores escreveram. No fim, /founder-plan compila um plano de negócios com um veredito calculado a partir dos números (Profitable, Not yet ou Incomplete), não escrito livremente pelo modelo.

O destaque é o painel de consumidores: ele cria 100 agentes compradores a partir do seu cliente-alvo, cada um com renda, hábitos e objeções próprios, e apura quem compra, quem não compra e por quê. Quatro ferramentas em Python puro (sem rede, sem pip install) fazem as contas de unidade econômica, preço e veredito.

Principais recursos

  • Conselho (/founder-board): três subagentes aplicam frameworks publicados ($100M Offers, Zero to One e a biografia de Steve Jobs), dão nota, apontam o que mataria a ideia e votam.
  • Concorrentes (/founder-competitors): diretos, indiretos e substitutos, com preços, posicionamento e reclamações dos clientes, tudo com link para a fonte pública.
  • Painel de consumidores (/founder-consumer): 100 compradores simulados por padrão, com as razões nas palavras deles e o que viraria um "não".
  • Preço e oferta: faixa de preço aceitável pelo método Van Westendorp, comparada com concorrentes e margem; pacote de oferta (bônus, garantia, urgência real) retestado no painel.
  • CFO (/founder-cfo): contribuição por venda, margem real, ponto de equilíbrio por dia, ano 1 mês a mês, caixa necessário, payback e cenários.
  • Marketing, marca e operações: campanha de lançamento de 30 dias com datas, dez ganchos, custo máximo por cliente, nomes com checagens de marca e domínio, fornecedores, rotinas, licenças a verificar e registro de riscos.
  • Lançamento e plano: teste barato no mundo real primeiro, contagem regressiva, roteiro do dia do lançamento e plano de negócios final.

Pré-requisitos

  • Claude (Claude Code ou chat).
  • Python 3.8 ou mais novo para as ferramentas. Nada para instalar com pip.

Instalação

Colando o link no Claude

https://github.com/Jakeschincariol/founder-skill

install skill

Plugin do Claude Code

/plugin marketplace add Jakeschincariol/founder-skill
/plugin install founder-skill@founder-skill

Como plugin, os comandos ficam com prefixo: /founder-skill:founder-board etc.

Cópia manual (comandos sem prefixo)

git clone https://github.com/Jakeschincariol/founder-skill.git
cp -r founder-skill/skills/founder-* ~/.claude/skills/

No Windows (PowerShell), o equivalente da cópia é Copy-Item -Recurse founder-skill\skills\founder-* $HOME\.claude\skills\. Para instalar só num projeto, copie as pastas para .claude/skills/ do repositório. Sem Claude Code, dá para colar um SKILL.md no início de um chat, mas sem subagentes nem ferramentas Python.

Comandos e uso

Ordem recomendada:

board -> competitors -> consumer -> pricing -> offer -> cfo -> marketing -> brand -> ops -> launch -> plan

/founder-board          # registra a ideia em founder/idea.md e leva ao conselho
/founder-competitors    # mapeia concorrentes com preços e reclamações
/founder-consumer       # roda o painel de 100 compradores simulados
/founder-consumer --quick   # versão rápida, para uma ideia ainda vaga
/founder-pricing        # faixa de preço aceitável
/founder-offer          # monta a oferta e retesta no painel
/founder-cfo            # unidade econômica e ano 1
/founder-marketing      # posicionamento e campanha de 30 dias
/founder-brand          # nome, voz e briefing visual
/founder-ops            # fornecedores, rotinas, riscos
/founder-launch         # teste real, contagem regressiva, primeiros 30 dias
/founder-plan           # compila founder/business-plan.md com o veredito

Ferramentas Python (rodam sem rede):

python3 skills/founder-cfo/unit_economics.py founder/numbers.json --out founder/cfo.md   # margens, equilíbrio, ano 1
python3 skills/founder-consumer/panel.py init --customer founder/customer.json --pitch founder/pitch.md   # gera os cartões de comprador
python3 skills/founder-pricing/van_westendorp.py founder/panel/answers --price 6.50       # faixa de preço aceitável
python3 skills/founder-plan/compile.py --dir founder                                     # plano e veredito
python3 -m unittest discover -s tests -v                                                 # testes

O repositório traz um exemplo completo (uma cafeteria de matcha em Toronto) com todos os dados de entrada.

Quando usar

  • Validar uma ideia de negócio antes de gastar dinheiro com ela.
  • Montar a unidade econômica e o ponto de equilíbrio de um negócio físico ou digital.
  • Descobrir objeções e segmentos de cliente antes de escrever a oferta.
  • Produzir um plano de negócios completo a partir de uma conversa.

Observações

  • Compradores simulados não são clientes. Modelos de linguagem tendem a concordar, então trate a taxa de compra como teto e confirme com pessoas reais. As respostas do painel nunca devem virar depoimento.
  • O conselho aplica frameworks publicados, não é aquelas pessoas. O projeto não tem vínculo com Hormozi, Thiel ou Jobs.
  • Não é consultoria financeira, jurídica ou tributária. Os números valem o que valem as entradas; confira custos com fornecedores e impostos com um contador. As skills dizem o que verificar (licenças, marcas), mas no Brasil isso passa por um profissional local.
  • Exemplos e referências do projeto são em dólar e no contexto norte-americano.
  • Para marketing de produto digital em profundidade (CRO, SEO, anúncios, e-mails), as Marketing Skills cobrem muito mais; a Founder Skill foca em validar o negócio antes do lançamento.
