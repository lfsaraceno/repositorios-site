O que é

O Humanizer é uma skill para agentes de IA que edita textos para leitores humanos. Ela se baseia no guia da Wikipédia "Signs of AI writing", usado por editores para identificar texto gerado por IA, e funciona no Claude Code, no Codex e em outros agentes.

A ideia do README: um modelo de linguagem escolhe o que serve para o maior número de leitores e assuntos, enquanto uma pessoa escolhe para um leitor e um assunto. Cada "tell" que a skill procura é uma forma dessa escolha padrão. Ela marca os sinais encontrados (os mais fortes primeiro), escreve um rascunho sem tratar a estrutura original como fixa, confere o rascunho contra os padrões e as afirmações originais e entrega a versão final.

Ao colar um texto, a skill mostra o trabalho: a primeira reescrita, uma crítica curta do que ainda soa artificial e a versão final. Ao apontar um arquivo, ela altera só a prosa e preserva código, dados, frontmatter e destinos de links. Ela não inventa nomes, números, datas, citações ou fatos.

Principais recursos

  • 26 padrões de escrita de IA, numerados por força e frequência, em seis grupos: encenação em vez de afirmação, ritmo por regra, inflação e autoridade emprestada, formatação, restos do chat e do rascunho, e escrita para o leitor errado.
  • Os cinco sinais mais fortes: "não é X, é Y", fechamentos de uma linha, frases que parecem profundas, introduções encenadas e "argumentar com ninguém".
  • Casamento de voz: você cola 2 a 3 parágrafos seus e a reescrita segue ritmo, vocabulário e pontuação.
  • Edição de arquivos, mexendo só na prosa.
  • Funciona como plugin do Claude Code e via Skills CLI em vários agentes.

Pré-requisitos

  • Um agente compatível: Claude Code (plugin exige a versão 2.1.142 ou superior), Codex, Gemini CLI, GitHub Copilot, Windsurf, entre outros suportados pela Skills CLI.
  • Node.js, para usar npx skills.

Instalação

Claude Code

/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer

O plugin responde a /humanizer:humanizer. Em versões do Claude Code anteriores à 2.1.142, use o comando abaixo.

npx skills add blader/humanizer --global --agent claude-code

Codex

npx skills add blader/humanizer --global --agent codex

Claude.ai e Claude Desktop

Baixe o repositório em ZIP (Code, Download ZIP) e envie como skill em Configurações.

Outros agentes

npx skills add blader/humanizer --global --agent '*'

Instala para todos os agentes suportados pela Skills CLI. Sem --global, a instalação vale só para o projeto atual. Para um agente que a CLI não conhece, copie o SKILL.md para a pasta de skills dele. O README não traz variações específicas para Windows.

Comandos e uso

Depois de instalada, a skill responde a /humanizer.

/humanizer

[cole o texto aqui]

Please humanize this text: [seu texto]

Humanize the prose in docs/launch-post.md

Para casar com a sua voz, inclua uma amostra:

/humanizer

Here's a sample of my writing for voice matching:
[cole 2 a 3 parágrafos seus]

Now humanize this text:
[cole o texto da IA]

A skill foi escrita pensando em textos em inglês; para textos em português, teste com um trecho antes de aplicar em tudo.

Quando usar

  • Revisar posts, e-mails, documentação e README escritos com ajuda de IA que ficaram com cara de texto genérico.
  • Tirar vícios como "não é só X, é Y", fechamentos dramáticos, travessões em excesso, negrito decorativo e tom de vendedor.
  • Manter o seu estilo em textos longos, usando uma amostra da sua escrita.

Observações

  • O próprio README diz que o objetivo é editar para leitores humanos, não enganar detectores de IA; os detectores ainda sinalizam a maior parte da saída.
  • O README cita um teste cego em que juízes preferiram a reescrita 16 de 16 vezes (issue #229); é um resultado do autor, de amostra pequena.
  • Revise sempre o resultado: a skill promete não inventar fatos, mas a revisão final é sua.
  • O README menciona patrocínio (cfo.ai).
  • Repositório muito popular (~58k estrelas) e ativo (último push em out/2026).
