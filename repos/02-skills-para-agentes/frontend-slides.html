O que é

O Frontend Slides ajuda quem não é designer a fazer apresentações bonitas para a web sem saber CSS ou JavaScript. Em vez de pedir que você descreva o estilo, ele gera três prévias visuais (um preset seguro, um template ousado e uma opção curinga) e você escolhe.

O resultado é um único arquivo HTML, com CSS e JS embutidos, em 16:9 fixo e acessível. Também converte arquivos .pptx, mantendo textos, imagens e notas.

Principais recursos

  • Arquivo HTML único, sem npm, build nem framework.
  • Escolha de estilo por prévias visuais.
  • Conversão de PowerPoint para web.
  • 12 presets (temas escuros, claros e especiais, como Swiss Modern e Terminal Green).
  • 34 templates ousados do beautiful-html-templates.
  • Evita o visual genérico de IA (nada de gradiente roxo no branco).
  • Publicação na Vercel com um comando e exportação para PDF.

Pré-requisitos

  • Um agente de código com acesso a arquivos e terminal.
  • Para converter PowerPoint: Python com python-pptx.
  • Para publicar: Node.js e conta gratuita na Vercel.
  • Para PDF: Node.js (o Playwright é instalado sozinho).

Instalação

Claude Code (rode as duas linhas em mensagens separadas):

/plugin marketplace add https://github.com/zarazhangrui/frontend-slides

/plugin install frontend-slides@frontend-slides

Use a URL HTTPS: a forma curta zarazhangrui/frontend-slides pode fazer o Claude Code tentar SSH e falhar.

Instalação manual (sem prefixo no comando):

git clone https://github.com/zarazhangrui/frontend-slides.git ~/.claude/skills/frontend-slides

Em outros agentes (Codex, OpenCode, Gemini CLI), mande o link do repositório e peça para usar a skill a partir do SKILL.md.

Comandos e uso

/frontend-slides:frontend-slides
> "I want to create a pitch deck for my AI startup"

Na instalação manual, o comando é /frontend-slides. Para converter, peça "Convert my presentation.pptx to a web slideshow".

Para compartilhar:

bash scripts/deploy.sh ./presentation.html        # publica na Vercel
bash scripts/export-pdf.sh ./presentation.html ./output.pdf

Quando usar

  • Pitch decks, apresentações de produto e aulas com visual próprio.
  • Converter um .pptx antigo para uma apresentação web compartilhável por link.

Observações

  • O PDF é uma captura estática: as animações não vão junto.
  • Último commit em jun/2026.
  • Relacionados no catálogo: o Diagram Design faz os diagramas para colocar nos slides.
