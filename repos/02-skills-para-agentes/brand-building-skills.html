O que é

Uma coleção de skills de branding para agentes de IA, feita para estrategistas de marca, donos de agência e fundadores. Cada skill é um arquivo SKILL.md com um fluxo de trabalho de uma área (estratégia, naming, identidade, voz etc.), e o agente aciona a skill certa quando você pede uma tarefa de marca.

A base é a skill brand-context: ela coleta nome, público, posicionamento, valores e voz da marca e grava tudo em .agents/brand-context.md. Todas as outras skills leem esse arquivo antes de agir, e elas se referenciam entre si (por exemplo, brand-strategy ↔ brand-positioning ↔ brand-messaging, ou brand-audit → rebranding → brand-launch).

Segue o padrão Agent Skills, então funciona em Claude Code, Cursor, Windsurf e outros agentes compatíveis. Várias skills geram entregáveis de agência: relatório de estratégia a partir de um questionário, briefing de identidade visual para o designer, manual de marca e plano de lançamento.

Principais recursos

  • Fundação: brand-context (contexto da marca, lido por todas as outras).
  • Estratégia: brand-strategy (questionário + relatório completo), brand-naming (gera nomes com justificativa ou avalia opções existentes), brand-architecture (marca única, casa de marcas, endossada ou híbrida).
  • Identidade: brand-identity (briefing de logo, cores, tipografia), brand-story (história de origem em três tamanhos), brand-packaging (briefing de embalagem e unboxing).
  • Voz e mensagens: brand-voice, brand-messaging (taglines, proposta de valor, hierarquia de mensagens).
  • Público e posicionamento: target-audience (ICP e personas), brand-positioning, competitor-branding (mapa de como os concorrentes se posicionam).
  • Lançamento e transformação: brand-launch, rebranding.
  • Auditoria e padrões: brand-audit (saúde da marca em 6 dimensões), brand-guidelines (manual de marca), brand-measurement (KPIs de marca).
  • Marca pessoal e parcerias: personal-brand (plano de 90 dias), brand-manifesto, brand-partnerships, b2b-brand-marketing.
  • Canais de marketing: d2c-marketing, meta-ads, google-ads, email-marketing, whatsapp-marketing, ugc-strategy, influencer-marketing, aso.

Pré-requisitos

  • Um agente compatível com Agent Skills (Claude Code, Cursor, Windsurf etc.).
  • Node (npx) para a instalação via CLI.

Instalação

CLI (forma documentada no README)

npx skills add arnabbagxd/brand-building-skills

A CLI é a Vercel Skills CLI. Segundo o README, as skills vão para .agents/skills/. O Claude Code não lê essa pasta; se for o caso, passe o agente explicitamente com -a claude-code (opção da CLI, ver a ficha dela).

Plugin do Claude Code

O README só diz para apontar o projeto para o repositório ou copiar a pasta skills/. O repositório traz um .claude-plugin/marketplace.json (marketplace e plugin chamados brand-building-skills, com as 29 skills), então também funciona pelo mecanismo padrão de plugins do Claude Code:

/plugin marketplace add arnabbagxd/Brand-building-skills
/plugin install brand-building-skills@brand-building-skills

Cópia manual

Copie a pasta skills/ do repositório para a pasta de skills do seu agente (por exemplo, .claude/skills/ no Claude Code).

Comandos e uso

Comece sempre pelo contexto da marca:

Set brand context for [Brand Name] — [what it does], targeting [audience]

Depois peça a tarefa em linguagem natural; cada skill tem frases-gatilho na descrição:

"I have a new branding client"                 → brand-strategy (apresenta o questionário)
"Help me name this brand"                      → brand-naming (modo geração)
"Rank these names: Lumo, Brava, Nexo"          → brand-naming (modo avaliação)
"Audit our brand"                              → brand-audit
"Create brand guidelines"                      → brand-guidelines

Ou chame a skill direto pelo nome (/brand-context, /brand-positioning, /brand-launch etc.).

Fluxos sugeridos no README:

# marca do zero
brand-context → target-audience → competitor-branding → brand-positioning → brand-strategy
→ brand-naming → brand-identity → brand-voice → brand-messaging → brand-guidelines → brand-launch

# marca existente
brand-context → brand-audit → rebranding

# trabalho de agência
brand-strategy → brand-naming → brand-identity → brand-guidelines

Quando usar

  • Montar a estratégia, o nome e a identidade de uma marca nova antes de contratar um designer.
  • Entregar a um cliente de agência relatório de estratégia, briefing visual e manual de marca com estrutura padronizada.
  • Diagnosticar uma marca existente e planejar um rebranding.
  • Criar uma marca pessoal para fundador ou executivo.

Observações

  • Projeto pequeno e recente (criado em jun/2026), de um único autor, sem releases. A versão vem só do VERSIONS.md e do marketplace.json (1.2.0).
  • Os textos e os exemplos são em inglês. A skill whatsapp-marketing recomenda plataformas pensando na Índia e em mercados emergentes; as de influenciadores e UGC citam regras da FTC (EUA). Adapte para o Brasil (CONAR, LGPD).
  • Relacionados no catálogo: a Marketing Skills tem o mesmo modelo (arquivo de contexto + skills que se referenciam) e cobre mais marketing de SaaS (CRO, SEO, analytics), com sobreposição em aso, anúncios, e-mail e influenciadores. Esta coleção é mais forte em marca (naming, identidade, voz, manual). A Founder Skill tem só uma skill de marca (/founder-brand) dentro de um fluxo de validação de negócio.
