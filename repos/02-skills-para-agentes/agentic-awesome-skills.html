O que é

O Agentic Awesome Skills é uma biblioteca de mais de 2.700 skills instaláveis em formato SKILL.md. Seu núcleo, o AAS Core, ajuda o Codex ou o Claude a pesquisar o catálogo local completo, registrar as skills que o agente escolheu e gerar um plano que você pode inspecionar antes de alterar qualquer destino.

O Core não ranqueia nem recomenda skills: quem escolhe é o agente. Um servidor MCP local expõe ferramentas como compose_stack, que valida em memória os IDs e a estrutura escolhidos. O CLI aas pode gravar o manifesto aas-stack.json, validá-lo (aas stack validate) e gerar uma prévia imutável (aas stack plan).

É um projeto comunitário independente, sem afiliação ao Google. O catálogo hospedado e o Workbench (que revisa artefatos no navegador, sem acessar seu sistema de arquivos) são superfícies complementares.

Principais recursos

  • Catálogo com 2.712+ skills, todas pesquisáveis e legíveis individualmente.
  • MCP local para Codex e Claude, com seleção feita pelo agente e plano em modo prévia.
  • Instalador direto por npx agentic-awesome-skills para Cursor, Gemini CLI, Codex, Kiro, Antigravity, OpenCode e outros.
  • Plugins especializados para Claude Code e Codex (Web App Builder, Security Engineer, DevOps & Cloud, QA & Test Automation, entre outros).
  • Bundles por papel/objetivo e workflows com ordem sugerida de uso.
  • Filtros de instalação por --risk, --category e --tags.

Pré-requisitos

  • Node.js e npm (os comandos usam npm exec/npx).
  • Codex ou Claude Code para o fluxo AAS Core; ou outro agente suportado para a instalação direta.

Instalação

Configurar o MCP local do AAS Core

O primeiro comando mostra uma prévia da alteração e devolve um digest de aprovação. Para Claude, use --host claude com o caminho de configuração correspondente:

npm exec --yes --ignore-scripts --package=agentic-awesome-skills@19.9.0 -- aas mcp configure \
  --host codex \
  --scope user \
  --config /absolute/path/to/codex/config.toml \
  --cache-root /absolute/path/to/aas-cache

Guias completos: docs/users/codex-cli-skills.md e docs/users/claude-code-skills.md no repositório.

Instalar skills escolhidas diretamente

Primeiro como prévia (--dry-run), depois repita sem a flag:

npm exec --yes --ignore-scripts --package=agentic-awesome-skills@19.9.0 -- \
  agentic-awesome-skills --release 19.9.0 --path .agents/skills \
  --skills brainstorming,systematic-debugging --dry-run

Atalhos por ferramenta (do README)

npx agentic-awesome-skills --cursor
npx agentic-awesome-skills --gemini
npx agentic-awesome-skills --codex
npx agentic-awesome-skills --agy
npx agentic-awesome-skills --path ./my-skills

Comandos e uso

  • aas stack validate valida o manifesto de seleção.
  • aas stack plan grava uma prévia imutável para revisão.
  • aas stack install-preview prepara uma prévia --dry-run para o instalador direto.

Exemplos de uso nos agentes: @brainstorming help me plan a feature (Cursor), Use brainstorming to plan a feature (Gemini CLI, Codex), /brainstorming help me plan a feature (Antigravity CLI).

Quando usar

  • Você quer que o agente escolha skills certas para o seu projeto, com revisão humana antes de instalar.
  • Precisa de um catálogo grande e pesquisável de playbooks para vários agentes.
  • Quer plugins temáticos prontos (segurança, dados, DevOps, acessibilidade).

Observações

  • O modo "apply" e a recuperação do AAS Core ainda são experimentais (versão 19.9.0 no momento da leitura).
  • No Antigravity, instalar muitas skills pode sobrecarregar o contexto; o destino padrão exige um conjunto selecionado, um filtro ou --all explícito.
  • O instalador direto não aplica um plano do Core.
  • O README lista também skills de terceiros (algumas pagas e hospedadas); revise a fonte antes de instalar.
