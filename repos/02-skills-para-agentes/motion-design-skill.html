O que é

Uma skill de princípios de motion design, mantida pela LottieFiles. Não gera vídeo nem traz código pronto: ensina o agente a escolher a duração, a curva de aceleração (easing), a ordem dos elementos e a intenção emocional de cada movimento antes de escrever a animação.

Funciona com qualquer sistema de animação: CSS, Framer Motion, GSAP, Lottie, Spring etc. O SKILL.md traz um checklist de 8 passos, arquétipos de "personalidade" de movimento, tabelas de duração e easing e regras de qualidade. As pastas de apoio aprofundam a filosofia, trazem receitas e tabelas de consulta.

Para exportar arquivos renderizados (MP4, GIF, WebM, dotLottie, Lottie JSON), o README indica conectar o Creator MCP, serviço da LottieFiles.

Principais recursos

  • Checklist de 8 passos e tabelas de duração e easing.
  • 12 princípios da Disney adaptados para interface.
  • Quatro arquétipos de personalidade de movimento, para definir a identidade de movimento da marca.
  • Mapeamento de emoção para movimento e estrutura narrativa curta.
  • Receitas de entrada/saída, feedback de estado (sucesso, erro, carregando, hover), movimento ambiente e coreografia de vários elementos.
  • Checklist de qualidade e solução de problemas comuns de animação.
  • Adaptação a contexto: plataforma, acessibilidade e desempenho.

Pré-requisitos

  • Um agente compatível com Agent Skills (Claude Code, Cursor, Codex, GitHub Copilot etc.).
  • Node (npx) para a instalação via CLI.

Instalação

npx skills add LottieFiles/motion-design-skill

A CLI é a Vercel Skills CLI. No Claude Code, se as skills forem parar só em .agents/skills/, passe -a claude-code.

Opcional: Creator MCP (exportar arquivos)

claude mcp add --transport http --scope user creator-mcp https://creator.mcp.lottiefiles.com/mcp   # Claude Code
codex mcp add creator-mcp --url https://creator.mcp.lottiefiles.com/mcp                           # Codex

No Cursor, em ~/.cursor/mcp.json:

{"mcpServers":{"creator-mcp":{"url":"https://creator.mcp.lottiefiles.com/mcp"}}}

Comandos e uso

A skill (motion-design) ativa sozinha quando você trabalha com animações, transições, microinterações, estados de carregamento ou efeitos de rolagem. Exemplos de prompt:

Add a playful entrance animation to these card components
Create a loading → success → error state transition for this form submit button
Choreograph the entrance sequence for this dashboard — hero chart first, then stats cards, then sidebar
Review my animation code and suggest improvements based on motion design principles

Quando usar

  • Dar ritmo e intenção às animações de uma interface (botões, cards, modais, transições de página).
  • Definir a identidade de movimento de uma marca.
  • Revisar animações existentes que parecem "erradas" sem saber por quê.
  • Complementar skills que geram vídeo, como base de princípios.

Observações

  • É só conhecimento: não renderiza nada. Para gerar arquivos, use o Creator MCP (serviço externo da LottieFiles) ou outra skill de vídeo.
  • Há outras skills com nome parecido, como kylezantos/design-motion-principles e iart-ai/motion-design-skills.
  • Relacionados no catálogo: o Motionmaxxing gera vídeos de motion graphics completos; o Impeccable também cuida de animação de interface, dentro de um vocabulário de design mais amplo.
