O que é

O Prompt Master é uma skill que transforma uma ideia vaga em um prompt afiado para a ferramenta de destino. O problema que ele ataca é o ciclo clássico: prompt vago, resposta errada, novo prompt, resposta mais próxima, e assim por diante até acertar na quarta tentativa, gastando créditos e tempo.

Funciona com Claude, ChatGPT, Codex, Grok, Gemini, o1/o3, Cursor, Claude Code, GitHub Copilot, Windsurf, Bolt, v0, Lovable, Devin, Perplexity, Midjourney, DALL-E, Stable Diffusion, ComfyUI, Sora, Runway, ElevenLabs, Zapier, Make e qualquer outra ferramenta, para a qual usa um "Universal Fingerprint" de 4 perguntas. A filosofia declarada: o melhor prompt não é o mais longo, é aquele em que cada palavra tem função.

Principais recursos

  • Pipeline em 8 etapas: detecta a ferramenta de destino, extrai 9 dimensões da intenção (tarefa, entrada, saída, restrições, contexto, público, memória, critérios de sucesso, exemplos) e faz no máximo 3 perguntas de esclarecimento.
  • Roteia silenciosamente para o framework de prompt adequado e aplica só técnicas seguras (papel, few-shot, estrutura XML, âncoras de fundamentação).
  • Auditoria de eficiência de tokens: remove o que não muda o resultado.
  • Perfis para mais de 30 ferramentas, incluindo modelos de raciocínio (que não recebem cadeia de pensamento forçada), modelos locais e geradores de imagem.
  • Bloco de memória (Memory Block) que carrega decisões anteriores para o novo prompt não contradizer o que já foi decidido.
  • Catálogo de 37 padrões que desperdiçam créditos, com a correção para cada um.
  • Modo de reescrita: você cola um prompt ruim e ele corrige; também lida com edição de imagem de referência.

Pré-requisitos

  • Claude.ai (upload de skill) ou Claude Code.

Instalação

Recomendado: Claude.ai (navegador)

  1. Baixe o repositório como ZIP.
  2. Vá em claude.ai > Sidebar > Customize > Skills > Upload a Skill.

Alternativa: Claude Code (o README diz "não sugerido")

mkdir -p ~/.claude/skills
git clone https://github.com/nidhinjs/prompt-master.git ~/.claude/skills/prompt-master

Comandos e uso

Invocação natural ou explícita com /prompt-master:

Write me a prompt for Cursor to refactor my auth module

I need a prompt for Claude Code to build a REST API — ask me what you need to know

Here's a bad prompt I wrote for GPT-4o, fix it: [paste prompt]

Generate a Midjourney prompt for a cyberpunk city at night

/prompt-master

I want to ask Claude Code to build a todo app with React and Supabase

A saída é um bloco de prompt pronto para copiar, com uma linha de estratégia (ferramenta alvo, framework e justificativa).

Quando usar

  • Escrever prompts para agentes de código (Claude Code, Cursor, Codex) com escopo, restrições e critérios de aceite claros.
  • Gerar prompts para Midjourney, Stable Diffusion, ComfyUI, Sora etc.
  • Consertar prompts que dão respostas erradas e adaptar um prompt entre ferramentas.

Observações

  • A skill só deve ser acionada quando você pede explicitamente para escrever, melhorar ou adaptar um prompt.
  • Versão 1.8.0 no momento da leitura; o README registra atualizações frequentes de perfis de modelos.
