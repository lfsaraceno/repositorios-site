O que é

É a coleção oficial de skills da Vercel Labs, no formato Agent Skills: pacotes de instruções e scripts que ampliam o que um agente de código sabe fazer. Cada skill tem um SKILL.md com as instruções e, opcionalmente, pastas scripts/ e references/.

Depois de instaladas, as skills ficam disponíveis automaticamente e o agente as usa quando detecta uma tarefa relacionada. O repositório publica, a cada mudança em main, uma release imutável com um índice de descoberta de skills e um artefato por skill.

Skill em destaque: react-best-practices

É o guia de otimização de performance de React e Next.js da engenharia da Vercel. O README fala em 40+ regras em 8 categorias; o SKILL.md atual (nome vercel-react-best-practices, versão 1.0.0) declara 70 regras, priorizadas por impacto.

Quando é aplicada: ao escrever componentes React ou páginas Next.js, implementar busca de dados (cliente ou servidor), revisar código quanto a performance e otimizar tamanho de bundle ou tempo de carregamento.

Categorias, em ordem de prioridade (prefixo da regra entre parênteses):

  1. Eliminar waterfalls, crítico (async-), por exemplo async-parallel (usar Promise.all() para operações independentes) e async-suspense-boundaries.
  2. Tamanho do bundle, crítico (bundle-), por exemplo bundle-barrel-imports (evitar barrel files) e bundle-dynamic-imports (next/dynamic).
  3. Performance no servidor, alto (server-), por exemplo server-cache-react e server-after-nonblocking.
  4. Busca de dados no cliente, médio-alto (client-).
  5. Otimização de re-renders, médio (rerender-).
  6. Performance de renderização, médio (rendering-).
  7. Performance de JavaScript, baixo-médio (js-).
  8. Padrões avançados, baixo (advanced-).

Principais recursos

  • react-best-practices: regras de performance para React e Next.js.
  • web-design-guidelines: revisão de UI com mais de 100 regras (acessibilidade, foco, formulários, animação, tipografia, i18n).
  • vercel-optimize: auditoria de custo, performance e cache de um projeto Vercel a partir de métricas reais.
  • react-native-guidelines: 16 regras para apps React Native e Expo.
  • react-view-transitions: View Transition API do React, incluindo integração com Next.js.
  • composition-patterns: padrões de composição para evitar excesso de props booleanas.
  • writing-guidelines: revisão de documentação conforme o handbook de escrita da Vercel.
  • vercel-deploy-claimable: deploy instantâneo na Vercel com URL de preview e URL de "claim".

Pré-requisitos

  • Node.js e npm/npx para o instalador skills.
  • Um agente compatível com o formato Agent Skills.

Instalação

npx skills add vercel-labs/agent-skills

As skills ficam disponíveis automaticamente; o agente as usa quando a tarefa combina.

Comandos e uso

Não há comandos de barra obrigatórios: basta descrever a tarefa. Exemplos do README:

Deploy my app

Review this React component for performance issues

Help me optimize this Next.js page

Para revisão de interface, frases como "Review my UI", "Check accessibility" ou "Audit design" ativam web-design-guidelines.

Quando usar

  • Escrever ou revisar componentes React e páginas Next.js com foco em performance.
  • Auditar acessibilidade e UX de uma interface.
  • Reduzir custo e tempo de resposta de um projeto implantado na Vercel.
  • Criar transições de página e animações com a View Transition API.

Observações

  • vercel-deploy-claimable foi pensada para uso com claude.ai e Claude Desktop; a implantação pode ser "reivindicada" (transferida) para a sua conta Vercel.
  • O número de regras de react-best-practices diverge entre o README (40+) e o SKILL.md (70); considere o SKILL.md como mais atual.
