O que é

Um pacote de Agent Skills com fluxos de trabalho profissionais do Blender, para agentes de código. Sem as skills, o agente até consegue escrever scripts bpy, mas tende a errar a API do Blender 5.x e a pular etapas que um artista 3D faria (normais ponderadas, densidade de texel, LODs, checagem de z-fighting). As skills trazem essas regras e scripts prontos.

São 28 skills que cobrem o pipeline 3D completo, feitas para o Blender 5.2 LTS ou mais novo e verificadas no 5.3. Segundo o autor, todo script é testado num Blender real (67 testes headless).

O agente roda o Blender em segundo plano (headless). Se você tiver um servidor MCP do Blender, ele também pode trabalhar direto na cena aberta.

Principais recursos

  • Ponto de entrada: blender-core executa código, direciona a tarefa para a skill certa e traz as regras da API 5.x.
  • Modelagem: hard surface (bevels, booleanas, normais ponderadas), escultura orgânica, retopologia e UVs, geometry nodes a partir de JSON simples.
  • Materiais e texturas: PBR correto, desgaste, sujeira, decalques, trim sheets, baking de normal/AO/curvatura e mapas ORM.
  • Personagens: rigging com Rigify, skinning, esqueletos para jogos, 52 blendshapes ARKit e visemas, roupas sem clipping, cabelo e hair cards, animação com retarget de mocap e root motion.
  • Cenários e visual: kits de ambiente (terreno, florestas, módulos de level), iluminação de estúdio e HDRI, horário do dia, clima (chuva, neve, poças, raios), toon/anime e simulações (corpos rígidos, tecido, fluidos).
  • Saída: exportação para Roblox, Unity, Unreal, Godot, web e USD; otimização para jogos (orçamento de polígonos, LODs, draw calls); render em Cycles e EEVEE em lote; edição de vídeo.
  • QA de asset: detecta z-fighting, peças soltas, normais invertidas e problemas de pesos e texturas.
  • Automação: desenvolvimento de extensões do Blender, jobs em lote, conversão de arquivos e playbooks completos de assets.

Pré-requisitos

  • Blender 5.2 LTS ou mais novo. O autor recomenda o 5.3.0, que é onde todas as skills foram verificadas e que traz exportação KTX2 para web, efeitos de compositor e Gaussian splats.
  • Um agente compatível com skills: Claude Code, Codex, OpenCode, Gemini CLI, GitHub Copilot ou Cursor.
  • Opcional: um servidor MCP do Blender, para o agente operar a cena aberta.

Instalação

Claude Code (plugin)

/plugin marketplace add EL4CTEO/blender-skills
/plugin install blender-agent-skills@blender-agent-skills

Qualquer agente (instalador)

git clone https://github.com/EL4CTEO/blender-skills
./blender-skills/install/install.sh          # macOS / Linux

No Windows (PowerShell):

git clone https://github.com/EL4CTEO/blender-skills
.\blender-skills\install\install.ps1

Por padrão instala em ~/.claude/skills e ~/.agents/skills (esta última é lida por Codex, OpenCode, Gemini CLI, Copilot e Cursor). Opções do instalador:

--agent claude|codex|opencode|gemini|copilot|cursor|all   # escolhe o agente
--project DIR                                             # instala só num projeto
--uninstall                                               # remove

Comandos e uso

As skills são acionadas pelo próprio agente conforme o pedido; comece pela blender-core. Exemplos de prompt do README:

Make a game-ready crate for Unreal with baked normals and LODs.
Rig this character with Rigify and export it to Unity with a walk cycle.
Check this model for z-fighting and floating parts, then export it for Roblox.
Make this street a rainy night with puddles and lightning.
Give my character a shirt and hair cards, then retarget this Mixamo run onto it.

Para quem desenvolve o pacote:

python tools/validate_skills.py   # valida a especificação e o orçamento de tokens das skills
python tools/run_tests.py         # roda os 67 testes headless no Blender (BLENDER_EXE muda o executável)

Quando usar

  • Gerar assets prontos para jogos (Unreal, Unity, Godot, Roblox) pedindo em linguagem natural.
  • Automatizar tarefas repetitivas do Blender: baking, LODs, exportação em lote, conversão de formatos.
  • Revisar modelos antes de entregar (QA de z-fighting, normais, pesos).
  • Montar cenas e iluminação (clima, horário do dia, turntables) sem dominar todos os menus do Blender.

Observações

  • Exige Blender 5.2+; versões 4.x não são o alvo das skills.
  • Projeto pequeno (~2k estrelas) e mantido por um autor só.
  • Para modelos mecânicos com medidas exatas (peças para impressão 3D, CNC), o Text-to-CAD é mais adequado: ele trabalha com CAD paramétrico (STEP), enquanto estas skills trabalham com malhas para arte e jogos. O Text-to-CAD usa o Blender só para renders.
