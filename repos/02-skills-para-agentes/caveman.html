Caveman

Skill e proxy que fazem o agente de IA responder curto ("why many token when few do trick") e ler menos, mantendo código, comandos e erros exatos; inclui compressão de logs e JSON, roteamento automático de modelo e scripts reutilizáveis.

O que é

Começou como piada em abril de 2026: uma skill que faz o agente falar como homem das cavernas, sem cerimônia, mantendo toda a substância técnica. A mesma correção que levaria 63 tokens sai em 20. A voz segue regras do inglês controlado de manuais de aviação (ASD-STE100): resposta primeiro, uma ideia por frase, negações e números nunca omitidos, código e erros copiados exatamente, e frases completas para alertas de segurança e ações irreversíveis. Seus prompts nunca são reescritos.

Na versão 4.0 virou seis partes ("rocks"), instaladas por um único comando:

  1. Say less: a voz curta.
  2. Read less: comprime logs, JSON, CSV, YAML e saída de testes antes de o modelo ler (33,2% menos tokens de entrada por sessão no benchmark do autor).
  3. Auto: escolhe modelo e esforço para cada pedido (54% mais barato que Opus 5.5 em xhigh, mesma nota, em teste parcial).
  4. Blocks: guarda os scripts que o agente escreve e os reaproveita.
  5. Waste fixes: mostra onde os tokens vão e mantém o cache de prompt aquecido.
  6. Browse: páginas web comprimidas.

Citado por pesquisa da Adobe e testado pela JetBrains (sem perda de qualidade mensurável).

Principais recursos

  • Níveis /caveman, /ultracave e /megacave (chinês clássico, o mais curto).
  • /caveman-commit (commit em uma linha), /caveman-review (uma linha por achado), /caveman-compress (encolhe CLAUDE.md com backup), /caveman-stats.
  • Subagentes cavecrew (investigar, editar, revisar) e padrões de trabalho (investigate-first, surgical-patch, safe-refactor, verify-and-stop e outros).
  • Funciona em Claude Code, Codex, Gemini CLI, OpenCode e mais de 30 agentes.
  • Middleware para Vercel AI SDK, LangChain, OpenAI e Anthropic.
  • Caveman Cloud (pago) para observabilidade e evals de agentes que você constrói.

Pré-requisitos

  • Node.js 22.13+ para o instalador completo.

Instalação

Tudo (CLI + proxy + skill)

npx @caveman-ai/cli@latest

Detecta seus agentes e logins, mostra o que vai mudar e pede Enter.

Só a skill (voz curta)

npx skills add JuliusBrussee/caveman -g

Plugin do Claude Code

claude plugin marketplace add JuliusBrussee/caveman && claude plugin install caveman@caveman

Windows (PowerShell 5.1+)

irm https://raw.githubusercontent.com/JuliusBrussee/caveman/v4.1.0/install.ps1 | iex

Desinstalar: npx -y github:JuliusBrussee/caveman -- --uninstall; só a skill: npx skills remove JuliusBrussee/caveman -g.

Comandos e uso

No agente:

/caveman            # liga a voz curta (stop caveman para voltar)
/ultracave          # mais curto ainda
/caveman-review     # revisão compacta
/caveman-compress CLAUDE.md

No terminal:

caveman status               # o que está ligado
caveman off browse           # desliga uma parte (output, input, waste-fixes, routing, scripts, browse)
caveman claude               # abre o Claude Code com caveman
caveman learn                # onde os tokens estão indo
caveman stats                # histórico de tokens
caveman telemetry off        # desliga a telemetria
caveman doctor               # diagnóstico

Quando usar

  • Respostas mais diretas e baratas no terminal, sem perder detalhe técnico.
  • Sessões que leem muitos logs, JSON ou saída de testes.
  • Reduzir custo escolhendo modelo por pedido (Auto).

Observações

  • Telemetria da CLI ligada por padrão (comandos, contagem de tokens, ID de instalação, SO e IP; nunca prompts ou código). Desligue com caveman telemetry off ou DO_NOT_TRACK=1.
  • Auto envia à Caveman Cloud o último pedido (com o que o agente anexa, como CLAUDE.md e arquivos mencionados); no plano gratuito pode ser guardado para melhorar o roteamento. Atenção a dados sensíveis.
  • /caveman-compress envia o arquivo ao seu provedor de modelo.
  • Em planos cobrados por requisição (GitHub Copilot), respostas curtas não economizam.
  • Os números de economia são em grande parte do próprio autor; veja HONEST-NUMBERS, onde ele lista os casos em que perde.
  • Complementares no catálogo: RTK (saída de comandos) e Ponytail (menos código).
