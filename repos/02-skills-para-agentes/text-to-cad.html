O que é

O Text-to-CAD transforma o seu agente de código num assistente de engenharia mecânica. Você pede uma peça ou uma montagem, e o agente escreve o modelo como um script Python com build123d e o kernel OpenCASCADE, executa o script para gerar o sólido e mostra o resultado num visualizador de CAD.

O instalador configura o plugin em todos os apps de agente que encontrar no computador: Claude Code, Claude Desktop, Codex, Cursor, Grok Build e Gemini CLI. Ele também registra o comando cad. Para os agentes sem suporte a plugin (Copilot, Windsurf, Cline, Hermes Agent, OpenCode e outros), ele copia só as skills.

Além da modelagem, o plugin cobre o caminho até a fabricação: verifica se a peça pode ser usinada, cortada, dobrada, moldada ou impressa; calcula tensões; gera desenho técnico em PDF; e prepara arquivos para serviços como SendCutSend e impressoras Bambu.

Principais recursos

  • Peças e montagens: modelos em Python (build123d + OpenCASCADE), exportados como STEP, STL, 3MF ou GLB, e perfis/planificações DXF para corte a laser e jato d'água, com juntas e animações para mecanismos.
  • Placas de circuito: esquemáticos e placas no KiCad, com posicionamento, roteamento, checagens ERC e DRC e exportação dos arquivos de fabricação.
  • Checagem de fabricação: avalia usinagem, corte e dobra, moldagem e impressão 3D conforme as regras de cada processo e diz o que mudar.
  • Análise de tensão: resolve com CalculiX a tensão máxima, o fator de segurança e o deslocamento de cada peça, desenhados sobre o modelo.
  • Desenhos técnicos: folhas em PDF cotadas, com vistas, linhas ocultas, marcas de centro, chamadas de furo e carimbo.
  • Renders: imagens fotorrealistas, turntables e vídeos no Blender, com rascunho rápido antes do final.
  • Serviços de fabricação: confere DXF e STEP contra o guia da SendCutSend e fatia impressões no OrcaSlicer, enviando para o Bambu Connect ou Bambu Studio.
  • Robótica: descrições para simulação e planejamento de movimento (URDF para ROS, SRDF para MoveIt, MJCF para MuJoCo).

Pré-requisitos

  • O instalador busca ou instala o uv, que baixa o Python 3.14 para o text-to-cad.
  • Pelo menos um agente: Claude Code, Claude Desktop, Codex, Cursor, Grok Build, Gemini CLI ou outro que aceite skills.
  • Node (npx) para instalar as skills em agentes sem plugin.
  • KiCad, Blender e OrcaSlicer só para as skills que os usam (PCB, render, impressão 3D).

Instalação

Instalador (todos os apps de uma vez)

macOS e Linux:

curl -fsSL https://texttocad.dev/install.sh | sh

Windows (PowerShell):

irm https://www.texttocad.dev/install.ps1 | iex

No Windows, use o endereço com www (o PowerShell 5.1 não segue o redirecionamento do domínio sem www). Rode a primeira instalação num terminal próprio (Windows Terminal ou PowerShell), não no shell de um app da Microsoft Store como o Claude Desktop. Rodar o mesmo comando de novo atualiza tudo.

Só no Claude Code

claude plugin marketplace add earthtojake/text-to-cad#latest
claude plugin install text-to-cad@earthtojake

Para atualizar (e depois reiniciar o Claude Code):

claude plugin marketplace update earthtojake
claude plugin update text-to-cad@earthtojake

Outros agentes (só as skills)

npx skills add earthtojake/text-to-cad#latest

Comandos e uso

Peça a peça ou a montagem ao agente; ele escreve o script, gera o modelo e mostra no visualizador. No Claude Code no terminal, o agente devolve um link que abre o modelo no navegador.

cad doctor            # diagnostica a instalação e diz de onde cada app tira o plugin
cad doctor --check    # saída para anexar em relatos de bug
cad plugin            # mostra a pasta do plugin
cad uninstall         # remove o text-to-cad (pede confirmação)

Skills incluídas: cad, pcb, fea, engineering-drawing, render, print3d, sendcutsend e robot-simulation.

Exemplos de prompt:

Design a wall bracket for a 30 mm pipe with two M5 mounting holes, export STEP and STL.
Check if this part can be 3D printed and slice it for my Bambu printer.
Make a dimensioned drawing of this part as a PDF.

Quando usar

  • Projetar peças para impressão 3D, corte a laser, dobra de chapa ou CNC descrevendo em texto.
  • Gerar placas de circuito simples no KiCad com checagens antes de encomendar.
  • Validar se uma peça aguenta a carga antes de fabricar.
  • Produzir desenhos técnicos e renders de apresentação a partir do mesmo modelo.

Observações

  • Windows 11 com Smart App Control: o kernel CAD (OCP) usa um módulo nativo sem assinatura, então todo comando cad falha com ImportError: DLL load failed while importing OCP. Não há exceção por app: desligue o Smart App Control (só volta reinstalando o Windows) ou rode as skills CAD no WSL. O cad doctor detecta esse caso.
  • Telemetria ligada por padrão: envia estatísticas de uso e relatórios de falha com um ID aleatório, sem arquivos, caminhos ou prompts. A política de privacidade explica como desligar.
  • Instalação por curl | sh / irm | iex: o script mexe na configuração de vários apps de agente de uma vez (instala plugin, remove cópias antigas, troca o servidor MCP do Claude Desktop). Leia a documentação de instalação se quiser instalar app por app.
  • Para arte 3D, personagens e assets de jogo, as Blender Skills são mais adequadas; o Text-to-CAD é CAD paramétrico para engenharia.
  • Comunidade: o Studio é um app desktop de CAD open source feito sobre o text-to-cad.
