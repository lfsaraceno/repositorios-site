O que é

O Anidoodle é uma skill/plugin que faz o agente criar arte desenhada à mão escrevendo código. Cada traço é uma função e cada trilha sonora é escrita como dados, então o mesmo código redesenha a mesma imagem em qualquer máquina e tamanho.

São 32 estilos (lápis e aquarela, nanquim, giz, colagem de papel, risografia, pixel art, xilogravura/ukiyo-e, rubber-hose dos anos 1930, bordado, tijolinhos de brinquedo etc.). Cada estilo vem com um filme do próprio desenho sendo feito, na ordem em que um artista daquele meio trabalharia.

Vai além da ilustração: gera curtas e explicativos com trilha composta em código (21 estilos musicais), filmes de lançamento de produto a partir de um template, arte interativa para sites (um mascote que segue o cursor, por exemplo) e aulas de desenho com timelapse legendado.

Principais recursos

  • 32 estilos de traço, cada um com o filme do desenho sendo feito.
  • Música composta em código: 21 vocabulários (lo-fi, house, synthwave, orquestral, jazz, folk, piano solo), com pacote opcional de instrumentos gravados.
  • Kit de efeitos sonoros sincronizados ao quadro exato.
  • Kit de vídeo de lançamento: 16:9, 1:1, 4:5 e 9:16, legendas .srt/.vtt e checagem de áudio e de texto cortado.
  • Ilustrações interativas para sites (<ani-doodle>, sem framework, com suporte a movimento reduzido e teclado).
  • Copia o estilo de uma imagem sua, recria fotos em qualquer estilo e mantém um personagem igual entre cenas.
  • Exporta PNG, MP4 com trilha, GIF, WebM e PNG animado com transparência, e um HTML único que toca offline.
  • Quatro backends de render: playwright, html-player, remotion e hyperframes.

Pré-requisitos

  • Claude Code, Codex, Grok Build ou outro agente que leia skills.
  • Node 20+.
  • Chromium do Playwright (npx playwright-core install chromium).
  • ffmpeg para tudo que se move.

Instalação

Claude Code

/plugin marketplace add alexgreensh/anidoodle
/plugin install anidoodle@alexgreensh-anidoodle

Codex

codex plugin marketplace add alexgreensh/anidoodle

Depois, no Codex: /plugins e instale o anidoodle.

Grok Build

grok plugin marketplace add alexgreensh/anidoodle
grok plugin install anidoodle --trust

Outros agentes

Copie a pasta skills/anidoodle/ (tem o SKILL.md) para a pasta de skills do agente.

Comandos e uso

Peça em linguagem natural:

draw a pencil & watercolour pear for our recipes page
a risograph lighthouse for our careers page, 1600×900
a chalkboard explainer of how our pricing tiers stack up

Para usar o motor direto:

node <anidoodle>/engine/tools/scaffold.mjs ~/art --still hero --film intro --format 9x16 --duration 60   # cria o projeto
cd ~/art && npm install && npx playwright-core install chromium
node tools/still.mjs  hero  --out out/hero.png --scale 2   # ilustração pronta, em tamanho de impressão
node tools/render.mjs intro --out out/intro.gif            # loop; também .mp4 com trilha ou .webm com alfa
node tools/emit.mjs   intro --out out/intro.html           # a peça inteira num HTML offline
node tools/gate.mjs   hero                                 # checa determinismo, contrato e trechos parados
node tools/verify-export.mjs intro --file out/intro.mp4   # decodifica e confere o arquivo final
node tools/music.mjs check score.ts#myScore                # confere tom, volume, equilíbrio e originalidade da trilha
node tools/launch.mjs new myLaunch                         # cria o roteiro de um filme de lançamento

Pacote opcional de instrumentos gravados (373 MB):

node <skill>/engine/tools/soundfetch.mjs list      # o que está instalado
node <skill>/engine/tools/soundfetch.mjs get all   # baixa, confere o hash e descompacta

Quando usar

  • Ilustrações de site (hero, ícones, estados vazios, 404) num estilo só, com cara de feitas à mão.
  • Vídeo de lançamento de produto com trilha original.
  • Explicativos e infográficos animados.
  • Mascote interativo ou ilustração que se desenha ao rolar a página.

Observações

  • grok plugin install --trust libera o plugin a rodar comandos; sem a flag, o Grok mostra o que ele pode executar e para.
  • Arquivos de vídeo grandes e o pacote de sons (373 MB) são opcionais; sem ele, a trilha toca com instrumentos sintetizados.
  • Relacionados no catálogo: o HyperFrames é um dos backends de render; a Claude Drawing Skill faz ilustração em código em Python (83 estilos) sem música nem vídeo completo; o Motionmaxxing é focado em motion graphics de marca, não em desenho à mão.
