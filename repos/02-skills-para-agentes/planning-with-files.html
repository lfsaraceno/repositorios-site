Planning with Files

Skill de planejamento persistente em arquivos Markdown (padrão do Manus) para agentes de IA: plano, descobertas e progresso ficam em disco e são reinjetados a cada turno, para o agente retomar a tarefa depois de /clear, compactação ou falha.

O que é

A janela de contexto do agente funciona como memória RAM: volátil e limitada. O sistema de arquivos é o disco: persistente. O Planning with Files aplica a regra "tudo que importa vai para o disco", o padrão de engenharia de contexto descrito pelo Manus.

A skill mantém três arquivos no seu projeto:

your-project/
├── task_plan.md   ← fases e checkboxes; o ponto de retomada depois de /clear
├── findings.md    ← notas de pesquisa e decisões, acrescentadas ao longo do trabalho
└── progress.md    ← log da sessão e resultados de testes

No Claude Code, hooks reinjetam o contexto do plano ativo a cada mensagem e podem segurar o fim da tarefa até o plano estar marcado como completo. No benchmark interno do autor, retomar uma tarefa interrompida levou 5,0 turnos em média com os arquivos, contra 13,3 sem.

Principais recursos

  • Padrão de 3 arquivos em Markdown, ignorados pelo git por padrão.
  • Tarefas paralelas em pastas isoladas (.planning/YYYY-MM-DD-slug/).
  • Reinjeção do plano a cada turno e recuperação após /clear.
  • Portão de conclusão: o agente só para quando o plano diz "complete".
  • Atestação do plano por SHA-256 (hooks recusam plano adulterado).
  • Comandos de status, autodiagnóstico, modo meta (/plan-goal) e ciclo (/plan-loop).
  • Versões traduzidas (árabe, alemão, espanhol, chinês simplificado e tradicional).
  • Plugins nativos para Claude Code, OpenCode, Hermes, Pi e DeepSeek Harness; skill padrão para mais de 60 agentes.

Pré-requisitos

  • Um agente de programação (Claude Code recomendado para o conjunto completo com hooks).
  • Bash; alguns hosts exigem Python 3.10+.

Instalação

Claude Code (plugin: skill, hooks e comandos)

/plugin marketplace add OthmanAdi/planning-with-files
/plugin install planning-with-files@planning-with-files

Qualquer agente (Agent Skills, só a skill)

npx skills add OthmanAdi/planning-with-files --skill planning-with-files -g

Outras rotas

npm install planning-with-files          # fixa versão no projeto (sem hooks)
pi install npm:planning-with-files       # Pi Coding Agent

Guias por ferramenta (Cursor, Copilot, Gemini CLI, Codex, Kiro, OpenCode, Hermes e outros) em docs/.

Comandos e uso

Digite /plan ou peça "plan this task"; a skill também dispara sozinha em tarefas de vários passos.

/planning-with-files:plan          # cria os três arquivos e inicia a sessão (atalho /plan)
/planning-with-files:pwf           # alias; --autonomous ou --gated
/planning-with-files:status        # fase atual e totais
/planning-with-files:plan-doctor   # autodiagnóstico (PASS/WARN/FAIL)
/planning-with-files:plan-attest   # trava task_plan.md com SHA-256
/planning-with-files:plan-goal     # roda até o plano ficar completo
/planning-with-files:plan-loop     # ciclo com /loop, a cada 10 minutos por padrão

Regras principais da skill: criar o plano antes de começar; salvar descobertas a cada 2 operações de leitura ou navegação; registrar todos os erros; nunca repetir uma tentativa que falhou.

Quando usar

  • Tarefas longas que atravessam várias sessões e compactações de contexto.
  • Pesquisas e refatorações grandes em que o agente costuma se perder.
  • Retomar trabalho depois de uma queda ou de /clear.

Observações

  • Os números de benchmark são do próprio autor (avaliação de fidelidade ao padrão e retomada após limpeza de contexto), com limites declarados.
  • A rota npm não registra hooks; para o comportamento completo no Claude Code, use o plugin.
  • A ficha cobre instalação, comandos, regras e benchmarks; as seções de recursos para execuções longas e variáveis de ambiente não foram detalhadas.
  • Alternativa com banco de dados e dependências entre tarefas: Beads.
